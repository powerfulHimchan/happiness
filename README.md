# Happiness Tale: Rewind to Dawn

밝은 캐주얼 판타지 분위기의 안드로이드용 2D 횡스크롤 로그라이트 액션 게임 프로젝트입니다.

## 현재 상태

- 게임 기획서 버전: `0.1`
- 전투 프로토타입 명세 버전: `0.1`
- 단계: `GP-133` 민첩한 회피·대장간 스킬 도감·회복약 주머니·마을 유물 도감·시계추 조각·두 유물 선택·마력 방벽·삼연 베기·집중 사격·스킬 후보 전환·능력 도감·흡수 강화·공중 도약·약방·경로 도감· 전투 회복약·직업 도감·스킬 교체·시간의 닻 마을·무기 설계도·위험 경로·영구 기억 해금·선택·다음 도전 보상·이어하기 개발용 시제품
- 주인공: 로안 / 루미
- 미소의 여왕: 세라
- 구현 소스: 3스테이지 연속 진행·두 경로 선택·중간 회복, 성장·직업·필살기를 중간 저장하고 재실행 후 이어하기
- 검증 상태: 2026-09-30 사용자 보고로 실기기 20분 안정성 통과 확인, CP-406 나머지 개별 항목은 확인 대기

정예 휴식의 **스킬 교체 살펴보기 → 다른 후보**에서 검·활 각 다섯 스킬 중 보유하지 않은 기술을 모두 비교할 수 있습니다. 삼연 베기는 정면 2.4m의 3타, 집중 사격은 0.7초 준비 후 정면으로 80 피해 화살 한 발을 발사합니다. 준비 중 이동할 수 없으며 회피로 취소할 수 있습니다. 교체한 슬롯과 대기시간은 중간 저장에 유지됩니다.

레벨업에서 **마력 방벽**을 선택하면 피해 20을 먼저 흡수합니다. 남은 방벽은 중간 저장에 유지되고, 실제 다음 스테이지 진입 시 20으로 충전됩니다. 회복약과 휴식은 방벽을 충전하지 않습니다.

마을의 **대장간 → 스킬 도감**에서 검·활 10개 스킬의 재사용 시간, 동작 시간, 기본 피해, 범위와 교체 조건을 확인할 수 있습니다. 이번 도전의 두 무기 장착 슬롯을 함께 표시하며, 시계추 조각을 획득하면 보조 무기까지 감소한 재사용 시간을 표시합니다. 도감은 조회 전용이고 실제 교체는 정예 보상에서 진행합니다.

레벨업에서 **민첩한 회피**를 선택하면 이후 지상 회피의 재사용 시간이 0.45초에서 0.36초로 감소합니다. 이미 진행 중인 대기시간과 무적 0.18초·회피 동작 0.24초·공중 대시 1회는 유지합니다. 지상 회피 버튼에 남은 대기시간과 준비 상태를 표시하고, 이어하기에 보존하며 새 도전에서 초기화합니다.

## 프로토타입 실행

Godot 4.7.2 stable에서 [`game/project.godot`](game/project.godot)를 엽니다. 현재 `GP-133` 빌드는 기존 전투 구역을 재사용한 3개 스테이지를 이어서 진행합니다. 새 도전과 결과 화면의 재도전에서 검·활 시작 무기를 선택하고, 중간 완료 시 체력을 일부 회복하고 희귀·영웅 검·활 중 하나를 교체한 뒤 풀숲 길·바람 길 중 하나를 선택합니다. 현재 무기를 유지할 수도 있습니다. 등급은 무기 피해를, 검의 고유 효과는 스킬을, 활의 고유 효과는 기본 공격을 강화합니다. 보조 무기 고유 효과는 절반 적용합니다. 보상 선택 전후 상태를 저장하여 앱 재시작 후 같은 화면으로 복귀합니다. 다음 스테이지에서 풀숲 길은 평지 다리와 가까운 적 배치, 바람 길은 징검 발판과 흩어진 적 배치를 제공합니다. 현재 경로·지형은 HUD에 표시합니다. 레벨·카드 강화·직업·필살기를 유지해 다음 전투에서 활용하고, 마지막 관문에서 웃는 태엽 기사의 돌진·충격파·탄막을 상대합니다. 보스 승리 후 구출·파괴를 선택·확정해야 전체 결과를 표시하며, 선택 대기 상태도 저장합니다. 선택은 결과와 로컬 이력에 남습니다. 재도전은 새 도전으로 초기화합니다. 기존 빌드의 20분 안정성 통과 기록과 CP-406 진단·로컬 기록·조작 설정 기능을 유지합니다.

스테이지 1·2 완료 후 회복된 상태를 자동 저장합니다. 앱 재실행 후 메인의 **이어하기**를 누르면 완료한 스테이지의 경로 선택 화면으로 복귀합니다. 전투 중 종료한 경우 마지막 완료 지점부터 다시 시작합니다. 사망·3스테이지 완주·새 도전은 중간 저장을 삭제합니다. 손상된 최신 저장은 이전 정상 저장으로 복구하고, 복구할 수 없으면 새 도전을 안내합니다. 10개 스테이지와 새 지역은 후속 범위입니다.

```bash
./scripts/check_godot_project.sh
godot --path game --editor
```

자세한 실행과 Android 연결 방법은 [Godot 프로토타입 안내](game/README.md)를 참고하세요.

`main` 반영 전 PR에서 전체 자동 검증과 APK 빌드를 수행하고, 병합 후에도 GitHub Actions가 ARM64 테스트 APK를 자동으로 생성합니다. 이 APK는 개인 기기 설치용 디버그 빌드이며 Google Play 제출용이 아닙니다.

PDF에는 Noto Sans KR 글꼴이 포함되어 있어 한글이 깨지지 않습니다. GitHub에서 내용을 빠르게 확인할 때는 Markdown 문서를 사용할 수 있습니다.

## 기획서 생성

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r planning/requirements.txt
python planning/build_gdd.py
```

`planning/build_gdd.py`는 편집 가능한 DOCX 원본을 생성합니다. 배포·열람용 문서는 글꼴이 포함된 PDF를 기준으로 관리합니다.

GP-110에서는 구출·파괴 완료 후 다음 새 도전 1회에 보상을 적용할 수 있다. 시작 무기 화면에서 켜거나 건너뛴다. 구출은 체력 +10, 정예마다 지원 피해 20, 비치명타 뒤 체력 25% 이하에서 최대 체력 30% 회복 1회다. 파괴는 주는 피해와 받는 전투 피해 각각 +10%다. 보상 소비와 지원·회복 사용 기록은 중간 저장과 테스트 기록 초기화에서 독립적으로 보존한다. 자세한 범위는 [GP-110 구현 상태](docs/prototype/GP110_NEXT_RUN_LEGACY_STATUS.md)를 참고한다.

GP-111에서는 보스 구출로 태엽 수호(최대 체력 +5), 파괴로 핵의 잔향(스킬 피해 +10%)을 영구 해금한다. 새 도전 준비 화면에서 하나만 장착하거나 기억 없이 시작한다. 같은 선택을 반복해도 수치가 누적되지 않으며 기존 일회 보상과 독립적이다. 이전 GP-110 저널의 소비된 선택도 해금으로 복원한다. 상세 범위는 [GP-111 구현 상태](docs/prototype/GP111_PERMANENT_MEMORIES_STATUS.md)를 참고한다.

GP-112에서는 파괴 일회 보상을 적용한 다음 도전의 2스테이지에 **태엽 폐허 · 위험**을 추가한다. 기존 두 경로도 선택할 수 있다. 좁은 발판, 첫 웨이브 세 종류, 적 체력 ×1.20을 적용하며 통과 시 기본 회복 외 체력 +20과 필살기 게이지 +50(상한 100)을 지급한다. 영구 공격 기억만 장착하면 경로는 열리지 않는다. 이어하기는 해당 도전의 권한·경로·지급 상태를 복원한다. 상세 범위는 [GP-112 구현 상태](docs/prototype/GP112_RISK_ROUTE_STATUS.md)를 참고한다.

GP-113에서는 보스 파괴로 태엽 검·활 설계도를 영구 해금한다. 이후 정예 무기 보상에 기본 검·활과 함께 제공한다. 태엽 무기는 무기 피해 보너스를 줄이고 고유 효과를 강화하며 보조 효과는 50% 적용한다. 선택한 설계·등급은 이어하기에 복원하고 새 도전은 초기화하며 해금만 유지한다. 상세 범위는 [GP-113 구현 상태](docs/prototype/GP113_WEAPON_BLUEPRINTS_STATUS.md)를 참고한다.

GP-114에서는 메인 화면의 **시간의 닻 마을**에서 대장간 설계도, 기억의 쉼터 해금 조건, 광장 도전 기록을 확인한다. 구출한 태엽 기사는 일회 보상 소비 뒤에도 정착하며, 새 도전 준비·이어하기로 연결한다. 마을 방문은 전투를 멈추고 저장이나 보상을 변경하지 않는다. [GP-114 구현 상태](docs/prototype/GP114_TIME_ANCHOR_VILLAGE_STATUS.md)를 참고한다.

GP-115에서는 정예 무기 보상을 확정한 경로 화면의 **스킬 교체 살펴보기**에서 새 스킬과 기존 두 슬롯을 비교한다. 반달 베기·연속 사격 또는 이전에 버린 기술로 정예마다 한 번 교체할 수 있으며, 현재 구성을 유지하고 경로를 바로 선택해도 된다. 선택한 구성과 대기시간을 이어하기에 복원한다. [GP-115 구현 상태](docs/prototype/GP115_SKILL_REPLACEMENT_STATUS.md)를 참고한다.

GP-116에서는 마을의 **직업 도감**에서 선봉대·추적자의 발현 조건, 전용 능력과 필살기를 확인한다. 실제 발현한 직업은 별도 영구 기록으로 남고, 새 도전·사망·도전 기록 초기화 뒤에도 유지한다. 발견이 시작 직업이나 추가 패시브를 지급하지는 않는다. 이전 이어하기 저장의 발현 직업도 복구한다. [GP-116 구현 상태](docs/prototype/GP116_JOB_CODEX_STATUS.md)를 참고한다.

GP-117에서는 전투 화면의 **회복약**을 눌러 최대 체력의 25%를 회복한다. 도전당 2회이며 스테이지 전환과 이어하기에 남은 횟수를 유지한다. 체력이 가득 찼거나 사망·복귀·선택 화면에서는 소비하지 않는다. 조작 배치 편집과 양손 프리셋에서 위치·크기를 조절할 수 있다. [GP-117 구현 상태](docs/prototype/GP117_RECOVERY_POTIONS_STATUS.md)를 참고한다.

GP-129에서는 두 번째 정예 뒤 불사조 깃털과 시계추 조각 중 하나를 선택한다. 깃털은 기존 50% 부활 1회를 유지하고, 시계추는 검·활의 두 액티브 스킬 재사용 대기를 20% 줄인다(10초 → 8초). 보조 무기도 적용되며 스킬 비교·HUD에는 실제 남은 시간을 표시한다. 저장된 원본 대기시간은 보존하고 이어하기에서 유물 효과를 복원한다. 새 도전은 유물 없이 시작한다. 상세 범위는 [GP-129 구현 상태](docs/prototype/GP129_CLOCK_RELIC_STATUS.md)를 참고한다.

GP-130에서는 마을 기억의 쉼터에서 **영구 기억 / 유물 도감** 탭을 전환한다. 유물 도감은 실제 보상 원본을 사용해 두 유물의 효과·획득 조건을 미리 보여주고 현재 진행 중인 도전의 미보유·보유 중·사용 완료 상태를 표시한다. 도감 조회와 카드 터치는 저장·전투 상태를 바꾸지 않는다. 저장된 도전의 유물은 이어하기 후 표시하며 새 도전이나 완주 후에는 미보유로 표시한다. 상세 범위는 [GP-130 구현 상태](docs/prototype/GP130_RELIC_CODEX_STATUS.md)를 참고한다.

GP-131에서는 공용 성장 카드 **회복약 주머니**를 도전당 한 번 선택한다. 선택 즉시 회복약을 1개 보충하고 최대 소지량을 1개 늘린다(기본 3개 / 농축 2개). 소진 상태에서 선택하면 1개만 보충한다. 도감에는 15개 능력을 표시한다. 스테이지 이동·이어하기·부활은 남은 개수를 유지하고 새 도전은 원래 소지량으로 초기화한다. 상세 범위는 [GP-131 구현 상태](docs/prototype/GP131_POTION_POUCH_STATUS.md)를 참고한다.
