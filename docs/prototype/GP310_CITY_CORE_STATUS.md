# GP-310 · 행복의 나라 중심부

전체 여정10스테이지 `행복의 나라 중심부`에 시계탑 회랑과 궁전 앞 광장을 추가한다. 기존 풀숲 다리 대신 고정 충돌 발판5개를 사용하며, 기본 점프로 회랑을 건너 마지막 궁전 쉼터에 도착할 수 있다. 높은 발판은 보스 전장 밖에 두고, 궁전 앞은 기존 높이840의 평지로 유지한다. 발판의 표시와 충돌 좌표·크기는 동일하다.

집·멈춘 시계탑·궁전·장식 계단을 Godot 벡터 도형으로 그린다. 장식은 배경이며 충돌·표적·보상이나 저장 상태를 갖지 않는다. 첫 웨이브는 기존 높은 발판 위 씨앗 포대와 슬라임·공중 정령을, 둘째는 궁전 앞 양쪽 지상 적과 공중 정령을 배치한다. 기존 적 AI와 전투 관문 진행은 유지한다.

성문 다음 경로 카드·HUD·도전 상태의 지형 이름과 이동/웨이브 목표를 중심부에 맞춰 안내한다. 마지막 웃는 태엽 기사960체력·돌진/충격파/탄막·2페이즈·검/활 피해와 구출/파괴 선택은 유지한다. 보스 구간에는 기존 패턴 대응 안내를 표시한다. 이야기 모드의10스테이지 완료 장면과 최종 선택 대기 상태를 기존 저장으로 연결한다.

체크포인트 버전1과 `city_core` 경로 ID를 유지한다. 성문 완료에서 이어하기는 성문 배치를 복원하고, 다음 구간 진입 시 중심부 배치로 바꾼다. 중심부 완료에서 이어하기는 중심부와 이야기/최종 선택을 복원한다. 선택 저장 실패는 선택을 되돌리고 기존 정상 저장을 보존한다. 전투 도중 종료는 마지막 완료한 성문부터 다시 진행하며 새 일반 도전에서는 중심부 몸체와 배경을 제거한다. 기존3/5단계·지역 순회 지형은 유지한다.

## 검증

신규24개 실행 단계: 로안/루미×검/활에서 성문 완료 저장, 별도 프로세스 반복 이어하기·중심부 진입/완료 저장, 최종 이야기·구출/파괴 선택 실패/재시도·10단계 결과/이력, 실제 기본 점프5발판 횡단·낙하 복귀, 궁전 평지 실제 보행과 기존 보스 패턴/피해/페이즈, 조회 정지·마을·전투 중 종료 복원·일반 도전 초기화를 검사한다. 횡단은2단 점프·공중 대시를 사용하지 않는다. GP-309 검사의 중심부 진입 기대값도 새 전용 지형으로 갱신한다.

전체 검사 스크립트는 기존739개와 신규24개를 합친763개 실행 단계 및 Android 리소스 내보내기·변환된 패키지 부팅을 실행한다. 로컬/PR/main 결과는 각 작업 로그에서 확인한다. 창 환경에서 시계탑/궁전 화면 배치를 확인한다. 자동 검사와 창 화면 확인은 실기기 조작감·프레임률·난이도·전체 여정 소요 시간 검증을 대신하지 않는다.
