# GP-145 추적 사격

정예 보상에서 활 **추적 사격**을 두 슬롯 중 하나에 교체한다. 시전 시 활 자동 표적 선택기의 정면·사거리·화면 조건과 기존20% 전환 기준으로 표적 하나를 고정한다. 시전 뒤 다른 가까운 적이 생겨도 재지정하지 않는다.

| 항목 | 원본 |
| --- | --- |
| 피해 / 타격 개체 | 44 / 최대1개체 |
| 재사용 | 9초, 시계추 사용 시7.2초 |
| 시전 / 발사 | 0.35초 / 0.14초 |
| 이동 / 방향 전환 | 이동 가능 / 시전 방향 고정 |
| 회피 취소 | 0.08초부터 |
| 비행 | 초록 화살, 속도14m/s, 누적 경로 최대8m |
| 추적 | 최대1초, 초당 최대180도 |

발사 전 표적이 숨거나 죽거나 삭제·화면 이탈·다른 생명으로 재생성되면 시전 방향으로 직진한다. 발사 후 같은 일이 발생하면 현재 방향으로 직진한다. 약한 참조와 생명 세대를 확인해 삭제된 인스턴스를 사용하거나 재생성된 표적을 다시 추적하지 않는다. 추적 시간이 끝나도 현재 방향을 유지한다. 다른 적이 경로를 가로막으면 기존 화살 충돌처럼 그 적에게 한 번 명중한다. 피해·처치·흡수·게이지는 기존 활 공통 처리로 연결한다.

발사 전 피격·회피·무기 전환은 예정 발사를 취소하고 원본 대기시간은 유지한다. 발사된 화살은 무기 전환 후에도 비행한다. 적 감속은 아군 화살의 비행 시간을 바꾸지 않는다. 도전 상태 조회와 복귀 카운트다운은 화살·추적 잔량·시전·대기를 함께 정지한다.

## 보상·도감·저장

검7종·활8종으로 후보 수가 달라져도 도감에서15종 모두 한 번씩 표시한다. 기존14종의 순서를 보존하고 추적 사격을 마지막에 추가한다. 두 화면비의 실제 후보 순환과 슬롯 비교·확정, 도감 페이지와 안전 영역을 검증한다. 저장 형식은 기존 스킬 ID 배열을 사용하며 잘못된 무기·중복 슬롯은 거부한다. 새 도전은 기본 스킬로 초기화하고 이전 저장에 소급 지급하지 않는다.
