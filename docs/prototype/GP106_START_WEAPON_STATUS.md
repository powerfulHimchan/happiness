# GP-106 · 시작 무기 선택

새 도전과 결과 화면의 다시 도전 버튼에서 검·활 중 하나를 시작 주 무기로 선택한다. 별도 선택 화면에서 카드와 실제 스킬·사거리를 확인하고 ‘이 무기로 시작’을 누르면 도전을 초기화한다. 다른 무기는 보조 무기로 보유하며 기존 전환 버튼으로 바꿀 수 있다.

## 동작

- 확정 전에는 도전 기록을 만들거나 기존 중간 저장을 삭제하지 않는다. 돌아가기는 원래 메인/결과 화면과 기존 무기 선택을 복구한다.
- 확정하면 기존 중간 저장을 삭제하고 체력·성장·직업·필살기·무기 대기시간을 초기화한다. 주 무기만 선택한 검/활로 설정한다. 시작 자체는 무기 전환 횟수나 0.5초 제한을 소비하지 않는다.
- 검 시작은 근력 0.20·투지 0.12, 활 시작은 사격 0.20·자연 0.12의 초기 무기 성향을 준다. 직업은 고정되지 않으며 기존 능력·무기·정확한 회피 점수로 발현한다.
- 자동 공격 범위·스킬 두 개·HUD와 전환 버튼이 주 무기에 맞게 즉시 갱신된다. 검·활 전환 후에도 각 무기의 스킬 대기시간을 유지한다.
- 이어하기는 별도 버튼으로 GP-105의 저장된 무기·성장·직업·필살기를 복원한다. 메뉴에서 임시로 고른 시작 무기를 적용하지 않는다.
- 현재 시제품은 연습용 검·활 두 개를 선택할 수 있다. 무기 획득·등급·영구 해금과 나머지 무기 네 종류는 후속 범위다.

## 검증

GP-106 런타임 검사는 두 화면 비율의 안전 영역·카드/버튼 비중첩, 실제 화면 터치 선택/확정/취소, 앱 복귀 입력 해제, 두 주 무기의 실제 스킬 시작·보조 무기 전환·대기시간, 초기 성향·직업 미고정, 두 직업 발현·중간 저장, 저장이 있는 상태의 새 도전 취소와 이어하기, 잘못된 무기·중복 확정 차단, 결과 화면 재도전 취소를 검사한다.

GP-105의 활 시작 재시작 검사는 이제 전환해서 활을 들게 하는 대신 실제 활 시작 API를 사용한다. 기존 CP-206~406 및 GP-101~105 검사도 함께 실행한다. PR에서 자동 검증·APK 빌드를 통과한 후 main에 병합하고 main APK를 다시 생성한다.

실기기에서는 메인에서 검/활을 각각 선택하고 시작 버튼의 스킬·사거리·전환을 확인한다. 저장이 있는 상태에서 새 도전 선택 화면을 열었다가 돌아가기 후 이어하기가 유지되는지도 확인한다. 자동 검사와 Android 실제 플레이 결과는 구분한다.
