# GP-257–266 · 네 지역 순회 도전

새 도전 준비에 `지역 순회 · 5단계`를 추가한다. 연습1구간 후 바람꽃 평원(기존 바람 길 지형), 거꾸로 자란 숲, 별시계 유적, 태엽 축제장을 한 번씩 통과한다. 마지막 지역에서 기존 웃는 태엽 기사와 싸운다.

| 단계 | 구현한 동작 |
| --- | --- |
| GP-257 | 기존3/5스테이지 옆에 지역 순회5단계 선택. 길이/모드 미리 선택·취소·앱 복귀·검/활 시작, 지원하지 않는 모드/길이 조합 거부 |
| GP-258 | 새 도전 시작 때 네 지역 우선순위를 Fisher–Yates 셔플. 독립 RNG를 사용하고 후보 조회·보상 화면 재진입은 다시 추첨하지 않음 |
| GP-259 | 저장된 우선순위에서 미방문 최대 두 지역을 다음 후보로 표시. 이미 통과한 지역·연습 경로·위험 경로의 직접 재선택 거부. 마지막 한 지역은 한 카드 |
| GP-260 | 첫 스테이지는 연습 구간으로 표시하고 지역 통과 집계에서 제외. 바람 길은 순회에서 바람꽃 평원으로 안내. HUD·경로 화면에 통과/남은 지역 표시 |
| GP-261 | 선택한 지역의 기존 실제 지형·발판·함정·적 패턴과 보너스를 적용. 성장·무기·스킬·유물·회복 잔량은 스테이지 간 유지. 마지막 보스720체력·구출/파괴 유지 |
| GP-262 | 현재 도전의 도전 정보에 순회 진행·통과한 지역 이름을 표시. 조회와 복귀 카운트다운은 전투·발판·시간을 동결하고 지역 우선순위/저장을 바꾸지 않음 |
| GP-263 | 순회 체크포인트의 스테이지에 모드/네 지역 우선순위 추가. 기존 저장 버전1 유지. 잘못된 자료형·순열·누락 필드·중복 이력·미제시 후보 이력은 원자적으로 거부 |
| GP-264 | 완료 지점마다 별도 프로세스 반복 이어하기. 선택 화면의 현재 길이/모드와 독립적으로 저장된 모드·후보·성장·잔량을 복원. 일반 저장은 추가 필드 없이 이전 형식 유지 |
| GP-265 | 결과에 순회 완주 표시, 광장 최근 이력에 순회 종류 표시. 재시작·이어하기도 같은 도전으로 유지. 순회는5스테이지 길이 통계에 포함하고 보스 선택 대기/완주 집계는 기존 규칙 사용 |
| GP-266 | 새 일반 도전에서 순회 모드·지역 순서를 초기화하고 영구 답사는 유지. 보상 저장 실패 시 장비 롤백·후보 순서 보존·재확정 지원. 파괴 핵은 효과/1회 소비를 유지하되 위험 길은 일반 도전에서 선택하도록 안내 |

## 자동 검증

신규22개 실행 단계는 검/활 각각의 연습 완료→2/3/4지역 별도 프로세스 복원→마지막 지역/보스 선택 대기→구출/파괴 완주·이력 복원, 이전 일반 저장·순회 준비 취소·두 화면비 입력/글꼴을 검사한다. 파괴 핵을 실제 획득/소비한 순회의 후보·안내도 검사한다.96개 시드의 순열/다양성·조회 무추첨,14종 잘못된 저장 거부, 보상 쓰기 실패/롤백/재시도, 도전 정보 조회 정지도 확인한다.

전체 검사 스크립트는 기존562개+신규22개, 총584개 실행 단계와 Android 리소스 내보내기·패키지 부팅을 실행한다. PR과 병합 후main에서도 같은 검사를 실행한다.

## 확인 범위

기존3·5스테이지 자유 경로 선택을 유지하며 순회는 별도 선택지다. 순회 우선순위는 도전마다 무작위이고 실제 방문 순서는 두 후보 중 플레이어의 선택에 따라 달라진다. 지역별2구간·행복의 나라·정식10스테이지 및 새 지역 보스는 후속 범위다. 실기기 조작감·난이도·렌더링 성능은 별도 확인이 필요하다. APK는 제작을 명시적으로 요청할 때만 만든다.
