# GP-769 · 로안과 루미 고유 특성

사용자가 선택한 로안2번·루미10번을 자동 장착 특성으로 연결했다. 무기 계열 제한 없이 기존 공격력·치명타 계산을 사용한다.

| 주인공 | 특성 | 동작 |
| --- | --- | --- |
| 로안 | 반격의 순간 | 실제 정확한 회피 성공 후3초간 공격력25% 증가. 발동 시점부터6초 재사용 대기 |
| 루미 | 별빛의 응답 | 실제 무기 전환 후 전환한 무기의 다음 유효 타격1회가 확정 치명타. 발동 시점부터8초 재사용 대기 |

## 전투 동작

로안은 기존 `UltimateController.register_precise_evade`의 성공 경로에서만 강화된다. 회피 버튼만 누르거나, 무적이 아니거나, 사망·일시정지 상태일 때는 발동하지 않는다. 쿨다운 중 추가 성공으로 지속시간을 늘리지 않는다. 현재 공격력에1.25배를 적용하며 무기별 성장 보너스는 기존 합산 구조를 유지한다. 소수 공격력은 실제 피해의 마지막 반올림까지 보존하고 능력치 카드에는 정수로 표시한다. 기본 공격·스킬·공격형 필살기에 공통 적용한다.

루미는 즉시 전환과 예약 전환이 실제 성공하는 `_perform_switch`에서만 충전한다. 초기 무기 배치·무기 선택 미리보기·실패한 연속 전환·이어하기 복원은 충전하지 않는다. 충전과 쿨다운은 중첩하지 않는다. 대기 중 추가 전환으로 대상을 바꾸거나 충전을 쌓지 않는다. 전환한 무기의 유효 피해에만 사용하므로 이전 무기의 비행 중 투사체는 소비하지 않는다.

확정 치명타는 기본 공격·스킬·공격형 필살기의 첫 유효 타격1회에 적용한다. 빗나감·잘못된 표적·무적·중복 이벤트 차단은 소비하지 않는다. 다중 타격·관통·범위 공격의 이후 타격은 원래 치명타 확률을 사용한다. 처치 콜백이 중간 저장을 만들 수 있어 타격 적용 전에 충전을 예약 소비하고, 차단된 경우에만 원복한다. 이 순서로 처치와 동시에 저장해도 소비한 충전이 되살아나지 않는다. 일반 치명타 피해·흡수·금색 숫자 경로를 그대로 사용한다.

## 표시·시간·저장

주인공 선택 포스터에 두 특성의 이름·효과·재사용 대기를 함께 표시하고 기존 ‘두 주인공의 능력은 같습니다’ 안내를 교체했다. 상단 단계 표시는 추가하지 않는다. 도전 정보 첫 페이지는 도전 진행·능력치·고유 특성을 표시하며, 강화 남은 시간과 재발동 대기 또는 확정 치명타를 기다리는 무기를 보여준다. 조회는 충전을 사용하거나 시간을 진행시키지 않는다.

특성 시계는 기존 플레이어 물리 처리에서만 진행한다. 전투 일시정지·능력치 조회·메뉴의 전투 정지와 함께 멈춘다. 스테이지 이동은 남은 상태를 유지하며 새 도전 또는 다른 주인공으로 전환하면 초기화한다.

버전1 체크포인트의 선택적 `player.hero_traits`에 로안 강화·쿨다운, 루미 쿨다운·충전 무기를 저장한다. 필드가 없는 이전 저장은 미발동 상태로 복원한다. 복원 중 무기를 배치해도 특성이 발동하지 않으며 반복 이어하기로 충전이나 남은 시간이 늘어나지 않는다. 잘못된 타입·음수·상한 초과·다른 주인공의 특성·미휴대 무기 충전은 저장을 거부한다.

## 검증

`hero_traits_runtime_test.gd`의 두 주인공 × seed/resume/combat6단계로 실제 성공 신호,3/6/8초 경계, 중복 발동 차단, 여섯 무기 × 기본/스킬/필살기의 확정 치명타, 이전 무기 탄·무적·중복 차단의 비소비, 처치 시 소비 순서, 실제 일시정지의 시계 정지, 별도 프로세스 반복 복원, 이전 저장 호환과 새 도전 초기화를 검사한다. 신규 단계를 기존 프로젝트 검사 스크립트에 연결했다.

실제 렌더러로 두 주인공의 선택·도전 정보 화면을 확인하고 기존 전투·성장·무기 전환·저장·주인공 선택 검사도 수행한다. 실기기 플레이 확인과 APK 빌드는 이번 작업 범위에 포함하지 않는다.

로컬 결과: 신규 특성 실행6단계(416개 assertion), 기존 관련 실행 검사102개, 능력치 검사3단계를 모두 통과했다. 두 주인공의 선택/정보 화면8장 실제 렌더링을 확인했고 Android 리소스 내보내기와 패키지 부팅을 통과했다. 기존 전체 콘텐츠 조합 행렬의 완료를 뜻하지 않는다.
