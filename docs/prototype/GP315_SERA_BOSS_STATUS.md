# GP-315 · 미소의 여왕 세라 전투

## 새 전체 여정

- 새 전체 여정10스테이지의 마지막 보스를960체력 세라로 교체한다. 일반3/5단계와 지역 순회의 태엽 기사는 유지한다. 성문 수호기사와 조력자 지원도 독립적이다.
- 궁전 앞 혼합 웨이브 뒤 세라와 재회한다. 이야기를 켰으면 전투를 정지하고 주인공·성문 선택·기발견 단서에 맞는3페이지를 읽거나 건너뛴 뒤 전투를 시작한다. 이야기가 꺼져 있어도 같은 세라와 싸운다.
- 재회는 전투 중 장면이다. 전투/재회 중 종료하면 기존 규칙대로 마지막 성문 완료 지점에서 복원하고 중심부를 다시 진행한다. 세라 처치 후 완료 장면·선택은 체크포인트에서 복원한다.

## 전투

- 시계바늘 돌진: 방향을 경고 시작 때 고정한다. 좁은 궁전 평지3920~4880 안에서 이동하고 짧은 돌진 또는 경계 접촉 뒤 왕관의 빈틈을 연다. 기존 기사의 벽 충돌 기절·검 방어 배율은 사용하지 않는다.
- 미소의 파문: 양방향 지면 충격파다. 점프하거나 정확 회피한다. 2페이즈에는 지연 파문을 한 번 추가한다.
- 왕관의 빛살: 여덟 방향 경고 후 전용 빛살을 발사한다. 2페이즈에는0.28초 뒤22.5도 회전한 두 번째 여덟 빛살을 발사한다. 지연 공격도 시간 정지·감속을 적용하고 처치/페이즈 전환/초기화에서는 취소한다.
- 체력50%에서2페이즈로 전환하며 고정된 미소가 사라진 외형으로 바뀐다. 경고/이동/투사체가 빨라지고 추가 공격이 생긴다. 검·활은 기본100%, 공격 뒤 빈틈125%로 적용한다. 원본 피해 이벤트·정확 회피·방벽·기존 성장과 스킬의 계산 경로를 유지한다.
- 세라 전용 이름·상태·페이즈·체력·패턴/빈틈 안내를 표시한다. 다른 보스의 지표가 세라 HUD를 덮지 않으며 일반/자유 전투에서는 세라를 숨긴다.

## 승리·선택·기록

- 이야기 켜짐은 전투 후 `돌아온 친구의 이름`에서 두 사람이 약속의 상대였음을 확인한다. 이후 세라 전용 구출/파괴 카드로 이번 여정의 선택을 확정한다. 카드 비교는 조회 전용이며 선택 저장 실패는 선택을 되돌린다.
- 결과·광장 이력·이야기 여행 기록에 세라를 표시한다. 새 여행 기록2종을 기존4종 뒤에 추가하고 기존 기억 조각9종·수첩을 유지한다. 여행 기록 쓰기 실패는 확정 선택 체크포인트를 보존해 재시도로 복구한다.
- 이번 선택은 현재 여정 기록이다. 태엽 기사 일회 보상·기억·설계도·조력자를 세라 선택으로 지급하거나 소비하지 않는다. 세라 영구 조력/설계도·행복의 심장 진입·정식 엔딩은 후속 범위다.

## 저장 호환

- 체크포인트 버전1을 유지한다. 새 전체 여정은 `stage.final_boss=sera`를 첫 완료 지점부터 저장하며10스테이지 완료 이력에도 같은 정체를 기록한다.
- 필드 없는 이전 전체 여정은 `clockwork_knight`로 복원하고 이후 저장에 그 정체를 유지한다. 이전 성문/중심부 완료 저장을 새 세라 전투나 선택으로 바꾸지 않는다. 이전 GP-307~314 회귀는 이 태엽 기사 여정을 명시적으로 사용하고, 새 기본 세라는 GP-315의 실제 시작 입력으로 검사한다.
- 잘못된 타입/ID·이전 구간의 최종 보스 필드·완료 이력과 정체 불일치를 거부하고 정상 파일을 보호한다. 두 보스의 완료 기록과 영구 보상 경로를 구분한다.

## 검증

- 신규32개 실행 단계: 주인공2×무기2×저장/복원/처치 후 복원/완주16개, 실제 공격 패턴6개, 선택/이야기/여행 기록 쓰기 실패3개, 이전 성문/중심부·일반 도전3개, 중도 종료/조회·이야기 꺼짐2개, 변조 거부·두 화면비2개.
- 로안/루미×검/활 실제 기본 공격 처치·구출/파괴·50% 전환, 양방향 돌진·왕관 피해·정확 회피, 충격파/빛살 실제 충돌·정지/감속·2페이즈 추가 공격/사망 취소, 잔량/보상/장면 복원·중복 기록 차단·세라 HUD/선택/이력을 검사한다.
- 기존883개와 함께 전체915개 및 Android 리소스 내보내기·패키지 부팅을 로컬/PR/main에서 실행한다. 추가 검사 시간을 확보하도록 CI 전체 제한을25→35분으로 늘리고 개별 실행의 제한 시간은 유지한다. APK 수동 빌드 정책을 유지한다.
- Android 실기기 터치·조작감·장시간 성능·세라 난이도는 별도다.
