# GP-131 · 공용 성장 능력 회복약 주머니

공용 성장 카드 ‘회복약 주머니’를 도전당 한 번 선택한다. 선택 즉시 현재 회복약을 1개 보충하고 해당 도전의 최대 소지량을 1개 늘린다. 기본 조제는 최대 3개, 농축 조제는 최대 2개다. 소진 후 선택해도 1개만 보충한다. 선택 자체는 체력을 회복하지 않는다.

- 기존 조제와 최대 체력 25%/40% 정수 올림 회복을 유지한다. 만피·소진·사망·입력 잠금·비전투 화면에서는 기존 사용 차단을 유지한다. 회복약 버튼은 늘어난 소지량과 실제 잔량을 표시한다.
- 실제 기록에 성공한 성장 선택만 1개 보충·등급·성향·영구 발견을 적용한다. 기록 실패는 같은 카드 재선택을 기다린다. 획득 후 후보에서 제외하며 오래된 중복 선택이나 동일 해금 재호출은 추가 보충하지 않는다.
- 능력 도감은 카드 원본을 사용해 총 15개 능력과 현재 도전 등급을 표시한다. 영구 발견은 다음 도전에서 자동 능력을 지급하지 않는다.
- 중간 저장은 기존 `growth.ranks.potion_pouch=1`과 `player.potions_remaining`을 사용한다. 별도 소지량 필드는 추가하지 않는다. 저장 검증은 실제 선택 등급으로 소지량을 계산하여 기본 3개/농축 2개를 허용하며 미선택 상태의 초과 잔량·잘못된 타입·음수·소수·상한 초과는 거부한다.
- 이어하기는 능력 등급으로 소지량을 먼저 복원한 뒤 저장된 잔량을 읽어 농축 2개나 기본 3개가 잘못 잘리지 않도록 한다. 반복 이어하기·다음 스테이지·정예 휴식·불사조 부활은 회복약을 보충하지 않는다. 소진 0개도 그대로 복원한다.
- 새 도전은 능력과 보충 효과를 초기화하고 선택한 조제의 원래 개수로 시작한다. 영구 발견은 유지한다. 능력이 없는 기존 저장과 회복약 필드가 없던 초기 저장은 기존 기본 2개 규칙을 유지한다.
