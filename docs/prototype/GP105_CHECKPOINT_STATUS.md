# GP-105 · 중간 저장과 앱 재시작 이어하기

2026-09-30 구현. GP-104의 3스테이지 도전을 유지하고 Android 프로세스 재시작 이후 이어하기를 추가한다.

## 동작

- 스테이지 1·2 완료 후 최대 체력 20% 회복을 적용한 상태를 자동 저장한다.
- 메인에 저장된 완료 단계와 **이어하기** 버튼을 표시한다. **새 도전**은 기존 저장을 삭제한다.
- 이어하기는 마지막 완료 단계의 경로 선택 화면으로 복귀한다. 전투 중 종료한 경우 진행 중이던 전투를 직전 완료 지점부터 다시 수행한다.
- 레벨·경험치·카드·성향·직업·체력·무기·공격/스킬 대기시간·선택 필살기·게이지·완료 스테이지 시간·같은 도전 기록 ID를 보존한다.
- 재실행 시 회복과 직업 패시브를 다시 지급하지 않는다. 다음 경로의 추가 회복/게이지 보상은 경로를 실제로 선택할 때 한 번 지급한다.
- 사망·완주·새 도전 시 주 저장·백업·임시 파일을 삭제한다. 완료 기록이 먼저 기록된 경우 남은 저장도 재실행 시 폐기한다.

## 저장과 복구

네트워크를 사용하지 않는 기기 로컬 저장이다. 버전, SHA-256 체크섬, 필수 구조와 값 범위, 카드/직업/필살기 호환, 경험치 및 성장 수치 일관성을 검사한다. 임시 파일을 기록·flush한 뒤 주 파일로 교체하며 기존 정상 주 파일은 백업한다. 손상된 주 파일은 정상 백업을 덮어쓰지 않는다. 첫 중간 완료에는 이전 저장이 없으므로 백업은 두 번째 완료부터 생긴다. 둘 다 손상되면 이어하기를 제공하지 않고 새 도전을 안내한다.

## 자동 검증

`./scripts/check_godot_project.sh`에 기존 CP-206~406 및 GP-101~104 회귀검사와 GP-105 테스트를 포함했다.

- 서로 다른 Godot 프로세스에서 1스테이지 저장 → 재시작 → 2스테이지 저장 → 전투 중 종료 → 재시작 → 3스테이지 완주.
- 선봉대/추적자 두 직업, 터치 이어하기, 두 화면 비율(1280×720 / 2400×1080)의 버튼 안전 영역.
- 체력·카드·성향·패시브·필살기·게이지·공격/스킬 대기시간 보존, 회복 중복 방지, 도전 단일 완료 집계.
- 잘못된 필드 형식·값 차단, 중단된 파일 기록 및 정상 체크섬/잘못된 상태의 백업 복구, 양쪽 손상 시 차단.
- 사망·새 도전·완주 후 재실행에서도 이어하기가 나타나지 않는지 확인.

테스트 데이터는 실제 사용자 데이터와 분리된 임시 경로를 사용한다.

## 실기기 확인

자동 테스트는 Android 실제 기기의 프로세스 종료 검증을 대신하지 않는다. 스테이지 1 완료 후 앱을 완전히 종료해 다시 열고 이어하기로 복귀한 뒤 체력·직업·필살기가 같은지 확인한다. 스테이지 2 전투 도중 종료하면 스테이지 1 완료 경로 화면으로 복귀하는지, 완주·사망 이후 이어하기가 사라지는지 확인한다. 앱 삭제 시 중간 저장도 삭제된다. 기존 임시 디버그 서명과 새 빌드 서명이 다르면 업데이트 설치를 할 수 없으며 삭제 후 설치 시 기존 데이터는 보존되지 않는다.
