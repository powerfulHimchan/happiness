# GP-137 · 대장간 무기 도감

대장간의 기존 설계도·스킬 도감에 무기 도감 탭을 추가한다. 세 탭은 같은 안전 영역을 나누어 사용한다. 일반 검/활 각 세 등급과 태엽 검/활 각 두 등급의 10종을 세 카드씩 네 페이지로 표시한다. 태엽 일반 등급은 유효한 장비가 아니므로 표시하지 않는다. 첫/마지막 페이지를 넘어갈 수 없으며 탭 진입은 첫 페이지부터 시작한다.

무기 보상의 profile 원본에서 이름·무기 피해·고유 효과·보조 효과 50%를 읽는다. 12.5/17.5% 소수 효과를 그대로 표시한다. 기본 장비는 시작 무기, 희귀는 첫 정예, 영웅은 두 번째 정예 보상으로 안내하고 태엽 장비에는 보스 파괴 영구 해금을 명시한다. 미해금 장비도 효과를 미리 볼 수 있다. 카드 조회로 장착하거나 해금하지 않는다.

현재 도전이 활성 상태일 때만 실제 양 무기 장비·설계·사용 무기를 읽고 주/보조 무기 카드를 강조한다. 장착 카드의 기본/스킬 피해 합산은 실제 damage_multiplier를 사용한다. 성장·기억·거리 보정 전이고 필살기에는 적용되지 않음을 명시한다. 영웅 태엽 두 장비에서는 검 기본+37.5%/스킬+55%, 활 기본+55%/스킬+37.5%다. 합산은 두 무기 모두 현재 장비를 대상으로 계산하며 주 무기 전환에 따라 해당 두 카드의 역할만 변경한다.

재시작 후 이어하기 전이나 도전 완료 후에는 현재 장착 표시를 제거한다. 실제 이어하기로 장비를 복원해야 다시 표시하고 반복 이어하기도 장비/대기시간/해금을 변경하지 않는다. 새 도전은 기본 장비로 초기화하고 해금만 유지한다. 이전 설계도 필드 없는 저장은 일반 설계로 복원한다. 새 저장 필드는 추가하지 않는다.

`gp137_runtime_test.gd` seed/resume/finish/legacy/combinations 다섯 별도 프로세스를 전체 검사에 추가한다. 실제 보상·보스 파괴 해금·장착 저장 실패 롤백·양 태엽 무기 재시작 복원·완주·새 도전·기존 저장·25종 장비 조합·실제 피해 반올림·전환을 확인한다. 두 화면비에서 10카드·세 탭·페이지 상하한·입력 비중첩·원본 설명·제목/상태/설명 글자 너비를 검증한다. 조회와 탭/카드/페이지 터치가 저장·장비·스킬 대기시간·성장·유물·영구 해금·체력·회복약·필살기를 바꾸지 않는지도 검사한다. 기존 전체 회귀 검사는 유지한다.
