# GP-267–276 · 로안·루미 주인공 선택

새 도전 준비에서 `주인공 · 로안/루미 · 변경`을 눌러 두 외형을 비교한다. 주인공을 확정하면 무기·길이 준비로 돌아오고 실제 새 도전을 시작할 때 선택한 외형을 적용한다. 이동·피해·체력·스킬·성장·직업 경로는 같은 코드를 사용한다.

| 단계 | 구현한 동작 |
| --- | --- |
| GP-267 | 주인공 ID 로안/루미·한국어 이름·외형 설명·공통 여행 문장과 텍스처를 한 카탈로그에 정의. 캐릭터별 능력 보정은 추가하지 않음 |
| GP-268 | 준비의 변경 버튼에서 별도 주인공 선택 화면. 두 SVG 미리보기·선택 표시·확정/취소. 긴 머리·보랏빛 망토의 루미 외형 추가 |
| GP-269 | 선택 취소/뒤로 가기는 직전 준비 주인공 복구. 주인공을 확정한 뒤 전체 준비 취소도 원래 선택 복구. 앱 복귀는 선택 유지·입력 해제. 메인·광장·결과의 기존 준비 경로에서 사용 |
| GP-270 | 실제 Player의 Sprite2D 텍스처에 선택 외형 적용. 같은 크기의 SVG와 기존 충돌체 사용. 좌/우 방향·피격 효과·스테이지 이동에서 외형 유지 |
| GP-271 | 검/활·일반3/5스테이지·지역 순회5단계에 두 주인공을 연결. 기존 시작 API는 로안 기본값 유지. 지원하지 않는 ID는 새 도전/외형 API에서 무변경 거부 |
| GP-272 | 버전1 체크포인트 player에 character_id 추가. 로안/루미 문자열만 허용. 잘못된 ID·자료형은 원자적 저장 거부, 주 파일 변조는 정상 백업으로 복구 |
| GP-273 | 이어하기는 준비 화면 선택과 독립적으로 저장한 주인공 복원. 별도 프로세스 반복 이어하기·정예 보상·보스 선택 대기에서도 유지. 캐릭터 필드 없는 이전 저장은 로안 복원 |
| GP-274 | 실제 주인공 이름을 전투 HUD와 현재 도전 정보에 표시. 기존 카드 수와 페이지 유지. 정보 조회·3초 복귀 중 주인공과 저장 상태 보존 |
| GP-275 | 결과와 로컬 시작/이어하기/완주 이벤트에 주인공 기록. 광장 최근 이력에 이름 표시. 이전 이력은 로안으로 표시. 같은 도전의 충돌 이력·완주 후 이벤트는 주인공을 바꾸지 않음 |
| GP-276 | 다음 보상 소비 저장에 실패하면 이전 캐릭터·도전 ID·중간 저장 유지. 재시도 성공 때 외형 변경/보상1회 소비. 새 기본 도전은 로안 초기화. 전투 중 선택 화면 진입 차단 |

## 자동 검증

신규22개 실행 단계는 로안/루미×검/활의 시작→별도 프로세스 이어하기→보스 선택/완주를 검사한다. 로안은 일반3단계, 루미는 지역 순회5단계로 진행하고 모든 길이/모드 조합은 별도로 검사한다. 두 화면비1280×720/2400×1080의 안전 영역·입력 비중첩·18px 버튼 글꼴, 선택/준비 취소·앱 복귀·뒤로 가기, 실제 좌/우 외형과 피해, 생존/장비/성장/스킬/필살기 상태의 동일성도 확인한다.

이전 캐릭터 없는 저장과 이벤트 이력,10종 잘못된 캐릭터 저장의 원자적 거부, 올바른 체크섬을 가진 변조의 백업 복구, 보상 소비 쓰기 실패와 재시도, 결과/광장 조회를 검사한다. 전체 스크립트는 기존584개+신규22개, 총606개 실행 단계와 Android 리소스 내보내기·패키지 부팅을 실행한다. PR과 병합 후main에서도 같은 검사를 실행한다.

## 확인 범위

외형은 개발용 SVG다. 새 원화·프레임 애니메이션·캐릭터 음성·이야기 연출은 후속 범위다. 이번 선택은 현재 도전 단위이며 앱 종료 후 새 도전의 선호 캐릭터를 별도 영구 설정으로 저장하지 않는다. 기존 중간 저장에는 도전 중인 주인공을 저장한다. 실기기 조작감·화면 배치·성능은 별도 확인이 필요하다. APK는 명시적 요청 시에만 만든다.
