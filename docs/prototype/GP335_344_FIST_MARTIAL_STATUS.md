## 주먹 전투

기본4연타는 피해7/8/9/14, 간격0.18/0.18/0.20/0.30초다. 유효한 정면 대상에게만 사거리1.1m 이내에서 자동 공격하며, 대상이 없으면 기존0.9초 콤보 초기화를 적용한다. 마지막 타격은0.18초 경직, 나머지는0.04초다. 기본 적중은 게이지4, 스킬 적중은8을 충전한다.

| 스킬 | 피해/범위 | 재사용/동작 | 타격 시점 |
| --- | --- | --- | --- |
| 쇄도권 | 피해30·대상1개·전진2m·타격 거리1.4m | 5초/0.30초 | 0.12초 |
| 연환권 | 정면1.1m·상하0.7m·9/9/9/9/14·총50 | 7초/0.65초 | 0.10/0.20/0.30/0.40/0.50초 |
| 파동권 | 피해42·거리6m·상하0.5m·최대2개체 | 9초/0.48초 | 0.18초에 파동 생성 |

쇄도권·연환권으로 시작하며 정예 후 스킬 교체에서 파동권을 얻는다. 동작 중 이동/회전을 막고0.18초부터 회피 취소를 허용한다. 공유 근접 실행기의 피격·사망·부활·낙하·단계 이동 정리와 시계추 재사용 배율을 사용한다. 발사한 파동은 기존 검기와 같이 방향 고정·중복 적중 방지·가까운 적 우선 관통을 적용한다.

주먹 태그는 실제 피해/흡수·공용 성장·유물·기억·성향·게이지 경로를 따른다. 씨앗 주머니/축제 병정의 근접 피격 중단, 갑옷 멧돼지의 근접 갑옷60%/기절175%, 수호기사의 방패 정면65%/빈틈125%/기절150%, 세라 빈틈125%와 심장 핵 노출150%를 적용한다. 검/활 전용 성장·유물은 해당 계열에만 적용한다.

현재 타격 연출은 코드로 그린 권격 원/호와 기존 주인공 이동 외형을 사용한다. 주먹 전용 인체 공격 스프라이트와 고유 상태 이상은 후속 그래픽/밸런스 범위다.

## 두 무기와 장비·성장

시작 화면의 세 카드로 주 무기를 고르고 각 카드 아래 보조 버튼으로 다른 계열을 고른다. 현재 보조를 주 무기로 고르거나 현재 주 무기를 보조로 고르면 둘을 교환한다. 선택 취소는 이전 조합으로 되돌린다. 시작 후 계열은 두 개로 고정하며0.50초 전환 제한·행동 종료 예약과 각 계열의 대기시간을 유지한다. 기존 호출/저장은 기본 검+활 조합을 유지한다.

권갑은 일반 연습용 권갑·희귀 철제 권갑·영웅 새벽 권갑이다. 등급별 공통 피해0/15/30%p와 기본 공격 고유0/10/20%p를 적용한다. 보조 무기의 고유 보너스는50%만 적용한다. 예를 들어 영웅 권갑+영웅 활은 주먹 기본 피해100→160, 스킬100→130이며, 영웅 검과 함께면 기본150/스킬140이다. 장비는 필살기 피해를 올리지 않는다.

정예 장비/스킬 보상은 휴대한 두 계열만 제안하고 미휴대 계열의 설계도는 제외한다. 주먹은 미장착 스킬이 하나이므로 같은 후보를 복제하지 않는다. 교체 저장 실패 시 슬롯·대기시간을 복구한다. 무기 도감은 기존38개 뒤 권갑3개를 붙여41개, 스킬 도감은 기존34개 뒤 권법3개를 붙여37개다. 현재 도전 조회는 실제 두 무기·네 슬롯·실제 강화 피해와 남은 시간을 보여준다. 결과는 휴대한 두 무기의 적중·피해·사용 비율을 표시한다.

날쌘 주먹은 주먹 피해15%p와 기교2.5/연계1.5를 주며 반복 선택할 수 있다. 검/활/주먹 전용 성장 카드는 휴대한 계열만 후보에 들어간다. 공용 능력의 기존 성향 태그는 유지한다.

## 무도가와 두 진화

무도가는 기교5/연계3에서 발현하며 주먹 기본·스킬 피해10%p를 받는다. 능력70%·무기20%·특수10%와 출처별 상한은 기존과 같다. 주먹 사용 기여는 기교1/연계0.6이며 실제 적중과 정확한 회피가 기여한다.

| 기본 전용 능력 | 효과 |
| --- | --- |
| 무도가의 일격 | 주먹 기본·스킬·필살기 피해20%p·반복 가능 |
| 무도가의 호흡 | 최대 체력20/회복30·반복 가능 |
| 연계의 극의 | 일격 선행·피해30%p·도전당1회·환영무희 분기 |

전체 여정7단계 이후 기교8/연계5를 충족하면 진화한다. 연계의 극의가 없으면 뇌권투사, 있으면 환영무희다. 조건을 늦게 충족해도 진화하며 이미 확정된 진화는 이후 선택으로 바뀌지 않는다. 기본 직업 능력은 계승하고 새 패시브만 한 번 적용한다.

| 직업 | 진화 패시브 | 기본 전용 두 능력 | 공격/생존 특화 택1 |
| --- | --- | --- | --- |
| 뇌권투사 | 주먹20%p·체력10/회복10 | 번개의 주먹25%p / 뇌명의 심장 체력20·회복40 | 천뢰의 권30%p / 뇌전의 가호 체력40·회복50 |
| 환영무희 | 주먹10%p·체력30/회복30 | 환영의 연타20%p / 환영의 숨결 체력30·회복40 | 분신의 춤30%p / 몽환의 장막 체력40·회복50 |

두 진화의 전용 능력은 각각 도전당1회다. 공격 특화는 공격 능력, 생존 특화는 체력 능력이 선행하며 서로 배제한다. 새 직업의 피해 능력은 주먹 기본·스킬·공격형 필살기에 적용한다. 공통 회복 경로를 사용하므로 원정2 이상은 회복만75%·정수 올림하고 최대 체력 증가는 유지한다. 발현/진화 기록 실패는 확정을 보류하고 재시도한다. 무도가 원형·뇌권 번개·환영 초승달 표식과 영구 발견을 제공한다.

## 저장과 검증

버전1을 유지하고 `weapons.equipment`의 두 계열을 기준으로 장착·스킬·타이머를 검증한다. 주먹 보유 시 선택 필드 `player.fist`에 피해 보너스를 저장한다. 필드가 없는 기존 검+활 저장은0으로 해석한다. 새 세 직업ID와 기교/연계 기여·선행/상호 배제·한 번 상한을 검증하며 능력 원본으로 체력/피해를 재계산한다. 세 계열 동시 보유·미휴대 활성 무기·타 계열 스킬·변조한 보너스/성향/필살기를 거부한다. 복원은 체력·패시브·카드 회복을 재지급하지 않는다. 새 도전은 주먹 성장/전용 상태를 초기화하고 발견만 유지한다.

`gp344_runtime_test.gd`는 두 주인공×주먹 보조 두 계열×두 진화의 `seed/resume/legacy/late`32회와 전투4회를 검사한다. 실제4연타·세 권법·흡수·전환·등급/보조 배율·보스 방어/약점·12필살기·결과 통계, 실제 카드/적중을 통한 발현/진화·기록 실패 재시도·스킬 저장 롤백·변조 거부·별도 프로세스 반복 복원·이전 저장/초기화를 포함한다. 기존 네 진화·성장·장비/스킬/도감·게이지·조회·저장 회귀 검사를 함께 실행한다.

1280×720·1600×720에서 세 무기 선택, 세 직업 필살기, 권격/번개 표식, 기본/상위 직업·권갑 도감 화면을 실제 렌더링해 한글·배치·안전 영역을 확인했다. 로컬 자동 검사는 Android 실기기 조작·성능·밸런스를 대신하지 않으며 주먹 추가 후 실기기 확인은 아직 없다. APK는 빌드하지 않는다.

최종 로컬 검증은 신규36회와 기존 회귀134회, 총170개 시나리오를 확인했다. 정적 검사·Godot4.7.2 리소스 가져오기·Android용 리소스 팩 내보내기와 팩 부팅도 확인했다. 전체 CI 스크립트의 모든 과거 검사를 로컬에서 한 번에 실행한 결과를 뜻하지 않는다.

기존 검사에서는 전체 스킬 수/미휴대 계열 접근과 짧은 주먹 필살기를 반영하도록 기대값·표적 위치를 수정했다. GP-116의 사망 검사는 신호만 방출하던 방식을 실제 치명 피해와 즉시 저장 삭제 검증으로 바꿨다. 두 동시 실행에서 GP-116 저장 삭제 후 다음 프로세스 비교와 GP-143 조회 복귀 파일 비교가 간헐 실패했으며, 독립 데이터/설정 환경의 순차14회는 모두 통과했다. GP-137 조회 불변 비교도 재실행에서 통과했다. 이 간헐 비교 실패의 원인은 확정하지 않았으며 이전 GP-334 검증에서도 유사한 현상을 기록했다.
