# GP-124 · 생명 흡수

기획의 흡혈 능력을 레벨업 성장 카드에 연결한다. 생명 흡수는 도전당 한 번 선택하며, 검·활의 기본 공격과 스킬로 실제로 감소시킨 적 체력의 5%를 회복한다. 해금 후 후보와 재추첨에서 제외한다.

- 피해 20당 체력 1을 회복하고 나머지 피해 0~19를 정수로 누적한다. 작은 타격마다 올림하지 않는다. 갑옷 감소와 과잉 피해는 실제 적 체력 감소량으로 계산한다.
- 중복·무적·사망 대상의 차단된 타격, 훈련 대상, 필살기·조력 효과·검사 직접 처치는 회복하지 않는다. 실제 전투가 진행 중이며 플레이어가 살아 있고 체력이 부족할 때만 적용한다. 최대 체력 상태의 새 피해는 누적하지 않는다.
- 적 처치 콜백이 레벨업 화면을 여는 타격도 공격 시점에 자격을 확인해 정상 회복한다. 이미 정지된 전투의 잔류 타격은 회복하지 않는다.
- 회복 시 초록색 파동, HUD에 `흡수 5%`를 표시한다. 기존 피해·최대 체력·약·대기시간은 바꾸지 않는다. 능력 성향은 자연 0.75·투지 0.75다.
- 스테이지 이동·이어하기는 등급 `lifesteal: 1`과 선택적 `player.lifesteal_progress` 필드로 복원한다. 새 도전에서 초기화한다. 이전 저장은 누적량 0으로 읽고 능력 없이 누적량이 있거나 잘못된 범위·형식·2등급 이상은 거부한다.
