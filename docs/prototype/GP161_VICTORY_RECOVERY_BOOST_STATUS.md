# GP-161 · 처치 회복 강화

처치 회복을 먼저 획득한 뒤 공용 성장 카드로 도전당 한 번 선택한다. 이후 실제 적 처치의 체력 회복을 현재 최대 체력2%에서3%로 늘리고 소수는 올림한다. 최대 체력100/101/105/110/120/200/300에서 각각3/4/4/4/4/6/9를 회복한다. 선택 자체는 체력을 회복하지 않으며 선택을 일으킨 처치는 기존 비율을 사용한다.

기존 처치 자격·생명별 중복/위조 신호·숨김/연습/사망/정지/단계 완료/도전 비활성 차단을 유지한다. 검·활·공격형 필살기, 일반·정예·보스 처치에 같은 비율을 적용하며 체력 상한을 넘지 않는다. 생명 흡수·시간 수집·회피 방벽·회복약 방벽은 각각 독립 적용한다.

성장 등급 `victory_recovery_boost: 1`만 저장한다. 기존 저장은2%로 복원하고 반복 이어하기는3%를 한 번 적용하며 새 도전에서 초기화한다. 능력 도감은 원본 비율과 선행 조건을, 현재 도전 화면은 현재 최대 체력 기준 실제 회복량을 표시한다.

GP-159·160과 함께9단계 검사로 실제 선택·실패 재시도·선행/중복/저장 변조·별도 프로세스 복원·완주·기존 저장을 확인한다. 실제 검/활/필살기 처치·유형·새 생명·중복·정수 올림·체력 상한·여덟 자격 차단·잠금 해제 후 재전송, 세 강화·흡수·모래시계/시간 수집 조합을 검사한다. 전체299개 실행 검사와 PR/main 검증을 기준으로 한다. APK는 요청 시에만 만들며 새 기능 실기기 플레이는 미확인이다.
