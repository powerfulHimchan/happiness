## 전투·표시

- 피해 배율은 기존 성장·장비·유물 배율에 곱하고 마지막에 한 번 반올림한다. 다른 계열과 필살기에는 적용하지 않는다. 체력30%·80% 경계는 정수 비교로 계산한다.
- 조건은 기존 공격의 피해 계산 시점에 평가한다. 직접 타격은 실제 타격 시점, 투사체는 생성 시점이다. 이미 발사한 화살·마법탄·검기의 피해는 비행 중 체력이나 착지 상태가 바뀌어도 유지한다.
- 재충전은 해당 계열의 두 슬롯과 비활성 보조 무기에도 적용한다. 원본 대기시간을 줄여 덮어쓰지 않고 경과시간에 배율을 곱한다. 시계추와 함께면1.25×1.15=1.4375배, 단독이면1.15배다. 전환·이어하기로 시간을 초기화하지 않는다.
- HUD·스킬 보상 후보·교체 슬롯·능력/스킬 도감·도전 정보에 실제 계열별 재충전 시간을 표시한다. 시작·미휴대 스킬 미리보기는 기본값을 유지한다.

## 저장

기존 성장 `ranks`에 선택만 저장하고 효과는 선택/복원 때 재구성한다. 저장 형식을 바꾸거나 이전 저장에 숙련을 소급 부여하지 않는다. 다음 구간에서 유지하고 새 도전에서 초기화한다. 영구 능력 발견은 새 도전과 독립적이다. 발견 기록 실패 시 효과·등급을 적용하지 않고 선택을 재시도한다. 기존 체크포인트 검증으로 선행 없는 선택·중복 등급·미휴대 계열·집중/결의 동시 보유를 거부한다.
