## 판정·조합

30%/80% 문턱은 정수 곱셈으로 현재 체력·현재 최대 체력을 비교한다. 타격마다 판정하며 회복이나 피해로 문턱을 넘으면 다음 타격부터 달라진다. 파괴 핵·생존 본능·방어 유물을 곱한 뒤 한 번 반올림하고, 양수 원본 피해는 최소1을 유지한다. 공유 피해 이벤트·경직·중복/무적 규칙을 보존하며 낙하 환경 피해는 감소시키지 않는다.

피해 강화도 성장·장비·기억·유물·체력 조건을 곱한 뒤 마지막에 한 번 반올림한다. 흡수는 실제 적용 피해를 사용하고 과잉 피해를 제외한다. 1/20 체력 단위의 누적값을 유지하며 목걸이 단독 누적도 중간 저장에 허용한다. 실제 전투의 검/활 기본·스킬에만 적용하고 조회·만피·사망·위조·중복에는 회복하지 않는다. 성장과 유물 획득 자체는 회복·충전·재사용 초기화를 지급하지 않는다.

## 저장·표시

기존 성장 등급·유물ID·스킬 슬롯/원본 대기·흡수 소수 형식을 사용하며 파생 배율은 저장하지 않는다. 선행 없는 강화·잘못된 등급·유물 상태·무기/슬롯·흡수 소수는 기존 검증에서 거부한다. 일반 저장에서는 기본 흡수나 목걸이 없이 누적값을 넣을 수 없다. 저장 실패는 효과/선택/정상 파일을 보존하고 재시도를 허용한다.

도감의 조건·효과, HUD의 실제 흡수율/회피 게이지, 현재 도전의 현재 체력별 피해/흡수/처치 회복/스킬 상태를 연결한다. 새 도전은 모든 효과와 소수를 초기화하고 영구 발견만 보존한다. 이전 저장은 새 효과를 자동 지급하지 않는다.
