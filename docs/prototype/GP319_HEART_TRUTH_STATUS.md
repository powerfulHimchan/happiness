# GP-319 · 도착 이후 재여정과 행복의 심장의 진실

## 플레이 흐름

도착 엔딩을 영구 발견한 뒤 시작하는 새 이야기 전체 여정은 `도착 너머의 진실` 프롤로그를 사용한다. 네 지역과 세라 전투는 기존 진행을 따르며, 세라 선택 후 심장 입구에서 슬픔을 전가하는 고대 마법 기계의 정체를 밝힌다. 은발 로안/금발 루미의 이름, 세라 구출 동행/파괴 후 왕관 단서, 성문 수호기사 선택을 반영한다. 이후 `도착 너머의 약속`으로 이번 여정을 마무리한다. 도착 엔딩의 최초 발견 기록은 유지한다.

심장 입구 확인/건너뛰기는 열 번째 기억 `미소를 만드는 심장`을 영구 수집한다. 수첩의 기억 조각 네 번째 페이지에서 다시 읽으며, 도전 기록 삭제와 새 도전에 영향을 받지 않는다. 일반 도전과 이야기 꺼짐에는 이 후속 장면을 넣지 않는다.

## 저장과 복구

- 새 도전 시작 때 도착 엔딩 발견 여부를 `story.arrival_seen` 불리언으로 확정하고 기존 버전1 체크포인트에 보존한다. 이후 다른 기록이 바뀌더라도 진행 중인 여정은 소급 해금하지 않는다. 이 필드가 없는 이전 저장은 false로 복원하며, 불리언 외 타입은 거부한다.
- 심장 확인 체크포인트를 먼저 저장하고 진실을 영구 기록한다. 체크포인트 실패는 기존 상태/파일을 보존한다. 진실 저널 실패는 장면과 확인한 체크포인트를 유지하고 동일 버튼·이어하기·다음 실행에서 재시도한다. 영구 기억 기록은 멱등이며 엔딩과 완주 기록은 별도로 한 번만 남긴다.
- 첫 여정의 입구/도착 엔딩, 기존 세라 보상, 이전 저장, 기존 9종 기억과 일반 도전을 유지한다. 현재 도전·수첩·결과의 기억 총수는 원본 데이터의10종을 사용한다.

## 검증과 후속 범위

신규 실행 검사는 두 주인공×두 무기×두 세라 선택의 별도 프로세스 생성·복원·완료, 저장 실패·재실행 복구, 첫 여정/이전 저장, 상태 타입, 이야기 꺼짐/일반 도전, 두 화면비 배치를 다룬다. 관련 기존 엔딩/입구/재회 검사를 함께 실행하고 PR 전체 자동 검사 후 병합한다. 한국어 후속 장면과 수첩을16:9/20:9로 렌더링한다.

이번 범위는 첫 엔딩 이후 진실 발견과 영구 기억이다. 행복의 심장 전투, 귀환·해방·새벽 엔딩은 후속 범위이며 Android 실기기 플레이 확인은 별도다. APK는 요청 시에만 만든다.
