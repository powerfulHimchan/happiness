## 획득·계산·저장

장비는 기존 정예 보상에 추가한다. 두 휴대 계열의 후보만 표시하며, 첫 정예는 희귀·둘째 이후는 영웅이다. 같은 등급의 설계도 교체와 더 높은 등급을 허용한다. 주 무기의 공통 피해와 해당 기본/스킬 고유 보너스, 보조 무기의 같은 종류 고유50%를 합산한다. 장비 보너스는 필살기에 적용하지 않는다. 이전50개 무기 도감 순서 뒤24개 희귀/영웅 항목을 붙여 총74개를 지원한다.

유물은 둘째 정예에서 기존25개와 새8개 중 하나를 선택한다. 총33종, 기존 순서 뒤에 추가한다. 펜던트는 해당 계열 기본·스킬·공격 필살기1.15배, 비전 문장은 해당 계열 스킬1.3배다. 다른 계열·회복·재사용·게이지는 바꾸지 않는다. 기존 유물·성장·장비 계산 뒤 최종 한 번 반올림한다.

성장8개는 해당 계열을 휴대하고 기본 피해 강화 능력을 얻어야 후보가 된다. 기본과 스킬 훈련을 각각1회 선택하며 같은 계열의 공통/직업 보너스와 +20%p를 합산한다. 필살기와 다른 계열에는 적용하지 않는다. 실제 카드 선택으로 성향과 영구 능력 도감에 기록한다. 유효한 저장의 능력 등급에서 효과를 재구성하므로 숫자 보너스를 별도로 중복 저장/지급하지 않는다. 자료형을 보존하도록 기본 목록과 훈련 목록을 합친다.

양면봉은 시전 방향 기준 앞/뒤를 순서대로 검사하고 실제 적 위치에 따라 바깥쪽으로 밀친다. 정예·보스는 강제 이동하지 않는다. 서약의 파동은 기존 선분 관통 판정을 공유하고 방패 계열로 피해·흡수·게이지를 기록한다. 두 기술을 기존56개 뒤에 붙여 전체58종, 네 추가 계열은 각6스킬이다.

모든 신규 콘텐츠는 기존 저장 버전1을 유지한다. 기록 실패 시 장비·유물·성장 선택 효과를 되돌리거나 적용을 보류한다. 다른 계열 설계/스킬·선행 없는 성장·이미 소비한 새 유물 상태는 저장 검증에서 거부한다. 이어하기에 즉시 회복·게이지·직업 보상을 다시 지급하지 않고, 새 도전에서는 임시 효과를 초기화한다.
