# GP-157 도탄 사격

정예 이후 스킬 보상에 활 기술 **도탄 사격**을 추가한다. 두 슬롯 중 하나를 비교·교체할 수 있으며, 검 8종·활 9종과 기존 순서를 보존한 17종 스킬 도감에 표시한다.

| 항목 | 기본값 |
| --- | --- |
| 재사용 / 동작 / 발사 | 10초 / 0.40초 / 0.16초 |
| 첫 화살 | 시전 방향 고정 · 최대 8m · 피해 48 |
| 도탄 | 첫 유효 적중 위치의 주변 3m · 가장 가까운 다른 적 하나 · 피해 32 |
| 최대 적중 | 화살당 두 개체 · 도탄 한 번 |
| 조작 | 이동 허용 · 시선 고정 · 0.08초 이후 회피 취소 |
| 시계추 | 원본 대기 10초를 유지하며 실제 재사용 8초 |

첫 명중은 그룹 등록 순서가 아니라 비행 경로의 가까운 교차부터 판정한다. 실제 피해가 적용된 경우에만 도탄하며 첫 적이 사망해도 도탄할 수 있다. 두 번째 적은 살아 있고 화면 안에 보이는 전투 적 중에서 선택한다. 숨김·사망·화면 밖·3m 밖·연습 표적을 제외한다. 도탄 방향과 대상 생명을 고정해 이동 표적을 추적하거나 다른 적으로 재지정하지 않는다. 대상이 사라지거나 새 생명으로 교체되면 화살을 정리한다. 고정 이후 나타난 적과 첫 적의 새 생명은 추가로 타격하지 않는다.

첫 피해와 도탄 피해에 성장·장비·기억·여명의 불씨를 각각 반영해 최종 반올림한다. 실제 유효 적중마다 기존 스킬 게이지와 생명 흡수를 적용하며, 실제 처치에는 시간 수집·강화·모래시계와 기존 경험치를 독립적으로 적용한다. 발사 전 회피·피격·무기 전환은 발사를 취소하고 재사용 대기를 유지한다. 발사 후 무기 전환과 적 감속은 화살 속도를 바꾸지 않는다. 첫 경로와 도탄 경로는 각각 거리 상한을 지키고 다음 스테이지·새 도전은 남은 화살을 정리한다.

원본 스킬 ID·양 슬롯·원본 대기만 기존 저장 구조에 저장한다. 교체 기록 실패는 슬롯·대기를 되돌리고 같은 보상에서 재시도한다. 별도 프로세스 반복 이어하기는 도탄 스킬과 시계추를 한 번만 복원하며, 기존 저장은 원래 구성과 이전 필드 기본값을 유지한다. 새 도전은 시작 스킬로 초기화한다. 도감과 현재 도전 조회는 원본 첫/도탄 피해·장착 슬롯·실제 대기를 표시하고 비행·고정 대상·행동·대기시간을 정지한다. 3초 복귀 뒤 같은 도탄 비행을 재개하며 파일은 바꾸지 않는다.

`gp157_runtime_test.gd`의 seed/resume/finish/legacy/combat-right/combat-left/flows 일곱 별도 프로세스에서 실제 보상 교체·실패 재시도·17종 전체 도감/후보·양 슬롯과 시계추 반복 복원·5스테이지 완주·기존 3스테이지 호환, 좌우 실제 투사체·가까운 첫 명중·한 번 도탄·거리 경계·생명/자격/표적 상실·중복·동작 취소·강화/흡수/처치 조합·실제 프레임 조회 정지·단계 이동 정리를 확인한다. 기존 전체 Godot 회귀 검사와 PR/main 검사에 포함한다. APK는 요청 시에만 생성하며 새 기능 실기기 플레이는 미확인이다.
