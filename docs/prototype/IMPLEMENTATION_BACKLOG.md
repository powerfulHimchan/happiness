# 첫 전투 프로토타입 구현 작업 목록 v0.1

이 작업 목록은 1인 개발을 기준으로 한다. 예상치는 학습과 첫 Android 실기기 검증을 포함한 상대적인 규모이며, 그래픽 완성도보다 입력과 전투 검증을 우선한다.

## 진행 기준

- `P0`: 설치 가능한 첫 프로토타입에 반드시 필요
- `P1`: 전투 판단과 테스트 품질을 높이므로 첫 테스트 전에 필요
- `P2`: 첫 외부 테스트 결과에 따라 추가
- 한 티켓은 가능하면 0.5–2일 안에 끝낼 수 있는 크기로 유지
- 각 단계가 끝날 때 Android 실제 기기에서 확인

## 마일스톤

| 단계 | 결과물 | 예상 |
|---|---|---:|
| M0 기술 확인 | Godot Android 빈 앱 설치와 입력 지연 확인 | 1–2일 |
| M1 이동 샌드박스 | 이동, 점프, 회피, 낙하 복귀 | 4–6일 |
| M2 전투 샌드박스 | 자동 공격, 검·활, 스킬, 필살기 | 7–10일 |
| M3 완성 스테이지 | 적 4종과 3분 진행 | 6–8일 |
| M4 모바일 검증판 | 조작 편집, 기록, 효과와 Android APK | 5–7일 |

전체 초기 예상은 23–33일이다. 임시 도형과 단색 효과를 사용하며 캐릭터 원화·애니메이션 제작 기간은 포함하지 않는다.

## M0. 기술 확인

### CP-001 · Godot Android 빌드 스파이크 `P0`

- 가로 고정 빈 프로젝트 생성
- 실제 기기에서 설치·실행
- 화면 안전 영역과 해상도 정보 출력
- 5개 이상의 동시 터치 인식 확인

완료 기준: 테스트 기기에서 오프라인 실행되고 터치 ID가 누락 없이 표시된다.

### CP-002 · 프레임과 입력 지연 기준 확인 `P0`

- 60 FPS와 30 FPS 모드에서 이동량 동일 여부 확인
- 터치 시각화 점을 표시해 체감 지연 확인
- 물리 갱신과 화면 갱신 분리

완료 기준: 프레임 설정에 따라 게임 속도가 달라지지 않고 입력이 한 프레임 이상 불필요하게 지연되지 않는다.

## M1. 이동 샌드박스

### CP-101 · 입력 명령 계층 `P0`

- 포인터 ID 기반 멀티터치 처리
- 이동 벡터와 액션 명령 분리
- 명령 우선순위와 입력 버퍼 구현

완료 기준: 이동 패드를 유지하며 점프·회피·스킬 버튼을 각각 누를 수 있다.

### CP-102 · 캐릭터 지상 이동 `P0`

- 가속, 감속, 방향 전환
- 바라보는 방향 관리
- 경사면은 프로토타입 범위에서 제외

완료 기준: 입력을 놓으면 정해진 감속값으로 멈추고 반대 방향 전환 시 진동하지 않는다.

### CP-103 · 가변 점프와 입력 보정 `P0`

- 누르는 시간에 따른 점프 높이
- 0.10초 코요테 타임
- 0.12초 점프 입력 버퍼

완료 기준: 발판 끝과 착지 직전 입력이 테스트 케이스에서 재현 가능하게 성공한다.

### CP-104 · 회피와 공중 대시 `P0`

- 지상 회피 0.18초 무적
- 방향 기반 공중 대시
- 공중 1회 제한과 착지 복구

완료 기준: 피격 판정 로그로 무적 시작·종료 프레임을 확인할 수 있다.

### CP-105 · 낙하와 안전 발판 복귀 `P0`

- 마지막 안전 발판 기록
- 낙하 시 최대 체력 10퍼센트 차감
- 입력 잠금 후 복귀

완료 기준: 연속 낙하로 복귀 지점이 낙하 구역에 저장되지 않는다.

## M2. 전투 샌드박스

### CP-201 · 대상 탐색과 표시 `P0`

- 정면 반원과 무기 사거리 필터
- 최근접 대상 및 20퍼센트 전환 기준
- 0.10초 재탐색과 대상 외곽선

완료 기준: 두 적이 교차해도 대상이 빠르게 번갈아 바뀌지 않고 후방 적을 공격하지 않는다.

### CP-202 · 피해·피격 공통 처리 `P0`

- 공격자, 피해량, 경직과 태그를 포함한 피해 이벤트
- 플레이어 피격 후 0.50초 무적
- 체력 0과 사망 상태 처리

완료 기준: 같은 공격이 한 타격 시점에 중복 적용되지 않는다.

### CP-203 · 검 기본 공격과 스킬 `P0`

- 3연격과 콤보 초기화
- 돌진 베기, 회전 베기
- 회피 취소 가능 시점

완료 기준: 명세 피해량과 타격 시점이 전투 로그와 일치한다.

### CP-204 · 활 기본 공격과 스킬 `P0`

- 화면 안 대상 제한과 투사체
- 관통 화살, 화살비
- 근접 거리 피해 감소

완료 기준: 화면 밖 대상에게 발사하지 않고 관통 개체 수 제한이 적용된다.

### CP-205 · 두 무기 전환 `P0`

- 0.50초 전환 제한
- 공격 대기시간 유지
- 무기별 스킬 재사용 대기시간 유지

완료 기준: 반복 전환으로 기본 공격이나 스킬 대기시간을 초기화할 수 없다.

### CP-206 · 공용 필살기 `P1`

- 게이지 획득과 사용 조건
- 적과 적 투사체만 3초간 15퍼센트 속도
- UI 충전 상태 표시

완료 기준: 플레이어 이동과 플레이어 투사체 속도는 변하지 않는다.

## M3. 완성 스테이지

### CP-301 · 일반 적 세 종류 `P0`

- 풀잎 슬라임, 씨앗 포대, 바람 정령
- 경고 표시, 공격, 빈틈과 사망 처리

완료 기준: 각 적이 한 가지 학습 목표를 만들고 공격 전에 시각적 경고를 준다.

### CP-302 · 갑옷 멧돼지 정예 `P0`

- 돌진, 벽 충돌 기절, 충격파
- 체력 50퍼센트 패턴 전환
- 검·활 약점 보정

완료 기준: 같은 패턴을 세 번 연속 사용하지 않고 두 무기의 사용 기회가 생긴다.

### CP-303 · 3분 스테이지 진행기 `P0`

- 전진 2개, 웨이브 2개, 정예 1개 구간
- 관문 개폐와 적 출현
- 목표 시간과 실제 구간 시간 기록

완료 기준: 빠른 플레이어도 구간을 건너뛰지 않으며 느린 플레이어를 3분에 강제 실패시키지 않는다.

### CP-304 · 전투 HUD와 결과 화면 `P1`

- 체력, 시간, 무기, 스킬 대기시간과 필살기
- 결과 화면의 완료 시간, 피격 원인, 무기 사용 비율

완료 기준: 작은 화면에서도 HUD가 안전 영역과 조작 버튼을 침범하지 않는다.

## M4. 모바일 검증판

### CP-401 · 조작 배치 편집 화면 `P0`

- 드래그 위치 변경과 선택 표시
- 크기 70–140퍼센트, 불투명도 30–100퍼센트
- 실제 터치 영역과 안전 영역 표시
- 겹침 검사와 적용 차단

완료 기준: 모든 조작 요소를 이동할 수 있고 잘못된 배치는 저장할 수 없다.

### CP-402 · 조작 프리셋과 저장 `P0`

- 기본, 왼손잡이, 사용자 설정 프리셋
- 적용, 취소, 초기화
- 버전이 있는 JSON 저장과 요소별 복구

완료 기준: 앱을 완전히 종료한 뒤에도 적용한 배치가 유지되고 손상된 한 요소만 기본값으로 복구된다.

### CP-403 · 배치 테스트 모드 `P1`

- 편집 화면의 10초 이동·액션 테스트
- 실제 입력과 겹침 상태 표시
- 전투 복귀 전 3초 카운트다운

완료 기준: 저장하지 않고도 변경된 배치의 멀티터치를 확인할 수 있다.

### CP-404 · 타격 피드백 `P1`

- 타격 정지, 피격 점멸, 카메라 흔들림
- 효과음과 선택적 진동
- 위험 공격의 색상과 도형 경고

완료 기준: 진동과 화면 흔들기를 각각 끌 수 있고 게임 판정에는 영향을 주지 않는다.

### CP-405 · 로컬 테스트 기록 `P1`

- 실행과 구간 이벤트 JSON Lines 기록
- 결과 화면 집계
- 설정에서 기록 초기화

완료 기준: 네트워크 권한 없이 기록이 생성되고 중간에 앱이 종료돼도 이전 줄을 읽을 수 있다.

### CP-406 · Android 검증 APK `P0`

- 디버그 APK 생성
- 최소 2개 화면 비율에서 안전 영역 확인
- 20분 연속 플레이와 백그라운드 복귀 테스트

완료 기준: 치명적 오류 없이 10회 완주하고 조작 설정과 최고 기록이 유지된다.

## P2 후보

첫 테스트에서 필요성이 확인된 경우에만 진행한다.

- 버튼별 불투명도 설정
- 조작 배치 슬롯 2개 이상
- 블루투스 게임패드 입력
- 공격 대상 수동 고정 버튼
- 30 FPS 자동 전환
- 접근성용 고대비 위험 표시

## 첫 테스트 이후 판단

아래 중 하나라도 충족하지 못하면 직업·성장 시스템으로 넘어가지 않고 프로토타입을 한 차례 수정한다.

1. 이동과 점프 첫 성공률 80퍼센트 이상
2. 무기 전환 자발적 사용률 60퍼센트 이상
3. 평균 완료 시간 2분 40초–3분 40초
4. 사용자 조작 배치 저장 성공률 100퍼센트
5. 20분 연속 플레이 중 입력 멈춤과 강제 종료 0회
