# GP-415–444 · 도전 중 여행 보급소

각 도전은 두 무기 계열을 휴대하므로 실제 상점에는 서비스4종, 승급2종, 기술 추천4종이 표시된다. 기술 재입고는 미장착 후보에서 새로 선택하며, 이미 구매한 추천 번호는 재입고 뒤에도 품절이다. 무료 스킬 보상과 유물 선택 횟수를 소비하지 않는다. 전설 등급·신규 계열 추가·설계도 영구 해금은 판매하지 않는다.

저장은 기존 체크포인트에 선택적인 `supplies` 필드를 추가한다. 이전 저장에 이 필드가 없으면 해당 도전은 상점 없이 기존 형식을 유지하고, 새 도전부터 사용한다. 재화 소급 지급은 없다. 장부의 시드·단계·잔액·구매 순서·중복 영수증·가격·재고·계열/슬롯을 검증하고 실제 완료 경로 수입에서 지출을 재계산한다.

## 검증

`gp415_444_runtime_test.gd`는 로안/루미의22개 상품 경로를 실제 터치 입력으로 구매하고 별도 프로세스에서 두 번 복원하며 다음 휴식과 새 도전까지 확인한다. 구매/재입고 저장 실패, 부족한 재화·가득 찬 자원·정비 불필요 상태, 변조 저장 거부와 이전 저장 호환성을 검사한다. 추가 progression 단계는 여섯 계열의 영웅 승급·복원과 마지막 스테이지의 구매 차단을 확인한다. 1280×720 및1600×720 안전 영역과 페이지 중복도 검사한다.

로컬 검증에서 신규168개와 기존331개, 총499개 실행 사례를 통과했다. 기존 범위는 GP-385–414 콘텐츠189개, 전투·성장·그래픽55개, 체크포인트/전체 여정67개와 이야기20개다. 상점48개 화면과1600×720 상점·경로 선택·지갑3개 화면을 렌더링해 확인했다.

실행 검사 목록은 `scripts/check_godot_project.sh`에 등록한다. Android 리소스 팩 내보내기와 실행은 검증하되 APK는 생성하지 않는다. 실제 Android 기기에서 터치 조작과 긴 플레이 밸런스는 별도 확인이 필요하다.
