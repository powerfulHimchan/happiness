## 실행·표시

신규 스킬은 원본 리소스의 실행 유형, 방향별 타격, 확산 각도, 사거리를 사용한다. 기존 스킬의 기본값과 실행 규칙을 유지한다. 검기에는 해당 스킬의 공격ID를 전달한다. 활 화살비/추적/산개 로그는 실제 원본 이름과 타격/화살 수를 표시한다. 정예 보상 순환에서 12종 모두 두 슬롯에 교체할 수 있으며 기존 도감22종의 순서를 보존한다.

직업 발현 화면은 직업별4개 후보를2×2로 표시한다. 이전2개 후보를 앞에 보존하고 새2개를 뒤에 추가한다. 후보 비교·확정 실패는 프로필과 게이지를 변경하지 않는다. 마을 직업 도감에도 전체 필살기를 표시한다. 두 화면비1280×720/2400×1080에서 카드·확정 버튼의 안전 영역, 비중첩, 글자 너비를 검사한다.

피해 배율은 현재 체력과 실제 방벽 잔량을 타격마다 조회하고, 성장·장비·기억·유물과 곱한 뒤 마지막에 반올림한다. 전투 피해 감소는 방벽 흡수 전에 적용하며 공유 이벤트/경직/무적/중복/낙하 규칙을 유지한다. 새로운 적중 게이지는 기존 실제 적중 신호에서 지급하고 최대100을 유지한다. 시간 조율의5/10에 종+2 또는 프리즘+3을 합산하며 모래시계 배율은 마지막에 적용한다. 시계판과 시간의 여운/깊은 여운은 다음 발동 시간에만 합산한다.

## 저장·검증

성장 등급·유물ID·스킬ID·직업 필살기ID를 기존 형식으로 저장하고 파생 배율은 저장하지 않는다. 기존 검증은 선행 조건, 최대1등급, 무기별 슬롯, 직업별 필살기를 원본 데이터에서 검증한다. 실패한 기록/체크포인트는 선택·효과·정상 파일을 보존한다. 반복 이어하기는 체력·약·방벽·흡수 소수·게이지·원본 대기를 무료 보충하지 않는다. 새 도전은 추가 효과를 초기화하고 영구 발견만 보존한다. 기존 저장은 새 효과를 소급 지급하지 않는다.
