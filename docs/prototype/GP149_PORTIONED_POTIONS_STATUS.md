# GP-149 · 소분 회복약과 세 조제

태엽 기사 파괴로 영구 기억 `core_echo`를 해금하면 약방에서 소분 회복약을 선택할 수 있다. 이전 버전에서 파괴한 기기도 기존 영구 저널로 바로 해금한다. 별도 재료나 비용은 추가하지 않는다.

| 조제 | 도전당 개수 | 1회 회복 | 해금 조건 |
|---|---:|---:|---|
| 기본 회복약 | 2 | 최대 체력25% | 항상 제공 |
| 농축 회복약 | 1 | 최대 체력40% | 태엽 기사 구출 |
| 소분 회복약 | 3 | 최대 체력20% | 태엽 기사 파괴 |

회복량은 정수 백분율로 곱한 뒤 정수 올림하고 최대 체력을 넘지 않는다. 20%+10%의 소수 계산 오차로 체력100에서31을 회복하지 않으며 정확히30을 회복한다. 소분은 한 번의 회복량 대신 사용 횟수를 늘리는 선택이다. 회복약 주머니를 실제 선택하면 한 개를 보충하고 최대4개가 된다. 샘의 이슬은20→30%로 강화하며, 회복 방벽은 실제 소비마다 방벽10을 기존20/30 상한까지 보충한다. 만피·소진·입력 잠금·비전투·정지·도전 종료에서는 소비와 회복을 차단한다.

약방은 기본·농축·소분 순서로 세 카드를 표시한다. 구출과 파괴의 잠금 조건, 개수·회복률·분할 전략을 비교하고 터치로 다음 새 도전 조제를 저장한다. 저장 실패는 기존 선택과 저널을 유지하고 재시도를 안내한다. 같은 조제 재선택은 중복 기록을 쓰지 않는다. 새 도전 준비 취소와 조회는 약을 지급하지 않는다.

진행 중 도전은 저장한 조제와 잔량을 유지한다. 약방에서 다음 조제를 바꿔도 기존 도전과 중간 저장을 변경하지 않는다. 이어하기·단계 이동·스테이지 휴식은 약을 보충하지 않는다. 새 도전에서만 선택한 조제의 원래 개수를 지급하고 주머니·유물·성장 효과를 초기화한다. HUD와 현재 도전 상태는 소분 이름·남은 개수/최대·이슬 적용률·방벽 보충량을 표시한다.

기존 기본/농축 저장과 조제 필드 없는 저장은 기존 규칙을 유지한다. 새 조제도 공통 검증으로 잔량의 타입·정수·범위와 주머니 최대를 확인하고 변조 저장은 정상 파일을 보호한다. 기존 영구 파괴 해금과 조제 저널은 별도 마이그레이션 없이 읽는다.

## 검증

GP-149의 `seed`, `resume`, `finish`, `legacy-seed`, `legacy`, `combat` 별도 프로세스는 실제3단계 보스 파괴, 세 조제의 해금 조건과 약방 터치, 두 화면비1280×720·2400×1080의 안전 영역/비중첩/설명 글자 폭, 저장 실패 재시도, 실제 주머니/회복 방벽/이슬 획득, 현재 상태 조회, 5단계 이어하기와 소진, 기존 농축 저장과 다음 조제 독립을 검사한다. 기존 회복 방벽 전투 검사는 세 조제를 모두 순회해 올림·체력/방벽 상한·누른 버튼 중복 차단·잠금 조건을 확인한다. 체력100·120·101·105에서 소분+이슬 회복량30·36·31·32를 고정값으로 검사해 정수 올림 경계를 확인한다.

전체 Godot 실행 검사는 기존237단계와 새6단계로 총243단계다. 실기기의 새 조제 선택과 전투 플레이는 별도 확인이 필요하다. APK는 명시적인 요청이 없어 이번 작업에서 생성하지 않는다. PR/main의 자동 Godot 검사와 수동 APK 빌드 정책을 유지한다.
