# GP-548–597 · 영구 업적 50종

기존 여정의 영구 발견·이야기 기록을 바탕으로 50개 업적을 추가한다. 마을의 **광장 기록 → 영구 업적**에서 세 카드씩, 총17페이지로 진행률과 조건을 확인한다. 달성 카드를 누르면 같은 이름의 칭호를 장착하며 다시 누르면 해제한다. 칭호는 메인 화면에 표시하고 전투 수치·획득 확률·기존 중간 저장에는 영향을 주지 않는다.

## 기록과 실패 복구

- 실제로 저장된 지도 답사, 직업·능력 발견, 기억·엔딩·원정·인연·비밀 기록을 읽는다. 도감 열람이나 아직 저장되지 않은 런 상태는 업적을 주지 않는다.
- 이전 설치의 영구 기록을 시작 때 반영한다. 같은 기록을 다시 반영해도 중복 쓰기가 없고, 한 번 저장한 업적과 부분 진행은 줄어들지 않는다. 새 도전과 로컬 테스트 기록 삭제로 초기화되지 않는다.
- `permanent_achievements.jsonl`은 체크섬을 포함한 별도 줄 저널이다. 버전1 중간 저장 스키마와 기존 영구 저널은 변경하지 않는다. 잘못된 ID·범위·소수 진행·손상 체크섬·미달성 칭호 행을 거부하며 부분 손상 뒤의 새 정상 행도 복구한다.
- 업적 기록 실패는 기존 발견 저장·전투·여정 진행을 막지 않는다. 업적 탭에 실패 안내를 표시하고 카드를 누르면 저장을 재시도한다. 칭호 저장 실패 시 이전 선택을 유지한다.
- 페이지 이동·카드 조회·다른 탭 방문은 파일을 쓰지 않는다. 기록 삭제와 다른 도전의 신규 발견을 포함해 영구 업적은 독립적으로 보존한다.

## 검증

- Godot 4.7.2에서 전용 `catalog → seed → resume → live → failure → corrupt` 여섯 단계를 통과했다. 총7,783개 검증으로 50종 조건·임계값·독립 저장·중복 방지·진행 유지·재실행 복원·실제 저장 콜백·실패 재시도·손상 행 복구를 확인했다.
- 1280×720·1600×720·1280×800의 세 화면비에서 17페이지와 전체 칭호의 실제 터치 입력, 안전 영역, 터치 영역 겹침, 페이지 경계를 검사했다. 실제 렌더러로 63개 화면을 생성하고 대표 화면의 한글·카드·진행 표시·선택 강조·메인 칭호 배치를 확인했다.
- `scripts/check_godot_project.sh`를 `GODOT_CHECK_SHARD_COUNT=16`으로 분할한 전체 통합 검사를 통과했다. 16개 묶음 모두 종료 코드0이며, 기존 전투·직업·도감·보스 선택·저장/이어하기 검사와 Android 리소스 팩 검증을 포함한다.
- Android 실기기 플레이는 미확인이다. APK는 요청 시에만 빌드한다.
