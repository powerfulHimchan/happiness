# GP-119 · 첫 유물 불사조 깃털

2스테이지 정예 무기 보상 뒤 경로 화면에서 희귀 유물 불사조 깃털을 선택할 수 있다. 이번 시제품은 확정 후보 한 개이며 무작위 유물 상자·다중 유물 빌드는 이후 범위다. 나중에 선택하거나 바로 다음 경로를 선택해 건너뛸 수 있다. 획득 확정은 중간 저장 성공 후에만 완료하고 실패하면 유물과 기존 저장을 보존해 다시 시도한다. 획득 자체는 체력·회복약·무기·성장을 바꾸지 않는다.

전투 중 치명적인 피해를 실제로 받으면 도전당 한 번 최대 체력의 50%를 정수 올림으로 회복해 되살아난다. 1초 피격 보호를 부여하고 진행 중 액션과 이동 입력은 해제한다. 양 무기 재사용 대기시간·회복약·경험치·피격 집계는 유지한다. 피해 이벤트 처리 기록을 보존해 같은 치명타 재전달을 막는다. 부활 시에는 사망·결과·저장 삭제·회복 구슬 삭제 신호를 내보내지 않는다. 부활에 실패하거나 이미 소진했다면 기존 사망 처리를 사용한다.

소비는 기존 체크섬 영구 저널에 도전 ID별로 먼저 기록한다. 저장 성공 없이 부활시키지 않는다. 중간 저장의 미사용 유물보다 소비 저널이 최신이면 이어하기에서 사용 완료로 복원한다. 진단 기록 초기화와 중간 저장 이전 정상 파일 복구가 도전당 1회를 재충전하지 않는다. 새 도전은 유물을 제거하고 별도 ID로 시작한다. 보유·소비 여부는 전투 HUD에 표시한다.

성장·직업·보상·마을·조작 편집·배치 연습·복귀 카운트다운·일시정지에서는 발동하지 않는다. 낙하 복귀는 기존 최소 체력 1 규칙을 유지한다. 유물 없는 기존 GP-118 저장은 빈 유물 상태로 읽는다. 잘못된 ID·필드·타입과 첫 스테이지 유물 저장은 거부해 정상 저장을 보호한다.

GP-119 네 별도 프로세스는 두 화면비의 실제 보상 터치·취소·원자적 저장 실패/재시도, 치명타 부활·50% 올림·보호·중복 타격·양 무기 대기시간, 잠금 화면, 미사용 중간 저장보다 최신 소비 저널의 재실행 복원, 소진 후 실제 사망·새 도전·소비 저장 실패, 이전 저장 호환·유물 건너뛰기·실제 보스 완주를 검증한다. 기존 83회 회귀 검사도 실행한다.
