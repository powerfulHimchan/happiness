# GP-323 · 원정 2 체력 회복 제한

원정 1 전체 여정을 엔딩까지 완주하고 영구 기록하면 새 전체 여정 준비에서 기본→원정 1→원정 2를 선택한다. 엔딩만 발견한 상태는 원정 1까지만 선택한다. 다른 도전 모드에서는 원정을 시작하지 않는다. 준비 취소·다시 도전·HUD·도전 정보·결과·마을 최근 기록에 선택 난이도를 연결한다.

원정 2는 원정 1의 열 스테이지 두 번째 웨이브 추가 정예를 유지한다. 기존 규칙으로 계산된 정수 체력 회복량에75%를 한 번 적용하고 정수 올림한다. 예를 들어25는19, 10은8, 4는3, 1은1이다. 회복약·회복 구슬·흡수·처치 회복·성장 선택·회복형 필살기·스테이지 완료/지역 회복과 동행/구출 등 공통 체력 회복 경로에 적용한다. 최대 체력 증가·시작 체력 보너스·방벽 회복·불사조 부활 체력은 기존 효과를 유지한다. 저장한 현재 체력 복원에는 다시 감소를 적용하지 않는다. 기본과 원정 1의 회복은 기존과 같다.

## 저장과 해금

버전1 체크포인트의 선택 필드 `stage.expedition`은0/1/2 정수를 허용한다. 필드가 없는 기존 저장은 기본으로 복원한다. 진행 중 저장을 상위 난이도로 바꾸지 않으며 준비 화면 선택과 독립적으로 난이도와 회복 규칙을 복원한다. 잘못된 값·전체 여정 외 원정 저장은 거부하고 쓰기 실패 시 정상 저장을 보존한다.

기존 이야기 영구 저널에 엔딩과 동일 실행의 `expedition_clear` 기록을 추가한다. 엔딩 기록 성공 후 원정 기록까지 성공해야 완주를 확정한다. 엔딩만 저장되고 원정 기록이 실패하면 결과/다음 해금을 보류하고 이어하기에서 재시도한다. 별도 프로세스에서도 중복 완주 없이 복구한다. 도전 기록 삭제 후에도 해금은 유지한다.

이전 GP-322 원정 완주는 로컬 도전 기록의 전체 여정10스테이지 완주와 동일 실행의 영구 엔딩(엔딩 ID·주인공·선택)이 일치할 때 영구 기록으로 이관한다. 최근12개 표시 범위보다 오래된 기록도 확인한다. 엔딩 없는 기록은 해금하지 않고 이관 쓰기 실패는 잠금을 유지한 채 재시도한다. 이미 삭제한 과거 도전 기록은 복구할 수 없으므로 그 경우 원정 1을 다시 완주한다.

## 검증

`gp323_runtime_test.gd`의 두 주인공×검/활×13단계, 총52개 실행을 기존 PR/main Godot 검사에 추가한다. 실제 준비 입력·잠금·순환·취소, 이전 완주 이관과 쓰기 실패, 별도 프로세스 원정 2 저장/이어하기, 변조/이전 저장, 회복약·구슬·성장·필살기·실제 무기 흡수/처치 회복·방벽·불사조·스테이지 회복, 두 화면비 배치·이야기 꺼짐, 원정 1 완주 부분 실패와 별도 프로세스 복구, 실제10스테이지·추가 정예10마리·심장 기본 공격 처치·최종 엔딩·결과/이력을 검사한다.

1280×720·1600×720 실제 화면의 한글과 안내 배치, Android 리소스 내보내기·패키지 부팅, 기존 자동 검사를 확인한다. Android 실기기 조작·성능·난이도 평가는 별도 확인 대상이다. APK는 요청 시에만 만든다. 원정 3~5의 새 패턴·제약은 후속 범위다.
