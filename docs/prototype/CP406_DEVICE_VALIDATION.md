## 확인 순서

1. 기존 진단 앱이 설치되어 있으면 제거한 뒤 CP-406 APK를 설치한다.
2. 메인 화면과 전투 화면에서 카메라 홀·둥근 모서리가 HUD와 조작 버튼을 가리지 않는지 확인한다.
3. 조작 배치에서 버튼 위치와 불투명도를 변경해 적용하고 앱을 완전히 종료한 뒤 다시 실행한다.
4. 최소 20분 동안 전투·점프·회피·무기 전환을 반복한다.
5. 연속 실행 중 앱을 세 번 백그라운드로 보냈다가 복귀하고, 입력이 눌린 채 남지 않는지 확인한다.
6. 스테이지를 총 10회 완주한다. 설정 화면의 `Android 검증` 완주 수와 연속 실행 시간, 복귀 횟수를 확인한다.
7. 앱을 완전히 종료하고 다시 실행해 조작 배치와 결과 화면의 최고 기록이 유지되는지 확인한다.

## 통과 기준

- 치명적 오류, 앱 강제 종료, 진행 불가가 없다.
- 두 화면 비율에서 모든 HUD와 터치 영역이 안전 영역 안에 있다.
- 20분 이상 실행 뒤에도 프레임·입력에 지속적인 이상이 없다.
- 백그라운드 복귀 뒤 잔류 입력이 없고 전투를 계속할 수 있다.
- 10회 완주 수와 최고 기록이 유지된다.
- 저장한 조작 위치·크기·불투명도가 재실행 뒤 유지된다.
