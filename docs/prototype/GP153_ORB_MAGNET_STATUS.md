# GP-153 · 구슬 자석

공용 성장 능력 구슬 자석을 도전당 한 번 선택한다. 선택 이후 회복 구슬 획득 거리가76px(0.76m)에서152px(1.52m)로 늘어난다. 이미 떨어진 구슬에도 다음 획득 판정부터 적용한다. 구슬을 움직이는 연출 없이 기존 원형 거리 판정을 확장하고, 활성화된 동안 구슬 주변의 옅은 원호와 자석 거리 설명을 표시한다.

최대 체력10% 회복·소수 올림·최대 체력 상한은 유지한다. 회복약 개수나 방벽·스킬 대기·필살기 게이지는 변경하지 않는다. 일반 적 드롭 확률20%·생명당 한 번 추첨·스테이지 두 개 상한·안전 지면 배치는 기존 규칙을 사용한다. 만피에서는 구슬을 소비하지 않으며 피격 경직·낙하 복귀·사망·일시정지·비전투 화면·환경 동결·단계 완료·도전 종료 시 획득을 차단한다. 다음 스테이지에서 구슬과 드롭 집계를 초기화하고 능력은 유지한다.

실제 성장 카드 선택과 영구 발견 기록 성공 후에만 거리를 확장한다. 기록 실패는 같은 카드를 재선택할 수 있고 거리·등급·성향·체력·회복약·방벽·양 무기 대기·게이지를 보존한다. 이미 획득하면 무작위 후보와 중복 확정에서 제외한다.

기존 성장 등급에 `orb_magnet: 1`을 기록하고 별도 효과 필드는 추가하지 않는다. 이전 저장의 능력 부재는 기본 거리로 복원한다. 반복 이어하기는152px로 복원하고 회복이나 구슬을 새로 지급하지 않는다. 새 도전에서 기본 거리로 초기화하되 능력 도감의 영구 발견은 유지한다. 25능력 도감에 원본 효과·공용 조건·현재 등급을 표시하고, 현재 도전의 생존 상태에 실제 획득 거리를 표시한다. 조회는 효과와 저장을 변경하지 않는다.

## 검증

`seed`, `resume`, `finish`, `legacy-seed`, `legacy`, `combat` 여섯 단계에서 실제 처치 레벨업·자연 후보·모바일 카드 선택·기록 실패 재시도·중복 선택 거부·등급 타입/범위 변조 차단·별도 프로세스 반복 이어하기·5스테이지 보스 완주·이전 저장과 새 도전 초기화를 확인한다.

실제 구슬 컨트롤러로152.1px의 수평/수직 범위 밖,152px 경계와150px 대각선 안쪽을 판정한다. 체력100/101/105/120의 원래10% 정수 올림 회복, 만피 보존·체력 상한·중복 회복 차단, 여덟 종류의 획득 잠금, 실제 일반 적 처치 드롭·생명 중복 차단·두 개 상한, 완료 화면 획득 차단·다음 단계 정리·실제 사망 정리를 확인한다. 1280×720·2400×1080의 성장 카드·전체 도감·현재 도전 설명 폭과 안전 영역, 조회/복귀 중 파일과 상태 보존을 검사한다.

전체 검사는 기존252단계와 새6단계로 총258개의 runtime test 성공을 확인한다. 실기기 플레이는 별도 확인이 필요하다. 명시적 요청이 없어 APK를 만들지 않고 PR/main Godot 검사와 수동 APK 정책을 유지한다.
