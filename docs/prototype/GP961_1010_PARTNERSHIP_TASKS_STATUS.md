## 저장과 판정

- 조합 과제는 두 무기를 모두 휴대해야 진행된다. 실제 기술 적중/무기 피해를 각각 검사하며 빗나간 시전은 집계하지 않는다.
- 지출액은 구매 당시 구간의 가격으로 재구성하고 재입고 비용을 포함한다. 상품 구매/종류 수에는 재입고와 과제 보상 영수증을 포함하지 않는다. 상품 종류는 보급소 상품 ID 기준이다.
- 보상 영수증 이전까지의 구매 기록만 달성 근거로 사용한다. 보상 수령을 구매 이전으로 옮긴 저장은 거부한다.
- 과제 기능이 없는 이전 보급소 저장은 그대로 유지한다. 과제 기능이 있는 진행 중 저장에는 현재 도전의 기존 기록을 사용한다.
- 마지막 구간에는 보급소가 없으므로 구간 목표는 휴식이 존재하는 구간에서 완료하도록 제한한다.

## 검증

- 새 과제42개 전체의 달성/미달성 경계, 두 무기 휴대 조건, 중복 지급, 이전 저장, 필터·정렬 조합을 검사한다.
- 로안/루미 각각42개 과제를 실제 전투/구매로 달성하고 수령·별도 실행 복원·다음 구간 진행을 검사한다. 저장 실패 복구·변조 거부·새 도전 초기화를 포함한다.
- 기존 Godot 실행 검사, Android 리소스 내보내기와 팩 실행을 함께 검증한다.
- 게시판은1280×720,1600×720,1280×800의 실제 렌더링과 터치 영역을 확인한다.
- Android 실기기 플레이는 확인하지 않았다. APK는 이번 일반 기능 작업에서 생성하지 않는다.
