# GP-316 · 세라의 영구 인연·동행·설계도

## 동작

- 새 전체 여정10스테이지의 세라 구출/파괴를 별도 영구 저널에 기록한다. 이야기 켜짐/꺼짐과 무관하다. 다른 여정에서 두 선택을 모두 달성하면 함께 보유한다. 태엽 기사 일회 보상·영구 기억과 성문 수호기사 선택은 독립적이다.
- 구출: 이후 새 도전부터 세라가 정예전 지원으로 동행한다. 3/5스테이지·지역 순회·전체 여정에서 각 스테이지 마지막 정예에게 기본40피해를 한 번 준다. 수호기사30·태엽 기사20 지원과 독립적으로 합산한다. 필드 없는 진행 중 이전 저장에는 소급 적용하지 않는다. 이동 AI·동행 애니메이션은 포함하지 않는다.
- 파괴: 약속의 검·왕관의 활 설계도를 영구 해금한다. 희귀/영웅 무기 피해는20/30%, 고유 효과는15/25%이며 검 기본 공격·활 스킬에 적용한다. 보조 고유 효과는 절반, 필살기는 제외한다. 실제 정예 보상에서 장착하고 저장·이어하기로 보존한다.
- 기억의 쉼터의 `세라의 인연` 탭에서 두 선택과 보상을 조회한다. 대장간 세 번째 설계도 페이지와 무기 도감에 잠금 조건·희귀/영웅 성능을 표시한다. 기존 태엽·수호 설계도 순서를 유지한다. 전체 영구 설계도6개·무기 도감38개다.
- 새 도전 준비·메인의 세라 동행 해금 표시와 현재 도전 정보의 지원 사용 스테이지 수를 연결한다. 완주/사망 시 현재 동행만 정리하며 영구 해금은 유지한다. 도전 기록 초기화·조회는 인연 저널을 변경하지 않는다.

## 저장·오류 복구

- 체크포인트 버전1·체크섬 저널 형식을 유지한다. 세라 선택 체크포인트 저장에 성공한 뒤 `sera_reward`를 기록한다. 도전ID의 같은 선택은 멱등이며 반대 선택은 거부한다.
- 체크포인트 실패는 선택을 되돌리고 영구 보상을 주지 않는다. 영구 저널만 실패하면 확정 선택과 체크포인트를 보존하고 새 도전 진행을 막는다. 이어하기/새 도전의 사전 복구에서 재시도하고 완주·보상 중복을 막는다.
- 이전 GP-315의 선택 확정 체크포인트도 복원 시 해금한다. 이미 완료되어 체크포인트가 삭제된 과거 도전은 소급 변환하지 않는다. 세라가 아닌 이전 태엽 기사 여정은 기존 보상을 유지한다.
- 지원은 타격 전 별도 `sera_assist` 소비를 기록한다. 실패하면 소비/타격하지 않고 다음 갱신에 재시도한다. 이전 체크포인트의 사용 배열과 저널을 합쳐 중복 지원을 차단한다. 두 기사 지원의 소비와 독립적이다.
- 세라 동행의 타입·도전ID·중복·미래·0/11·소수·불리언 스테이지를 거부하고 정상 파일을 보호한다. 필드 없는 이전 저장은 동행 없음으로 복원한다.

## 검증 범위

- 신규32개 실행 단계: 로안/루미×검/활×구출/파괴의 세라 완주→다음 새 도전→1/2단계 별도 프로세스 반복 복원→3단계 완주24개, 선택/영구 저널 실패·변조/이전 진행 저장·이전 확정 선택 각2개, 독립 저널·네 도전 모드 각1개.
- 세라 희귀/영웅 무기를 실제 보상 카드로 장착하고 검 타격·활 투사체의 기본/스킬 피해, 보조50%, 필살기 제외를 검사한다. 실제 지원 합산·반복 지표/백업 중복 차단·기록 초기화 독립·손상 저널 복구를 검사한다.
- 인연 탭 실제 입력·설계도 세 페이지·잠금/해금·경계와 조회 불변을 두 화면비에서 검사한다. 16:9·20:9 인연/설계도/준비/선택 화면을 실제 렌더링으로 확인한다.
- 전체 실행 단계는 기존915+신규32=947개다. Android 리소스 내보내기·패키지 부팅도 검사한다. APK는 생성하지 않는다.
- Android 실기기 터치·장시간 성능·세라 지원/무기 밸런스는 별도 검증 대상이다. 다음 범위는 행복의 심장 진입과 이후 이야기이며 정식 엔딩은 후속 범위다.
