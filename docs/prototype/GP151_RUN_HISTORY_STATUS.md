# GP-151 · 광장 최근 도전 이력

마을의 광장 기록에 전체 통계와 최근 도전 탭을 제공한다. 기존 JSON Lines의 기록을 읽어 최근12개 도전을 최초 관측 순서의 역순으로 표시한다. 한 페이지에 세 카드, 최대 네 페이지를 사용한다. 도전 시작 기록이 없는 이어하기나 완주 기록도 조회할 수 있다.

완주한 도전은 스테이지 수·완주 시간·보스 구출/파괴를 표시한다. 미완료 도전은 마지막 기록 스테이지와 완료한 스테이지 수를 표시한다. 미완료에는 진행 중 도전도 포함하며, 사망이나 포기로 단정하지 않는다. 기존 단일 스테이지 기록의 보스 선택이 없으면 선택 기록 없음으로 표시한다.

도전 ID별로 이어하기와 반복 시작을 묶는다. 완주 기록은 첫 기록을 채택하고 이후 중복 완주·시작으로 시간이나 선택을 덮어쓰지 않는다. 새 도전만 목록 순서를 바꾼다. 목록 제한은 화면에 제공하는 이력에만 적용하며 전체 통계와 원본 로그를 줄이지 않는다. JSON Lines 스키마와 체크포인트 형식은 그대로 유지한다.

조회·탭 이동·페이지 이동·복귀는 파일과 영구 해금·체크포인트를 변경하지 않는다. 기존 마을의 전투·물리·타이머 동결을 사용한다. 기록이 없거나 삭제하면 안내 카드 하나와1/1페이지를 표시하고 페이지 범위를 보정한다. 기록 삭제와 영구 해금은 독립적이다.

## 검증

새 `seed`, `resume`, `finish` 세 단계는 실제3스테이지 구출 완주, 다음 도전의 중간 저장, 별도 프로세스 마을 이어하기, 파괴 완주, 다시 시작한 후 이력 유지와 삭제를 검사한다. 실제 터치로 시설·탭·이전/다음·복귀를 확인하고 파일 바이트·저장·해금·타이머·체력의 보존을 확인한다.

별도 로그에서 중복 기록, 시작 기록 없는 이어하기, 스냅샷 깊은 복사, 최근12개 제한과 전체 집계 유지, 손상된 마지막 줄 무시, 네 페이지 순서와 처음/마지막 경계를 검사한다. 1280×720·2400×1080의 안전 영역·비중첩·세 카드 설명 폭을 확인한다.

기존249단계와 새3단계를 합쳐252개의 runtime test 성공을 확인한다. 실기기 플레이는 별도 확인이 필요하다. 명시적 APK 요청이 없으므로 APK를 생성하지 않으며 PR/main Godot 검사와 수동 APK 정책을 유지한다.
