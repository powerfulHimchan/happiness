# GP-126 · 마을 능력 도감·영구 발견

시간의 닻 마을의 네 번째 시설을 성장 도감으로 표시하고 기존 직업 도감과 새 능력 도감 탭을 연결한다. 9개 기본/강화 성장 카드와 4개 직업 전용 카드, 전체 13개 능력을 세 장씩 다섯 페이지로 조회한다. 미발견 능력도 효과·성향 점수·선행 조건·도전당 선택 제한을 확인할 수 있다. 효과와 조건은 실제 카드 원본을 사용한다. 생명 흡수 강화의 두 선택 관계도 기존 카드 설명으로 표시한다.

- 직접 선택한 능력만 체크섬 저널 `ability_discoveries.jsonl`에 영구 발견으로 기록한다. 도감 방문·페이지 이동·재추첨·조건에 막힌 오래된 선택은 발견을 지급하지 않는다. 발견은 시작 능력이나 보상·패시브를 지급하지 않는다.
- 능력 기록 저장에 성공한 뒤 실제 카드 효과를 적용한다. 실패 시 카드 화면과 전투 정지를 유지하고 효과·등급·성향을 적용하지 않는다. 같은 카드를 다시 선택해 기록을 재시도한다.
- 반복 발견은 추가 쓰기가 없다. 잘못된 ID/형식과 혼합 목록은 부분 기록하지 않으며 손상 줄·체크섬 불일치는 정상 발견을 지우지 않는다. 손상 끝줄 뒤 새 기록을 추가할 때 줄바꿈을 복구한다.
- 영구 발견과 현재 도전의 능력 등급을 구분한다. 사망·새 도전·도전 기록 삭제 후에도 발견은 유지하고 도전 능력은 정상 초기화한다. 기존 여섯 마을 시설 배치는 유지한다.
- 이전 버전의 정상 중간 저장에서 실제 보유 등급만 발견으로 복구한다. 복구 실패 시 이어하기·새 도전·중간 보상 확정을 보류해 기존 정상 저장을 보호한다. 별도 발견 파일을 사용해 보스 보상·직업 기록·메모리·설계도·도전 저장 스키마는 유지한다.

## 검증

`gp126_runtime_test.gd`의 seed/resume/finish/legacy-fail/legacy-resume 다섯 프로세스는 실제 처치 레벨업·기본/강화 카드 터치·기록 실패와 재선택, 두 화면비의 13개 능력 페이지·탭·버튼 안전 영역·터치 비중첩·원본 데이터·실제 그리기, 미발견 조회 독립성·현재 등급, 반복 발견·변조/손상 저널·직업 전용 카드 선택, 사망·새 도전·기록 삭제, 중간 저장/이어하기·이전 저장 복구 실패/성공과 실제 보스 완주를 검사한다. 기존 실행 검사 전체도 함께 실행한다.

Android: versionCode 53 / `0.0.53-gp126-ability-codex` / ARM64. 실기기 가독성·터치 확인은 별도 대기다.
