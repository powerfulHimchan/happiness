# GP-156 시간 수집 강화

**시간 수집**을 먼저 획득한 뒤 공용 성장 카드 **시간 수집 강화**를 도전당 한 번 선택한다. 선택 이후 실제 적 처치의 필살기 게이지가 5에서 8로 증가한다. 모래시계의 전투 획득 배율은 강화한 8에 적용하고 마지막에 반올림한다.

| 보유 상태 | 처치 게이지 |
| --- | --- |
| 시간 수집 | 5 |
| 시간 수집 + 모래시계 | 6 |
| 시간 수집 + 강화 | 8 |
| 시간 수집 + 강화 + 모래시계 | 10 |

선택을 일으킨 처치는 기존 획득량을 사용하고, 카드 선택 자체는 게이지를 지급하지 않는다. 검·활 실제 타격과 공격형 필살기, 일반·정예·보스 처치에 같은 수치를 적용한다. 기존 생명별 중복·위조·연습 표적·숨김·사망·도전 비활성 판정을 유지한다. 타격·정확 회피·경로 보상, 게이지 100 상한, 필살기 소비·지속·피해·회복과 발동 중 재충전은 기존 규칙을 유지한다. 시간의 여운·생명 흡수·처치 회복은 각각 독립적으로 적용한다.

선행 미충족과 최대 등급 이후 후보·확정을 거부한다. 영구 발견 기록 실패 시 등급·성향·효과를 적용하지 않고 같은 카드로 재시도한다. 27종 능력 도감에는 원본 효과·선행 조건·실제 발견·현재 등급을 표시한다. HUD와 현재 도전 정보는 유물까지 반영한 실제 처치 게이지 8/10을 사용한다. 두 화면비 조회와 3초 복귀는 게이지·체력·대기시간·파일을 바꾸지 않는다.

기존 `growth.ranks`에 강화 등급을 저장하고 런타임 효과만 복원한다. 새 저장 필드나 버전은 추가하지 않는다. 반복 이어하기는 강화·모래시계를 한 번만 반영하며 게이지·체력·회복약·양 무기 대기를 그대로 복원한다. 기존 시간 수집 저장은 5를 유지하며, 새 도전은 등급·효과·게이지를 초기화하고 영구 발견만 보존한다. 등급 타입·상한·선행 검증과 저장 실패 시 정상 파일 보존은 기존 검증 경로를 사용한다.

`gp156_runtime_test.gd`의 seed/resume/finish/legacy-seed/legacy/combat 여섯 별도 프로세스로 실제 처치 경험치·카드 터치·기록 실패 재시도, 발동 도중 선택, 5스테이지 완주·별도 프로세스 반복 복원·기존 3스테이지 완주, 모래시계 동시 복원·실제 검 타격/활 투사체/공용 및 네 직업 필살기·종류/생명/자격·100 상한, 조합과 도감/현재 도전/파일 보존을 검사한다. 기존 전체 Godot 회귀 검사와 PR/main 자동 검사에 포함한다. APK는 명시적 요청 시에만 생성하며 새 기능 실기기 플레이는 미확인이다.
