# 첫 전투 프로토타입 테스트 계획 v0.1

## 1. 목적

첫 설치 버전은 콘텐츠 양이 아니라 모바일 조작과 전투 판단을 검증한다. 테스트 결과는 직업과 성장 시스템 제작을 시작해도 되는지 판단하는 근거로 사용한다.

## 2. 테스트 단계

| 단계 | 대상 | 목적 |
|---|---|---|
| 개발자 기능 테스트 | 개발 중 매 빌드 | 상태 전이, 피해 수치와 저장 규칙 확인 |
| 기기 호환 테스트 | 기능 통합 후 | 화면 비율, 멀티터치, 성능과 백그라운드 복귀 확인 |
| 무설명 사용성 테스트 | 외부 5명 이상 | 조작 발견성과 3분 전투 흐름 확인 |
| 20분 안정성 테스트 | 외부 테스트 전 | 반복 플레이 중 입력 멈춤, 메모리 증가와 종료 확인 |

## 3. 기준 기기 범주

특정 모델명에 고정하지 않고 아래 조건을 만족하는 실제 기기를 확보한다.

| 구분 | 화면 조건 | 성능 조건 | 필수 여부 |
|---|---|---|---|
| A | 16:9 또는 유사 비율 | 중급 이상 | 필수 |
| B | 19.5:9 이상 긴 화면 | 중급 이상, 카메라 홀 포함 | 필수 |
| C | 작은 가로 폭 또는 큰 글자 설정 | 중급 이상 | 권장 |
| D | 비교적 낮은 성능 | 30 FPS 검증 대상 | 권장 |

## 4. 기능 테스트 케이스

### 입력과 이동

| ID | 시나리오 | 기대 결과 |
|---|---|---|

## 5. 성능 검사

| 지표 | 목표 | 측정 구간 |
|---|---:|---|
| 프레임 | 기준 기기 A·B에서 전투 중 60 FPS 유지 | 웨이브 2와 정예 전투 |
| 프레임 시간 급증 | 50 ms 초과 구간이 1분당 3회 이하 | 전체 전투 |
| 입력 지연 | 터치 후 다음 프레임에 명령 생성 | 테스트 모드 |
| 메모리 | 10회 반복 후 계속 증가하지 않음 | 재시작 반복 |
| 로딩 | 타이틀에서 전투 진입 3초 이내 | 앱 첫 실행 제외 |
| 발열 | 20분 플레이 중 운영체제 강제 성능 제한 없음 | 안정성 테스트 |

수치는 엔진 프로파일러와 화면 내 디버그 오버레이로 기록한다. 디버그 오버레이는 배포 빌드에서 숨긴다.

## 6. 무설명 사용성 테스트

### 참가 조건

- 5명 이상
- 이 문서를 읽지 않은 사람
- 모바일 액션 게임 경험자를 절반 이하로 구성
- 플레이 전에 버튼 기능을 설명하지 않음

### 진행

1. 기본 배치로 첫 플레이를 진행한다.
2. 관찰자는 질문에 답하지 않고 멈춤, 오입력과 시선 이동을 기록한다.
3. 결과 화면 후 조작 배치 기능을 안내하지 않고 스스로 찾는지 확인한다.
4. 원하는 배치로 조정한 뒤 두 번째 플레이를 진행한다.
5. 5분 이내 인터뷰를 진행한다.

### 관찰 지표

| 지표 | 통과 기준 |
|---|---:|
| 10초 안에 이동과 점프 성공 | 참가자의 80퍼센트 이상 |
| 90초 안에 무기 전환 자발적 사용 | 60퍼센트 이상 |
| 첫 플레이 완료 시간 | 평균 2분 40초–3분 40초 |
| 버튼을 찾기 위해 1초 이상 멈춘 횟수 | 첫 플레이 평균 3회 이하 |
| 배치 변경 후 오입력 감소 | 참가자의 60퍼센트 이상 |
| 다시 플레이 의향 | 60퍼센트 이상 |

### 인터뷰 질문

1. 어떤 행동이 자동이고 어떤 행동을 직접 해야 한다고 느꼈나요?
2. 검과 활을 바꿔야겠다고 생각한 순간이 있었나요?
3. 가장 누르기 어려웠거나 헷갈린 버튼은 무엇인가요?
4. 버튼을 옮긴 이유와 옮긴 뒤 좋아진 점은 무엇인가요?
5. 적의 공격을 미리 알아볼 수 있었나요?
6. 한 번 더 플레이하고 싶은 이유 또는 하고 싶지 않은 이유는 무엇인가요?

## 7. 결함 심각도

| 등급 | 기준 | 처리 |
|---|---|---|
| S0 | 저장 손상, 앱 실행 불가, 조작 불가 | 테스트 중단, 즉시 수정 |
| S1 | 사망·클리어 불가, 입력이 반복적으로 누락 | 외부 테스트 전 수정 |
| S2 | 특정 배치나 패턴에서 오동작 | 첫 테스트판 전 수정 권장 |
| S3 | 시각 어긋남, 문구 문제 | 기록 후 묶어서 수정 |

## 8. 다음 단계 진입 조건

아래 조건을 모두 만족하면 직업 발현과 레벨업 카드의 상세 기획 또는 구현으로 이동한다.

- S0과 S1 결함 0개
- 조작 관련 필수 테스트 케이스 전부 통과
- 기준 기기 A·B에서 완주 가능
- 무설명 사용성 테스트의 핵심 지표 6개 중 5개 이상 통과
- 자동 공격이 플레이를 빼앗는다는 평가가 참가자의 40퍼센트 미만

통과하지 못하면 콘텐츠를 추가하지 않고 버튼 배치, 공격 대상 선택, 적 경고와 스테이지 페이싱을 먼저 수정한다.
