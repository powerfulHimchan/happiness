# 전체 여정 보스 스테이지 3종

## 플레이 흐름

기존 지역 10스테이지의 순서와 저장 번호는 유지하고 별도 보스 전투를 사이에 삽입한다. 전체 여정(`journey`)의 새 도전에 적용하며, 3·5스테이지 단축 도전과 업데이트 전 중간 저장의 진행 규칙은 유지한다.

| 전투 | 진입 | 전용 전장 | 기본 체력 |
| --- | --- | --- | --- |
| 가면극장 단장 벨로 | 5스테이지 완료 후 필수 | 버려진 인형극장 | 1,200 |
| 시계룡 아우렐 | 해당 회차의 기존 마지막 전투·선택 이후, 엔딩 직전 필수 | 새벽의 경계 | 2,400 |
| 잊힌 시계공 이안 | 6스테이지 완료 후 조건부 선택 | 시계탑 아래 비밀 공방 | 1,800 |

첫 여정은 세라 선택과 연결하고, 행복의 심장이 열린 이후 여정은 심장 전투·승리 확인을 거친 뒤 아우렐로 연결한다. 아우렐을 처치하고 승리를 기록해야 기존 도착 이야기나 마지막 엔딩 선택으로 진행한다. 기존 수호기사·세라의 구출/파괴, 심장·엔딩 조건은 유지한다.

## 숨겨진 공방 조건

- 영구 업적 **첫 새벽**: 전체 여정 엔딩을 처음 기록하면 달성한다. 이전 버전에서 기록한 전체 여정 엔딩도 인정한다. 기존 업적 목록에 추가되어 총93종이다.
- 업적 달성 이후 시작한 새 여정에서 2·4·6스테이지의 시계 문양을 모두 활성화해야 한다. 진행 상태는 새 도전마다 초기화한다.
- 문양은 각 해당 스테이지의 전진 구간(월드 x=3,130 부근)에 나타난다. 빛나는 문양 가까이 약0.55초 머무르면 활성화되고, 효과음은 사용자 음량 설정을 따른다. HUD와 공방 화면에 획득 수를 표시한다.
- 6스테이지 완료 뒤 공방 진입/일반 경로를 선택한다. 조건을 충족하지 못하면 이유를 표시하고 진입을 비활성화한다. 뒤로가기는 일반 경로를 선택한다. 필수 보스는 뒤로가기로 건너뛸 수 없다.

## 전투와 보상

- 벨로: 실 내려찍기의 표시에서 이동, 인형 행진은 점프로 회피, 가면 전환 시 양옆 위험 영역을 피하며 공격한다. 체력50%부터 공격 순서와 경고 간격이 바뀐다. 처치 후 보유 무기의 영웅 등급 강화 또는 주 무기의 다른 스킬(첫 슬롯 교체) 중 하나를 고르고 최대 체력20%를 회복한다. 이미 모든 보상을 보유하면 휴식으로 진행할 수 있다.
- 아우렐: 낮은 꼬리, 예고 방향으로 발사되는 시간 구슬, 세 구역을 순서대로 덮는 숨결. 체력50%부터 두 공격을 연결하되 두 번째 공격도 별도로 예고한다. 공격 뒤 머리를 낮추며 모든 무기에 반격 기회를 제공한다.
- 이안: 위치를 바꾼 뒤 렌치 공격, 바닥 태엽, 플레이어가 들고 있던 무기 계열을 흉내 내는 잔상. 검·활·주먹·지팡이·장봉·방패 모두 사용할 수 있다.
- 세 보스 모두 경고→공격→빈틈, 체력50% 전환, 실제 피해·회피 무적·동일 공격 중복 차단을 사용한다. 빈틈에는 모든 계열 피해가125%다. 아레나 내 밀치기 범위를 제한하고, 전투 종료 시 투사체를 제거한다.
- 이안 처치 후 공방 기록과 **시계공의 회중시계**를 영구 해금한다. 현재 유물을 유지하거나 회중시계를 장착할 수 있다. 장착 효과는 기본 공격 속도+10%와 스킬 대기시간-15%다. 이후 도전의 기존 유물 선택에도 후보로 추가된다. 공방의 기억은 기억 수첩의 여행 기록에서 읽는다. 일반 엔딩의 필수 조건은 아니다.
- 기획의60~120초는 전투 시간 목표이며 제한 시간이 아니다. 실기기 난이도·목표 시간은 추가 플레이 조정 대상이다.

## 저장과 구현

- `JourneyBossDirector`: 입장·전투·보상·선택 경로·엔딩 연결과 문양 수집을 관리한다.
- `JourneyBossProgress`: 선택적 `journey_bosses` 체크포인트 필드의 상태·문양·업적 해금 스냅샷·보스별 전투 시간을 검증한다. JSON 숫자가 실수로 복원되어도 문양의 의미를 일관되게 비교한다.
- `JourneyBoss`: 전용 보스 원화, 실제 피격 판정, 두 페이즈와 세 가지 패턴을 실행한다. 기존 타깃·플레이어 피해·무기·게이지 시스템을 사용한다.
- `JourneyBossView`: 진입·선택·보상·승리 화면을 그린다. 전투에는 별도 전장과 예고 도형을 사용한다.
- 임시 저장 파일을 flush·close한 뒤 현재 파일로 교체한다. 진입 전과 처치 후 저장하고, 저장 실패 시 전투·다음 단계 진행을 차단한다. 보상 확정 저장 실패는 장비·스킬·체력·유물을 되돌려 재시도한다. 보상 재터치로 중복 지급하지 않는다.
- 전투 중 종료하면 진입 전 저장 상태에서 다시 시작한다. 입장·보상 화면은 해당 화면으로 복원한다. 완료한 보스는 다시 지급하지 않는다. 추가 보스 전투 시간은 전체 여정 시간에 합산한다.
- 이전 저장에는 새 필드가 없으므로 기존 여정 그대로 이어진다. 새 도전부터 보스 확장을 활성화한다. 회귀 검사용 기존 장면은 확장을 비활성화하여 과거 규칙과 저장 호환을 별도로 검사한다.
- 원화·전장3종씩과 문양·유물 아이콘은 저장소의 자체 SVG다. `scripts/build_journey_boss_art.py`로 재생성할 수 있다.
