# GP-113 · 무기 설계도 해금과 태엽 무기

웃는 태엽 기사를 파괴하면 **태엽 검·태엽 활 설계도 두 종**을 영구 해금한다. 다음 도전의 정예 무기 보상에 기존 검·활과 함께 추가한다. 시작 장비는 기존 일반 검·활이며 설계도가 있다고 특수 무기를 자동 장착하지 않는다. 무기 보상에서 한 가지를 선택하거나 현재 장비를 유지한다. 현재 검·활의 기본 공격과 두 스킬을 재사용한다.

| 무기/등급 | 무기 피해 보너스 | 고유 효과 | 보조 고유 효과 |
|---|---|---|---|
| 기본 희귀 검·활 | +15% | +10% | +5% |
| 태엽 희귀 검·활 | +10% | +25% | +12.5% |
| 기본 영웅 검·활 | +30% | +20% | +10% |
| 태엽 영웅 검·활 | +20% | +35% | +17.5% |

검의 고유 효과는 스킬, 활의 고유 효과는 기본 공격에 적용한다. 일반 피해를 줄이고 해당 공격의 효과를 강화하는 선택이다. 주 무기의 등급 보너스·해당 고유 효과와 보조 무기의 해당 고유 효과 50%를 먼저 더한다. 성장 카드·일회 핵·영구 기억은 기존 계산을 유지한다. 필살기에 장비 효과를 더하지 않는다. 피해 계산 마지막에 정수로 반올림한다. 고유 효과가 누적되거나 전투 버튼·대기시간이 추가되지 않는다.

파괴 승리·결과·메인에서 설계도 해금을 표시한다. 해금 전 두 보상, 해금 후 네 보상을 제공하며 카드에 성능·현재 무기를 표시한다. 교체 시 선택한 무기 종류의 설계와 등급만 변경하고 주 무기 선택·검/활 스킬 대기시간을 유지한다. 같은 등급의 다른 설계로 교체할 수 있으나 등급 하향·같은 무기 재지급·한 정예의 중복 확정은 거부한다.

## 저장과 호환

기존 보상 저널의 정상 파괴 이벤트에서 설계도 해금을 복원한다. 이전 버전에서 소비한 파괴 보상도 포함하며 일회 핵을 다시 지급하지 않는다. 반복 파괴·도전 실패·테스트 기록 초기화는 해금 수치에 영향을 주지 않는다. 파괴 일회 보상을 건너뛰어도 영구 설계도는 사용할 수 있으며, 위험 경로의 일회 핵 적용 조건은 기존대로 유지한다.

완료 지점 저장의 `weapons.blueprints`에 검·활의 선택을 보존한다. 이어하기는 해당 도전의 설계를 복원하고, 필드가 없는 이전 저장은 기존 검·활로 해석한다. 미등록·다른 종류·손상 타입·일반 등급의 특수 설계를 거부한다. 저장 실패는 등급·설계·확정 상태를 함께 복구하며 이전 저장을 유지한다. 새 도전에서는 등급과 장착 설계를 초기화하고 영구 해금만 남긴다.

## 검증 범위

GP-113의 네 별도 프로세스 검사: 잠금·실제 파괴 완주 해금, 이전 소비 저널·중복 해금·기록 초기화, 네 보상 터치와 두 화면 비율의 안전 영역·글자 너비, 저장 실패 복구·쿨다운 보존, 검 타격·활 투사체의 실제 피해, 고유·보조 소수 효과·필살기 제외, 스테이지 유지·이어하기·반대 보스 선택 완주·결과·새 도전, 설계 필드 없는 이전 저장 복원을 확인한다. 기존 CP-206~406·GP-101~112도 실행한다.

자동 검사와 Android 실기기 플레이는 구분한다. 실기기에서는 파괴 후 다음 도전의 네 보상 카드, 검/활 전환과 체감 피해, 앱 재실행 이어하기를 확인해야 한다. 개발 APK는 빌드마다 서명이 달라 기존 앱 삭제 후 설치가 필요할 수 있으며, 삭제 시 진행·영구 해금도 삭제된다. 추가 무기 종류·별도 스킬·전설 등급·대장간 승급·마을은 후속 범위다.
