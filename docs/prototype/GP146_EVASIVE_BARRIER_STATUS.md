# GP-146 회피 방벽

마력 방벽을 먼저 얻은 뒤 공용 성장 카드 **회피 방벽**을 도전당 한 번 선택한다. 지상 회피의 무적 구간에 적의 유효한 공격이 닿아 정확한 회피로 판정되면 방벽5를 회복한다. 회피 입력만으로 회복하지 않는다.

| 조건 | 동작 |
| --- | --- |
| 기본 방벽 | 최대20까지5 회복 |
| 견고한 방벽 | 최대30까지5 회복 |
| 같은 회피의 여러 적/투사체 | 방벽 회복은 한 번 |
| 가득 찬 상태에서 정확 회피 | 현재 회피의 회복 기회 소비 |
| 무적 종료 후 타격 | 원래 피해와 방벽 흡수 적용 |
| 공중 대시·피격/부활 보호 | 회피 방벽 보상 없음 |

기존 일반 적 근접·씨앗 투사체·정예 돌진/충격파·보스 공격의 정확한 회피 신호를 사용한다. 실제 지상 회피 동작과 생존·진행 중 전투·화면 상태를 함께 확인한다. 같은 회피의 재전달 신호나 중복 공격으로 추가 회복하지 않으며, 다음 회피에서 다시 받을 수 있다. 기존 정확한 회피 게이지12와 직업 성향 계산은 유지한다. 체력·회복약·스킬 재사용·지상 회피0.24초/무적0.18초/재사용0.45초·민첩한 회피0.36초도 유지한다.

## 성장·조회·저장

선행 미충족·최대 등급 이후 후보/재추첨/확정을 차단한다. 실제 선택의 영구 발견 기록에 성공해야 등급·성향을 적용하고 실패 시 같은 카드로 재시도한다. 선택 자체는 방벽을 즉시 회복하지 않는다.

23능력 도감에 원본 효과·선행·현재 등급·영구 발견을 표시한다. 전투 HUD의 기존 방벽 원호와 잔량은 즉시 갱신하고 현재 도전 상태의 생존 카드에 정확 회피+5를 표시한다. 조회·백그라운드 복귀·3초 카운트다운·단계 종료·전투 환경 정지·사망 후 신호는 보상을 지급하지 않는다.

기존 growth.ranks와 player.barrier_health를 사용해 저장 형식을 유지한다. 반복 이어하기는 잔량·체력·게이지·양 무기 대기를 그대로 복원하고 무료 충전하지 않는다. 새 도전은 능력을 초기화하고 영구 발견만 유지한다. 이전 마력 방벽 저장에도 회피 방벽을 소급 지급하지 않는다. 잘못된 등급·선행 없는 저장은 거부한다.
