그림은 모두 저장소 안의 SVG와 Godot 그리기로 구성한다. 가격·재화·상품 후보·구매/저장·버튼 터치 영역은 기존 규칙을 유지한다. 새 표시 계층인 `SupplyShopArt`는 입력 이벤트와 게임 상태를 수정하지 않는다. 사용한 파일은 [그래픽 설명](../../game/assets/supplies/README.md)을 참고한다.

## 확인 범위

기존 상점 테스트에서22개 상품 × 두 주인공 × 구매/별도 프로세스 복원/다음 스테이지132사례와, 여섯 계열 × 두 주인공의 규칙/이전 저장24사례를 실행한다. 실제 구매·재입고 뒤의 품절/잔액 부족 상태와 슬롯 선택을 렌더링하고, 그리기 전후 재화·체력·기술·장비·저장 파일이 변하지 않는지 확인한다.

1280×720의 두 주인공·여섯 계열·네 페이지48화면, 960×540 및1600×720의 기술 선택/품절/잔액 부족/재입고/전투 지갑/경로 선택12화면을 확인한다. Android 리소스 팩 내보내기와 부팅도 검사한다. APK는 생성하지 않는다. Android 실기기의 시인성과 터치 감각은 별도 확인이 필요하다.

### 2026-10-21 검증 결과

Godot4.7.2에서 상점156사례와 기존 외형/애니메이션/전투/성장55사례, 총211개 실행 검사를 통과했다. 원본 프로젝트의60화면을 렌더링하고 각 해상도의 상품·슬롯·지갑·상태 표시를 확인했다. Android 리소스 팩 내보내기·부팅·상점 규칙 검사와 팩 안의 기술/품절2화면 렌더링도 통과했다. 정적 프로젝트 검사·셸 문법·diff 공백 검사를 통과했다. 전체 과거 CI를 모두 로컬 실행한 결과는 아니며, main push 후 기존 CI가 실행된다.
