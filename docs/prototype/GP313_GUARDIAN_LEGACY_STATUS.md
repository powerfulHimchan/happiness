# GP-313 · 수호기사 영구 동행·수호 무기 설계도

## 동작

- 전체 여정9스테이지 수호기사 구출/파괴 선택을 영구 해금에 연결한다. 현재 여정의 즉시 회복·전투 배율은 GP-312 규칙을 유지한다.
- 구출: 이후 **새 도전**부터 자동 동행한다. 3/5스테이지·지역 순회·전체 여정에서 스테이지마다 마지막 정예 진입 시 기본30피해를 한 번 준다. 기존 태엽 기사 조력20과 독립적이며 공존하면50이다. 현재 진행 중이거나 동행 필드가 없는 이전 저장에는 소급 적용하지 않는다.
- 파괴: 수호 검·수호 활 설계도를 영구 해금한다. 정예 무기 보상에서 실제 선택하고 기존 무기 도감에서 잠금 조건·성능·장착 상태를 확인한다. 희귀/영웅 무기 피해는15/25%, 검 스킬·활 기본 공격 고유 보너스는20/30%, 보조 고유 효과는 절반이다. 필살기는 장비 효과에서 제외한다.
- 기존 태엽 검·활 및 마지막 태엽 기사 기억/일회 보상은 독립적으로 유지한다. 두 성문 선택을 다른 도전에서 달성하면 동행과 설계도를 함께 보유한다.
- 시작 준비·메인에 동행/4개 설계도 해금을 표시하고 현재 도전 정보에 동행·사용 스테이지 수를 표시한다. 수호기사 이동 AI·공격 애니메이션은 포함하지 않는 정예전 지원이다.

## 저장·오류 복구

- 기존 버전1 체크포인트와 체크섬 저널 형식을 유지한다. 성문 선택과 즉시 보상을 체크포인트에 먼저 확정한 후 별도 `guardian_reward` 이벤트로 영구 해금을 기록한다. 원본 도전ID의 중복은 쓰지 않고 반대 선택은 거부한다.
- 체크포인트 실패는 즉시 효과·선택을 되돌리고 영구 해금도 주지 않는다. 선택 저장 성공 후 해금 저널만 실패하면 확정 선택을 보존하고 다음 보상·다음 구간·새 도전 진행을 막는다. 보상 재시도/이어하기에서 다시 기록하며 회복을 재지급하지 않는다.
- 동행은 도전ID와 사용 스테이지 배열을 저장한다. 실제 지원 전에 소비 저널을 기록한다. 실패하면 타격/소비하지 않아 다음 지표 갱신에 재시도한다. 이전 체크포인트로 돌아가도 독립 저널의 이후 사용을 합쳐 재사용을 막는다.
- 동행 상태의 타입·도전ID·중복/미래/범위 밖·비정수 스테이지를 거부한다. 완료/사망 시 현재 동행 상태는 정리하지만 영구 해금은 유지한다. 필드 없는 이전 저장은 동행 없음으로 복원한다.

## 검증

- GP-313 실행 검사30개: 로안/루미×검/활×구출/파괴의 실제 성문 선택→새 도전→1/2단계 별도 프로세스 반복 복원→3단계 완주24개, 저장 실패/이전 저장·검증4개, 저널/네 모드2개.
- 수호 무기 실제 카드/페이지 입력·희귀/영웅 장착·피해 합산·두 화면비 안전 영역, 두 조력자 합산·중복 타격 차단, 독립 해금/최종 보상·손상 저널·이전 백업 사용 방지, 조회 불변을 확인한다.
- 전체 실행 검사859개와 Android 리소스 export/패키지 부팅을 PR/main에서 실행한다. APK 빌드는 실행하지 않는다.
- Android 실기기 터치·장시간 플레이·밸런스 검증은 별도다. 세라·행복의 심장·정식 엔딩은 후속 범위다.
