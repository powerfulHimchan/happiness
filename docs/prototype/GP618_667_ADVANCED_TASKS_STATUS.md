# GP-618–667 · 복합 과제42종과 게시판 개선8개

기존30개 과제를 유지하고42개를 추가해 전체72개가 된다. 새 과제는 모든 조건을 동시에 충족해야 보급전5~15전을 수령한다. 기술 사용 횟수 대신 실제 적중·피해를 사용하며 휴대 무기별로 집계한다. 전투 중에는 수령할 수 없고, 구간 완료·무기 보상을 확정한 뒤 보급소 게시판에서 직접 받는다. 최종 구간에는 보급소가 없으므로 구간 목표는 최대9구간까지다.

## 저장과 보상

- 기존 체크포인트 카운터와 수령 장부를 그대로 사용한다. 신규 영구 보너스는 없으며 새 도전은 과제와 보급전을 초기화한다. 이전 과제30개의 ID·보상·수령 이력을 유지한다.
- 보상 장부 저장에 성공해야 수령이 확정된다. 실패하면 잔액·장부를 되돌리고 같은 과제를 재시도할 수 있다. 이어하기와 반복 입력은 이미 수령한 과제에 추가 지급하지 않는다.
- 과제 마커가 없는 이전 보급소 저장에는 과제를 소급 활성화하지 않는다. 마커가 있는 기존 저장은 현재 카운터로 신규 과제를 판정한다.
- 수령 장부 상한은9휴식×11개 상점 행동+72과제로 확장한다. 알 수 없는 ID·중복 수령·잘못된 잔액·미충족 조건·미래 구간 수령을 거부한다.
- 조회·필터·분류·정렬·페이지 이동은 저장하지 않는다. 화면 재진입은 전체·목록순으로 시작한다.

## 검증

- Godot4.7.2의 전용 검사에서42종의 모든 조건 충족/개별 조건 미달, 중복 보상, 이전 저장 비활성, 분류·필터·세 정렬·요약 합계를 확인했다.
- 42과제 × 두 주인공 × 수령/별도 프로세스 복원/다음 구간 이동의252사례를 통과했다. 실제 타격·성장 카드·무기 승급·지역 이동, 저장 실패 롤백·중복 방지·변조 거부·새 도전 초기화를 포함한다.
- 세 화면비1280×720·1600×720·1280×800에서 필터5종·분류5종·정렬4종의 실제 터치, 페이지 경계·안전 영역·터치 영역 비중첩·조회 중 저장 보존을 검사했다. 최종 문구/안내 수정 후 조건 판정·수령/재실행/다음 구간·터치 조작을 다시 통과했다.
- 실제 렌더러로12페이지 × 세 화면비의36개 화면을 생성해 한글·복합 조건·진행률·안내·버튼 배치를 확인했다.
- `scripts/check_godot_project.sh`의 전체 통합 검사를8개로 분할 실행했고 모두 종료 코드0으로 통과했다. 기존 전투·직업·보스·이야기·원정·도감·저장/이어하기 및 Android 리소스 팩 내보내기/부팅을 포함한다. 최종 UI 안내와 요약 문구는 별도 전용 검사와36개 렌더링으로 재검증했다.
- Android 실기기 플레이와 난이도 평가는 미확인이다. APK는 생성하지 않았다.
