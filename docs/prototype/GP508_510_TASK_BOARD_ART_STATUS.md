`TaskBoardArt`는 조회/그리기만 담당한다. 과제 조건·보상·수령 트랜잭션·터치 영역은 기존 모델과 입력 처리를 사용한다. 실제 상태와 저장 파일을 변경하지 않으며 배경/문양은 저장소 안의SVG로 제공한다.

`gp508_510_art_runtime_test.gd`는 실제 과제 획득 화면에서30개 문양의 연결·카드 내부 안전 영역·제목/도장/보상 겹침·그리기 전후 전투/장부/체크포인트 무변경을 검사한다. 1280×720,1600×720,2400×1080에서 수령 가능/완료/저장 실패/빈 목록/무기 수련/성장/상점 목표21화면과 진행 불가 과제 선택2화면, 총23화면을 렌더링한다.
