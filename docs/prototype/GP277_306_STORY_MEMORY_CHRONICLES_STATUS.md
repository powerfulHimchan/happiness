# GP-277–306 · 여행 이야기·기억 조각·되감기/여행 기록

## 검증

신규35개 실행 단계는 두 주인공×검/활의 실제 설정→프롤로그→1/2스테이지 장면 별도 복원→보스 장면/선택→결과/영구 기록 재실행을 검사한다. 로안은 일반3단계, 루미는 지역 순회5단계로 네 지역과 모든 기록 종류를 확인한다. 장면 확인/건너뛰기·직업 발현·앱 복귀·두 화면비의 버튼/문장 배치도 검사한다.

조각·장면 확인·되감기·여행 기록 쓰기 실패, 완료 저장 후 재실행 회수, 이전 이야기 없는 저장, 순서가 다른 지역/반복 길, 잘못된 이야기 필드30가지·잘못된 저널 줄, 수첩 조회의 파일/도전 상태 보존을 검사한다. 기존606개+신규35개, 총641개 실행 단계와 Android 리소스 내보내기·패키지 부팅을 로컬·PR·main에서 확인한다.

## 확인 범위

이야기 모드는 새 도전에서 선택하며 별도 영구 선호 설정은 만들지 않는다. 첫 완료 전 프롤로그/전투 중에는 기존처럼 중간 저장이 없고 스테이지 완료 장면부터 이어할 수 있다. 기억 조각과 여행 기록은 수집 콘텐츠이며 장착형 영구 기억 능력2종과 별개다. 이번 기록4종은 현재 태엽 기사 여행의 마무리다. 행복의 나라10스테이지·세라·정식 도착/귀환/해방/새벽 엔딩은 후속 범위다.

되감기 기록 쓰기가 실패하고 앱까지 종료하면 메모리의 미확정 사망을 복구할 수 없다. 화면의 저장 오류에서 재시도해야 하며 실패한 기록을 저장된 것으로 표시하지 않는다. 새 원화/음성·실기기 배치·조작감/성능은 별도 확인이 필요하다. APK는 명시적 요청 시에만 만든다.
