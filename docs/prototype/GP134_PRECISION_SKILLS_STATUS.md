# GP-134 · 정밀 찌르기·이중 관통

정예 휴식의 스킬 교체 보상에 검 정밀 찌르기와 활 이중 관통을 추가한다. 시작 장착은 유지하며 검·활 각 여섯 기술 중 미보유 후보를 네 번 순환한다. 후보 조회는 보상을 소비하지 않는다. 장착·대기시간·시계추 적용을 대장간 12종 스킬 도감에 표시한다.

| 기술 | 동작 / 발동 | 기본 피해 / 범위 | 재사용 | 조작·취소 |
| --- | --- | --- | --- | --- |
| 정밀 찌르기 | 0.55초 / 0.18초 한 번 | 55 / 정면 3m·상하 0.45m | 7초, 시계추 5.6초 | 이동·방향 고정, 0.22초부터 회피 |
| 이중 관통 | 0.55초 / 0.16·0.36초 | 화살별 26 / 각 최대 2개체 | 8초, 시계추 6.4초 | 이동 가능·방향 고정, 0.20초부터 회피 |

검 기존 일섬·삼연의 상하 0.9m는 기본값으로 유지하고 실제 판정과 범위 표시 모두 기술 원본의 높이를 사용한다. 활 두 발은 서로 다른 공격 ID와 개별 관통 한도를 사용한다. 동일 화살은 같은 대상에 중복 피해를 주지 않으며 서로 다른 화살은 같은 두 대상을 다시 맞힐 수 있다. 피격·무기 전환은 남은 타격/발사를 취소하고 대기시간을 보존한다. 이미 발사된 화살은 기존과 같이 계속 비행한다.

교체 성공 후 해당 슬롯을 기본 대기시간으로 잠그며 중간 저장에 장착 ID와 잔량을 유지한다. 저장 실패는 장착·잔량·보상 소비를 롤백한다. 잘못된 무기·중복 슬롯 저장은 거부하고 기존 저장은 기본 장착으로 호환한다. 새 도전은 초기 장착으로 돌아간다.

`gp134_runtime_test.gd` seed/resume/finish/legacy/combat 다섯 별도 프로세스를 기존 전체 검사에 추가한다. 실제 정예 보상·모바일 스킬 버튼·교체 실패 재시도·변조 거부·두 슬롯 재시작·보스 완주·기존 저장·두 화면비 도감 읽기 전용 동작을 검증한다. 실제 피해 처리에서 좌우·상하·거리 경계 및 경계 밖·첫 타격 전/후·재사용·피격 중단, 화살별 관통·중복 방지·고유 ID·둘째 발사 취소·보조 무기 시계추 감소를 확인한다.
