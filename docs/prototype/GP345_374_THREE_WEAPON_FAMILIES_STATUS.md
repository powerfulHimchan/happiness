## 전투와 행동 수명

지팡이 마법탄·화염구·얼음창은 이동 선분과 대상 몸체 중심을 검사한다. 투사체는 시전 방향을 유지하며 기본 게이지4/스킬8과 성향·흡수·피드백을 실제 피해 적용 뒤 반영한다. 피해에 staff와 magic/fire/ice/lightning 태그를 사용한다. 지속 화상·속성 내성·빙결은 후속 범위다. 낙뢰는 준비 원과 수직 섬광, 마법탄은 색별 구체로 표시한다.

장봉 밀치기와 방패 기절은 살아 있는 일반 적의 유효한 피해에만 적용한다. 정예·보스와 연습 표적에는 강제 이동/기절을 주지 않는다. 밀치기는 순찰 중심도 옮기고x100~4900에 제한한다. 도약 중 슬라임은 공격을 중단하고 중력으로 착지한다. 기절 시간은 적 시간 배율을 따르며 새 웨이브에서 초기화한다. 장봉은 봉과 원호, 방패는 외곽/방어 푸른 빛/응수 준비 금빛으로 표시한다.

방패는 전방 enemy 피해만 줄인다. 함정·낙하·후방은 그대로 적용한다. 핵·유물·방패를 곱한 뒤 한 번만 반올림하고 원본 DamageEvent를 바꾸지 않는다. 방벽은 감소 후 피해만 흡수하며 완전 흡수도 정상 방어 성공이다. 중복·무적·잘못된 이벤트·사망 차단은 응수를 준비하지 않는다. 방어 준비와 반격 강화는 같은 행동에만 속하며 회피·전환·단계 이동·낙하·사망·부활·재시작 때 정리한다.

갑옷 멧돼지는 장봉/방패 근접60%·기절175%, 지팡이는 물리 갑옷 보정을 받지 않는다. 수호기사 방패 정면65%/빈틈125%/기절150%, 심장 핵 노출150%, 세라 빈틈125%를 각 새 무기에도 연결한다.

## 성장과 직업

성향은 기존 능력70%/무기20%/특수10% 가중치와 상한을 따른다. 지팡이=마력/원소, 장봉=집중/조화, 방패=방어/신념이다. 기본 능력은 피해20%p와 체력20/회복30을 반복 선택할 수 있으며 선행 피해 능력 뒤 분기 카드30%p를 한 번 선택한다.

화염현자/천공봉승/성벽기사는 전용 공격25%p와 체력20/회복40, 빙결술사/시간방랑자/룬 수호자는 공격20%p와 체력30/회복40을 각각1회 제공한다. 전용 공격 뒤 공격 특화30%p 또는 전용 체력 뒤 생존 특화 체력40/회복50 중 하나만 선택한다. 기본 능력을 계승하며 성장·직업 피해는 기본/스킬/공격형 필살기에 적용한다. 최대 체력 증가와 실제 회복을 분리해 원정2 이상 회복75%를 공유한다.

각 기본·상위 직업은 필살기4종 중 하나를 선택한다. 세 계열에 총36개를 추가한다. 기본형은 주변60 / 회복40 / 전방75 / 주변25+회복25, 공격 진화형은 주변130 / 주변40+회복45 / 전방150 / 회복65, 생존 진화형은 주변100 / 주변30+회복60 / 전방130 / 회복80이다. 게이지·사용 중인 이전 필살기와 감속 종료·원정 제한을 보존한다.

## 도감·저장

기존 도감 순서 뒤 무기9개·스킬9개를 붙여 무기50/스킬46개다. 기본 직업은6장의 단일 행에서 능력과 필살기를 분리해 표시하며, 상위 직업은2개씩6페이지에서 현재 성향·분기·단계를 비교한다. 시설의 발견 직업 총수도18개로 표시한다. 새 도전 선택, 현재 빌드와 결과는 실제 휴대 두 계열만 표시한다.

버전1 선택 필드player.staff/polearm/shield를 사용한다. 없는 이전 저장은0이다. 저장 검증은 카드/직업 원본으로 보너스와 체력을 재계산하고 세 무기·다른 계열 스킬·조작한 성향/보너스/필살기를 거부한다. 이어하기는 패시브/회복을 다시 지급하지 않는다. 재사용 대기와 적중/피해 집계는 복원하되 투사체·밀치기·방어/반격·기절의 일시 상태는 저장하지 않는다.

## 검증 범위

새 실행 검사는 계열별 두 주인공×다섯 보조×두 진화×seed/resume/legacy/late80개와 실제 전투10개, 합계270개를 CI 스크립트에 등록한다. 실제 발사체/범위/좌향/관통/위치 고정·방어·반격·밀침/기절·장비/흡수·36필살기·카드 발현/진화·특화·저장 실패 복구·변조 거부·반복 복원을 검사한다. 기존 기능의 도감 수 검사는 확장된 원본 수와 실제 표시 행에 맞춘다.

Android 실제 기기 조작·성능·체감 밸런스, 전용 인체 공격 스프라이트, 밀치기의 발판/벽 충돌은 후속 검증 대상이다. 이번 요청에서는 로컬 커밋까지만 수행하며 APK를 만들지 않는다.
