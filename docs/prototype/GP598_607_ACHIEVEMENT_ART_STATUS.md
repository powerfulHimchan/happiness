기존 SVG 그래픽 체계에 맞춘 원본 벡터 에셋 10개다. 업적 50개의 분류 10개를 문양 9개로 연결한다. 기본·상위 직업은 방패를 공유하고 상위 직업에는 별 장식을 추가한다. 미달성·달성·칭호 장착은 자물쇠·체크·왕관과 기존 상태 문구를 함께 표시한다.

`AchievementArt`는 그리기와 영역 계산만 담당한다. 기존 업적 카드의 터치 영역·페이지·탭·칭호 선택 경로를 사용한다. 제목·분류·상태·조건·보상·진행률을 분리하며 업적 조건·저장 스키마·전투 수치를 변경하지 않는다. 다른 마을 화면은 기존 표시를 사용한다.

## 검증

- Godot 4.7.2 에셋 가져오기 및 10개 SVG XML 검사 통과.
- 기존 업적 검사에 50개 문양 연결과 카드 내부 영역·겹침 검증을 추가했다. 3개 화면 크기의 실제 탭/페이지/칭호 선택·저장 무변경 검사를 포함한 seed 단계 6,985개 단언과 catalog 단계 513개 단언이 통과했다.
- 실제 OpenGL 렌더링 63장: 1280×720·1600×720·1280×800의 전체17페이지·빈 진행/부분 달성/오류 상태·메인 칭호 표시. 모든 분류와 마지막 부분 페이지, 잠금·장착 표시의 배치를 시각 확인했다.
- 기존 전체 Godot 실행 검사 16개 묶음이 모두 종료 코드0으로 통과했다. 각 묶음에서 Android 리소스 팩 내보내기와 내보낸 게임 부팅도 통과했다. 검사한 16개 사본의 변경 게임 소스·에셋·검사 스크립트가 최종 소스와 동일함을 확인했다.

Android 실기기 플레이는 수행하지 않았다. APK는 생성하지 않는다.
