# GP-314 · 중심부 세라 첫 재회·여왕의 시계 장식

## 동작

- 이야기를 켠 전체 여정10스테이지에서 마지막 태엽 기사를 쓰러뜨리면 `시계탑 아래의 재회`를 표시한다. 기존 완료 장면 ID `stage:10`을 사용한다. 로안/루미 이름을 실제 선택으로 표시하고 세라 전용 SVG 초상·인물 이름·3페이지 대사를 제공한다.
- 주인공은 어린 시절 가장 친했던 친구의 목소리를 알아본다. 세라는 약속은 기억하지만 상대의 얼굴은 떠올리지 못한다. 새벽시계와 여왕의 장식의 같은 문양이 단서다. 성문에서 수호기사를 구출/파괴했는지에 따라 마지막 대사가 달라지고, 새 도전 시작 때 이미 장식을 발견했다면 반복 만남 대사로 바뀐다.
- 장면 중 전투·대기시간을 정지한다. 끝까지 읽거나 건너뛰면 새 기억 조각 `queen_pendant`를 기록하고 기존 태엽 기사 구출/파괴 선택으로 돌아간다. 세라 구출/파괴 선택을 대신하는 장면이 아니다.
- 기억 조각은 기존8종과 새1종의9종이다. 기억 수첩 세 번째 페이지에 발견/미발견 조건·내용을 표시하며, 결과·현재 도전 정보·수첩의 총수를 콘텐츠 목록에서 계산한다. 일반3/5단계·지역 순회·이야기 꺼짐은 기존 이야기/전투 진행을 유지한다.

## 저장·호환

- 버전1 체크포인트·저널·기존 여행 기록 ID를 유지한다. 재회 확인 전 종료하면 같은 장면 첫 페이지부터 복원한다. 확인 후 재실행하면 장면 재표시 없이 기존 마지막 기사 선택 대기로 복원한다. 체력·게이지·스킬 잔량·성문 선택을 보존한다.
- 기억 쓰기 실패는 장면 확인 대기를 유지한다. 기억 쓰기 성공 후 확인 체크포인트만 실패하면 대기를 되돌리고 재시도한다. 저널은 발견한 ID를 다시 기록하지 않아 부분 성공에서도 중복되지 않는다. 페이지 이동·비교·수첩 조회는 저장을 바꾸지 않는다.
- 이전8종 저장의 중심부 장면이 대기 중이면 새 재회를 표시한다. 이전 버전에서 이미 장면을 확인한 저장에는 재회를 강제 재표시하지 않는다. 이전 도전의 완료 기록·영구 해금·구출/파괴 보상을 수정하지 않는다.
