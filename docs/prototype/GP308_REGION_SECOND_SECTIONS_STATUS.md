# GP-308 · 네 지역 전용 두 번째 구간

전체 여정의 2·4·6·8단계에서 같은 지역의 전용 두 번째 구간을 진행한다. 홀수 단계, 일반3/5단계, 지역 순회5단계, 성문9·중심부10은 기존 배치를 유지한다.

| 지역 | 두 번째 구간 | 지형·전투 차이 |
| --- | --- | --- |
| 바람 | 바람꽃 능선 | 높낮이가 다른 고정 발판5개, 양쪽 지상 적과 공중 정령 |
| 숲 | 수관 오솔길 | 횡단 발판5개 중 덩굴 이동 발판2개, 둘째 전투의 높은 발판1개 |
| 유적 | 엇갈린 시계 회랑 | 시간에 따라 멈추고 이동하는 발판2개, 첫/둘째 전투의 시간 함정 위치 변경 |
| 축제 | 기계 정원 | 회전·승강 발판의 진폭 변경, 중앙/출구 고정 쉼터 |

첫 웨이브는 지상·원거리·공중 적3종을 함께 배치하며 둘째 웨이브도 지역별 위치를 사용한다. 기존 지역의 적 AI와 정예를 재사용하고 새 보스 패턴은 추가하지 않는다. 구간 선택 카드·HUD·실행 지표에 전용 이름과 이동 목표를 표시한다.

구간은 저장된 모드·단계 번호·지역에서 결정한다. 체크포인트 버전1을 유지하며 새 필수 필드를 추가하지 않는다. 완료 지점 복원 시 같은 지형을 운동 위상0으로 재생성한다. 보상·장비·회복약·유물·지역 순서·이야기 저장은 기존 구조를 유지한다. 마을/도전 정보 화면에서 발판 시간이 멈추고, 다음 지역 시작 시 전용 몸체를 제거한다.

## 검증

네 지역×6단계의 신규24개 자동 실행 검사: 실제 준비 입력→첫 구간 완료→전용 카드 선택, 첫/둘째 웨이브3종 배치, 실제 무기/유물 보상, 별도 프로세스 반복 이어하기, 발판 충돌/표시 좌표와 운동 주기, 탑승자 운반, 기본 점프 횡단, 출구 안전 지점 낙하 복귀, 조회/마을 정지와 저장 불변, 함정 경고→피해12 단일 적용, 기존 모드의 첫 지형 복원을 검사한다. 기본 점프 검사는 2단 점프·공중 대시 없이 수행한다.

전체 검사 스크립트는 기존695개와 신규24개를 합친719개 실행 단계, Android 리소스 내보내기와 변환된 패키지 부팅을 실행한다. 늘어난 검사 시간을 고려해 CI 제한을25분으로 조정한다.

## 범위와 후속 작업

이번 작업은 기존 자원을 사용한 네 지역 전용 두 번째 지형·전투 배치다. 행복의 나라 전용 아트·주민 연출·관문 보스·세라·행복의 심장·정식 엔딩은 후속 범위다. 실기기 조작감·프레임률·전투 밸런스와 전체 여정30분 목표는 아직 확인하지 않았다. APK는 요청 시에만 만든다.
