# GP-123 · 공중 도약·2단 점프

기획의 능력 해금 2단 점프를 성장 도전에 연결한다. 새 도전은 1단 점프로 시작하고 레벨업 공용/무작위 후보의 공중 도약을 선택하면 공중에서 한 번 더 점프할 수 있다. 선택은 도전당 1회이며 획득 후 후보와 재추첨에서 제외한다.

- 공중 도약은 코요테 시간이 끝난 뒤 공중 입력으로 실행한다. 기존 지상 점프·코요테·착지 버퍼를 보존한다. 공중에서 발판을 벗어난 경우도 추가 도약 1회를 사용할 수 있다.
- 공중 도약의 상승 속도와 버튼을 떼는 높이 조절은 기존 점프와 같다. 길게 누르거나 세 번째 입력으로 반복하지 않는다. 착지와 안전 복귀 시 충전한다.
- 공중 도약과 공중 대시는 각각 한 번이다. 대시는 도약을 재충전하지 않는다. 공격 동작·입력 잠금·낙하 복귀 중에는 도약을 소비하지 않는다.
- 도약 때 발밑에 짧은 하늘색 파동을 그린다. 점프 버튼에 지상 `2단 점프`, 공중 `도약 1/0`을 표시한다.
- 능력은 스테이지 이동과 이어하기에 유지하고 새 도전에서는 초기화한다. 별도 중간 저장 필드를 추가하지 않고 성장 등급 `air_jump: 1`에서 복원한다. 두 등급 이상 변조는 거부한다. 기존 저장은 1단 점프로 읽는다.
- 능력 성향은 자연 0.75·투지 0.75이며 기존 능력 가중치를 적용한다. 피해·체력·회복약·스킬 대기시간을 바꾸지 않는다.
