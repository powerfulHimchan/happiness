# GP-325 · 원정 4 보스 강화 패턴

원정 3 전체 여정을 엔딩까지 완주하고 영구 기록하면 새 전체 여정 준비에서 원정 4를 선택한다. 기본→원정 1→2→3→4 순환 선택과 취소를 지원하며 다른 도전 모드·미해금·미구현 원정 5 시작은 차단한다. 이전 원정 3 완주 저널로도 바로 해금한다.

추가 정예·회복75%(정수 올림)·일반 적 추가 공격을 유지한다. 보스 체력, 한 번의 피해, 탄 수와 기존 경고 시간을 바꾸지 않고 아래 공격 묶음만 한 차례 더 사용한다.

| 보스 | 원정 4 강화 | 각 공격 묶음 전 경고(1/2페이즈) |
| --- | --- | --- |
| 웃는 태엽 기사(이전 전체 여정 저장) | 태엽 탄막 재조준·재사격 | 1.00 / 0.75초 |
| 행복의 수호기사 | 빛의 창 재조준·재사격 | 1.10 / 0.80초 |

| 행복의 심장 | 바늘 부채탄 재조준·재사격, 기억 절단 높이 재조준·재발사 | 1.05 / 0.72초 |

첫 공격 뒤 기존 약점 시간(1페이즈0.75초/2페이즈0.55초)을 모두 유지한 다음 새 경고를 시작한다. 추가 공격은 새 경고가 끝나야 발동한다. 조준은 경고 시작에 고정하고 각 발사에 고유 피해 이벤트를 사용한다. 두 번째 공격 뒤에는 원래 대기·패턴 순환으로 복귀한다. 돌진·충격파/지면 맥박과 갑옷 멧돼지는 원래 패턴을 유지한다.

보스 전용 공통 기반 `ExpeditionBoss`가 1회 예산과 빈틈→경고 전환을 관리한다. 실제 궤적·투사체·피해는 각 보스의 기존 전투 구현과 그래픽 표현을 사용한다. 감속은 경고·빈틈 모두에 적용하고 시간 정지/화면 조회 중에는 진행하지 않는다. 페이즈 전환·처치·재등장·하위 난이도로 재사용할 때 예약 공격을 취소한다.

## 저장과 표시

버전1 체크포인트의 선택 필드 `stage.expedition`에0~4 정수만 허용한다. 필드 없는 이전 저장은 기본, 원정1~3은 원래 규칙으로 복원하며 보스 강화는 비소급이다. 저장한 난이도로 모든 재사용 보스와 일반 적 상태를 구성한다. 새 준비 화면 선택이 이어하기 난이도를 덮어쓰지 않는다.

영구 저널·텔레메트리의 원정 완주 기록과 최근 이력에4를 허용한다. 엔딩과 원정 완주 기록이 모두 성공해야 완주를 확정한다. 원정 기록 쓰기만 실패하면 기존 체크포인트에서 별도 프로세스로 재시도하고 한 번만 완주한다. 원정4 완주로 아직 구현하지 않은 원정5는 해금하지 않는다. 도전 기록 삭제는 영구 해금과 독립이다.

준비 난이도 선택, 실제 보스전 HUD 목표, 도전 정보의 원정 규칙, 결과·광장 최근 이력에 연결한다. 회복약 감소 안내와 방벽·부활·최대 체력·현재 체력 복원의 기존 원정 규칙은 유지한다.
