# GP-152 · 도전 길이별 완주 통계

마을 광장 기록에 전체 통계·길이별 통계·최근 도전 세 탭을 제공한다. 길이별 통계는3스테이지와5스테이지 카드 두 개로 완주 횟수·최고 시간·평균 시간·누적 시간을 비교한다. 기록이 없는 길이는 완주0회와 아직 기록 없음 안내를 표시한다.

기존 `completion_by_stage_count` 집계를 조회하므로 JSON Lines 스키마·체크포인트·완주 기록 저장 방식을 변경하지 않는다. 중간 스테이지 완료나 진행 중 도전은 완주 통계에 포함하지 않는다. 같은 도전 ID의 중복 완주는 기존 집계의 첫 기록을 유지한다. 최근12개 도전 목록에서 제외된 완주도 길이별 통계에는 포함된다.

과거 단일 스테이지 시제품 완주는 전체 통계에 남고3/5비교 카드에는 섞이지 않는다. 전체 통계의 최고·평균에는 모든 길이의 완주 기록을 사용한다는 설명을 표시한다. 조회·탭 이동·마을 복귀는 파일·영구 해금·체크포인트를 변경하지 않고 마을의 전투·물리·타이머 동결을 유지한다. 기록 삭제 후 두 길이 카드의 횟수와 시간 안내를 즉시 초기화한다.

## 검증

별도 화면 검증의 세 프로세스에서 실제3스테이지 구출 완주,5스테이지 도전의3/5중간 저장, 마을 조회 후 이어하기와5스테이지 파괴 완주, 앱 재시작과 기록 삭제를 확인했다. 저장·기록·능력 발견·영구 해금 파일 바이트, 위치·체력·타이머의 보존과 두 화면비1280×720·2400×1080의 안전 영역·입력 비중첩·탭/설명 글자 폭을 확인했다.

| 기록 | 길이별 기대값 |
|---|---|
| 3스테이지100초·200초 | 완주2회·최고100.0초·평균150.0초·누적300.0초 |
| 5스테이지500초·700초 | 완주2회·최고500.0초·평균600.0초·누적1200.0초 |
| 이전1스테이지10초 | 전체 통계에만 포함·총5회·전체 평균302.0초 |
| 중복 완주·미완료·손상 꼬리 | 위 통계를 변경하지 않음 |
| 최근 목록12개 제한·파일 재로드 | 길이별 전체 집계 보존 |

기존252개 runtime test와 전체 프로젝트 검사를 수행한다. 실기기 플레이는 별도 확인이 필요하다. 명시적 요청이 없으므로 APK를 생성하지 않으며 PR/main Godot 검사와 수동 APK 정책을 유지한다.
