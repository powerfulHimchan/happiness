# GP-107 · 경로별 지형과 전투

첫 스테이지는 기존 이동·전투 검증 지형을 유지한다. 1·2스테이지 완료 후 선택한 경로에 따라 다음 스테이지의 두 번째 전진 구간과 후반 웨이브 배치를 바꾼다.

| 경로 | 이동 | 전투 | 선택 보상 |
|---|---|---|---|
| 풀숲 길 | 낙하 구간을 가로지르는 평지 다리. 점프 없이 통과 가능 | 첫 웨이브는 슬라임·씨앗 포대. 후반에는 적을 가까이 배치 | 기존 추가 체력 회복 20 |
| 바람 길 | 높낮이가 있는 징검 발판 3개. 길게 누르는 기본 점프로 통과 가능 | 첫 웨이브는 슬라임·바람 정령. 후반에는 씨앗 포대를 멀리, 바람 정령을 높게 배치 | 기존 필살기 게이지 25 |

두 경로의 후반 웨이브는 동일한 세 종류의 적을 사용하므로 경험치 총량은 동일하다. 관문·정예·3스테이지 완주 구조와 체력 증가 규칙도 유지한다. HUD에는 현재 경로와 지형을, 경로 선택 카드에는 이동·전투·보상을 표시한다. 무기 전환은 두 경로 모두 사용할 수 있다.

새 발판에 실제 착지하면 그 발판의 안전한 중앙을 낙하 복귀점으로 기록한다. 공중 통과로는 복귀점을 바꾸지 않는다. 경로 전환·재도전 시 이전 발판을 정리하고 시작점으로 복귀한다. 자유 전투에서는 추가 지형을 제거한다.

중간 저장 형식은 GP-105와 동일하다. 저장된 스테이지 번호와 경로로 지형을 다시 구성하므로 발판을 별도로 저장하지 않는다. 전투 중 종료하면 직전 완료 지점의 경로 선택 화면으로 복귀하며, 다음 경로를 다시 선택한다.

## 자동 검증

GP-107 실행 검사는 풀숲→바람과 바람→풀숲 순서를 검·활 시작으로 각각 완주한다. 실제 화면 터치 전환, 풀숲 다리의 물리 이동, 바람 발판 세 개의 실제 점프·착지, 낙하 피해·안전 발판 복귀, 후반 적의 거리·고도, 두 경로 저장·이어하기, 재도전 발판 정리와 경험치 총량을 검사한다. 기존 CP-206~406 및 GP-101~106 회귀 검사도 실행한다.

## 실기기 확인

1. 첫 스테이지 완료 후 풀숲 길을 골라 낙하 구간을 걸어서 지나간다.
2. 다른 도전에서 바람 길을 골라 세 발판을 길게 누르는 점프로 건넌다. 낙하 후 마지막 착지 발판으로 복귀하는지 확인한다.
3. 후반 웨이브에서 검·활 전환으로 가까운 적과 높은 적을 상대한다.
4. 두 번째 스테이지 완료 후 앱 종료·이어하기를 수행하고 반대 경로를 선택한다.

자동 검사와 Android 실제 플레이 결과는 구분한다. 무기 보상·등급, 새 지역, 보스 구출·영구 해금은 다음 후보 범위다.
