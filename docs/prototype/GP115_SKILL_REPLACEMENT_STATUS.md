# GP-115 · 정예 보상 스킬 교체

정예 무기 보상 후 경로 화면에서 스킬 교체를 선택한다. 검·활 각각 세 스킬 중 보유하지 않은 하나를 제안하고, 선택한 무기의 두 기존 슬롯과 성능을 비교해 하나를 교체한다. 정예마다 한 번만 확정할 수 있다. 유지 버튼은 기존 구성으로 경로 화면에 돌아오며, 경로를 바로 선택해 교체를 건너뛰어도 된다. 다음 정예에서는 이전에 버린 기술도 다시 제안한다.

- 검 반달 베기: 주변 3m 범위, 52 기본 피해 한 번, 재사용 10초, 동작 0.48초. 기존 돌진보다 이동을 줄이고 회전보다 넓은 범위를 한 번에 타격한다.
- 활 연속 사격: 18 기본 피해 화살 세 발, 각 최대 한 개체, 재사용 8초, 동작 0.65초. 각 화살은 고유 피해 ID를 가지며 스킬 피해·성향·필살기 집계로 연결한다.

두 슬롯 중 어느 쪽에서도 해당 기술의 행동과 대기시간을 사용한다. 시전 도중 피격·회피·무기 전환은 기존 취소 규칙을 따른다. 교체 시 대기시간은 기존 슬롯 잔여 시간과 새 기술 재사용 시간 중 긴 값으로 시작한다. 다른 슬롯·보조 무기의 대기시간, 무기 등급·설계, 성장 보너스는 그대로 유지한다. 도전 내 고정 1레벨 기술 시제품이며 레벨별 계승·무작위 신규 무기 계열은 이후 범위다.

기술 구성·정예 교체 완료 여부·슬롯 대기시간을 같은 중간 저장에 기록한다. 저장 실패는 구성·소비 여부·대기시간을 되돌려 재선택할 수 있게 한다. 아직 확정하지 않은 UI 선택은 저장하지 않으며, 재시작하면 경로 화면에서 교체를 다시 열 수 있다. 이전 버전 저장은 기본 기술과 해당 정예 교체 완료로 해석해 보상을 소급 지급하지 않는다. 다음 정예에는 다시 교체할 수 있다. 새 도전에서는 기본 구성으로 초기화한다.

CP-206~406·GP-101~114 회귀 검사와 다섯 별도 프로세스 검사를 실행한다. 첫 확정·취소·실패 롤백·손상 저장 거부, 재시작과 무기 등급 교체 뒤 구성 보존, 검/활 서로 다른 슬롯 동시 복원·실제 완주, 이전 저장 호환, 실제 반달 피해·연사 세 발 피해/집계·쿨다운·취소와 두 화면비 UI 입력을 검증한다.
