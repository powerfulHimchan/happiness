# GP-160 · 회복 방벽 강화

회복 방벽을 먼저 획득한 뒤 공용 성장 카드로 도전당 한 번 선택한다. 이후 실제 회복약 소비 시 방벽 회복을10에서15로 늘린다. 선택 자체는 체력·방벽·회복약 개수를 바꾸지 않는다.

기본/농축/소분 조제·주머니·샘의 이슬의 기존 체력 회복률과 소비 수량을 유지한다. 기본20·견고한 방벽30 상한으로 실제 보충량만 로그에 기록한다. 만피·회복약 소진·버튼 유지·피격/낙하/사망/정지/단계 완료/도전 종료는 무료 사용이나 중복 보충을 일으키지 않는다. 다른 회복은 방벽 충전으로 연결하지 않는다.

기존 성장 등급 `restorative_barrier_boost: 1`에서 런타임 효과만 복원한다. 기본 회복 방벽을 먼저 복원한 뒤 강화 플래그를 적용하며, 기본 능력/방벽 해제·새 도전은 플래그를 초기화한다. 기존 저장은10을 유지한다. 능력 도감·HUD·현재 도전 화면은 실제15를 표시한다.

GP-159·161과 함께9단계 검사로 실제 선택·기록 실패 재시도·선행/중복/저장 변조, 별도 프로세스 반복 복원·이전 저장·완주를 확인한다. 세 조제와 이슬/주머니 조합·정수 회복·소비·상한·실제 피해17의 방벽15/체력2 차감·여덟 잠금·조회 정지와 세 강화 합산도 검사한다. 전체299개 실행 검사와 PR/main 검증을 기준으로 한다. APK는 요청 시에만 만들며 새 기능 실기기 플레이는 미확인이다.
