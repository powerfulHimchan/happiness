# GP-324 · 원정 3 일반 적 연속 패턴

원정 2 전체 여정을 엔딩까지 완주하고 영구 기록하면 새 전체 여정 준비에서 원정 3을 선택한다. 기존 원정 1 완주는 원정 2까지만 해금한다. 기본→원정 1→2→3 순환 선택, 준비 취소, 다른 모드/미구현 원정 시작 차단을 지원한다. 이전 원정 2 완주 저널도 바로 해금에 사용한다.

원정 1의 추가 정예와 원정 2의 체력 회복75%·정수 올림을 유지하고 일반 적 한 공격 묶음에 추가 공격1회를 연결한다. 적 체력과 한 번의 피해량·탄 수는 기존 수치다.

슬라임·정령은0.30초, 원거리 적·병정은0.35초 빈틈 뒤 다음 경고를 시작한다. 각 경고 시간을 모두 기다린 뒤 공격하므로 연속 타격이 즉시 발생하지 않는다. 원거리 적·병정은 기존 검 피격 중단으로 남은 반복도 취소한다. 처치·재등장·지역/난이도 변경에서 반복 횟수를 초기화한다. 정령의 재돌진 경고선은 조준 즉시 갱신하고 원정 슬라임·정령은 맵 좌우 경계를 벗어나지 않는다. 적 시간 감속과 일시정지 처리는 기존 상태 기계를 사용한다. 보스 강화 패턴은 원정 4의 후속 범위다.

## 저장과 표시

버전1 체크포인트의 선택 필드 `stage.expedition`은0~3 정수만 허용한다. 필드 없는 이전 저장은 기본, 원정 1/2는 기존 규칙으로 복원한다. 준비에서 선택한 값과 무관하게 저장한 난이도로 적 재사용 상태와 회복 규칙을 복원한다. 전체 여정 외 원정과 잘못된 저장은 거부하며 정상 파일을 보존한다.

기존 영구 저널의 원정 완주 기록에3을 허용한다. 엔딩 기록과 원정 기록이 모두 성공해야 완주·결과를 확정한다. 원정3 기록만 실패하면 기존 체크포인트로 별도 프로세스에서 재시도하며 한 번만 완주한다. 원정3 완주로 아직 구현하지 않은 원정4를 해금하지 않는다. 도전 기록 삭제와 영구 해금은 독립적이다.

준비 화면, HUD 목표, 도전 정보의 원정 규칙, 회복약 안내, 결과와 최근 이력에 연결한다. 상위 원정에서도 방벽·부활·최대 체력 증가·체크포인트 현재 체력 복원은 기존 규칙이다.
