# GP-1011–1030 · 과제 게시판 그래픽 10개와 애니메이션 10개

두 무기 조합·보급소 과제를 구별하고, 수령 가능한 과제와 완료한 과제를 문양과 색으로 구분한다. 메뉴 안에서만 재생하는 짧은 애니메이션이며, 완료 후에는 정지한다. 기존 과제 판정·가격·보상·저장 형식은 유지한다.

## 동작과 검증

- 애니메이션은 메뉴 전용 객체에만 존재하며 체크포인트에 저장하지 않는다.
- 앱 비활성 상태에서는 시계가 멈추고, 게시판을 다시 열면 이전 수령 효과를 재생하지 않는다.
- 저장 실패·중복 갱신·화면 그리기만으로 보상 효과나 지급을 만들지 않는다.
- 카드·버튼의 실제 터치 영역을 유지하며 진행률 분할선은 복합 조건 수를 따른다.
- 새 테스트는 문양 실제 임포트, 레이아웃, 유한 재생·정지, 실제 터치, 저장 실패 후 수령 재시도와 중복 수령 차단을 검사한다.
- 기존 과제 검사와 1280×720·1600×720·1280×800 실제 화면 렌더링을 함께 확인한다.
- Android 실기기 플레이와 APK 생성은 이번 작업 범위에 포함하지 않는다.

## 이번 실행 결과

- 그래픽 10종 임포트·구역 검사, 메뉴 시계·실제 터치·중복 효과 차단 검사 통과.
- 로안 조합 과제와 루미 보급 과제의 seed/resume/next 총 6회 통과. 로안 복원은 초기 실행 1회에서 수령 기록 확인 실패가 있었고, 독립 저장 경로와 전체 재실행에서는 통과했다. 수령 직후 실제 파일에도 영수증이 남는지 검사하도록 보강했다.
- 기존 GP-618–667 목록·판정·영수증·정렬 검사, 정적 프로젝트 검사 통과.
- 세 해상도에서 상태·선택·진입 장면 21장과 실제 수령 효과 1장을 렌더링해 문구·터치 영역·문양 배치를 확인했다.
- Android 리소스 팩 내보내기 확인. 전체 GitHub 검사는 main 반영 후 자동 실행된다.
