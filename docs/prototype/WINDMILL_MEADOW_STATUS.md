# 첫 맵: 풍차 들판

일반/지역 도전의 첫 스테이지와 전체 여정의 평원 첫 구간에 적용한다. 전체 여정의 지역 순서와 두 번째 구간, 다른 지역은 유지한다. 기존 약 5,000px 공통 트랙 대신 42,000px의 별도 지형을 사용한다.

## 구역과 진행

| 구역 | 구현 |
|---|---|
| 들판 입구 | 높이가 달라지는 언덕, 표지판, 지나칠 수 있는 소규모 교전 |
| 개울 갈림길 | 낮은 징검다리와 높은 능선, 능선의 선택 전투와 회복 상자, 농장 앞 합류 |
| 버려진 농장 | 수레·지붕 발판, 두 주요 전투, 전투 중에만 잠기는 경계 |
| 풍차 진입로 | 낮은 언덕 길과 높은 바깥 길, 선택 전투와 필살기 충전 상자 |
| 풍차 장치실 | 내부 계단과 외부 계단, 위층 전투, 장치 작동 |
| 바람꽃 둔덕 | 장치 작동 후 연결되는 다리와 상승 기류, 높낮이 지형, 선택 회복약 상자 |
| 출구 초원 | 언덕을 지나 별도 경계를 갖는 정예 전투, 처치 후 실제 출구 통과 |

장치실 위층의 적을 처치하고 빛나는 장치 옆에서 0.8초간 멈추면 풍차가 작동한다. 별도 조작 버튼은 추가하지 않았다. 상승 기류 안에서 점프하면 위로 이동한다. 필수 경로는 기본 점프로 통과할 수 있으며 2단 점프를 요구하지 않는다.

목표 플레이 시간은 4~6분이며 기록 목표를 300초로 설정했다. 시간 초과로 실패하지 않는다. 실제 기기에서의 사람 플레이 시간과 난이도는 별도 조정 대상이다. 생성한 전체 맵 그림은 압축한 기획 시안이며 게임에는 충돌 지형·건물·나무·물·풍차 날개·기류를 각각 월드 좌표로 구현했다.

## 저장·호환

- 전투를 마치거나 상자를 획득하고 안전한 상태가 되면 탐험 진행을 자동 저장한다. 성장 선택 중에는 저장을 미룬다. 저장 실패 시 기존 정상 저장을 유지하고 재시도한다.
- 미완료 저장에는 완료한 전투·상자·풍차 전원·복귀 위치·진행 시간·장비/성장/소모품 상태를 담는다. 아직 마치지 않은 스테이지를 완료 이력에 추가하지 않는다.
- 선택 전투에서 물러났다가 돌아올 경우 이미 처치한 적은 다시 보상을 주지 않는다.
- 정예 처치 후 출구에 도달하면 기존 5개 진행 기록 형식과 보상·다음 경로 선택으로 연결한다. 이전 버전의 완료 스테이지 저장도 읽는다.
- 다음 맵과 자유 전투로 전환할 때 원래 바닥·카메라·적 이동 경계·표적 선택을 복원한다.
- 자동 공격은 새 맵의 다른 층/벽 너머 적을 표적으로 선택하지 않는다. 회복 구슬도 새 지형 위에 배치한다.

## 검증

`windmill_meadow_runtime_test.gd`는 실제 기본 씬을 사용한다.

- `flow`: 주요 전투, 상자 중복 방지, 장치/다리, 중간 저장과 두 차례 이어하기, 정예/출구/다음 맵 전환.
- `physics`: 실제 단일 점프 이동과 충돌, 기류, 다른 층 표적 차단, 낙하 복귀.
- `journey`: 평원 첫 구간에만 적용하고 다른 지역/두 번째 구간/자유 전투를 보존.
- `story`: 루미·활·스토리 전체 여정에서도 미완료 저장/복귀와 완료 보상을 검증.
- `render`: OpenGL 렌더러로 개울·농장·풍차·기류·출구 화면을 캡처하는 수동 시각 검증 경로.

기존 이동/전투/성장/저장 회귀 테스트는 `fixtures/legacy_movement_sandbox.tscn`에서 이전 지형을 명시적으로 사용한다. 새 지형 검사는 위의 실제 기본 씬 테스트로 분리했으며 네 가지 자동 검증 모드를 기존 CI 실행 스크립트에 등록했다.

### 재개 검증 기록 · 2026-10-26

실제 기본 씬의 `flow` 30개, `physics` 49개, `journey` 7개, `story` 30개 검사(합계 116개)를 다시 통과했다. 정적 검사, Android 리소스 팩 내보내기와 팩으로 게임 시작, 개울·농장·풍차·기류·출구의 렌더링도 확인했다. 사람의 Android 실기기 플레이와 실제 4~6분 소요 시간 측정은 아직 수행하지 않았다.

전체 기존 회귀가 모두 통과한 상태는 아니다. GP-364 연속 저장·복원 검사 실패는 변경 전 원격 `main` 기준 커밋 `817afdd`에서도 재현했다. 별도 프로젝트와 저장 경로에서 전체 여정 GP-307의 54개 실행 및 GP-323의 52개, GP-325의 44개 실행은 통과했지만, 일부 다른 기존 저장·도감 검사도 실행 조건에 따라 실패해 전체 회귀 성공으로 보고하지 않는다.
