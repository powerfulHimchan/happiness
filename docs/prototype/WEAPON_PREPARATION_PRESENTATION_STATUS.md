# 무기 선택 · 이미지 글자와 스킬 설명

## 승인 시안 적용

- 제목·주인공 변경·도전 설정·이전·모험 시작·보조 선택·무기 이름·스킬 이름·닫기는 담백한 이미지 글자다. 기존 큰 버튼 판과 무기 선택 카드 테두리를 제거했다.
- 시작 화면과 같은 NanumMyeongjoBold 경로 이미지 28종을 사용한다. 게임에서 글자를 조립하거나 기본 폰트로 메뉴를 출력하지 않는다. 변하는 능력치·설명·안내는 읽을 수 있는 실제 텍스트다.
- 검·활·권갑·지팡이·장봉·방패를 금속/목재/보석의 디테일과 구별되는 실루엣으로 다시 그렸다. 선택 목록과 오른쪽 상세, 두 주인공의 장착 대기에 같은 무기를 사용한다. 권갑은 한 손용과 목록용 한 쌍 이미지를 제공한다. 실제 전투의 판정/장비는 수정하지 않았다.
- 각 무기의 시작 스킬 2개, 총12종에 동작/특성 아이콘을 추가했다. 돌진·회전·관통·화살비·연속 주먹·화염 폭발·얼음창·장봉 밀침·방어·응수를 색과 형태로 구분한다.
- 현재 미리 보는 무기가 바뀌면 해당 무기의 시작 스킬 아이콘·이름·특성을 함께 표시한다. 아이콘과 이름을 모두 터치할 수 있다.
- 스킬을 누르면 설명 창에 이름·무기·특성·설명·효과·기본 피해/재사용/범위·이동/타격 횟수를 표시한다. 실제 `SkillDefinition`과 도감 효과 문구를 읽는다. 방패 올리기는 피해0 대신 전방 방어/지속 시간으로, 응수는 방어 성공 조건을 포함해 설명한다.
- 닫기·X·Escape는 설명 창만 닫는다. 창 뒤의 무기/보조/설정/모험 시작 입력은 차단한다. 미리보기 시계는 설명 창에서 멈췄다가 닫으면 재개한다. 도전 설정과 설명 창은 동시에 열리지 않는다.
- 조회로 세이브·체력·현재 무기/스킬·보상·준비 선택을 바꾸지 않는다. 보조 선택과 주무기 교환, 준비 취소·주인공 복귀는 기존 동작을 유지한다.

## 검증

- Godot 4.7.2 준비 화면 실행 검사 2,500개 통과.
- 실제 OpenGL 렌더러에서 1280×720·1600×720·1280×800·2400×1080의 172장을 생성하고 2,673개 검사를 통과했다. 두 주인공 × 여섯 무기 × 두 스킬의 아이콘/이름 열기, 정확한 스킬 정보, 뒤쪽 입력 차단, 닫기/X/뒤로가기, 시간 정지·재개 및 세이브/전투 무변경을 포함한다.
- 무기 7종(권갑 쌍 포함), 스킬 12종, 글자 28종 SVG의 XML/임포트와 정적 검사를 통과했다.
- 기존 시작 화면·GP-106 무기 준비·GP-120/149 조제 생성/복원·GP-267–276와 GP-277–306 두 주인공 preview 검사를 통과했다.
- GP-114 마을 복원은 첫 실행과 첫 격리 실행에서 실패했다. 읽기 진단을 추가한 별도 복사본에서는 성공했고, 제품 코드와 원본 검사를 바꾸지 않은 최종 격리 실행에서 seed/resume/finish 모두 통과했다. 최초 실패 원인은 확정하지 못했으며 재현 경과를 기록한다.
- Android 리소스 팩 내보내기와 내보낸 팩의 시작을 확인했다. Android 실기기 플레이는 하지 않았으며, APK는 생성하지 않았다.
