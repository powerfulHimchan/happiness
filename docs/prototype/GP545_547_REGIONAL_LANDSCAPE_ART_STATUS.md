# GP-545–547 · 폐허·축제·성문 배경 그래픽 3종

| 작업 | 지역 | 반영 내용 |
| --- | --- | --- |
| GP-545 | 태엽 폐허 · 위험 경로 | 멈춘 톱니 작업장, 굴뚝·배관·금속 창살, 원경 공장 지붕과 지면 리벳·배관 문양 |
| GP-546 | 태엽 축제장 · 기계 정원 | 회전목마·관람차·매표소, 원경 천막·가랜드, 연보라 지면과 발판 사선 장식 |
| GP-547 | 행복의 나라 성문 | 하얀 쌍탑·환영 시계·열린 아치, 주택 지붕·성벽 발코니, 석조 바닥·발판 장식 |

기존 벡터 배경 체계를 확장한 800×640 SVG 세 장을 사용한다. 원경·건축물·지면은 월드의 캐시된 CanvasItem에 그리며 새 프레임 처리·애니메이션·물리 몸체·공격 판정·저장 필드를 추가하지 않는다. 원화의 회전목마와 관람차는 정적인 배경이며 실제 회전 발판·승강대의 궤도와 지지대는 기존 지형에서 그린다.

성문 주민 세 명과 기존 환영 대사는 발코니에 유지한다. 기존 단순 도형 성문과 축제 가랜드는 새 배경으로 교체해 중복으로 그리지 않는다. 지역 전환·이어하기·자유 전투 복귀는 기존 배경 무효화 흐름을 사용한다. 중심부와 심장 의식의 방은 기존 표시 경로를 사용한다.

## 검증

- Godot 4.7.2 에셋 가져오기와 스크립트 구문 검사 통과.
- 실제 게임 렌더링 67장: 여섯 지역의 전투/발판·세 화면비 60장, 전투 HUD 6장, 자유 전투 복귀 1장. 두 구간이 있는 지역은 모두 포함하며 축제 발판은 이동한 위치에서도 확인한다.
- 강제 다시 그리기 전후 체크포인트 상태와 실제 발판 사각형·몸체 수·이동 시간이 동일함을 확인했다.
- 기존 실행 검사 16묶음 중 15묶음은 종료 코드0으로 완료했다. 나머지 묶음도 도감 검사 직전까지 통과했지만 GP-126 전체 능력 도감 검사에서 45초 제한에 걸렸다. 동일 소스의 단독 검사는 46.31초에 통과했으며, 49페이지를 두 화면비에서 순회하는 해당 검사의 제한만90초로 조정했다. seed·resume·finish·legacy-fail·legacy-resume 전부 개별 프로세스에서 순서대로 통과해 남은 검증을 완료했다.
- 각 묶음에서 Android 리소스 팩 내보내기와 내보낸 게임의 부팅을 통과했다. 이번 변경으로 APK를 빌드하지 않는다.
