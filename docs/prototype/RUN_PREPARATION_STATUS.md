# 새 도전 준비 · 주인공/무기 화면 분리

주인공 화면은 이후 승인된 **두 인물 선택 → 한 인물 상세**로 개편했다. 최신 동작·문구·검증은 [주인공 상세 화면](HERO_SELECTION_DETAIL_STATUS.md)을 따른다. 아래는 최초 분리 작업의 기록이다.

사용자가 선택한 주인공5번 포스터형과 무기3번 동화책형을 기준으로 구현한다. 두 화면 상단의 `1 주인공 → 2 무기` 단계 표시는 제거한다. 기존 원화·새벽 배경을 재사용하고 글자와 버튼은 게임 UI로 그린다. 책 배경은 별도 SVG이며 선택 문구나 인물이 고정 이미지에 포함되지 않는다.

## 화면과 이동

- 메인 새 도전, 결과 재도전, 마을 새 도전은 주인공 선택부터 시작한다. 로안/루미의 큰 상반신, 이름표, 선택 체크와 이야기 토글을 표시하고 다음 버튼으로 무기 화면에 이동한다.
- 무기 화면은 왼쪽 장착 주인공, 펼친 책의 왼쪽 페이지 여섯 무기, 오른쪽 페이지 선택 무기/스킬/주·보조 장착 정보를 표시한다. 아이콘/이름 영역은 주무기, 카드 하단 버튼은 보조무기를 선택한다. 같은 계열을 고르면 기존 두 무기를 교환해 항상 서로 다르게 유지한다.
- 무기 화면의 이전/주인공 버튼으로 주인공 화면에 돌아와 준비 선택을 유지한다. 주인공 화면에서 이전/Escape를 누르면 진입했던 메인·결과·마을로 복귀하고 준비 전의 주인공·무기·길이·난이도·이야기·기억 선택을 복원한다. 최종 모험 시작에만 기존 도전 생성 함수를 호출한다.
- 기존 길이4종, 원정 난이도, 영구 기억3종, 일회 보상, 회복약 조제 안내는 무기 화면의 도전 설정 패널에서 확인한다. 패널이 열려 있는 동안 아래 무기/시작 버튼은 작동하지 않는다. Escape는 패널을 먼저 닫는다.
- 내부 `show_start_weapon_selection()` API는 기존 통합 검사와 직접 무기 화면 접근을 유지한다. 실제 메뉴 진입은 `show_new_run_preparation()`을 사용한다. 저장 형식·기존 이어하기·전투 수치는 변경하지 않는다.

## 장착 미리보기

- `EquippedHeroPreview`는 별도 표현용 객체다. 실제 Player, WeaponController, 피해·투사체·보상·저장 신호를 호출하지 않는다.
- 로안/루미의 기존 대기 애니메이션 두 프레임과 호흡 움직임에 무기를 손 위치 기준으로 합성한다. 검·활·권갑·지팡이·장봉·방패 모두 장착 형태를 유지하며 무기와 주인공 변경 때 미리보기 시간을 초기화한다.
- 주무기뿐 아니라 보조무기를 선택해도 해당 장비를 즉시 미리 보여준다. 실제 주/보조 장착 내역은 책 오른쪽에 별도로 표시한다.
- 숨겨진 화면·도전 설정 패널·앱 비활성 상태에서는 미리보기 시간이 멈춘다. 복귀하면 이어서 재생한다. 미리보기는 실제 공격 시연이 아닌 장착 대기 애니메이션이다.

## 검증

- Godot4.7.2의 전용 검사1,333개를 통과했다. 두 주인공 × 여섯 무기 × 네 화면비의 실제 터치, 주/보조 교환, 미리보기 프레임/시간, 앱 비활성화/복귀, 숨겨진 화면·설정 패널의 시간 정지, Escape/뒤로가기, 취소 시 복원, 실제 도전 시작과 전투·저장 무변경을 확인했다.
- 1280×720·1600×720·1280×800·2400×1080에서 실제 렌더러로64개 화면을 생성했다. 렌더링 검사1,398개가 통과했으며 대표 화면의 인물·장착 위치·한글·책 페이지·설정 패널·버튼 배치를 확인했다.
- 기존 전체 통합 검사를16개 묶음으로 실행했다.13개는 첫 실행에서 완료했다. 이전 단일 준비 화면을 가정한 GP-111·120·149의 입력/배치 검사는 새 주인공 단계와 설정 패널에 맞게 보완했다. 제품 코드를 바꾸지 않은 상태에서 해당 검사 묶음부터 이후 할당된 검사까지 다시 실행해 나머지3개도 완료했다. 이미 통과한 이전 구간과 합쳐 전체 검사 범위를 통과했다.
- 전투·직업·성장·보스·엔딩·원정·도감·조제·보상·저장/이어하기를 포함한다. 주인공/직업/보조 무기별로 저장을 분리한 네 전투 행렬도 seed/resume 의존성을 유지하면서 분산한다. 검사 단계나 사례를 제거하지 않았다.
- 마지막 조력자 지원 안내 문구 보완 후 전용 검사와64개 렌더링을 다시 통과했다. 최종 Android 리소스 팩 내보내기 및 변환된 팩의 게임 부팅도 성공했다. APK를 빌드한 것은 아니다.
- Android 실기기 플레이와 기기별 성능은 미확인이다. APK는 요청할 때만 만든다.
