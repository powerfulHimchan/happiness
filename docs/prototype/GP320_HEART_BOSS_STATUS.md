# GP-320 · 행복의 심장 전투

## 플레이 흐름

첫 도착 엔딩을 발견한 뒤 시작하는 새 전체 여정은 세라 선택 후 행복의 심장과 싸운다. 이야기 켜짐에서는 입구의 진실 발견과 전투 설명을 읽거나 건너뛰어 진입하고, 이야기 꺼짐에서는 바로 전투로 이어진다. 첫 여정과 필드가 없는 이전 저장은 기존 도착 엔딩 흐름을 유지한다. 현재 여정의 장비·능력·체력·필살기 게이지·재사용 대기는 이어지며 전투 구역은 궁전 아래 의식의 방으로 바뀐다.

심장은 체력1200의 고정형 보스다. 예고된 지면 맥박, 방향이 고정된 부채 바늘3발, 경고 순간 높이에 고정된 수평 절단을 순환한다. 체력50%에서 과부하로 전환하고 경고가 짧아지며 맥박2회·바늘5발로 강화된다. 파문은 점프하고, 바늘은 틈으로 피하며, 절단은 높이를 바꾸거나 정확 회피한다. 공격 뒤 핵이 노출된 동안 검·활은150% 피해를 준다. 기존 필살기 감속·정지와 정확 회피 보상을 사용한다.

처치 후 세라 선택별 `멈춘 심장의 명령`을 확인하면 구출/파괴별 여행 기록을 영구 해금한다. 결과와 최근 도전 이력에 심장 제압을 표시한다. 첫 도착 엔딩의 최초 발견은 보존하며 같은 도전의 완주를 중복 지급하지 않는다. 이야기 꺼짐은 장면 없이 같은 승리 기록을 남긴다.

## 저장·복구

- 기존 버전1에 `stage.heart_battle`을 추가한다. 새 도전 시작 시 엔딩 발견에 따라 locked/available을 확정한다. 입구 확인은 pending을 먼저 저장하고 전투 중 active는 파일에 쓰지 않는다. 앱 종료 후 이어하기는 체력과 잔량을 보존한 전투 직전 체크포인트에서 보스 체력1200으로 재도전한다. 전투 중 사망은 기존 도전 실패·되감기·체크포인트 삭제 정책을 따른다.
- 처치 시 defeated를 저장하며, 확인 후 seen과 이력의 heart_cleared를 함께 확정한다. 확인 저장 실패는 상태와 정상 파일을 되돌린다. 진실/승리 저널 실패는 확인한 저장을 보존해 같은 버튼·이어하기·다음 실행에서 재시도한다. 미확인 승리·저널 오류 동안 완주를 먼저 기록하지 않는다.
- 상태 타입·전이·10스테이지/세라 선택/심장 입구/엔딩 일관성을 검증한다. 필드가 없는 GP-319 이전 저장에는 새 전투를 소급하지 않는다. 이전 흐름 검사는 실제 구버전 저장 조건을 유지하고 새 전투는 GP-320에서 검증한다.

## 검증과 후속 범위

신규60개 실행 단계: 주인공2×무기2×세라 선택2의 별도 프로세스 진입·복원·실제 기본 공격 처치·승리 확인32개, 선택별 입구/진실/승리 확인/저널 실패·재실행·이전 저장·첫 여정·상태 타입·공격 패턴·배치·사망·이야기 꺼짐·세라 보상 실패28개다. 검·활 실제 타격/투사체, 두 페이즈·경고/실제 공격·감속 정지·수평 절단의 점프/무적/적중·중복 완주를 확인한다. 기존 GP-317–319와 전체 PR 자동 검사, Android 리소스 내보내기·패키지 부팅, 두 화면비 한국어 전투/결과/수첩 렌더링을 확인한 뒤 병합한다. 10스테이지 결과 행은 두 줄 안에 맞춰 패널 밖으로 넘치지 않게 표시한다.

이번 범위는 심장 전투와 승리 기록이다. 제압 후 의식에 대한 최종 선택 및 귀환·해방·새벽 엔딩은 후속 범위다. Android 실기기 조작감·난이도·성능은 별도 검증 대상이며 APK는 요청 시에만 만든다.
