# GP-114 · 시간의 닻 마을

메인 화면에서 마을을 방문하고 대장간·기억의 쉼터·광장 기록을 살펴보는 첫 시제품이다. 세 시설의 조건을 잠금 상태에서도 확인할 수 있다. 대장간은 영구 해금한 태엽 검·활의 희귀/영웅 피해와 고유 효과를 보여준다. 무기 획득은 기존 정예 보상에서, 기억 장착은 새 도전 준비에서 진행한다. 제작 비용·강화 상점·새 전투 지역은 이번 범위에 포함하지 않는다.

구출 완료로 해금한 태엽 수호 기억에서 태엽 기사의 영구 정착을 읽는다. 일회 보상 소비, 다음 보스 파괴, 도전 기록 삭제 뒤에도 같은 저장소의 해금이 남아 있으면 기사가 정착해 있다. 정착 상태를 따로 저장하거나 보상을 추가 지급하지 않는다.

광장은 실제 로컬 기록의 총 도전·완주·미완료·최고/평균 완주 시간을 표시한다. 미완료는 저장된 시작 기록 중 완주 기록이 없는 도전 수로 진행 중 도전도 포함하며, 시간이 없는 경우 기록 없음으로 표시한다. 모든 완료 스테이지 수의 기록을 기준으로 한다.

마을 진입 시 입력을 해제하고 스테이지·적·투사체·플레이어·무기를 동결한다. 새 도전 준비 취소는 마을로 돌아오고 동결을 유지한다. 메인 복귀·준비 확정·이어하기는 원래 환경을 복원한다. 방문만으로 중간 저장, 영구 해금, 일회 보상, 기록을 변경하지 않는다. 이어하기는 기존 저장 복원 경로를 사용하며 준비 확정 시 저장 실패하면 메인으로 복구하고 보상을 남긴다.

세 개의 별도 프로세스 검사로 첫 방문 잠금과 실제 물리 동결, 시설 터치와 16:9/20:9 안전 영역, 실제 구출 완주 정착, 소비 실패 복구, 기억 준비와 취소, 다음 도전 중간 저장과 마을 이어하기, 실제 파괴 완주 후 두 시설/기사 유지, 재시작과 기록 삭제 독립성을 확인한다. 기존 CP-206~406·GP-101~113 검사를 함께 실행한다.
