# GP-101 · 경험치와 레벨업 능력 선택

GDD의 성장 시제품을 작은 단위로 구현하는 첫 개발용 빌드다. 2026-09-30 사용자 보고로 실제 기기 20분 플레이 안정성 통과를 확인했다. 입력 성공률·무기 전환 사용률 및 CP-406의 다른 개별 항목은 확인 대기다. 20분 안정성 통과와 GP-101 자동 검사 통과를 전투 프로토타입 전체 검증이나 성장 마일스톤 완료로 간주하지 않는다.

## 이번 범위

- 일반 몬스터 처치 경험치 10, 정예 처치 경험치 30. 연습 표적은 제외한다.
- 초기 레벨 1, 다음 레벨 요구 경험치 20/25/30/35… . 현재 스테이지의 일반 몬스터 5기와 정예 1기를 모두 처치하면 총 80으로 레벨업 3회, 최종 레벨 4와 잔여 경험치 5가 된다.
- 레벨업 시 플레이어, 적, 양쪽 투사체, 스킬 대기시간과 스테이지 시계를 정지한다. 입력 버퍼와 누른 버튼을 비운다.
- 현재 무기 관련 카드 1장, 공용 카드 1장, 나머지 전체 후보 중 무작위 1장을 중복 없이 제시한다. 후보 재추첨은 스테이지 전체에서 1회다.
- 선택 효과는 해당 도전 동안 누적하고 재도전 때 경험치·능력·체력 증가와 재추첨 횟수를 초기화한다. 영구 저장이나 직업 판정은 하지 않는다.
- 마지막 정예 처치로 레벨업하면 카드 선택을 끝낸 뒤 결과 화면으로 이동한다. 초과 경험치는 다음 선택까지 보존한다.

## 시제품 카드 수치

| 카드 | 효과 | 범위 |
|---|---|---|
| 예리한 검 | 검 피해 +15% | 검 기본 공격·돌진·회전 |
| 힘찬 시위 | 활 피해 +15% | 활 기본 사격·관통 화살·화살비 |
| 새벽의 힘 | 검·활 피해 +10% | 두 무기의 기본 공격과 스킬 |
| 튼튼한 심장 | 최대 체력 +20, 현재 체력 +20 | 상한까지 회복 |
| 다시 일어서기 | 최대 체력 +10, 체력 40 회복 | 상한까지 회복 |

피해 보너스는 합산하고 각 피해 이벤트에서 정수 반올림한다. 활 근거리 감쇠 이후 성장 보너스를 적용하며, 정예의 갑옷·기절 피해 보정은 기존 수신 경로를 유지한다. 발사된 화살의 피해는 발사 시점에 고정한다. 카드 수치와 경험치 곡선은 이 개발 빌드의 임시 밸런스이며 최종 기획 확정값이 아니다.

## 자동 검사

`game/tests/gp101_runtime_test.gd`는 실제 스테이지 노드에 테스트 피해를 주어 3회 레벨업과 결과 전환을 검사한다. 이는 사람의 플레이 완주 테스트가 아니다. 중복 처치 신호, 웨이브 재소환 보상, 카드 구성, 터치 선택·재추첨, 정지 중 시계·이동·투사체·쿨다운, 앱 비활성화·복귀 알림, 검·활·화살비 피해, 체력 상한, 초과 경험치, 재도전·사망·씬 종료 시 복구와 16:9/20:9 선택 영역을 검사한다. 기존 CP-206~406 런타임 검사도 함께 실행한다.

## 실기기 확인과 다음 단계

1. 웨이브 1 전멸 뒤 카드 3장과 멈춘 전투를 확인하고 하나를 선택한다.
2. 재추첨을 사용한 뒤 웨이브 2 레벨업에서 다시 사용할 수 없는지 확인한다.
3. 검·활 전환에 따라 관련 카드가 바뀌고 체력·피해 효과가 체감되는지 확인한다.
4. 카드 화면에서 앱을 백그라운드로 보냈다가 돌아와도 선택 화면과 입력이 정상인지 확인한다.
5. 정예 처치 후 마지막 선택을 마치면 결과가 나오고 재도전에서 레벨 1/체력 100으로 돌아가는지 확인한다.

다음 개발 단위는 선택 카드의 성향 태그와 점수 표시, 선봉대·추적자 두 직업의 발현 규칙이다. 전용 강화 가지·직업 보상·여러 스테이지로의 성장은 후속 범위이며 사용자 검증 결과에 따라 조정한다.
