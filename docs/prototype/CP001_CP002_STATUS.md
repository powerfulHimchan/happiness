# CP-001/002 구현 상태

| 티켓 | 상태 | 결과 |
|---|---|---|
| CP-001 Godot Android 빌드 스파이크 | 진행 중 | Godot 프로젝트와 가로 화면 설정 완료, Android APK는 실제 SDK 환경에서 확인 필요 |
| CP-002 프레임과 입력 지연 기준 확인 | 진행 중 | 30/60 FPS 전환과 멀티터치 진단 화면 완료, 실제 기기 측정 필요 |

## 구현 내용

- Godot 4.7.2 stable 대상 프로젝트 생성
- 1920×1080 기준 가로 화면과 `canvas_items` 확장 설정
- 모바일 안전 영역을 화면에 표시
- Android 프레임 페이싱 활성화
- 60 FPS / 30 FPS 제한 전환
- 터치 포인터 ID, 좌표, 현재·최대 동시 터치 수 표시
- 세 영역 동시 입력 확인
- 마우스를 단일 터치로 변환해 데스크톱에서도 기본 동작 확인 가능
- GL Compatibility 렌더러 사용

## 환경 확인 결과

현재 자동 작업 환경에는 Godot 실행 파일, Android SDK와 `adb`가 설치되어 있지 않다. 따라서 파일 구성과 참조 관계는 자동 검사했지만 아래 항목은 아직 완료로 표시하지 않는다.

1. Godot의 GDScript 파서로 프로젝트 열기
2. Android Debug APK 생성
3. 실제 기기 설치
4. 실제 기기에서 3개 이상의 멀티터치 확인
5. 30/60 FPS 체감 입력 지연 비교

## CP-001/002 완료 조건

- Godot 4.7.2 Editor에서 오류 없이 프로젝트가 열린다.
- USB 디버깅 기기에 원클릭 배포된다.
- 가로 화면과 안전 영역이 정상 표시된다.
- 세 손가락을 동시에 눌렀을 때 서로 다른 포인터 ID 세 개가 유지된다.
- 20초 동안 드래그해도 터치가 임의로 사라지거나 남지 않는다.
- 30/60 FPS 전환에 따라 표시 FPS가 안정되고 입력이 한 프레임 이상 불필요하게 지연되지 않는다.

실기기 검증을 통과한 뒤 `CP-001`과 `CP-002`를 완료 처리하고 `CP-101 입력 명령 계층`으로 이동한다.
