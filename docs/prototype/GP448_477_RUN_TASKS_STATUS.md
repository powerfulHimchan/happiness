게시판은 전체·수령 가능·수령 완료 필터와6개씩5페이지, 진행 막대와 현재 수치, 미휴대 무기·도전 길이·여정 조건 안내를 제공한다. 선택/열람만으로 보상을 주지 않고 별도 수령 버튼을 누른다. 전투·무기 보상 확정 전·최종 전투 중에는 수령할 수 없다. 보급소로 돌아가 수령한 보급전을 바로 사용할 수 있다.

무기 피해는 기존 `total_damage`, 기술 적중은 `skill_hit_count`를 합산한다. 기본 공격 피해를 포함하고 필살기/동행 피해는 포함하지 않는다. 기술의 다단 적중은 각 유효 타격을 합산하며 빗나간 시전은 진행하지 않는다. 계열 수련6종은 휴대 중인 두 무기에서 진행할 수 있다. 지역 횟수는 완료한 스테이지만 세며, 여정의 지역별 두 구간도 각각1회다. 높은 단계 과제는10스테이지 여정에서 진행한다.

수령은 기존 상점 장부의 `task:<id>` 영수증으로 기록한다. 수입·상품 지출·과제 수입을 장부 순서대로 재계산하고, ID·중복·수령 단계·조건·슬롯/페이로드·잔액과 구매 이력을 검증한다. 상점 이용 과제는 수령 이전의 구매/재입고 영수증만 근거로 삼는다. 저장 실패 시 지급한 보급전과 영수증을 되돌리고 선택을 유지해 재시도할 수 있다. 이어하기는 원래 진행률과 장부를 복원하고 수령한 과제를 다시 지급하지 않는다.

기존 보급소 저장에 `tasks` 표시가 없으면 그 도전은 과제 없이 기존 형식을 유지한다. 새 도전부터 활성화하며 과거 도전에 소급 지급하지 않는다. 기존 체크포인트 버전은 유지한다.
