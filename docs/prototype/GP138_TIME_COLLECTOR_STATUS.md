# GP-138 · 시간 수집

공용 성장 능력 ‘시간 수집’을 도전당 한 번 선택한다. 선택 이후 유효한 일반·정예·보스 처치마다 필살기 게이지를 5 얻고 최대 100을 유지한다. 기본 공격 적중4·스킬 적중8·정확한 회피12의 기존 충전은 그대로 적용한다. 따라서 기본 공격으로 처치하면 적중4와 처치5를 각각 받는다. 선택 전 처치나 카드 선택 자체에는 게이지를 지급하지 않는다.

경험치의 기존 생명 단위 중복 방지 판정을 함께 사용한다. 같은 적의 중복 신호는 충전하지 않고 다시 생성된 생명은 새 처치로 처리한다. 살아 있는 적, 숨긴 적, 연습 표적, 도전 비활성·플레이어 사망 상태의 신호는 제외한다. 공용 및 네 직업 필살기 발동 중에도 충전하지만 지속시간을 늘리거나 즉시 재발동하지 않는다.

HUD의 필살기 이름·게이지/발동 상태 옆에 ‘처치 +5’를 표시한다. 좁은 화면에서도 기존 글자 크기 조정으로 한 줄에 맞춘다. 완료 후 현재 도전 표시를 해제한다. 능력 도감은 원본 정의에서 효과·공용 조건·도전당1회·성향을 읽으며 18능력을 여섯 페이지로 보여 준다. 발견 기록 실패 시 카드 선택은 적용하지 않고 같은 카드로 재시도한다.

기존 성장 등급과 필살기 게이지 필드만 저장한다. 반복 이어하기는 현재 게이지를 보존하고 추가 충전하지 않는다. 새 도전은 능력·게이지를 초기화하며 영구 발견만 유지한다. 능력이 없는 이전 저장은 효과를 자동 지급하지 않는다. 최대1등급을 넘는 변조 저장을 거부한다.
