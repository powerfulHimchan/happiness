## 확인 방법

- 기존 GP-821–830 상태창 그래픽 검사를 사용해 로안·루미의 실제 상태창·상세·선택 화면, 투명 모서리와 독립 그림, 배치·일시정지·파일/RNG 보존을 검사한다.
- 기존 GP-608–617 유물 그래픽 검사로 전체 유물 페이지, 보유·사용 완료 상태, 실제 보상 선택·취소와 저장/전투 상태 보존을 검사한다.
- 기존 GP-548–597 업적 검사로 실제 탐색·칭호 선택·별도 실행 복원과 달성·부분 달성·미달성·오류 상태를 검사한다.
- 1280×720·1600×720·1280×800의 실제 렌더링을 확인한다. 프레임 문장은 제목 영역을 가리지 않도록 측면에 배치한다.
- Android 리소스 팩 내보내기·시작을 확인한다. Android 실기기 플레이는 확인하지 않았다.

## 이번 실행 결과

- 상태창 그래픽 검사 220개 조건과 로안·루미 화면 42장 통과. 장비 프레임의 왕관·달 문장을 측면으로 옮긴 뒤 재확인했다.
- 유물 검사 1,359개 조건과 화면 90장 통과. 보유·사용 완료·선택·취소에 따른 기존 상태와 파일 보존을 확인했다.
- 업적 화면 105장 통과. 실제 칭호 선택·저장·별도 실행 복원 검사도 각각 16,399개·16,185개 조건을 통과했다.
- 세 해상도의 최종 화면 총 237장 생성. 정적 프로젝트 검사, Android 리소스 팩 내보내기 및 팩 시작 검사 통과.
