# GP-150 · 여명의 불씨와 네 유물 선택

두 번째 정예 완료 후 불사조 깃털·시계추 조각·샘의 이슬·여명의 불씨 중 하나를 선택한다. 기존 세 후보의 순서를 유지하고 네 번째 공격형 유물을 추가한다. 불씨는 이번 도전에만 유지하고 사용 횟수를 소비하지 않는다.

| 항목 | 동작 |
|---|---|
| 검·활 기본 공격과 스킬 | 성장·장비·기억·일회 보상을 반영한 피해에1.1배 |
| 공격형 직업 필살기 | 해당 검/활 피해에1.1배 |
| 피해 반올림 | 전체 효과를 곱한 뒤 마지막에 한 번 |
| 체력·회복약·입력·게이지 | 기존 효과 유지 |
| 회복형·공용 필살기 | 회복량·감속 비율·지속 시간 유지 |
| 치명타 | 불사조 효과 없이 정상 사망 |

검 타격과 활 투사체의 기존 피해 처리 경로에 연결한다. 이미 발사한 투사체는 발사 시 계산한 피해를 유지한다. 흡수는 원래 비율로 실제 증가한 피해를 기준으로 계산하며, 중복 타격·투사체 재판정은 추가 피해와 게이지를 지급하지 않는다. 공격형 필살기의 피해 외 감속·지속 시간과 회복형 필살기의 회복량을 바꾸지 않는다. 피해100에 성장30%·일반 희귀 검 피해15%·불씨를 적용하면149.5를 먼저150으로 반올림하지 않고164.45를 최종164로 반올림한다.

실제 네 번째 카드 터치와 확인에서만 획득한다. 체크포인트 저장 실패는 유물과 피해 배율을 롤백하고 기존 파일·성장·체력·회복약·양 대기시간·게이지를 보존한다. 같은 화면에서 재시도할 수 있고 한 도전에서 다른 유물을 추가 획득할 수 없다.

마을 기억의 쉼터의 유물 도감은 네 후보의 원본 효과·조건·보유 상태를 표시한다. 전투 HUD는 불씨와 피해1.1배를 표시하고 현재 도전 상태는 실제 양 무기의 합산 피해를 보여준다. 1280×720·2400×1080에서 네 후보와 도감의 안전 영역·비중첩·설명 글자 폭을 검사한다. 조회·취소·복귀는 효과나 저장을 변경하지 않는다.

기존 유물 상태의 `{id, used}` 형식을 유지하고 불씨 ID만 추가한다. 불씨는 `used: false`만 허용하고 타입·누락·추가 필드·알 수 없는 ID를 거부한다. 저장에는 유물만 기록해 성장 보너스에 중복 복사하지 않는다. 반복 이어하기도1.1배 한 번만 적용한다. 같은 도전의 불사조 소비 저널과 독립적이며, 유물 없는 이전 저장에는 불씨를 소급 지급하지 않는다. 기존 시계추·깃털·이슬의 동작을 유지한다. 사망 시 중간 저장을 정리하고 새 도전에서 불씨를 제거한다.

## 검증

`seed`, `resume`, `finish`, `legacy-seed`, `legacy`, `combat` 여섯 단계는 실제 정예 보상 선택·저장 실패와 재시도, 두 화면비·원본 도감·조회, 별도 프로세스 반복 이어하기와5단계 보스 완주, 기존 저장·기존 시계추·새 도전 초기화를 확인한다. 실제 검 타격과 활 투사체의 기본/스킬143/154피해, 중복 차단, 증가한 실제594피해의 흡수29와 소수14, 기존 게이지24를 확인한다. 두 공격형 필살기는 실제86/69피해, 두 회복형 필살기는 원래40/30회복, 감속·지속 시간·회복약·들어오는 피해·정상 사망을 검사한다.

전체 검사는 기존243단계와 새6단계로 총249단계다. 새 유물의 실기기 플레이는 별도 확인이 필요하다. 명시적 APK 요청이 없어 이번 작업에서는 APK를 생성하지 않는다. PR/main 자동 Godot 검사와 수동 APK 정책을 유지한다.
