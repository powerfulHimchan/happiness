# GP-309 · 행복의 나라 성문

전체 여정의9스테이지 `행복의 나라 성문`에 전용 계단·성벽 쉼터와 배경을 추가한다. 기존 풀숲 다리 대신 고정 충돌 발판6개를 사용한다. 입구→낮은 계단→성문 중앙→내리막→출구 쉼터를 기본 점프로 건널 수 있고, 둘째 전투에는 높은 성벽 발판 위 씨앗 포대를 배치한다. 두 웨이브 모두 슬라임·씨앗 포대·공중 정령3종을 사용하며 기존 적 AI와 갑옷 멧돼지 정예를 유지한다.

흰 성벽·쌍탑·아치·집·깃발과 같은 미소를 짓는 주민3명을 Godot의 벡터 도형으로 그린다. 주민과 건축물은 배경 장식이며 충돌·표적·보상이나 별도 저장 상태를 갖지 않는다. 주민 애니메이션·상호작용·음악은 이번 범위에 포함하지 않는다. 실제 충돌 계단은 표시와 동일한 위치·크기를 사용한다. 기존 전투 관문은 웨이브 완료에 따라 여닫힌다.

8스테이지 뒤 경로 카드·HUD·현재 도전의 지형 이름·구간별 이동/전투 목표를 성문에 맞춰 안내한다. 이야기 모드에서는9스테이지 완료 뒤 `성벽 위의 같은 미소` 장면을 표시하고, 확인하거나 건너뛰면 기존 보상과 중심부 이동으로 돌아간다. 로안·루미의 이름을 반영하며 새 기억 조각·정식 엔딩은 추가하지 않는다.

체크포인트 버전1·기존 `city_gate` 경로 ID를 유지한다. 성문 완료 뒤 체력·장비·성장·스킬 대기·게이지·주인공·이야기 대기 상태를 저장하고 반복 이어하기에서 같은 전용 지형을 다시 구성한다. 보상 쓰기 실패는 선택을 되돌리고 정상 저장을 보존한다. 중심부 이동이나 새 도전에서 성문 몸체와 장식을 제거한다. 기존3/5단계와 지역 순회는 동일한 지형을 사용한다.

## 검증

신규20개 실행 단계: 로안/루미×검/활의 실제 준비 입력과1~8구간 완료·성문 진입, 전용 발판/충돌/카드/HUD, 두 웨이브의 실제 위치와 성벽 위 적, 성문 완료 이야기·저장, 별도 프로세스 반복 이어하기·중심부 이동·구출/파괴 완주, 실제 기본 점프6발판 횡단·낙하 복귀, 보상 저장 실패·재시도·재실행, 조회/마을 정지·일반 도전 회귀를 검사한다. 횡단은2단 점프·공중 대시를 사용하지 않는다.

전체 검사 스크립트는 기존719개와 신규20개를 합친739개 실행 단계 및 Android 리소스 내보내기·변환된 패키지 부팅을 실행한다. 로컬/PR/main 결과는 각 작업 로그에서 확인한다. 자동 검사는 실기기 조작감·프레임률·난이도·전체 여정 소요 시간을 대신하지 않는다.
