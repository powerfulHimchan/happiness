# GP-122 · 지도 제작소·경로 도감

- 마을의 여섯 번째 시설에서 풀숲 길·바람 길·태엽 폐허의 지형, 전투 구성, 보너스, 선택 조건을 비교한다.
- 기존 StageRunner 경로 정의를 그대로 읽는다. 풀숲의 체력 +20과 바람의 게이지 +25는 경로 선택 시, 위험 길의 체력 +20·게이지 +50은 통과 시 지급되는 현재 동작을 구분해 표시한다. 통과 기본 회복은 최대 체력 20%다.
- 실제 스테이지 통과 후에만 답사 완료로 기록한다. 방문·경로 진입만으로는 기록하지 않는다. 보스 스테이지도 전투 통과 시 경로가 답사되며 구출/파괴 결정과 독립적이다.
- 별도 영구 체크섬 저널에 신규 경로를 한 줄로 기록한다. 중복 기록은 쓰지 않는다. 사망·새 도전·도전 기록 초기화 후에도 유지한다.
- 저장 실패는 보상 선택과 중간 저장을 막지 않는다. 지도 제작소의 경로 카드를 눌러 재시도할 수 있다. 정상 중간 저장의 통과 이력으로 재시작 시 복구한다.
- 이전 GP-121 중간 저장과 저널을 그대로 읽고 정상 저장의 실제 통과 이력을 답사 기록으로 옮긴다. 새 중간 저장 필드나 버전 변경은 없다.
- 태엽 폐허는 기존처럼 파괴 핵을 적용한 도전의 2스테이지에서만 선택한다. 도감의 답사 완료는 경로 선택 권한에 영향을 주지 않는다.
- 여섯 시설은 3열·2행으로 배치한다. 기존 다섯 시설의 배열 순서와 약방 조제 터치를 보존한다.

## 검증

`gp122_runtime_test.gd`의 seed/resume/finish/legacy 네 프로세스에서 실제 통과와 입력, 기록 저장 실패·터치 재시도, 중복·잘못된 이벤트·손상 끝줄, 새 도전·기록 초기화, 위험 권한, 이전 중간 저장 복구와 보스 완주를 검사한다. 16:9와 20:9에서 카드와 하단 버튼의 안전 영역·겹침 및 마을 물리 동결을 확인한다. 기존 CP/GP 실행 검사도 함께 실행한다.

Android 버전: `0.0.49-gp122-route-atlas` / versionCode 49 / ARM64. 실기기 플레이와 실제 글자 가독성 확인은 별도 확인 대기다.
