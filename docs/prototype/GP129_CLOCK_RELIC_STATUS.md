# GP-129 · 시계추 조각과 두 유물 선택

두 번째 정예 완료 후 유물 화면에서 불사조 깃털·시계추 조각 두 후보를 비교하고 하나를 확정한다. 기본 선택은 기존 깃털이며 다른 카드를 터치하면 강조와 확정 문구가 바뀐다. 나중에 선택하거나 유물 없이 다음 스테이지로 갈 수 있다. 획득 후 다른 유물은 같은 도전에서 지급하지 않는다.

- 시계추 조각은 검·활 각 두 액티브 스킬의 실제 재사용 대기를 20% 줄인다. 원본 타이머를 1.25배 속도로 소진하므로 10초가 8초, 7초가 5.6초가 된다. 사용하지 않는 보조 무기도 적용된다.
- 기본 공격·콤보·스킬 준비와 타격 시점·회피·무기 전환·필살기의 시간 및 피해는 기존 동작을 유지한다. 획득 시 진행 중인 원본 타이머를 초기화하지 않는다. 스킬 교체는 원래 규칙대로 기존 잔량과 새 기술 기본 대기 중 긴 값을 사용한다.
- HUD와 스킬 후보/현재 슬롯 비교는 실제 초 단위를 표시한다. 유물 HUD는 ‘시계추 조각 · 스킬 대기 -20%’를 표시한다.
- 저장은 기존 유물 구조 `{id, used}`와 양 무기의 원본 타이머를 사용한다. 시계추는 `clock_fragment`·`used=false`만 허용한다. 알 수 없는 유물·잘못된 타입·추가 필드·소비된 시계추는 정상 저장을 덮어쓰지 않는다.
- 획득 저장 실패는 유물·효과를 되돌리고 원본 타이머·기존 정상 파일·선택 화면을 보존한다. 같은 카드로 다시 확정할 수 있다. 저장 성공 후 화면과 HUD에 효과를 적용한다.
- 별도 프로세스와 반복 이어하기는 원본 타이머를 복원하며 배율을 누적하지 않는다. 불사조 소비 저널은 깃털에만 적용한다. 시계추로는 부활하거나 깃털 소비를 기록하지 않는다. 깃털의 기존 50% 부활·1초 보호·소비 저널은 유지한다.
- 유물 필드가 없는 기존 저장은 유물 없이 복원한다. 새 도전은 유물·효과를 초기화하며 영구 해금은 유지한다.
