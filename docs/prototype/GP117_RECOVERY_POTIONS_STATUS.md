# GP-117 · 전투 회복약

기획의 기본 회복약을 전투 액션으로 연결한다. 도전 시작에 두 회를 지급하고 사용하면 현재 최대 체력의 25%를 정수 올림으로 회복한다. 최대 체력을 넘기지 않으며 만피, 소진, 사망, 낙하 복귀·입력 잠금에서는 소비하지 않는다. 공격·회피를 취소하거나 무적·부활을 지급하지 않는다. 전투 진행 화면에서만 사용할 수 있으며 레벨 선택·직업 확인·중간 보상·마을·배치 연습 중에는 실제 회복하지 않는다.

회복 버튼은 남은 횟수와 회복 비율을 표시한다. 기본·왼손 프리셋에 추가하고 기존 조작 편집의 위치·크기·불투명도·저장을 사용한다. 사용 가능한 피해 상태는 초록색, 만피·소진은 흐린 색이다. 누른 상태의 드래그·유지로 반복 사용하지 않으며 명령 큐는 회복 입력 하나만 보관한다. 기존 조작 저장의 정상 요소는 유지하고 누락된 회복 버튼만 해당 프리셋 기본 위치로 복구한다.

남은 횟수를 체력과 같은 체크섬 중간 저장에 기록한다. 다음 스테이지·스테이지 회복·무기 교체에서 보충하지 않는다. 재실행 이어하기는 소진된 0회도 보존하며 새 도전에서만 두 회로 초기화한다. 회복약이 없던 GP-116 이전 정상 저장은 미사용 두 회로 복원한다. 범위 밖·소수·잘못된 타입의 횟수 저장은 거부하고 이전 정상 파일을 보호한다. 스테이지 중 실시간 저장은 기존 설계대로 제공하지 않으며 마지막 완료 지점부터 이어한다.

GP-117 네 별도 프로세스 검사에서 실제 피해·모바일 입력·25% 회복·소진, 만피 소비 방지·최대 체력 상한, 성장 후 남은 횟수, 스테이지 전환·이어하기, 새 도전, 사망·낙하 복귀·선택·배치 연습 차단, 공격 상태 보존, 손상 저장·이전 저장·조작 설정 호환을 확인한다. 16:9/20:9 양손 프리셋의 안전 영역·터치 겹침·그리기와 기존 77회 회귀 검사도 함께 실행한다. 약방 NPC·회복약 강화·회복 구슬·유물은 이후 범위다. 시제품의 스테이지 완료 회복 20%는 유지한다.
