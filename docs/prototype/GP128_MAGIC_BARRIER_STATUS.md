# GP-128 · 성장 능력 마력 방벽

공용 성장 카드 ‘마력 방벽’을 도전당 한 번 선택한다. 선택 즉시 방벽 20을 지급하고, 이후 실제 다음 스테이지 진입 시 20으로 충전한다. 마을 능력 도감은 카드 원본을 사용해 14개 능력을 표시하며 실제 선택의 영구 발견을 기록한다.

- 유효한 새 피해 사건만 방벽을 소비한다. 체력 피해보다 먼저 흡수하며 초과분만 체력에서 뺀다. 잘못된 사건·같은 타격 중복·사망 후 타격·회피 및 피격 무적은 방벽을 소비하지 않는다. 완전 흡수도 정상 피격 집계·경직·피격 후 무적을 유지한다.
- 파괴 보상의 받은 피해 +10%를 먼저 계산한 후 방벽이 흡수한다. 원본 사건은 수정하지 않는다. 낙하 환경 피해는 기존 환경 경로로 체력에 적용한다.
- 체력 HUD에 방벽 잔량을 표시하고 플레이어 주변 원호의 길이로 잔량을 표현한다. 체력/방벽 문구는 왼쪽 HUD 폭에 맞춰 글자 크기를 조절한다.
- 회복약·처치 회복 구슬·생명 흡수·구출 조력은 기존 체력 회복으로 유지하며 방벽을 충전하지 않는다. 낮은 체력에서 완전 흡수한 타격은 구출 조력을 소비하지 않는다. 초과 체력 피해에는 기존 구출 조력이 적용된다. 방벽을 넘은 치명타만 불사조를 소비하며 부활은 방벽을 재충전하지 않는다.
- 획득 기록 저장 실패는 방벽·등급·성향을 적용하지 않고 같은 카드 재선택을 기다린다. 중간 보상 저장 실패는 기존 정상 저장과 잔량을 보존한다.
- 중간 저장의 선택적 `player.barrier_health`는 0–20의 정수 수치를 허용한다. 해당 능력 없이 양수 잔량·잘못된 타입·범위는 거부한다. 필드가 없는 이전 저장은 0으로 읽는다. 별도 프로세스와 반복 이어하기는 저장 잔량만 복원하며, 휴식·보상 조회·마을 방문은 충전하지 않는다. 새 도전은 능력·잔량을 초기화하고 영구 발견은 유지한다.
