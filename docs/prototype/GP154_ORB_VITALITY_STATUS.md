# GP-154 · 회복 구슬 강화

구슬 자석을 먼저 얻은 뒤 공용 성장 능력 회복 구슬 강화를 도전당 한 번 선택한다. 회복 구슬의 회복량이 현재 최대 체력의10%에서20%로 늘어난다. 정수 백분율로 계산한 뒤 소수를 올림하고 현재 체력을 최대 체력까지 제한한다. 최대 체력100/101/105/110/120/300에서 각각20/21/21/22/24/60을 회복한다. 선택 전에 떨어진 구슬도 다음 획득부터 적용한다. 선택 자체는 체력을 회복하지 않는다.

자석의1.52m 획득 거리와 일반 적 드롭 확률20%·생명당 한 번 추첨·스테이지 두 개 상한·안전 지면 배치를 유지한다. 만피에서는 구슬을 소비하지 않고 피격 경직·낙하 복귀·사망·일시정지·환경 동결·단계 완료·도전 종료·비전투 화면에서 획득을 차단한다. 구슬 회복 집계와 팝업은 최대 체력 상한을 반영한 실제 회복량을 사용한다. 회복약 조제·봄의 이슬·방벽·양 무기 대기·필살기 게이지의 규칙은 별도로 유지한다.

실제 성장 카드 선택과 영구 발견 기록 성공 후에만 효과를 적용한다. 선행 없는 후보·위조 확정과 중복 선택을 거부하며 기록 실패 때는 같은 카드를 재선택할 수 있다. 기존 성장 등급에 `orb_vitality: 1`만 추가한다. 등급 타입/범위와 선행 능력을 기존 저장 검증으로 확인하고 별도 회복 효과 필드는 저장하지 않는다. 이전 자석 저장은10%로 복원하며 반복 이어하기는20%로 복원하고 무료 회복이나 구슬을 지급하지 않는다. 스테이지 간 효과를 보존하고 새 도전에서10%·기본 거리로 초기화하되 영구 발견은 유지한다.

26종 능력 도감에 원본 효과·구슬 자석 선행 조건·발견·현재 등급을 표시한다. 현재 도전의 생존 카드에 구슬 회복 백분율과 현재 최대 체력 기준 정수 회복량을 추가하고, 떨어진 구슬의 설명도 현재10%/20%를 표시한다. 조회는 체력·성장·장비·대기시간·저장 파일을 변경하지 않는다.

## 검증

`seed`, `resume`, `finish`, `legacy-seed`, `legacy`, `combat` 여섯 실행을 전체 Godot 검사에 추가한다. 실제 처치 레벨업·자연 후보·모바일 카드 터치·영구 기록 실패 재시도·선행/중복 거부·정상 저장 보호·별도 프로세스 반복 복원·5스테이지 보스 완주·기존 자석 저장·새 도전 초기화를 검사한다.

실제 구슬 획득에서 현재 최대 체력에 따른20% 올림·팝업·집계·체력 상한·중복 회복 차단, 세 조제와 이슬 조합의 원래 회복약 비율을 확인한다. GP-153의 실제 드롭/거리/잠금 검사 경로를 강화 상태에서도 실행해 거리 경계·만피 보존·여덟 잠금·중복 생명·두 개 상한·완료 화면·다음 스테이지·사망 정리를 확인한다. 1280×720·2400×1080의 성장 카드·전체 도감·생존 카드 안전 영역과 설명 너비, 조회 후 파일 보존을 검사한다.

기존258개와 새6개로 총264개의 runtime test 성공을 기준으로 검증한다. 실기기 플레이는 별도 확인이 필요하다. APK는 명시적 요청이 있을 때만 만든다.
