## 보상·전투·저장

정예 보상의 `다른 후보`에서 새 스킬을 확인하고 두 슬롯 중 하나를 교체한다. 이전 대기시간과 새 스킬 원본 대기시간 중 큰 값을 유지한다. 도감은 장착 슬롯·원본 피해·재사용 시간·시계추 보정을 표시한다. 기존 체크포인트 버전을 그대로 사용하고 다른 계열의 스킬을 슬롯에 넣은 저장은 거부한다. 이전 저장의 스킬을 소급 변경하지 않는다.

모든 근접 기술은 실제 타격 시점의 범위를 검사한다. 전후방 교차는 시전 방향을 기준으로 판정한다. 강제 전진/후퇴는 기존 이동·벽 충돌·회피 취소 규칙을 사용하며 추가 무적은 없다. 장봉 밀침과 방패 기절은 일반 적에만 적용한다. 수호 돌진의 방어는 기존 방패의 후방/함정/무적/중복 피해 제외 규칙을 공유하고 응수 강화는 준비하지 않는다.

불씨 연사는 각 발사에 별도의 타격 식별자를 사용해 같은 표적에도 세 발이 모두 피해를 준다. 낙뢰 범위와 잔광은 시전 위치에 고정한다. 성장·장비·흡수·게이지·피해 통계는 기존 계열의 공통 경로를 따른다. 투사체·잔광·밀침·기절은 일시 상태이며 저장하지 않는다.

## 그래픽

네 계열의 전용 SVG 무기, 캐릭터별 보석 강조색, 타격 원호·금빛 파동권·불꽃 꼬리·얼음 창끝·꺾인 번개·방어/응수 고리를 연결한다. 사망·낙하·부활 시 남은 근접 잔광도 즉시 정리한다. 원형 방패격은 실제 좌우 방향으로 방패를 표시한다. [리소스 설명](../../game/assets/weapons/README.md).

## 검증

- 신규 실행 검사: 10스킬 × 2주인공 × 2방향 × 전투/보상저장/별도프로세스이어하기 = 120시나리오. 큰 프레임에서 모든 타격, 후방/범위 경계, 고정 낙뢰, 연사3발, 밀침/기절, 방어 종료, 취소/전환/낙하/사망, 실제 후보 페이지, 저장 실패 되돌림과 변조 거부를 검사한다. CI에 같은120시나리오를 등록한다.
- JSON 숫자는 메모리의 정수와 저장 파일의 실수 타입을 구분해 비교하되 실제 값·장착 슬롯·두 계열·활성 무기·청사진·모든 전투 집계/대기시간은 유지되는지 확인한다.
- 기존 외형/이동/전투 애니메이션, 검·활 스킬/도감, 네 추가 계열의 실제 전투/직업/저장 호환 검사를 실행한다.
- 실제 화면 렌더링과 Android 리소스 팩 내보내기·팩 부팅을 확인한다. Android 실기기 조작·체감 밸런스는 별도다. APK는 생성하지 않는다.
