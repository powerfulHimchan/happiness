# GP-166 · 결투의 문장

검과 활의 기본 공격 피해에1.2배를 적용한다. 성장·장비·일회 보상 뒤 최종 정수 반올림을 하며 스킬·공격 필살기는 해당 배율에서 제외한다. 보조 무기도 동일하게 적용한다. 활 근접 보정·공격 속도·게이지·흡수의 기존 규칙을 유지하며 흡수는 실제 적용 피해로 계산한다.

## 저장·표시

새 유물은 실제 두 번째 정예 보상에서 한 도전에 하나만 선택한다. 획득 자체는 체력·회복약·게이지·성장·양 무기 원본 대기를 변경하지 않는다. 기존 `relic`의 ID와 `used: false`만 저장하고 효과 배율을 중복 저장하지 않는다. 정상 저장 후 적용하고 실패하면 효과를 롤백한 상태로 같은 카드에서 재시도한다. 변조된 ID·사용값·추가 필드를 거부해 정상 파일을 보호한다. HUD·도감·현재 도전 상태에서 원본 효과와 실제 상태를 표시한다.

## 검증

`gp162_166_runtime_test.gd`는 네 유물 각각 `seed`, `resume`, `finish`, `combat`으로16개 실행을 검사한다. 실제 정예 진행·페이지 터치·확정·저장 실패 재시도·별도 프로세스 반복 이어하기·5스테이지 보스 선택·새 도전 초기화를 확인한다. 기존 유물/이전 저장 검사는 전체 검사에 유지한다. 두 화면비(1280×720, 2400×1080)의 모든 보상/도감 페이지에서 입력 안전 영역·비중첩·설명 글자 폭/높이와 조회 파일 보존을 검사한다.

수호의 인장은 실제 피해·방벽·무적·중복·파괴 핵·환경 피해·사망을, 바람의 매듭은 실제 모바일 회피·원본 무적/동작·민첩한 회피·남은 대기 보존·공중 대시를 검사한다. 씨앗은 실제 적 처치 드롭·구슬 획득·자석/구슬 강화·만피/조회 잠금·실회복 집계를 검사한다. 문장은 실제 검 타격·활 투사체의 기본/스킬 구분·장비/기억/파괴 핵·흡수/게이지/대기·공격 필살기 제외를 검사한다. 기존299개에 새16개를 더한315개 runtime 성공을 전체 검증 기준으로 사용한다. 실기기 플레이는 별도 확인이 필요하며 APK는 요청 시에만 만든다.
