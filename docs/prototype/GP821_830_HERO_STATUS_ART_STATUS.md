## 적용 범위

`HeroStatusArt`에서10개 리소스를 한 번 참조한다. 다섯 능력치 문양은 수치 왼쪽에 표시하고, 로안·루미 문장은 상태 화면의 고유 특성 패널과 주인공 선택 포스터에 함께 표시한다. 공격·방어·고유 특성 상세에도 같은 문양을 사용한다. 주·보조 프레임은 현재 무기의 이름·등급·아이콘 뒤에 표시한다.

문양·라벨·숫자의 영역을 분리하고, 선택 화면의 긴 효과 설명은 기존 글자 크기 조절을 사용한다. 장비·스킬·특성의 터치 영역은 기존 좌표를 유지한다. 배경 장식은 텍스트가 있는 패널보다 뒤에 배치한다.

## 검증

`gp821_830_art_runtime_test.gd`는10개 SVG의 실제 가져오기·서로 다른 이미지 내용·문양의 투명 여백·두 주인공의 올바른 문장·문양과 글자 비중첩·안전 영역을 확인한다. 실제 준비 화면과 상태/상세 탐색 전후 전투 상태·치명타 난수·저장/기록 파일이 바뀌지 않는지도 검사한다.

실제 렌더러에서 로안/루미 ×1280×720·1600×720·1280×800 ×상태/공격/방어/특성/주무기/보조무기/주인공 선택42장을 확인한다. 기존 주인공 선택 및 상태 화면 검사와 Android 리소스 내보내기/패키지 부팅도 확인한다. 실기기 플레이는 별도 확인 대상이다.

확인 결과: 신규 그래픽 검사177개 assertion과 실제 렌더링42장(렌더 실행220개 assertion), 기존 주인공 준비1333개 검사 및 상태 화면671개 assertion을 통과했다. Android 리소스 내보내기와 패키지 부팅도 통과했다. 그래픽과 연결된 화면을 검사했으며 전체 전투 조합의 재검사 완료를 뜻하지 않는다.
