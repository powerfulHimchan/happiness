# GP-132 · 대장간 스킬 도감

기존 마을 첫 번째 시설 대장간에 **무기 설계도 / 스킬 도감** 탭을 추가한다. 설계도 두 카드와 영구 해금 조건을 유지하고, 설계도가 잠겨 있어도 스킬 도감은 언제든 조회할 수 있다. 여섯 시설의 위치와 새 도전·이어하기 버튼은 유지한다.

- 검·활 각 다섯 기술을 실제 `PrototypeSkillRewards.SKILLS`, `POOLS`, `SkillDefinition`, `lines()`에서 읽어 번갈아 표시한다. 한 페이지 세 카드, 총 네 페이지이며 마지막 페이지에는 집중 사격 한 카드가 있다. 이전·다음 버튼은 페이지 범위를 벗어나지 않는다.
- 원본 이름·무기 종류·재사용 시간·동작 시간·타격 수·기본 피해·범위·교체 조건을 비교한다. 표기 피해는 장비·성장 강화 전 기본값임을 안내한다.
- 진행 중인 도전은 양 무기의 장착 슬롯 1/2 또는 미장착을 표시한다. 무기 전환과 관계없이 두 무기 정보를 조회한다. 시계추 조각을 획득하면 원본 재사용 시간을 실제 충전 배율 1.25로 나누어 표시한다. 집중 10초→8초, 삼연 9초→7.2초이며 보조 무기에도 적용한다. 현재 남은 대기시간을 기본 재사용 시간과 혼동하지 않는다.
- 첫 화면·완주 뒤에는 시작 장착 슬롯과 보상 교체 스킬을 안내한다. 저장된 도전이 있어도 이어하기 전에는 해당 저장 구성을 적용하지 않는다. 실제 이어하기 후 저장 슬롯·유물 효과를 복원하고 새 도전은 기본 구성으로 초기화한다.
- 조회·페이지·탭·카드 터치·마을 복귀는 스킬 지급/교체, 정예 보상 확정, 체력·회복약·필살기·대기시간·성장·발견 기록·중간 저장·보스 메타를 변경하지 않는다. 스킬 교체는 기존 정예 보상 화면에서만 가능하다. 추가 저장 필드나 영구 스킬 발견 파일은 만들지 않아 이전 저장을 호환한다.

## 검증

`gp132_runtime_test.gd` seed/resume/finish/legacy 네 별도 프로세스를 기존 전체 검사에 추가한다. 실제 시설·탭·페이지·카드·뒤로·이어하기 터치, 1280×720/2400×1080 안전 영역·입력 비중첩·글자 너비·줄 높이와 실제 그리기를 확인한다. 모든 10기술 중복 없는 조회·양 끝 범위 제한·설계도 탭 보존·첫 방문 저장 생성 없음·모든 상태 보존을 검사한다.

실제 첫 정예 보상의 삼연 슬롯2 교체, 두 번째 정예 시계추 선택 및 집중 슬롯1 교체, 교체 저장 실패 롤백 및 재시도 후 도감 정보 갱신, 재시작 첫 화면·반복 이어하기·감소한 재사용 시간, 보스 완주·새 도전 초기화, 스킬/유물 필드 없는 이전 저장의 실제 완주를 확인한다. 자동 검사는 Android 실기기 가독성·플레이 확인과 구분한다.

Android versionCode 59 / `0.0.59-gp132-skill-codex` / ARM64. 실기기 확인은 별도 대기이며 CI는 임시 디버그 서명을 사용한다.
