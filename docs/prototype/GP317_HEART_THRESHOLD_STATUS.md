# GP-317 · 행복의 심장 입구

## 동작

- 이야기를 켠 새 전체 여정에서 세라 선택 후 `행복의 심장 앞에서` 3페이지를 표시한다. 구출하면 세라가 궁전 지하의 길을 안내하고, 파괴하면 주인공이 홀로 문을 연다. 로안/루미 이름과 성문 수호기사의 선택도 반영한다.
- 심장 입구 문양과 장면별 확인/건너뛰기 문구를 사용한다. 장면 중 전투·체력·재사용·시간은 정지한다. 마지막 `여정 기록` 또는 `건너뛰고 기록` 입력 뒤 기존 결과로 돌아가며 입구 도착을 표시한다.
- 이 범위는 심장 입구와 후속 이야기다. 현재 10스테이지 구조를 유지하며 심장 내부 전투·첫 정식 엔딩·진 최종 보스는 후속 범위다.
- 세라 선택의 영구 보상은 확정 즉시 기록한다. 입구를 확인하기 전에는 완주·세라 여행 기록을 확정하지 않는다. 이미 해금한 지원/설계도와 기사 보상은 그대로 유지한다.

## 저장과 이전 버전

- 버전1을 유지하고 새 이야기 전체 여정에만 선택 필드 `stage.heart_threshold`를 저장한다. `unreached` → 세라 선택 시 `pending` → 장면 확인 시 `seen` 순서다.
- 미확인 상태로 앱 종료 후 이어하면 동일한 세라 선택과 장비/체력/필살기/재사용 잔량을 복원하고 입구 장면 첫 페이지를 표시한다. 보스는 재전투하지 않는다.
- 선택 저장 실패는 선택과 입구 상태를 함께 되돌린다. 확인 저장 실패는 장면에 남아 재시도하며 이전 정상 파일을 보호한다. 영구 보상 저장 실패도 장면 확인을 막고 재시도한다. 확인 후 결과·기록 쓰기 실패 시 기존 확정 체크포인트 복구를 사용한다.
- 입구 상태가 없는 이전 저장은 소급 변환하지 않으며 기존 세라 또는 태엽 기사 완료 흐름을 유지한다. 이야기 꺼짐·일반3/5단계·지역 순회에는 새 장면을 강제하지 않는다.
- 타입·상태·선택·보스·이야기와 모순되는 입구 저장을 거부한다. 중복 확인·반대 선택 변경·반복 복원으로 보상이나 완주를 중복 기록하지 않는다.

## 검증

- 신규36개 실행 단계: 로안/루미 × 검/활 × 구출/파괴의 별도 프로세스 생성/복원/확인24개, 두 선택의 확인 저장 실패·보상 실패·변조·이전 저장·이야기 꺼짐·화면 배치12개.
- 기존 GP-315 세라 완료 검사는 새 입구 확인을 실제 완료 경로에 포함한다. GP-316 보상 실패 검사는 입구에서 재시도하고 완료하며, 이전 확정 선택 검사는 새 필드 없는 이전 파일로 검증한다.
- PR과 main의 기존 자동 실행 검사, Android 리소스 내보내기·패키지 부팅을 사용한다. APK 빌드는 수동 정책을 유지한다. Android 실기기 터치·성능 확인은 별도다.
