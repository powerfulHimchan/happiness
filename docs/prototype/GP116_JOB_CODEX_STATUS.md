# GP-116 · 마을 직업 도감과 영구 발견

마을의 네 번째 시설인 직업 도감에서 현재 시제품의 선봉대·추적자를 확인한다. 미발견 직업도 성향 조건, 직업 패시브, 전용 능력 카드 두 종류, 필살기 두 종류를 보여준다. 조건과 효과는 실제 전투·직업 판정 데이터를 사용한다. 현재 진행 중 도전에서 발현한 직업을 표시하며 도전 종료 후 해당 표시는 해제한다.

직업이 실제 자동 발현한 즉시 기존 체크섬 영구 저널에 `job` 이벤트를 기록한다. 중간 저장·도전 진단 기록과 독립적이며, 새 도전·사망·진단 기록 초기화 뒤에도 발견을 유지한다. 동일 직업의 반복 발견은 추가 쓰기나 수치 누적이 없다. 발견만으로 시작 직업을 고정하거나 패시브·필살기·보상·기억·설계도를 지급하지 않는다. 6기본/12상위 직업 확장은 이후 범위다.

영구 기록 저장이 실패하면 발현 화면에 재시도 안내를 표시한다. 필살기 선택 후 확인을 눌러 다시 저장할 수 있으며, 성공 전에는 선택을 확정하거나 전투를 재개하지 않는다. 중간 저장에서도 직업 기록 저장을 먼저 확인한다. 이전 버전의 정상 이어하기 저장에 발현 직업이 있으면 그 직업만 영구 기록으로 복구한다. 복구 저장 실패 시 이어하기·새 도전을 보류하고 기존 정상 중간 저장을 유지한다. 복구는 반복 조회에도 중복 쓰기가 없다. 기존 영구 저널의 보상·소비·기억·설계도 이벤트 형식은 유지한다.

미발견/발견 상태, 실제 선봉대·추적자 발현, 기록 실패·확인 재시도, 조건 이전 미발견, 현재 직업 표시, 중간 저장·이어하기, 사망·새 도전·진단 기록 초기화 독립성, 손상 끝줄·잘못된 직업, 이전 저장 복구 실패·복구 성공을 다섯 별도 프로세스에서 확인한다. 네 마을 시설과 도감의 16:9/20:9 안전 영역·터치·그리기를 확인하고 기존 CP-206~406·GP-101~115 회귀 검사를 함께 실행한다.
