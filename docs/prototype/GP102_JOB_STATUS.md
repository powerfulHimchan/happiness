# GP-102 · 직업 성향과 자동 발현

GP-101의 경험치·능력 선택에 선봉대와 추적자 두 기본 직업을 연결한 개발용 시제품이다. 기존 빌드의 20분 실기기 안정성은 2026-09-30 사용자 보고로 통과했다. 이번 새 직업 기능의 실기기 검증은 별도로 진행한다.

## 구현 범위

- 카드에 성향 태그 두 개를 부여하고 선택 시 능력 출처 점수를 누적한다.
- 실제 전투 적의 검·활 적중 신호와 정확한 회피 신호로 무기·특수 행동 점수를 누적한다. 연습 표적, 숨겨진 적, 피해 없는 적중은 제외한다.
- 능력 70%, 무기 20%, 특수 행동 10% 가중치를 적용한다. 각 출처의 점수 상한에도 같은 비율을 적용하여 반복 공격·회피만으로 직업을 발현할 수 없다.
- 주 성향 5점과 보조 성향 3점이 모두 충족되면 즉시 자동 발현한다. 두 직업이 동시에 충족되면 성향 합계가 높은 직업, 동점이면 최근 선택 능력과 더 일치하는 직업을 우선한다. 완전 동률은 정의 순서로 결정한다.
- 시작 검은 초기 성향만 제공한다. 이후 활 능력을 선택하면 추적자로 발현할 수 있다.
- HUD에 가장 가까운 직업과 두 성향의 남은 점수를 표시한다. 남은 점수는 미충족 값이 0으로 보이지 않게 소수 첫째 자리에서 올림한다.
- 카드에 해당 선택으로 얻는 가중 성향을 소수 둘째 자리까지 표시한다.
- 발현하면 전투를 멈춰 직업·패시브를 알리고, 확인 터치 후 재개한다. 대기 레벨업 카드와 초과 경험치는 보존한다.
- 직업은 이번 도전 동안 고정하며 패시브를 한 번만 적용한다. 재도전 시 점수·직업·패시브·표식을 초기화한다.

| 직업 | 주 성향 | 보조 성향 | 즉시 패시브 | 머리 위 표식 |
|---|---|---|---|---|
| 선봉대 | 근력 5 | 투지 3 | 검 기본 공격·스킬 피해 +10% | 금색 마름모 |
| 추적자 | 사격 5 | 자연 3 | 활 기본 공격·스킬 피해 +10% | 초록 원형 조준 표식 |

## 시제품 점수

기본 성향 점수에 출처 가중치를 곱한다. 아래 값과 패시브는 한 스테이지에서 발현을 시험하기 위한 임시 밸런스다. GDD의 보통 2~4스테이지 발현 시점은 여러 스테이지 구현 후 조정한다.

| 출처 | 가중 후 주 성향 증가 | 가중 후 보조 성향 증가 | 주/보조 성향별 상한 |
|---|---:|---:|---:|
| 관련 무기 카드 1회 선택 | 1.75 | 1.05 | 능력 전체 7 / 4.2 |
| 시작 검의 초기 성향 | 근력 0.20 | 투지 0.12 | 무기 전체 2 / 1.2에 포함 |
| 전투 적에게 해당 무기로 1회 적중 | 0.02 | 0.012 | 무기 전체 2 / 1.2 |
| 해당 무기 사용 중 정확한 회피 | 0.05 | 0.03 | 특수 행동 전체 1 / 0.6 |

한 회피 행동에서 정확한 회피 신호가 여러 번 발생해도 한 번만 점수를 준다. 무기·특수 행동의 합계 상한은 주 성향 3, 보조 성향 1.8이므로 능력 선택이 필수다. 관련 무기 카드를 세 번 선택하면 능력만으로 주 5.25·보조 3.15가 되어 발현한다. 선봉대는 검 카드, 추적자는 활 카드 선택으로 확인할 수 있다.

공용 카드는 새벽의 힘(근력·사격), 튼튼한 심장(근력·자연), 다시 일어서기(자연·투지)로 성향을 나눈다. 원점수는 `PrototypeGrowthController.CARDS`, 가중치·상한·조건은 `PrototypeJobProgress`에서 관리한다.

## 자동 검사

`gp102_runtime_test.gd`에서 가중치와 상한, 두 성향 조건, 동시 조건과 동점, 시작 무기의 비고정성, 두 직업의 실제 선택 경로·패시브, 중복 회피·패시브 차단, 도전 중 고정, 재도전 초기화, 발현 화면 일시정지·터치·앱 복귀 알림·16:9/20:9 안전 영역, 대기 카드·경험치 보존, 마지막 정예 이후 결과 전환, 사망·씬 종료 시 정지 해제를 검사한다. 단계 전환은 테스트 피해와 신호로 재현하며 사람의 실제 플레이 검증과 구분한다. 기존 CP 테스트와 GP-101 성장 단독 회귀 검사도 유지한다.

## 실기기 확인

1. 카드 아래의 성향과 HUD의 가까운 직업·남은 점수를 확인한다.
2. 검 관련 카드를 반복 선택해 선봉대 알림, 패시브와 금색 마름모를 확인한다.
3. 재도전 후 활로 전환하고 활 관련 카드를 반복 선택해 추적자 알림과 초록 원형 표식을 확인한다.
4. 발현 알림에서 앱을 백그라운드로 보냈다가 돌아와 확인 버튼으로 전투를 재개한다.
5. 이미 직업이 발현한 뒤 반대 무기를 사용해도 직업이 바뀌지 않고, 재도전하면 초기화되는지 확인한다.
