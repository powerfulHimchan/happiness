# GP-237–246 · 별시계 유적 경로

다음10단계는 기존3·5스테이지 시제품에 별시계 유적을 선택 경로로 추가한다. 첫 스테이지 이후 선택하며, 이전 경로와 파괴 핵의 위험 경로 조건을 유지한다.

| 단계 | 구현한 동작 |
| --- | --- |
| GP-237 | 경로 선택은 한 페이지 최대4카드. 파괴 핵 적용 시 다섯 후보를 두 페이지로 표시하고 이전 경로 순서 유지. 페이지·보상 취소는 저장/성장 무변경 |
| GP-238 | 첫 정예 보상 이후 별시계 유적 선택. HUD·목표·경로 안내·전투 변형을 함께 적용 |
| GP-239 | 두 시간 발판은 정지1.5초→이동1.5초→정지1.5초→복귀1.5초 반복. 반대 방향으로90px 이동하며 입구/중앙 고정 쉼터는 낙하 복귀점 제공 |
| GP-240 | 두 전투 웨이브의 시간 함정: 노란 점선1초 경고→붉은 영역0.3초 발동→2.5초 휴식. 점프/이동/회피로 영역을 피할 수 있음 |
| GP-241 | 함정12피해·주기당 한 타격·고유 피해 ID. 방벽 선흡수, 정확한 회피 게이지, 필살기 감속, 일시정지, 사망·웨이브 종료 정리 연결 |

## 자동 검증

신규22개 실행 단계는 검/활 각각의 완료→복원→5단계 완주, 이전 바람 저장 호환, 실제 파괴 핵 적용 다섯 경로 선택과 보상 취소, 답사 쓰기 실패/재시도·복원, 시간 발판 위상/기본 점프/탑승 운반/낙하 복귀/일시정지, 함정 피해·방벽·정확한 회피·감속·마을 환경 정지·사망 정리, 양방향 인형 실제 발사체·고유 ID·고정 조준·재사격 경고·피격 취소를 검사한다.

방벽 보상 저장 검사는 실제 처치 경험치로 자연 성장 후보를 선택해 해금한 방벽을 사용한다. 복원 시 보너스가 중복되지 않는지 확인한다. 기존 경로 후보 수와 도감의 새 카드 수를 반영한 기존 검사도 유지한다.

전체 검사 스크립트는 기존518개+신규22개, 총540개 실행 단계와 Android 리소스 내보내기·패키지 부팅을 실행한다. APK 빌드는 명시적인 요청 시에만 실행한다.

## 확인 범위

유적은 기존 선형 스테이지의 선택 경로 시제품이다. 지역별 전체 랜덤 스테이지나10스테이지 완성 버전은 아니다. 실기기 발판 조작감, 함정/인형 난이도와 모바일 렌더링 성능은 별도 플레이 확인이 필요하다.
