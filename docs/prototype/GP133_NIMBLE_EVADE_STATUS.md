# GP-133 · 민첩한 회피

성장 공용 카드 **민첩한 회피**를 추가한다. 도전당 1회 선택하며 선택 후 시작하는 지상 회피의 재사용 시간을 0.45초에서 0.36초로 줄인다. 이미 진행 중인 회피의 잔여 대기시간을 줄이거나 즉시 회피를 지급하지 않는다. 반복 선택·반복 복원·시계추 유물로 감소 효과가 중첩되지 않는다.

- 실제 유효 성장 선택과 영구 발견 기록 저장이 성공한 뒤에만 적용한다. 실패하면 등급·성향·효과·현재 잔여 대기를 유지하고 같은 카드를 다시 선택한다. 최대 1등급과 이미 보유한 카드의 후보 제외를 기존 공통 검증으로 처리한다.
- 지상 회피의 방향·속도 9m/s, 동작 0.24초, 무적 0.18초를 유지한다. 공중 대시의 9.5m/s·0.18초·공중 1회·착지 충전을 유지한다. 동작 중·재사용 대기·복귀/피격 잠금·공격 취소 불가·사망 시 입력을 차단한다.
- 능력 보유 시 지상 회피 버튼에 실제 남은 대기를 0.01초 단위로 올림 표시한다. 사용 가능하면 ‘민첩 회피’로 표시한다. 공중에서는 기존 ‘회피’ 표시를 유지한다. 양 무기 스킬·필살기·회복약에는 영향을 주지 않는다. 시계추의 스킬 충전 배율과 독립이다.
- 기존 `growth.ranks.nimble_evade=1`만 저장하고 새 파일이나 저장 필드를 추가하지 않는다. 복원은 해당 등급에서 능력을 도출한다. 스테이지 전환·낙하 복귀는 능력을 유지하며 새 도전은 원래 0.45초로 초기화한다. 영구 발견만으로 시작 능력을 지급하지 않는다. 능력이 없는 기존 저장은 그대로 호환한다.
- 능력 도감은 16능력·여섯 페이지를 표시한다. 기존 도감 검사는 실제 원본 개수에서 페이지 수와 직업 카드 위치를 계산하도록 확장하여 기존 카드 원본·발견·등급·안전 영역 검증을 유지한다.

## 검증

`gp133_runtime_test.gd` seed/resume/finish/legacy/combat 다섯 별도 프로세스를 기존 전체 검사에 추가한다. 실제 적 처치 레벨업·선택 카드 터치·기록 실패 및 재선택·중복 후보/선택 차단·중간 저장 실패/재시도·최대등급 변조 차단·전체 도감 조회를 확인한다. 두 화면비의 실제 카드·도감 그리기와 안전 영역 검사를 유지한다.

물리 바닥 착지 후 실제 모바일 회피 입력, 좌방향·원본 속도·동작·무적 및 0.17초 적 타격 차단/0.19초 피해 적용, 30/60회 시간 갱신에서 재사용 직전 차단/직후 허용·HUD 준비/잔여 대기·양 무기 쿨다운 독립을 확인한다. 실제 점프→공중 대시→추가 대시 차단→착지 충전, 입력 잠금·취소 불가·사망 차단도 검사한다. 별도 프로세스·반복 이어하기, 실제 시계추 선택 및 동시 복원·보스 완주·새 도전 초기화·기존 카드 저장의 실제 완주를 확인한다.

Android versionCode 60 / `0.0.60-gp133-nimble-evade` / ARM64. 자동 검사와 실기기 플레이는 구분하며 실기기 확인은 별도 대기다. CI는 임시 디버그 서명을 사용한다.
