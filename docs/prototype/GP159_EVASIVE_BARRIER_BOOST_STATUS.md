# GP-159 · 회피 방벽 강화

회피 방벽을 먼저 획득한 뒤 공용 성장 카드로 도전당 한 번 선택한다. 다음 정확 지상 회피부터 방벽 회복을 5에서 8로 늘린다. 선택 자체는 방벽을 충전하지 않는다.

회피당 한 번, 기본 방벽20·견고한 방벽30 상한, 만충전에서도 회피 기회 소비를 유지한다. 씨앗·충격파·근접 공격의 실제 정확 회피를 사용하며 회피 시간·무적·게이지·직업 성향은 기존 규칙을 유지한다. 공중 대시·일반 무적·부활 보호·잠금·사망·종료 신호는 추가 회복을 주지 않는다.

기존 성장 등급에 `evasive_barrier_boost: 1`을 저장한다. 원래 회피 방벽과 마력 방벽을 선행 검증하며 별도 효과 저장 필드나 버전을 추가하지 않는다. 반복 이어하기는8을 복원하고 기존 저장은5를 유지하며 새 도전은 효과를 초기화한다. 능력 도감과 현재 도전의 실제 정확 회피 회복량에 연결한다.

GP-160·161과 함께 `gp159_161_runtime_test.gd`의9단계 검사로 검증한다. 실제 자연 후보·처치 경험치·카드 터치·기록 실패 재시도·선행/중복 거부·등급/선행 없는 저장 거부, 별도 프로세스 반복 복원·5스테이지 완주·기존3스테이지 저장, 양방향 정확 회피·중복/상한·실제 피해 흡수·잠금·조회 정지·두 화면비 도감을 검사한다. 기존290개에9개를 추가한 전체299개 실행 검사와 PR/main 검증을 기준으로 한다. APK는 요청 시에만 만들며 새 기능 실기기 플레이는 미확인이다.
