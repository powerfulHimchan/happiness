# GP-158 · 교차 베기

정예 스킬 보상에 검 `sword_cross`를 추가한다. 검과 활은 각각 9종이며 스킬 도감은 18종이다. 기존 17종의 순서를 유지하고 마지막에 교차 베기를 추가한다.

- 시전 방향의 정면을 0.16초에 피해 32로 베고, 반대쪽을 0.36초에 피해 44로 벤다. 각 범위는 가로 2.4m, 상하 0.9m이며 경계를 포함한다.
- 동작 0.60초, 원본 재사용 9초, 시계추 적용 7.2초. 시전 중 이동·방향 전환은 잠기며 추가 무적이나 강제 이동은 없다. 0.20초부터 회피로 남은 타격을 취소할 수 있다.
- 시전 방향과 각 타격의 표시 방향을 분리한다. 후방 타격 때문에 시선이나 이후 기존 정면 스킬의 방향이 바뀌지 않는다. 두 타격은 각각 실제 위치를 판정하므로 두 영역 사이를 이동한 적은 각 타격에 맞을 수 있다.
- 각 피해는 기존 검 피해 경로에서 성장·장비·기억·불씨를 반영한다. 실제 유효 적중·처치만 스킬 게이지·흡수·시간 수집에 반영하며 숨김·사망·피해 차단 대상은 충전하지 않는다.
- 피격·무기 전환·스테이지 이동은 아직 발생하지 않은 타격을 취소한다. 교체한 슬롯, 원본 대기와 시계추는 기존 체크포인트 형식으로 복원한다. 새 도전은 기존 기본 스킬로 시작한다.

## 검증

추가 실행 검사 7단계: `seed`, `resume`, `finish`, `legacy`, `combat-right`, `combat-left`, `flows`.

실제 후보 순환·두 슬롯 교체·기록 실패 롤백과 재선택, 두 화면비 도감·현재 도전 카드, 별도 프로세스 반복 이어하기·5스테이지 완주·기존 3스테이지 저장을 검사한다. 양방향 타격 시점·시전 방향 고정·적 이동과 신규 진입·큰 프레임·범위 경계·피해 차단, 기존 일섬 방향, 타격 전/사이 취소·시계추·불씨 최종 반올림·흡수·처치 게이지도 검사한다. 실제 프레임에서 타격 사이 조회 정지와 3초 복귀 후 남은 타격, 파일 보존을 확인한다.

로컬 전체 실행 검사와 PR/main 자동 검사로 기존 기능의 회귀 여부를 확인한다. APK는 명시적인 요청이 있을 때만 만든다. 새 기능의 Android 실기기 플레이는 미확인이다.
