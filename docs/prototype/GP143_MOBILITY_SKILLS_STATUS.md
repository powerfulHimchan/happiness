# GP-143 돌파 베기·후퇴 사격

정예 휴식의 스킬 교체 보상에 검 돌파 베기와 활 후퇴 사격을 추가한다. 기존 기본 스킬은 유지하며 새 기술은 직접 선택해 교체한다.

## 실제 전투

기존 전투 동작 속도와 플레이어 move_and_slide를 사용하므로 벽에 막히고 순간이동하지 않는다. 시전 중 일반 이동과 방향 전환을 잠근다. 후퇴 사격의 두 화살은 자동 표적이나 외부 방향 값이 바뀌어도 시전 당시 방향을 유지한다. 이동 자체가 무적을 부여하지 않는다.

피격·회피·무기 교체 시 강제 이동과 이후 타격 예약을 취소하고 이미 발사한 화살은 유지한다. 완료 후에도 이동 속도를 해제한다. 취소해도 이미 시작한 원본 재사용 대기시간은 유지한다. 시계추 조각은 보조 무기를 포함해 실제 재사용을 9→7.2초·8→6.4초로 줄인다.

## 보상·도감·저장

검·활 각7종, 총14종의 스킬을 제공한다. 두 장착 슬롯을 제외한 다섯 후보를 순환하며 비교한다. 대장간 스킬 도감은 다섯 페이지로 늘어나고 현재 장착 슬롯·시계추 적용 수치를 표시한다. 도감과 후보 조회는 저장을 변경하지 않는다.

교체 슬롯과 원본 대기9초·8초를 기존 중간 저장에 보존하며, 교체 저장 실패 시 슬롯·대기시간을 되돌린다. 다른 무기 기술이나 동일 기술 두 슬롯은 저장을 거부한다. 5스테이지 도전과 최종 보스 선택 복원을 지원한다. 추가 필드 없는 이전 저장은 기본 구성을 복원하며 새 기술을 소급 지급하지 않는다. 새 도전은 기본 스킬과 이동 상태로 초기화한다.

## 검증

GP-143의 seed·resume·finish·legacy·combat-sword·combat-bow·flows 일곱 단계로 실제 모바일 버튼, 양 방향 이동과 벽 충돌, 이동 위치별 정면 타격, 화살별 단일 명중과 시전 방향 보존, 취소·완료·무기 교체, 보조 무기 시계추, 실패 복구·별도 프로세스 저장 복원, 5스테이지 완주와 이전 저장을 검사한다. 도전 상태 조회에서는 이동·동작·재사용이 정지하고 3초 카운트다운 뒤 동일 상태로 복귀하는지 확인한다. 기존 회귀 검사도 실행한다.
