# GP-140 · 직업 전용 강화

선봉대와 추적자의 전용 공격 능력 뒤에 강화 카드를 추가한다. 기본 직업은 도전 중 고정되며 이번 기능은 상위 직업 진화가 아니다. 3·5스테이지 모두 같은 레벨업 조건으로 등장한다.

| 직업 | 선행 능력 | 강화 능력 | 효과 |
| --- | --- | --- | --- |
| 선봉대 | 선봉의 칼날 1등급 이상 | 여명의 칼날 | 검 피해 보너스 +30% |
| 추적자 | 추적자의 집중 1등급 이상 | 숲의 명중 | 활 피해 보너스 +30% |

해당 직업 발현과 선행 능력이 모두 필요하며 도전당 한 번만 선택한다. 기본 전용 능력의 반복 선택은 유지한다. 강화는 기존 능력·직업 패시브와 같은 무기 피해 보너스에 더한다. 기본/스킬 실제 타격과 해당 무기의 공격형 필살기에 적용한다. 반대 무기, 체력, 회복약, 회복형 필살기의 회복량, 스킬 대기, 필살기 지속 시간·감속·게이지는 바꾸지 않는다. 예를 들어 무기 강화45%·직업10%·전용20%·강화30%만 보유하면 일반 장비의 기본 피해100은205가 된다. 장비 고유 효과와 기존 기억/파괴 보상 배율은 기존 계산을 따른다.

추첨과 재추첨에서 모든 직업 카드에 발현·선행·최대등급 조건을 적용한다. 직업 카드 한 장과 공용 카드 한 장 보장, 세 후보 고유성을 유지한다. 오래된 후보나 직접 확정도 같은 조건으로 거부한다. 능력 영구 발견 기록이 성공해야 등급·효과·성향을 적용하며 실패하면 같은 카드를 다시 선택한다.

능력 도감은20종·일곱 페이지이며 원본 효과, 직업 발현과 선행 능력 두 조건, 도전당1회, 현재 등급과 영구 발견을 표시한다. 직업 도감에도 강화 이름을 안내하고 일곱 설명 줄을 카드 안에 배치한다. 도감 방문/영구 발견만으로 새 도전에서 능력을 지급하지 않는다.

기존 growth.ranks와 player.sword/bow 필드를 재사용하며 저장 버전/필드를 늘리지 않는다. 선행·최대1등급·직업 소속·실제 합산 보너스 일관성을 검사한다. 반복 이어하기는 저장된 보너스를 정확히 복원해 추가 지급하지 않는다. 새 도전에서 직업·강화·보너스를 초기화하고 발견은 유지한다. 기존 전용20%만 있는 저장은 강화30%를 자동 지급하지 않고 그대로 읽는다.

`gp140_runtime_test.gd`의 여덟 프로세스는 두 직업의 실제 처치 경험치→성향 카드→발현→전용 능력→강화 터치, 선행/직업/중복 차단·재추첨, 기록 실패 재시도, 실제 검 타격/활 투사체 기본·스킬205와 반대 무기100, 공격형 필살기 피해,3/5스테이지 보스 완주·선택 대기 별도 복원, 중간 저장 실패·변조 거부·정상 저장 보호, 반복 복원·초기화·이전 저장 호환과 두 화면비 카드/도감 글자·안전 영역을 검사한다. 이전 전체 실행 검사도 유지한다.

Android versionCode67 / `0.0.67-gp140-job-mastery` / ARM64. 자동 검사와 별도로 새 강화 기능의 실기기 플레이 확인은 대기한다.
