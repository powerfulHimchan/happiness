# GP-831–840 · 주인공 애니메이션10개 개선

로안과 루미의 기존 이동·검/활 전투 원화를 유지하고 발을 기준으로 한 작은 변형과 절차적 효과를 덧붙였다. `HeroMotionPolish`는 표시 전용이며 물리·판정·피해·재사용 대기시간·저장 형식을 변경하지 않는다.

| 단계 | 개선 | 적용 |
| --- | --- | --- |
| GP-831 | 대기 호흡 | 두 대기 프레임 사이에도 몸통이 부드럽게 호흡하며 발은 바닥에 고정 |
| GP-832 | 달리기 리듬 | 이동 거리에 따른 보폭 위상·작은 상하 반동·이동 방향의 기울기. 기존6프레임/12fps 보폭에 맞춤 |
| GP-833 | 점프 자세 | 상승/하강 속도에 비례한 작은 세로 늘어남과 방향 기울기, 정점에서 자연스럽게 완화 |
| GP-834 | 착지 반동 | 착지 두 프레임 동안 사인 곡선으로 눌렸다가 원래 비율로 복귀 |
| GP-835 | 지상 회피 잔상 | 실제 회피 자세·좌우 방향을 월드 좌표에 남기는 청록 잔상 |
| GP-836 | 공중 대시 잔상 | 공중 대시 자세의 금빛 잔상과 짧은 속도선 |
| GP-837 | 방향별 피격 반동 | 적용된 피해의 공격자 반대 방향으로 몸을 기울이고 부드럽게 복귀. 무효·중복 피해는 재시작하지 않음 |
| GP-838 | 공격 동작의 강약 | 여섯 무기의 실제 기본 공격/스킬 발동에 작은 몸통 반동. 스킬 준비→실제 타격/발사→회복을 연결하고 원거리 반동은 약하게 적용 |
| GP-839 | 무기 교체 효과 | 실제 교체 성공에만 회전 호와 세 반짝임. 로안은 청록, 루미는 금빛. 초기 장착·거부된 입력은 효과 없음 |
| GP-840 | 장착 미리보기 | 무기 선택의 발 위치를 고정하고 호흡에 손·무기가 함께 이동. 여섯 무기는 무게에 따라 다른 흔들림 폭 적용 |

## 표시와 중단 규칙

원본 아틀라스의 영역·프레임 번호·발 기준은 그대로 사용한다. 매 갱신마다 원래 크기와 위치를 먼저 적용하므로 작은 변형이 누적되지 않는다. 이동 속도·방향·공격 성공 이벤트를 읽으며 난수나 전투 입력을 생성하지 않는다. 검·활은 기존 전투 자세를, 나머지 무기는 기존 장비 표현과 몸통 반동을 함께 사용한다. 새 전신 스프라이트 시트를 추가한 작업은 아니다.

잔상은35ms 간격으로 최대6개만 유지하고180ms에 소멸한다. 현재 스프라이트의 텍스처·월드 변환·좌우 반전을 보존하며 플레이어가 이동해도 따라가지 않는다. 효과는 플레이어 뒤에 그린다. 교체 효과는340ms에 종료한다.

피격·사망·낙하 복귀는 공격 준비와 남은 잔상/교체 효과를 정리하고, 회피는 공격 반동을 중단한다. 스테이지 이동·도전 초기화·캐릭터 선택에서 변형과 표시 상태를 초기화한다. 전투 일시정지와 준비 화면의 기존 앱 중단 처리는 표시 시계도 멈춘다.

## 검증

- 신규 `gp831_840_animation_runtime_test.gd`:612개 assertion. 두 주인공의 변형 범위·발 고정·30/60/120Hz 일관성, 잔상 개수/소멸/월드 좌표/좌우 방향, 여섯 계열 실제 기본 공격·스킬 준비/발동, 거부 입력, 피격 방향, 중단/초기화, 저장 스냅샷·치명타 난수·물리 상태 불변, 일시정지와 여섯 장착 미리보기를 검사한다.
- 실제 OpenGL 렌더링: 두 주인공 ×30프레임의10동작 갤러리60장, 렌더 실행673개 assertion 통과. 반동·점프 정점·착지 복귀·잔상 겹침·교체 효과 소멸·여섯 미리보기 무기를 확인했다.
- 기존 이동 및 검/활 전투 애니메이션 검사 통과. 기존 준비 화면1333개 검사에서 발이 움직이는 조건을 새 발 고정/호흡/손 이동 조건으로 바꾼 뒤 전체 통과했다.
- 기존 GP-375–384의 지팡이 연사·장봉 후퇴·주먹 교차·방패 연속기 전투/취소 회귀 검사 통과.
- Android 리소스 내보내기와 해당 리소스 패키지 부팅 통과. APK 생성과 Android 실기기 플레이는 수행하지 않았다. GitHub의 전체 Godot 검사는 별도로 실행된다.

실행 예:

```bash
godot --headless --path game --script res://tests/gp831_840_animation_runtime_test.gd
# 실제 디스플레이/Xvfb에서60장의 재현 가능한 갤러리 출력
HERO_MOTION_RENDER_DIR=/tmp/motion-gallery godot --path game --rendering-method gl_compatibility --audio-driver Dummy --script res://tests/gp831_840_animation_runtime_test.gd
```

새 검사와 전용 스크립트를 기존 `scripts/check_godot_project.sh`의 필수 파일/실행 검사에 추가했다. 관련 범위의 검사 결과이며 전체 수천 전투 조합이나 실기기 플레이를 모두 재검증했다는 의미는 아니다.
