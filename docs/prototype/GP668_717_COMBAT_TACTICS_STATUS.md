## 획득·전투

- 카드42종은 레벨업 후보로 등장한다. 무기 전술은 해당 무기를 휴대하고 명시한 선행 카드를 모두 선택해야 한다. 도전당 한 번 선택하며 다른 계열의 선택과는 독립적이다.
- 같은 계열의 결계 기본/스킬은 택1, 평정/역전 재충전은 택1이다. 지상·공중 전술은 함께 선택할 수 있다. 기존 숙련·유물·장비의 배율에 곱하고 최종 한 번 반올림한다. 필살기에는 새 전술 배율을 적용하지 않는다.
- 착지·공중·방벽 조건은 기존 피해 계산 시점에 평가한다. 직접 타격은 적중 시점, 투사체는 생성 시점이며 비행 중 조건 변화로 이미 생성된 피해를 바꾸지 않는다.
- 재충전은 실제 경과시간에 곱한다. 현재 체력이 조건을 넘으면 다음 갱신부터 달라진다. 두 슬롯·비활성 보조에도 적용하고, 시계추와 기존 재충전 숙련에 곱한다. 전환·조회·이어하기가 대기를 초기화하지 않는다.
- 여섯 공용 강화는 기존 회피/회복/처치/적중 처리 경로를 사용한다. 회피당 한 번, 실제 회복약 소비, 최대 방벽/게이지 제한을 유지한다. 체력 회복에는 기존 원정75% 규칙을 적용한다.

## 조회·저장

- 도감은 한 번 만든 목록에서 선행·배제 이름을 찾는다. 카드마다 전체 목록을 반복 복사하지 않으며, 외부로 반환하는 조회 결과는 독립된 사본으로 유지한다.
- 도전 정보의 첫 탭에서 분류·정렬, 둘째 탭에서 주/보조 필터와 목록/대기순/자세별 피해/전술 상태를 순환한다. 분류 변경은 첫 페이지로 돌아가고, 탭 전환·재진입은 전체·목록순으로 초기화한다. 빈 분류에는 안내 카드를 표시한다.
- 피해 비교는 열기 직전 장비·유물·성장·현재 체력·방벽을 유지한 채 착지 여부만 비교한다. 기본 피해100 기준이며 거리와 적 방어 보정 전이다. 조건 상태는 새 무기 전술36종에 대한 적용/대기다. 기존 전투 정지와 3초 뒤 복귀를 유지한다.
- 기존 저장 버전1의 성장 ranks에 선택만 저장한다. 새 능력 효과를 별도 숫자로 중복 저장하지 않고 선택·복원에서 재구성한다. 이전 저장에 소급 지급하지 않는다. 다음 구간은 유지하고 새 도전은 초기화하며 영구 발견은 유지한다.
- 기존 저장 검증으로 모든 선행·상호 배제·휴대 계열·1등급 한도를 검사한다. 영구 발견 저장 실패 시 선택 효과와 등급을 적용하지 않고 같은 카드를 재시도한다. 조회·정렬·분류·페이지 이동은 파일을 쓰지 않는다.
