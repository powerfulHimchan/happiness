# GP-511 · 지역별 적 중복 제거

승인한 `평원과 숲의 적 배치안`, `지역별 적 배치안 ② · 유적과 축제장`, `행복의 나라 성문과 중심부`를 기준으로 일반 적과 지역 정예를 분리했다. 서로 다른 지역에서 같은 종을 재사용하지 않는다. 한 지역의 두 구간과 웨이브에서는 같은 종의 개체가 여러 번 등장할 수 있다.

| 지역 | 일반 적 | 정예 / 보스 |
| --- | --- | --- |
| 바람꽃 평원 | 풀잎 슬라임, 바람 정령, 바람뿔 토끼, 민들레 새 | 갑옷 멧돼지 |
| 거꾸로 자란 숲 | 씨앗 포대, 포자 나방 | 덩굴 사냥꾼 |
| 별시계 유적 | 별시계 인형, 되감기 인형 | 시곗바늘 파수꾼 |
| 태엽 축제장 | 장난감 병정, 축제 포탑, 풍선 광대 | 태엽 북장이 |
| 행복의 나라 성문 | 미소 가면 경비병 | 행복의 수호기사 |
| 행복의 나라 중심부 | 행복 행렬 인형 | 세라, 조건에 따른 행복의 심장 |

웃는 태엽 기사는 기존 단기 3·5스테이지 도전 보스로 유지한다. 중심부의 기존 보스 선택 및 저장 호환을 변경하지 않는다. 기억 인형은 승인안의 숨겨진 보스 기획 상태를 유지하며 출현·해금 조건을 임의로 추가하지 않는다. 단기 도전의 `meadow`와 위험 경로 `clockwork`는 평원 명단을 사용한다. 자유 전투 진단 모드는 기존 세 적을 유지한다.

## 새 적 10종

- 바람뿔 토끼: 경고 후 뿔 도약 돌진, 착지 뒤 빈틈.
- 민들레 새: 부유하며 조준한 방향으로 민들레 탄 1발.
- 포자 나방: 고정 조준과 세 갈래 포자탄. 경고선도 동일한 각도로 표시.
- 되감기 인형: 짧은 돌진 후 기록한 위치로 복귀. 복귀 이동에는 추가 타격이 없다.
- 풍선 광대: 세 갈래 느린 풍선탄.
- 미소 가면 경비병: 경고 뒤 짧은 창 돌진과 회복 시간.
- 행복 행렬 인형: 부채꼴 깃발탄.
- 덩굴 사냥꾼: 제한 거리의 덩굴 돌진과 뿌리 파문.
- 시곗바늘 파수꾼: 바늘 돌진과 원위치 되감기, 시간 파문.
- 태엽 북장이: 돌진 대신 북 파동, 2페이즈에서는 추가 파동.

기존 SVG 에셋 체계에 전용 본체 10개, 탄 4개와 정예 파문 3개를 추가했다. 원본 승인 이미지를 잘라 넣는 방식이 아닌 게임용 벡터 에셋으로 구현했다. 시각 효과는 배우 본체만 변형하고 체력·선택·경고선은 기존 좌표를 사용한다.

## 연결 및 호환

`RegionalEnemyRoster`가 지역/웨이브별 종을 결정한다. 평원은 두 번째 웨이브에서 바람 정령 슬롯을 민들레 새로 전환한다. 숲과 유적은 전용 두 종을 기존 세 배우 슬롯에 배치한다. 성문과 중심부도 기존 배우 수·높은 발판 배치를 보존하며 전용 종으로 교체한다. 원정 추가 정예도 현재 지역의 종을 사용한다.

공격은 기존 배우의 시간 배율과 피해 수신기를 사용한다. 사망 시 즉시 타격 대상을 해제하고, 방패 기절·장봉 밀치기는 대기 공격과 되감기를 취소한다. 새 투사체에는 배우 생명 주기별 고유 ID, 전용 그림, 생성 당시 시간 배율을 적용한다. 새 저장 필드는 없으며 지역과 웨이브로 배치를 다시 결정한다. 대상 표시와 지역 안내도 실제 종에 맞춘다.
