# GP-141 · 현재 도전 상태

전투 HUD의 **도전 상태**에서 현재 도전의 보유 능력, 장착 장비와 생존 상태를 조회한다. 새 도전 직후에는 능력 없음으로 표시하며 영구 발견만 한 능력은 보유 목록에 넣지 않는다. 도감은 마을에서 전체 후보를 조회하는 기존 기능을 유지한다.

| 탭 | 표시 |
| --- | --- |
| 보유 능력 | 실제 선택한 능력만 원본 순서로 표시, 누적 등급·효과·직업/선행 조건 |
| 장비·스킬 | 두 무기의 등급·주/보조 상태·원본 고유 효과, 피해100을 기준으로 성장·기억·장비·일회 보상을 반영한 피해 예시, 네 장착 스킬의 원본/슬롯/재사용/남은 대기 |
| 도전 정보 | 현재 단계·경로·시간·경험치, 체력·방벽·회복약 개수/실제 회복 비율·현재 흡수 비율·공중 도약, 직업·필살기·게이지·발동 잔량, 유물·기억·일회 보상 |

스킬의 기본 피해는 강화 전 원본이며 무기 카드의 피해 예시는 거리/대상 보정 전이다. 시계추는 두 무기의 실제 재사용 및 남은 대기를 표시한다. 능력은 선택 등급을, 유물은 실제 보유/사용 상태를 읽는다. 세 장씩 페이지를 넘기며 탭 전환은 첫 페이지로 이동한다. 카드 터치는 조회 상태나 장착을 바꾸지 않는다. 조회 진입 버튼은 기본·왼손·사용자 조작의 입력 영역을 피한 빈 공간에 배치한다. HUD 아래 안전 영역이 조작으로 완전히 덮이면 조회 버튼을 숨겨 기존 조작을 보호한다.

진입 시 실제 모델에서 스냅샷을 읽고 모든 이동·점프·멀티터치·예약 명령을 해제한다. 전체 트리를 정지하고 화면 조작만 처리하여 플레이어·적·투사체·구간 시간·무기 대기·필살기 지속시간이 진행하지 않는다. **전투로 돌아가기** 또는 Escape로 닫으면3초 카운트다운 동안 같은 정지를 유지한 뒤 기존 트리 정지와 화면 처리 모드를 복원한다. 이동을 다시 하려면 조작을 새로 누른다. 앱 비활성/복귀는 조회 화면과 정지를 유지한다.

메인·결과·성장 선택·직업 확인·정예 보상·경로 선택·배치 편집·기존 복귀 카운트다운·사망 상태에서는 진입하지 않는다. 중복 열기/닫기를 차단한다. 메인/결과/새 도전/성장 전환과 씬 종료 때 조회가 소유한 정지를 정리하여 다른 화면의 정지 소유권을 침범하지 않는다.

조회는 체크포인트·영구 발견·일회 보상·도전 이력에 쓰지 않으며 저장 필드/버전을 늘리지 않는다. 기존3/5스테이지 이어하기는 같은 실제 모델을 복원하여 조회한다. 새 도전은 보유 목록을 비우고 영구 발견 기록은 유지한다. 조회 중 앱 종료도 기존대로 마지막 완료 스테이지 저장에서 이어한다.

`gp141_runtime_test.gd` seed/resume/finish/flows 네 프로세스로 검증한다. 실제 성향 카드·직업·전용 강화·방벽·흡수·도약·영웅 보조 활·스킬 교체·시계추를 준비해 여섯 보유 능력,3등급/1등급, 합산 피해226/205, 양 스킬 잔량2.6/4.4,5/5 단계·게이지·충전 방벽을 확인한다. 실제 HUD 진입과 멀티터치 해제, 처리 중인 플레이어/적/투사체/필살기/대기/시간 정지, 카운트다운·앱 복귀·별도 프로세스 이어하기·보스 완주·새 도전 초기화, 모든 저장 파일 무변경·반환 스냅샷 독립, 두 화면비 탭/카드/페이지/복귀/문자 너비, 기본·왼손·사용자 배치의 진입 버튼 비중첩과 실제 점프/조회 입력, 외부 정지·성장/결과 전환·씬 종료 정리와 잘못된 진입을 검사한다. 기존 전체 실행 검사를 유지한다.
