## 저장·도감·전투

기존 능력의 순서와 유물 9종 및 스킬 18종의 도감 순서를 유지하고 새 항목을 뒤에 추가한다. 전체 공용28+직업6 능력34종, 유물13종, 검10/활10 스킬20종이다. 유물 보상은5종씩3페이지, 도감은3종씩5페이지, 스킬 도감은3종씩7페이지다. 한 도전에 유물 하나만 선택한다.

성장 등급·유물 ID·기존 스킬 슬롯/원본 대기시간만 저장한다. 새로운 효과 배율을 중복 저장하지 않는다. 중간 저장 복원은 실제 회복약 잔량을 그대로 사용하며, 확장 주머니의 획득 보충을 다시 지급하지 않는다. 능력/유물/교체의 기록 실패는 효과·잔량·성향·선택을 보존하고 재시도를 허용한다. 잘못된 등급·선행 없는 강화·다른 무기 스킬·중복 슬롯·허용 소지량 초과는 기존 저장 검증에서 거부한다. 이전 저장은 새 효과를 자동 지급하지 않는다.

새 도전에서 성장·유물·스킬 장착 효과를 초기화하며 실제 발견한 능력의 영구 도감 기록만 유지한다. 현재 도전 화면은 실제 소지량/회복률/구슬 거리/감속 시간/처치 게이지/스킬 슬롯과 대기를 표시한다. 도감과 도전 상태 조회는 전투를 정지하고 파일과 상태를 변경하지 않는다.
