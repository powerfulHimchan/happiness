# GP-330~334 · 숲의 파수꾼과 상위 직업 특화

GP-335~344에서 주먹·무도가 계열을 추가해 현재 상위 직업은6종/도감3페이지다. 아래는 GP-330~334의 당시 구현·검증 기록이다. [후속 구현](GP335_344_FIST_MARTIAL_STATUS.md)을 참고한다.

상위 직업을 완성하는 다섯 기능을 구현한다. 기존 용염기사·파쇄자·폭풍사수에 숲의 파수꾼을 추가하고 네 직업의 공격/생존 특화, 추가 필살기, 현재 달성도 비교 도감을 연결한다. 기본 직업은 선봉대·추적자이며 다른 기본 직업과 무기 계열은 후속 범위다.

## GP-330 · 숲의 파수꾼

전체 여정7단계 이후 추적자가 사격8·자연5와 **숲의 명중**을 갖추면 숲의 파수꾼으로 자동 진화한다. 숲의 명중은 추적자의 집중 뒤 선택하는 기존 강화 카드다. 미보유 시 폭풍사수가 된다. 성향은 기존 능력70%·무기20%·특수10%와 출처별 상한을 유지한다. 조건이 먼저 충족되면7단계 진입 때, 후반에 채우면 실제 카드 선택·적중·정확한 회피 뒤 진화한다. 기존 상위 직업은 이후 선행 강화를 얻어도 변경하지 않는다.

| 보상 | 효과 |
| --- | --- |
| 진화 패시브 | 추적자 계승 · 활 피해 추가10%p · 최대 체력40/회복40 |
| 숲의 화살 | 활 기본·스킬·필살기 피해20%p · 도전당1회 |
| 깊은 뿌리 | 최대 체력30/회복45 · 도전당1회 |
| 숲의 화살비 | 주변3m 활 피해90 · 4초 적 시간20% |
| 숲의 안식처 | 주변3m 활 피해30/회복60 · 5초 적 시간30% |

기본 추적자 패시브·카드·강화를 계승하고 다른 상위 직업 전용 카드는 제외한다. 연두색 나뭇잎 표식, 영구 발견, 도감, 새 도전 초기화와 별도 프로세스 이어하기를 포함한다.

## GP-331·332 · 공격/생존 특화

각 직업의 전용 공격 능력 뒤 공격 특화, 전용 체력 능력 뒤 생존 특화가 후보에 들어간다. 모두 도전당1회이며 **같은 직업의 두 특화 중 하나만** 선택한다. 전용 기본 두 능력을 모두 얻는 것은 허용한다. 선택 후에는 반대 특화와 재선택을 막으며 새 도전에서 다시 고른다.

| 직업 | 공격 특화 · 선행 | 공격 효과 | 생존 특화 · 선행 | 생존 효과 |
| --- | --- | --- | --- | --- |
| 용염기사 | 진홍의 용염 · 용염의 칼날 | 검 피해30%p | 용린의 가호 · 용의 심장 | 최대 체력40/회복50 |
| 파쇄자 | 파멸의 칼날 · 파쇄의 칼날 | 검 피해35%p | 불굴의 파쇄 · 파쇄자의 투지 | 최대 체력40/회복50 |
| 폭풍사수 | 천둥의 시위 · 폭풍의 화살 | 활 피해30%p | 바람의 장막 · 바람의 호흡 | 최대 체력40/회복50 |
| 숲의 파수꾼 | 가시의 맹세 · 숲의 화살 | 활 피해25%p | 거목의 심장 · 깊은 뿌리 | 최대 체력50/회복60 |

공격 보너스는 기존 무기 성장 보너스에 합산해 기본·스킬·공격형 필살기에 반영한다. 체력 효과는 기존 성장 회복 경로를 사용한다. 원정2 이상은 회복만75%·정수 올림하고 최대 체력 증가는 유지한다. 발견 기록 실패 시 선택을 보류하고 같은 카드를 다시 눌러 재시도한다. 실패 중 랭크·체력·보너스는 바꾸지 않는다.

## GP-333 · 추가 필살기8종

진화 화면에 기존 두 후보와 새 두 후보를2×2로 표시하고 하나만 확정한다. 선택 자체는 게이지를 변경하지 않으며 사용 중 효과·남은 시간은 기존 스냅샷으로 종료한다. 다음 발동부터 선택한 효과를 사용한다.

| 직업 | 추가 필살기 | 기본 효과 |
| --- | --- | --- |
| 용염기사 | 용염의 창 | 전방6m/높이1m 검150 · 2초 적 시간20% |
| 용염기사 | 용의 재생 | 회복70 · 4초 적 시간35% |
| 파쇄자 | 대지의 균열 | 전방5m/높이1.2m 검180 · 2초 적 시간25% |
| 파쇄자 | 파쇄의 격동 | 주변2.5m 검100/회복20 · 3초 적 시간20% |
| 폭풍사수 | 천둥 저격 | 전방10m/높이0.8m 활180 · 2초 적 시간20% |
| 폭풍사수 | 고요한 바람 | 회복65 · 5초 적 시간25% |
| 숲의 파수꾼 | 가시 물결 | 전방7m/높이1.4m 활130 · 3초 적 시간20% |
| 숲의 파수꾼 | 거목의 숨결 | 회복85 · 4초 적 시간35% |

전방 효과는 화면 안 적에게만 적용한다. 무기 성장·장비·기억·유물의 피해, 시간의 여운·시계판 지속시간, 회복75%와 원정5 새 발동 제한은 기존 경로를 사용한다. 기본 직업의 네 후보와 기존 상위 필살기ID·순서는 보존한다.

## GP-334 · 진화 비교 도감

마을의 상위 직업 탭은 선봉대 계열 두 장/추적자 계열 두 장을 페이지로 비교한다. 현재 도전의 실제 성향 점수와8/5 목표, 분기 선행 강화 보유 여부, 현재 단계와7단계 조건, 부족/발현 전/다른 기본 직업/반대 분기/진화 대기/확정 상태를 표시한다. 도전이 없으면 새 전체 여정 안내를 표시한다. 영구 발견과 이번 도전의 진화 상태는 따로 유지한다.

직업별 기본 두 능력·공격/생존 특화·필살기 네 후보와 계승/택1 안내를 보여준다. 이전/다음은 경계에서 멈추고 탭 재진입은 첫 페이지로 돌아간다. 조회는 성향·직업·랭크·체크포인트·영구 발견 파일을 변경하지 않는다. 성장 화면에서는 무작위 슬롯에 나온 직업 카드도 실제 소속을 표시한다.

## 저장과 검증

버전1의 기존 직업 문자열에 `forest_warden`을 추가하며 새 필수 필드는 없다. 선행·상호 배제·1회 상한·직업 소속을 확인하고 카드 원본 효과로 체력/피해 보너스를 검증한다. 두 특화 동시 보유는 레벨/랭크 합계와 보너스를 맞춘 변조라도 거부한다. 기본 직업·기존 세 상위 직업과 특화가 없는 이전 저장을 유지한다. 복원은 패시브·특화·회복을 재지급하지 않는다. 쓰기 실패와 변조 시 기존 정상 저장을 보존한다.

`gp334_runtime_test.gd`의 네 직업×두 주인공×`seed/resume/legacy/late`32회는 두 특화, 추가 필살기8종, 실제 진화·피해·회복·감속·높이/방향 경계, 진행 중 효과와 게이지 보존, 기록 실패 재시도·변조 거부·별도 프로세스 복원·진화 달성도/페이지를 검사한다. `gp329_runtime_test.gd`에는 숲의 파수꾼 기본 필살기 두 종류를 추가하고 용염기사/기존 진화·능력·저장·현재 도전 조회 회귀 검사를 유지한다. 시간 수집·모래시계·시간의 여운과 모든 필살기 조합, 기존 기본 직업의 추가 필살기도 확인한다.

관련 런타임100회, 정적 검사·Godot 리소스 가져오기, Android 리소스 팩 내보내기·팩 부팅을 로컬에서 확인했다. 1280×720·1600×720의 네 직업 필살기 화면·진화 비교 두 페이지·특화 카드·나뭇잎 표식을 실제 렌더링해 한글·안전 영역·가독성을 확인했다. Android 실기기 조작·성능·밸런스는 별도 확인 범위이며 APK는 빌드하지 않았다.

6개 동시 검사에서 일부 기존 저장/조회 상태 비교가 간헐적으로 실패했다. 해당 저장의 생성/복원10쌍을 독립 환경에서 반복해 파일 변경이 없음을 확인하고, 설정·데이터 경로를 분리한2개 동시 실행으로 최종100회를 통과했다. 병렬 실행에서 발생한 간헐 실패의 원인은 확정하지 않았다.
