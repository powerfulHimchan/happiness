# GP-148 회복 방벽

마력 방벽을 획득한 뒤 공용 성장 카드 **회복 방벽**을 도전당 한 번 선택한다. 이후 회복약을 실제로 소비해 체력을 회복할 때 방벽10을 보충한다. 선택 자체로 체력·방벽·회복약을 지급하지 않는다.

| 항목 | 동작 |
| --- | --- |
| 선행 / 등급 | 마력 방벽 / 최대1등급 |
| 효과 | 회복약1개 실제 소비 시 방벽+10 |
| 상한 | 기본20 / 견고한 방벽30 |
| 조합 | 기본·농축 조제, 회복약 주머니, 샘의 이슬 |
| 회복량 | 기존25%·40%, 이슬 장착 시35%·50% 유지 |

체력이 가득 차거나 회복약이 없으면 회복약과 방벽을 모두 사용하지 않는다. 체력이1만 부족해도 실제 회복약을 소비하면 방벽을 보충한다. 방벽이 가득 차면 원래 체력 회복만 적용한다. 회복약 로그에는 실제 보충량을 표시한다. 다른 회복·조제 준비·능력 선택으로는 방벽을 보충하지 않는다. 버튼을 누른 채 유지해도 소비와 보충을 반복하지 않는다.

피격 잠금·낙하 복귀·사망·조회·복귀 카운트다운·전투 환경 정지·단계 종료·도전 종료·메인 화면에서는 사용을 차단한다. 필살기 게이지와 양 무기 대기시간은 독립적으로 유지한다. 회복된 방벽은 기존 피해 흡수 처리로 실제 타격을 막는다.

## 도감·저장

전체24능력 도감에서 선행·등급·발견 상태를 조회한다. 현재 도전 상태의 보유 능력과 회복약 설명에 방벽 보충량을 표시한다. 두 화면비의 실제 성장 카드·도감·도전 상태 배치와 조회 중 트리 정지를 확인한다.

기존 능력 등급과 방벽/회복약 잔량 저장 형식을 사용한다. 별도 프로세스 및 반복 이어하기는 현재 잔량을 보존하며 무료 충전이나 회복약 보충을 하지 않는다. 잘못된 등급과 선행 없는 저장을 거부한다. 새 도전은 능력을 초기화하고 영구 발견만 유지한다. 이전 저장에 능력을 소급 지급하지 않는다.
