# GP-321 · 심장 제압 후 최종 선택과 세 엔딩

새 전체 여정은 기존 행복의 심장 전투 뒤 의식의 운명을 직접 선택한다. 첫 도착 엔딩과 GP-320까지의 필드 없는 저장은 기존 흐름을 유지한다. 도착·귀환·해방·새벽은 기억 수첩 엔딩 탭에서 영구 열람하며 결과와 최근 도전 이력에도 선택한 엔딩을 표시한다.

수첩 카드는 요약을 표시하고 발견한 카드를 누르면 엔딩 전체 장면을 다시 읽는다. 돌아가기는 수첩의 같은 페이지로 복귀하며 기록·도전 완료 수·일시정지 소유권을 바꾸지 않는다.

| 결말 | 조건 | 선택의 결과 |
| --- | --- | --- |
| 귀환 | 새 도전 시작 때 되감기 3회 이상 | 바깥의 기억을 놓고 국민으로 돌아간다 |
| 해방 | 시계·가족·심장의 핵심 기억 3종 | 슬픔 전가 의식을 파괴한다 |
| 새벽 | 기억 10종 + 시계탑 비밀 기록 | 동의한 이들과 고통을 나누도록 의식을 바꾼다 |

심장 제압을 확인할 때 의식에서 새벽시계·가족·기계의 핵심 기억을 확인·기록한다. 이야기 꺼짐에서도 해방은 선택할 수 있어 조건 미충족으로 진행이 막히지 않는다. 새벽의 비밀 장소는 기억 10종을 이은 뒤 최종 선택 화면에서 여는 시계탑 기록실 장면이다. 별도 횡스크롤 숨겨진 맵/보스는 이번 범위가 아니다. 기록실의 가족 설계는 독립 저널에 영구 보존하고 다음 여정에서도 유지한다.

카드 터치만으로 결말을 확정하지 않는다. 선택 확인 후 엔딩을 읽고 마지막 기록 버튼을 눌러야 완주한다. 기록 전에는 선택으로 돌아갈 수 있다. 최종 선택에서 뒤로가기는 임의의 결말을 선택하지 않으며 이야기 꺼짐도 자동 선택/완주하지 않는다. 귀환의 기억 상실은 이야기 표현이며 사용자의 영구 해금·기록을 삭제하지 않는다.

## 저장·복원

- 버전1의 선택적 `stage.final_ritual` 필드에 locked/choosing/ending/seen, 선택 ID, 기억과 시작 시 되감기 횟수, 비밀 기록 확인을 저장한다. 새 여정만 필드를 생성하며 구버전에는 소급하지 않는다.
- 선택/기록실/엔딩 확인 저장 실패는 전이 전 상태와 기존 정상 파일을 보존한다. 체크포인트 확정 뒤 영구 저널 기록이 실패하면 확정한 선택을 유지하고 재시도·재실행으로 복구한다. 한 도전의 다른 엔딩을 중복 지급하지 않는다.
- 영구 엔딩 기록 성공 전에는 별도의 메모리 내 완료 게이트를 닫아 완주 기록과 결과 화면을 차단한다. 이어하기는 저널 복구를 확인한 뒤 같은 결말을 완료한다.
- 수첩은 기존 도착 최초 발견을 보존하며 새 엔딩을 추가한다. 도전 기록 삭제와 새 도전으로 영구 기억·비밀 기록·엔딩을 잃지 않는다.

## 검증

GP-321 실행 검사47단계: 두 주인공×검/활×세 결말의 별도 프로세스 선택 대기·복원/선택 변경·최종 기록36단계, 저장/영구 저널 실패와 재실행 복구·조건 경계·이야기 꺼짐·구버전 비소급·첫 도착·화면 배치11단계. 실제 검/활로 심장을 제압한 뒤 실제 카드·확인 입력으로 검증한다. GP-318~320 관련 검사, PR 전체 Godot 검사와 Android 리소스 팩 내보내기/부팅을 함께 확인한다. Android 실기기 플레이는 별도 확인 대상이며 APK는 요청 시에만 만든다.

기존 전체 검사가 약28~33분이므로 새47단계의 실행 시간을 확보하도록 PR/main 작업 제한을35→45분으로 조정했다. 기존 검사와 개별 실행 제한은 유지한다.
