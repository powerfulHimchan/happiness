# GP-144 시간의 여운

시간 수집을 먼저 획득한 뒤 공용 성장 카드 **시간의 여운**을 도전당 한 번 선택한다. 다음 발동부터 공용 필살기와 직업 필살기의 적 감속 시간이 1초 늘어난다.

| 필살기 | 기본 감속 시간 | 여운 획득 후 |
| --- | --- | --- |
| 새벽의 틈 | 3초 | 4초 |
| 여명의 일격 / 새벽의 일제사격 | 3초 | 4초 |
| 불굴의 새벽 / 숲의 숨결 | 5초 | 6초 |

감속 비율·피해·회복·게이지 소비와 공격/처치/회피 충전은 기존 수치를 유지한다. 플레이어와 아군 투사체의 시간도 유지한다. 원본 필살기 프로필을 수정하지 않고 발동 시점의 지속 시간을 따로 보존하므로 반복 발동과 이어하기에 시간이 누적되지 않는다. 발동 중 능력을 얻거나 직업 필살기를 선택해도 이미 시작한 효과의 시간과 잔량은 바뀌지 않는다.

## 성장·조회·저장

선행 미충족 또는 최대 등급 이후에는 후보·재추첨·확정을 차단한다. 영구 발견 기록 실패 시 등급·성향·효과를 적용하지 않고 같은 카드로 재시도한다. 실제 선택만 영구 발견으로 기록하고 22종 능력 도감에 조건과 현재 등급을 표시한다. 영구 발견은 새 도전에 능력을 지급하지 않는다.

직업 발현 전에 획득하면 필살기 선택 화면에도 강화한 감속 시간을 표시한다. 전투 HUD는 현재 발동 시점에 확정한 시간으로 진행률을 표시한다. 도전 상태는 현재 남은 시간과 다음 필살기의 감속 시간을 구분한다. 조회와 3초 복귀 중에는 전투·대기시간·필살기가 함께 정지한다.

기존 growth.ranks에 시간 수집·여운 등급을 저장하며 새 저장 필드는 추가하지 않는다. 필살기 프로필·게이지·체력·양 무기 대기시간은 그대로 복원하고 보너스 1초만 적용한다. 등급 타입·최대 등급·선행 조건을 기존 저장 검증으로 확인한다. 새 도전은 원래 지속 시간으로 초기화하며 이전 저장에 여운을 소급 지급하지 않는다.
