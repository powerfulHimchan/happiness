## 획득·효과·저장 규칙

- 모든 신규 능력은 실제 레벨업 후보와 능력 도감·보유 능력·영구 발견에 연결했다. 무기 특화는 해당 무기를 휴대한 도전에서만 제안하며 선행 능력이 필요하다. 각 특화는 도전당1회다.
- 방어 자세는 현재 사용하는 무기의 것만 적용한다. 무기를 전환하면 방어력이 즉시 바뀌며 보조 무기 방어력은 합산하지 않는다.
- 공격의 치명타 특화는 실제 타격의 무기와 종류를 따른다. 이전 무기의 비행 중 투사체도 해당 무기의 특화를 사용한다. 체력80%/30%와 방벽 조건은 실제 타격·피격 시점에 계산한다.
- 치명타 확률은100%를 넘지 않으며 피해%는 총 치명타 배율에 더한다. 루미의 확정 치명타와 함께 사용해도 피해 강화는 한 번만 적용한다.
- 도전 중간 저장은 기존 성장 등급을 사용한다. 별도 능력치 사본이나 저장 버전 변경 없이 기존 저장을 읽으며 반복 이어하기로 중복 강화하지 않는다. 새 도전은 효과를 초기화하고 영구 발견은 유지한다.
