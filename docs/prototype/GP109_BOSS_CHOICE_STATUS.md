# GP-109 · 보스전과 구출·파괴 선택

3스테이지 도전의 마지막 정예를 **웃는 태엽 기사** 보스로 교체한다. 기존 1·2스테이지 정예, 무기 보상·성장·경로 선택은 유지한다. 이 기사는 사람들을 돌려보내라는 명령에 묶인 지역 수호자이며, 세라·행복의 심장을 대신하는 이야기의 최종 보스는 아니다.

## 전투

태엽 기사는 체력 480이며 평지 x=3920~4880 안에서 돌진→지면 충격파→태엽 탄막 순서로 공격한다. 돌진은 선, 충격파는 원, 탄막은 황금색 부채꼴로 먼저 경고한다. 체력이 50% 이하가 되면 전환 시간 0.75초를 거쳐 두 번째 페이즈로 강화한다. 갑옷은 검 피해 60%, 활 피해 125%를 적용한다. 돌진이 평지 경계에 부딪히면 기절하고 그때 검 피해가 175%가 된다. 장비와 카드의 피해는 이 약점 판정 전에 적용한다. 공용 시간 감속·회피·별도 무기 스킬 대기시간을 유지한다.

| 항목 | 1페이즈 | 2페이즈 |
|---|---|---|
| 돌진 경고 / 속도 | 0.65초 / 7.5 m/s | 0.45초 / 9 m/s |
| 돌진 피해 / 벽 기절 | 18 / 2초 | 22 / 1.5초 |
| 충격파 경고 / 피해 | 0.85초 / 12 | 0.60초 / 14 |
| 충격파 | 양방향 2개 | 양방향 2개 + 0.22초 후 2개 |
| 탄막 경고 / 탄수 | 1초 / 3개 | 0.75초 / 5개 |
| 탄막 피해 / 속도 | 8 / 5 m/s | 10 / 6 m/s |

보스는 기존 정예처럼 경험치 30을 제공해 도전의 총 경험치 240을 유지한다. 별도 벡터 캐릭터, 체력 막대·페이즈·상태, 보스 구간 목표를 표시한다. 기존 단일 스테이지·자유 전투 회귀 환경에서는 보스를 비활성화한다.

## 승리 선택과 복원

보스를 쓰러뜨리면 전투를 정지하고 구출·파괴 카드 중 하나를 선택한 뒤 확정한다. 구출은 태엽 명령을 해제해 기사를 자유롭게 하고, 파괴는 태엽핵을 파괴해 길목의 위협을 없앤다. 현재 시제품은 선택을 결과·스테이지 이력·로컬 완주 기록에 남기고 구출/파괴 횟수를 메인 화면에 표시한다. 선택 보상, 다음 도전 조력자·위험 경로, 영구 해금은 후속 범위다. 다른 도전에서는 반대 선택을 할 수 있다.

보스 승리는 선택 대기로 저장하고 아직 완주로 집계하지 않는다. 확정 상태를 원자 저장한 뒤 완주 이벤트를 기록한다. 저장 실패 시 선택과 이력을 되돌리고 같은 화면에서 다시 확정할 수 있다. 선택 전 앱 종료는 재전투 없이 선택 화면으로 복원하고, 확정 저장 직후 종료는 확정된 결과를 복원해 한 번만 기록한다. 정상 완료 이벤트가 기록된 뒤 중간 저장·백업을 정리한다. 이전 GP-105~108 중간 저장은 계속 호환하며 보스 저장 손상 시 이전 두 번째 스테이지 완료로 복구한다.

## 자동 검증

GP-109 실행 검사는 실제 3스테이지 진입, 전용 보스·체력·목표, 세 패턴 순서와 경고, 평지 경계 기절, 갑옷·활/검 약점과 중복 타격 방지, 실제 탄막 충돌 피해, 체력 타격에 따른 페이즈 전환, 시간 감속·강화 탄막·추가 충격파를 검사한다. 별도 프로세스는 선택 대기 저장/복원, 확정 직후 중단 복원, 저장 실패 롤백, 손상 파일 백업 복구, 두 화면 비율의 입력 영역, 백그라운드 복귀, 미선택·중복 입력 방지, 양쪽 선택 완주·재도전 초기화·재실행 이력 보존을 확인한다. 기존 CP-206~406, GP-101~108도 함께 실행한다.

## 실기기 확인

1. 3스테이지 마지막 관문에서 선·원·부채꼴 예고를 구분해 피한다.
2. 활로 갑옷을 공격하고 벽 충돌 기절 시 검으로 전환한다. 절반 체력 이후 탄막 수·속도·충격파 변화도 확인한다.
3. 보스 승리 후 앱을 종료하고 이어하기로 선택 화면이 복원되는지 확인한다.
4. 구출·파괴를 각각 다른 도전에서 확정하여 결과와 메인 기록을 확인한다.

자동 검사와 실제 Android 플레이 확인 여부는 구분한다.
