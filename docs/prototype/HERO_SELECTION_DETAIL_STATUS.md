# 주인공 선택 · 두 인물에서 한 인물 상세로

## 사용자 승인 시안 적용

- 진입 시 로안/루미의 전신 모습만 표시한다. 이름·특성·스토리·능력치·다음 입력은 숨기고, 인물 이미지 자체를 터치해 선택한다.
- 선택하면 다른 인물은 0.28초 동안 사라지고 선택한 인물이 왼쪽으로 이동한다. 오른쪽에는 이름·고유 특성·이야기·최초 전투 능력치를 표시한다. 숨겨진 인물의 입력 영역도 즉시 제거한다.
- 로안 이야기 306자, 루미 이야기 309자를 추가했다. 기존 희귀병·유품 시계·세라와의 약속이라는 도입 설정을 바탕으로 각각 시계 수리점과 별을 바라보던 과거를 담은 승인 초안이다.
- 체력100·공격력100·방어력0·치명타 확률0%·치명타 피해150%를 두 주인공의 공통 최초 수치로 표시한다. 실제 게임의 기본 상수를 공유하며 장비·기억·원정 효과나 현재 세이브의 잔량을 섞지 않는다. 기본 체력 상수는 공통 능력치 카탈로그로 옮기고 값100은 유지했다.
- 메뉴는 제목 화면과 같은 담백한 이미지 글자다. 버튼 틀과 하단 고유 특성 적용 안내를 제거했다. 이름도 이미지로 표시한다. 정보 본문은 실제 텍스트로 그려 화면 크기에 맞게 줄바꿈한다.
- 상세의 다시 선택/뒤로가기는 두 인물로, 두 인물의 이전/뒤로가기는 진입했던 메인·결과·마을/무기 준비로 돌아간다. 전체 준비 취소는 기존 선택을 복원한다. 무기 화면에서 이전으로 돌아오면 선택한 인물의 상세를 유지한다.
- 기억 수첩을 열었다 닫으면 선택 상태를 유지한다. 이야기 토글도 유지한다. 인물 선택만으로 전투/도전 생성이나 세이브 쓰기가 발생하지 않는다.
- 전환 시계는 앱 비활성화와 다른 화면에서 멈춘다. 긴 문단의 줄바꿈 결과는 최대16개만 캐시해 반복 계산을 줄인다.

## 검증 범위

- Godot 4.7.2의 확장한 준비 화면 검사 1,385개 통과: 선택 전 다음 입력 차단, 숨겨진 인물 터치 무효, 상세/다시 선택/뒤로가기, 이야기 전체 표시, 기본 수치, 앱 중지/복귀, 저장·체력·장비 무변경 및 실제 두 무기 도전 시작을 확인했다.
- 1280×720·1600×720·1280×800·2400×1080에서 선택 전/전환/로안·루미 상세와 기존 무기·도전 설정 76장을 실제 OpenGL 렌더러로 생성하고 1,462개 검사를 통과했다.
- GP-106, GP-114/120/149 생성·복원, GP-267–276와 GP-277–306 두 인물의 preview, 시작 화면 검사를 통과했다. 명시적 인물 선택과 두 단계 취소 흐름에 맞게 입력 검사를 갱신하고 기존 전투·저장 검증을 유지했다.
- 정적 검사, Android 리소스 팩 내보내기와 내보낸 팩의 메인 장면 시작을 통과했다. APK는 생성하지 않았다.
- Android 실기기 플레이는 확인하지 않았다.
