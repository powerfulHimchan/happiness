# GP-247–256 · 태엽 축제장 경로

## 자동 검증

신규22개 실행 단계는 검/활 시작 각각의 진행→별도 프로세스 복원→5단계 완주·이전 저장3단계 완주·실제 파괴 핵 적용 여섯 경로 페이지 입력, 답사 쓰기 실패/재시도·영구 기록 복원, 발판 실제 물리·탑승자 운반·기본 점프 횡단·낙하 복귀·조회/마을 정지, 양 방향 병정/포탑 경고·실제 피해·방벽/회피·고유 발사체·검 피격/사망 취소·감속을 검사한다.16:9·20:9의 카드/페이지 안전 영역과 축소 글꼴 너비를 확인한다.

전체 검사 스크립트는 기존540개+신규22개, 총562개 실행 단계와 Android 리소스 내보내기·패키지 부팅을 실행한다. PR과 병합 후main에서도 같은 검사를 실행한다.

## 확인 범위

기획의 네 지역에 해당하는 선택 경로 시제품이 모두 있다. 이번 범위는 기존 선형3·5스테이지에 축제장 지형/전투를 연결한 것으로, 네 지역 무작위 순서·정식10스테이지는 후속 범위다. 실기기 조작감·전투 난이도·모바일 렌더링 성능은 별도 플레이 확인이 필요하다. APK는 명시적인 제작 요청 시에만 만든다.
