# GP-311 · 행복의 나라 성문 수호기사

전체 여정9스테이지 `city_gate`의 마지막 전투에 행복의 수호기사720체력을 배치한다. 성문 두 혼합 웨이브·계단/성벽 지형은 기존 구성을 사용하고, 평지3920~4880 안에서 보스가 이동한다. 검·활 자동 공격 표적, 성장/필살기·조회 정지·시간 감속, 보스 체력·페이즈/약점 HUD를 기존 전투 시스템으로 연결한다. 비활성 정예/태엽 기사의 상태가 수호기사 HUD를 덮지 않도록 실제 단계에 해당하는 정예만 집계한다. 흰 갑옷·미소·별 방패·창의 전용 SVG와 빛의 창 투사체 외형을 사용한다.

## 전투

방패 돌진→충격파→빛의 창을 순환한다. 경고 시작의 방향을 고정하며, 플레이어가 움직여도 돌진/창 조준은 바뀌지 않는다. 돌진은 평지 양끝에 닿으면2초(2페이즈1.5초) 기절한다. 경고와 돌진 중 정면 검 피해는65%, 활은80%; 뒤쪽은100%다. 공격 뒤 빈틈은 검·활125%, 벽 충돌 기절은150%다. 대기/페이즈 전환은100%다. 원본 피해 이벤트를 복사해 보정하며 동일 타격ID 중복 차단을 유지한다.

| 패턴 | 1페이즈 | 체력50% 이하2페이즈 |
|---|---|---|
| 방패 돌진 | 경고0.90초·속도6.8m/s·18피해 | 경고0.65초·속도8.2m/s·22피해 |
| 지면 충격파 | 경고1.00초·좌우2개·12피해 | 경고0.70초·0.22초 간격으로좌우총4개·14피해 |
| 빛의 창 | 경고1.10초·고정 조준1개·11피해 | 경고0.80초·고정 부채꼴3개·14피해 |

돌진은 붉은 직선, 충격파는 원형, 창은 청록색 궤적을 사용해 색과 형태로 함께 경고한다. 창은1페이즈 한 궤적,2페이즈 세 궤적을 실제 발사 방향과 일치시킨다. 정확 회피의 기존 게이지와 전투 중복 타격 규칙을 유지한다. 공격 식별은 수호기사로 구분하며 기존 멧돼지/태엽 기사 공격 식별은 보존한다.

## 진행과 저장

수호기사 처치 뒤 성문 완료 이야기의 마지막 문장에서 명령을 반복하는 기사를 언급한다. 기존 장비/스킬 보상 뒤10스테이지 중심부로 이동하며, 중심부의960체력 태엽 기사와 마지막 구출/파괴 선택은 유지한다. 현재 수호기사는 관문 전투만 구현하고 별도의 구출/파괴 선택·조력자·설계도는 후속 작업이다.

`city_gate` ID·체크포인트 버전1을 유지하며 보스 상태는 단계/경로에서 결정한다. 완료 저장은 보스를 재등장시키지 않고 같은 이야기/보상 대기로 복원한다. 전투 중 종료는 마지막 완료한8스테이지로 돌아오며 성문에 다시 진입하면 수호기사 체력/패턴을 초기화한다. 보상 쓰기 실패는 정상 저장을 보존하고 재시도한다. 기존3/5단계·지역 순회·자유 전투에는 수호기사가 등장하지 않는다.

## 검증

신규24개 실행 단계: 로안/루미×검/활의8완료 저장→별도 프로세스 복원→실제 검/활 기본 공격 수호기사 처치→9완료 저장→반복 복원/보상 실패·재시도→중심부/최종 선택 완주, 양방향 돌진/경계/피해/정확 회피, 정면·뒤쪽·빈틈/기절 피해, 실제 충격파·창 충돌/페이즈, 시간 정지·감속, 조회 정지·전투 중 종료 복귀, 기존 일반 도전/지역 순회/자유 전투를 검사한다.

전체 검사 스크립트는 기존763개와 신규24개를 합친787개 실행 단계 및 Android 리소스 내보내기·변환된 패키지 부팅을 실행한다. 로컬·PR·병합 후main 각각 실제 로그에서 결과를 확인한다. 실기기 조작감·프레임률·난이도와 전체 여정 소요 시간은 자동 검사와 구분한다. APK는 요청 시에만 만든다.

## 후속 범위

수호기사 구출/파괴 분기와 보상·조력자, 미소의 여왕 세라·행복의 심장·정식 엔딩, 음악·배경 애니메이션은 후속 작업이다.
