## 검증 범위

- 모든 연출은 메뉴 전용 객체에만 저장하며 경제 모델과 체크포인트를 변경하지 않는다.
- 앱 비활성 상태에서는 시계가 멈춘다. 효과는 짧은 시간 후 종료하며 상점을 다시 열어도 이전 구매 효과를 재생하지 않는다.
- 실패한 저장, 중복 데이터 갱신, 초기 데이터 로드, 다른 휴식으로 이동한 경우 성공 효과를 만들지 않는다.
- 기존 구매 검사를 확장해 서비스·무기·스킬의 실제 구매/실패 복구/재실행 복원/다음 구간을 확인한다.
- 실제 재입고 실패·성공·중복 차감 차단과 상한·정비·복원 검사를 유지한다.
- 1280×720·1600×720·1280×800에서 각 상품 종류·빈 결과·진입·상세와 실제 구매 완료 효과를 렌더링한다.
- Android 실기기 플레이와 APK 생성은 이번 작업에 포함하지 않는다.
