# GP-108 · 무기 보상과 등급

3스테이지 시제품의 첫·두 번째 정예 처치 후 검·활 보상 화면을 열고, 교체할 무기를 선택한 뒤 확정하거나 현재 무기를 유지한다. 첫 보상은 희귀, 두 번째는 영웅 등급이며 수치는 고정한다. 보상을 마치면 기존 경로 선택과 다음 스테이지로 이어진다. 마지막 정예는 전체 결과 화면으로 진행한다.

| 등급 | 검 / 활 | 해당 무기 피해 | 검 고유: 스킬 피해 | 활 고유: 기본 공격 피해 | 보조 고유 효과 |
|---|---|---|---|---|---|
| 일반 | 연습용 검 / 연습용 활 | +0% | +0% | +0% | +0% |
| 희귀 | 풀잎 검 / 씨앗 활 | +15% | +10% | +10% | +5% |
| 영웅 | 새벽 검 / 바람 활 | +30% | +20% | +20% | +10% |

등급 피해는 그 무기의 공격에 적용하고, 보조 고유 효과는 반대 무기의 해당 공격 종류에 절반 적용한다. 등급·주 무기 고유·보조 고유의 증가율을 합산한 배율에 기존 카드·직업 배율을 곱하고 마지막에 반올림한다. 예를 들어 희귀 검을 보조로 든 영웅 활은 기본 공격 +50%, 스킬 +35%다. 필살기는 기존 카드·직업 피해만 적용하며 장비 효과를 추가하지 않는다. 두 무기를 계속 보유하고, 보상 교체는 현재 주 무기나 각 무기 스킬 대기시간을 바꾸지 않는다. HUD는 현재 등급 이름과 보조 효과를 표시한다. 무기 종류 추가·랜덤 옵션·상점/상자·인벤토리는 후속 범위다.

보상 대기와 확정 상태를 각각 원자 저장한다. 재실행하면 대기 중에는 보상 선택으로, 확정 후에는 경로 선택으로 복귀한다. 저장 실패 시 장비와 확정 상태를 되돌리고 오류를 표시하여 다시 확정할 수 있다. 동일 스테이지의 보상 확정은 이전 스테이지의 정상 백업을 유지한다. 이전 GP-105~107 저장은 일반 등급·보상 완료로 해석하여 기존 경로 선택으로 복원한다. 새 도전·재도전은 일반 등급으로 초기화하며 기존 사망·완주 저장 삭제 규칙을 유지한다.

## 자동 검증

GP-108 검사는 별도 프로세스로 보상 전 저장→복원/희귀 검 교체→확정 후 복원/영웅 활 교체→3스테이지 완주를 수행한다. 검 실제 타격, 활 투사체와 화살비 실제 타격의 피해·보조 효과, 필살기 제외, 무기 전환·쿨다운 유지, 미선택 확정·중복 보상 차단, 두 화면 비율의 안전 영역과 입력 겹침, 백그라운드 복귀, 저장 실패 롤백, 손상·미래 등급 거부, 이전 스테이지 백업, 이전 버전 복원·보상 유지 선택과 재도전 초기화를 검사한다. 기존 CP-206~406 및 GP-101~107 회귀 검사도 함께 실행한다.

## 실기기 확인

1. 첫 정예를 처치하고 희귀 검 또는 활을 선택·확정한다.
2. 보상 화면과 경로 선택에서 각각 앱을 종료하고 이어하기로 같은 상태가 복원되는지 확인한다.
3. 두 번째 정예의 영웅 무기를 교체하고 전환하면서 주 무기 이름·보조 효과와 스킬 대기시간을 확인한다.
4. 다른 도전에서 현재 무기 유지를 선택해 경로 진행과 완주를 확인한다.

자동 검사 결과와 새 기능의 실제 Android 플레이 확인 여부는 구분한다.
