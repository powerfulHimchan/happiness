# GP-147 검기 베기

정예 보상에서 검 **검기 베기**를 두 슬롯 중 하나에 교체한다. 시전 방향으로 청백색 반달 검기를 발사해 가까운 적부터 최대3개체를 관통한다. 자동 표적이 없어도 사용한다.

| 항목 | 원본 |
| --- | --- |
| 피해 / 관통 | 각36 / 유효 명중 최대3개체 |
| 재사용 | 10초, 시계추 사용 시8초 |
| 시전 / 발사 | 0.50초 / 0.20초 |
| 이동 / 방향 전환 | 불가 / 시전 방향 고정 |
| 회피 취소 | 0.12초부터, 추가 무적 없음 |
| 비행 | 속도12m/s, 발사 위치에서 최대6m |
| 판정 | 검기 중심 상하0.6m, 이동 구간 연속 판정 |

큰 프레임에서도 비행 경로를6m로 제한하고 실제 접촉 순서로 최대3개체에 피해를 준다. 뒤쪽·높이 밖·거리 밖·숨김·사망 표적은 제외한다. 이미 지나간 경로로 이동한 적은 소급 명중하지 않는다. 동일 표적은 검기당 한 번만 시도한다. 무적 차단은 유효 관통 개체수에 포함하지 않는다. 검 성장·장비·기억 피해 배율, 흡수·필살기 충전·스킬 적중 집계는 기존 검 처리에 연결한다.

발사 전 피격·회피·무기 전환은 예정 검기를 취소하고 원본 대기시간을 유지한다. 발사 후 검기는 무기 전환과 회피 뒤에도 진행한다. 적 감속은 검기 속도를 변경하지 않는다. 사망·부활·낙하·단계 이동·새 도전은 남은 검기를 정리한다. 도전 상태 조회 및 복귀 카운트다운은 검기·시전·대기를 함께 정지한다.

## 보상·도감·저장

검8종·활8종, 총16종을6페이지에서 조회한다. 이전15종 순서를 보존하고 검기 베기를 마지막에 추가한다. 두 화면비에서 실제 미보유 후보 순환·슬롯 비교·확정, 저장 실패 롤백, 도감의 모든 카드와 안전 영역을 검증한다. 저장 형식은 기존 스킬 ID 배열을 사용한다. 다른 무기 기술과 중복 슬롯은 거부하고, 새 도전은 기본 스킬로 초기화한다. 이전 저장에 새 기술을 소급 지급하지 않는다.
