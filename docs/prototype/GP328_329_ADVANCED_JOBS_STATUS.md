# GP-328·329 · 파쇄자와 폭풍사수

후속 [GP-330~334](GP330_334_ADVANCED_SPECIALIZATIONS_STATUS.md)에서 숲의 파수꾼과 네 직업의 특화·추가 필살기·진화 비교 도감을 추가했다. 추적자는 진화 직전 숲의 명중 보유 시 숲의 파수꾼, 미보유 시 폭풍사수가 된다. 기존 폭풍사수 저장은 유지한다. 아래는 GP-328·329 당시 구현 기록이다.

설계표의 선봉대 두 번째 진화와 추적자 첫 진화를 구현한다. 공통 조건은 전체 여정7스테이지 이후이며, 기존 능력70%·무기20%·특수10% 성향 점수와 출처별 상한을 유지한다. 조건을 미리 채우면7단계 진입 때, 후반에 채우면 실제 카드 선택·적중·정확한 회피 뒤 자동 진화한다. 짧은 도전과 지역 순회에서는 진화하지 않는다.

| 직업 | 진화 직전 조건 | 기본 직업에 더하는 패시브 |
| --- | --- | --- |
| 용염기사 | 선봉대 · 근력8/투지5 · 여명의 칼날 미보유 | 검 피해15%p · 최대 체력20/회복20 |
| 파쇄자 | 선봉대 · 근력8/투지5 · 여명의 칼날 보유 | 검 피해25%p |
| 폭풍사수 | 추적자 · 사격8/자연5 | 활 피해20%p · 최대 체력10/회복10 |

여명의 칼날은 선봉의 칼날을 먼저 선택한 뒤 얻는 기존 강화 카드다. 파쇄자 분기는 자동 진화 순간의 보유 여부로 결정한다. 이미 진화한 직업은 이후 선택으로 변경하지 않으며 기존 용염기사 저장도 유지한다. 기본 직업 패시브와 카드·선행 강화는 계속 사용할 수 있다. 다른 진화 가지 전용 카드는 등장하지 않는다.

## 전용 능력과 필살기

| 직업 | 콘텐츠 | 효과 |
| --- | --- | --- |
| 파쇄자 | 파쇄의 칼날 | 검 기본 공격·스킬·공격형 필살기 피해30%p, 도전당1회 |
| 파쇄자 | 파쇄자의 투지 | 최대 체력20 · 체력40 회복, 도전당1회 |
| 파쇄자 | 대지 파쇄 | 주변2m 검 피해160 · 2초 적 시간20% |
| 파쇄자 | 투지의 포효 | 주변3m 검 피해80 · 체력30 회복 · 4초 적 시간30% |
| 폭풍사수 | 폭풍의 화살 | 활 기본 공격·스킬·공격형 필살기 피해25%p, 도전당1회 |
| 폭풍사수 | 바람의 호흡 | 최대 체력20 · 체력40 회복, 도전당1회 |
| 폭풍사수 | 폭풍 일제사격 | 전방 화면 안10m/높이2.2m 활 피해120 · 3초 적 시간15% |
| 폭풍사수 | 폭풍의 눈 | 주변3m 활 피해50 · 체력45 회복 · 5초 적 시간20% |

진화 화면은 전투를 멈추며 두 필살기 중 하나를 확정해 기본 직업 필살기를 한 번 교체한다. 게이지는 유지한다. 사용 중인 효과·남은 시간은 별도 스냅샷으로 자연 종료하고 다음 발동부터 새 선택을 사용한다. 실제 피해는 기존 무기 성장·장비·기억·유물 계산을 사용한다. 회복은 기존 원정2 이상75%·정수 올림 규칙을 적용하고 최대 체력 증가는 그대로 지급한다. 시간의 여운과 원정5 발동 제한도 기존 경로를 따른다.

## 저장과 화면

버전1의 기존 직업 문자열에 `breaker`와 `storm_archer`를 추가하며 새 필수 필드는 없다. 모드/단계·성향·파쇄자 선행 카드·카드 소속/횟수·체력/피해 보너스·필살기 소속을 검사한다. 저장 실패와 변조는 기존 정상 저장을 보존한다. 복원은 저장된 수치를 사용해 패시브나 회복을 다시 지급하지 않는다. 새 도전은 직업·보너스·전용 카드를 초기화한다.

기존 영구 발견 저널과 상위 직업 도감에 두 직업을 추가한다. 기록 실패는 확인을 보류하고 같은 버튼으로 재시도한다. 도감은 세 직업의 조건·계승·능력·필살기와 현재/영구 발견 상태를 표시한다. 조회는 파일을 변경하지 않는다. 파쇄자는 분홍 파편, 폭풍사수는 하늘색 번개와 원호 표식으로 구분한다.

## 검증

`gp329_runtime_test.gd`를 PR/main 검사에 추가한다. 두 직업×두 주인공×`seed/resume/legacy/late`의16회 실행으로 실제 검 타격·활 투사체 적중과7단계/후반 진화, 네 필살기의 실제 피해·범위·회복·시간·감속/해제, 사용 중 효과 보존, 전용 카드1회 제한·기본 능력 계승, 기록 실패 재시도·쓰기 오류·변조 거부, 별도 프로세스 반복 복원·다음 단계·새 도전·기본 저장 호환을 검증한다.

용염기사8회와 GP-102/103/116/140 및 원정5 제약16회를 더한 관련 런타임40회, 정적 검사, Godot 리소스 가져오기, Android 리소스 팩 내보내기·팩 부팅을 로컬에서 확인했다. 스테이지 처치 보상은 고정 카드로 해소해 진화 분기를 무작위 후보와 독립적으로 검사한다. 1280×720·1600×720의 실제 진화 화면·세 직업 도감·표식을 렌더링하고 한글·가독성·안전 영역을 확인했다. Android 실기기 조작·성능·난이도 평가는 별도 확인 범위이며 APK는 빌드하지 않았다.
