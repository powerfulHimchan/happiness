# GP-130 · 기억의 쉼터 유물 도감

기존 마을의 두 번째 시설 ‘기억의 쉼터’에 **영구 기억 / 유물 도감** 탭을 추가한다. 시설 위치와 여섯 시설 배치는 유지하고 기존 두 영구 기억의 능력·해금 조건도 같은 탭에서 확인한다.

- 유물 도감은 불사조 깃털·시계추 조각 두 카드를 표시한다. 실제 보상의 `PrototypeRelic.OFFERS`에서 이름·효과를 가져오며 두 번째 정예 완료 후 하나 선택하는 조건을 추가한다.
- 깃털의 50% 부활·도전당 1회·1초 보호·사용 후 재부활 불가와 시계추의 검/활 스킬 대기 -20%·10초→8초·보조 무기 적용·기본 공격/회피/필살기 제외를 확인한다.
- 현재 진행 중인 도전만 기준으로 ‘미보유 · 효과 미리 보기’, ‘이번 도전 · 보유 중’, ‘이번 도전 · 사용 완료’를 표시한다. 저장된 도전이 있어도 이어하기 전에는 미보유로 표시한다. 실제 이어하기 후 보유 상태를 복원하며 새 도전·완주 뒤에는 미보유로 표시한다.
- 미보유 카드도 효과와 조건을 확인할 수 있다. 조회·카드 터치·탭 전환·마을 복귀는 유물을 지급하거나 소비하지 않고 성장·체력·회복약·필살기·대기시간·중간 저장·보스 보상을 바꾸지 않는다. 영구 유물 수집이나 자동 장착 기능은 추가하지 않는다.
- 기존 마을의 새 도전 준비·이어하기·뒤로 버튼을 사용한다. 별도 저장 필드나 파일은 추가하지 않아 기존 저장을 그대로 호환한다.

## 검증

`gp130_runtime_test.gd` seed/resume/finish/legacy 네 별도 프로세스를 전체 기존 검사와 함께 실행한다. 실제 기억의 쉼터 및 두 탭 터치·유물 카드 터치·마을 복귀·1280×720/2400×1080 안전 영역과 입력 비중첩·실제 그리기, 첫 방문 저장 생성 없음·조회 전후 모든 상태 보존을 검사한다. 실제 정예 보상 시계추 획득·별도 프로세스 및 도감 버튼 이어하기·반복 복원·보스 완주·새 도전 초기화·깃털 획득 및 실제 치명타 부활 후 사용 완료 표시·유물 필드 없는 이전 저장의 보스 완주를 확인한다.

Android versionCode 57 / `0.0.57-gp130-relic-codex` / ARM64. 실기기 플레이·가독성 확인은 별도 대기다. 개발 CI는 임시 디버그 서명을 사용한다.
