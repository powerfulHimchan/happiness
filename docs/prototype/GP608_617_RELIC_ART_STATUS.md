기존 벡터 체계에 맞춘 투명 배경 128×128 SVG 원화10개를 추가했다. 같은 텍스처를 유물 선택 화면의 큰 삽화와 유물 도감의 문양에 사용한다. 도감의 보유 유물은 체크, 사용한 불사조 깃털은 흐린 문양과 소진 표식을 기존 상태 문구와 함께 표시한다.

`RelicArt`는 그리기와 표시 영역 계산만 담당한다. 유물ID·목록 순서·페이지 수·보상 후보·획득/취소 터치·효과·중간 저장은 기존 경로를 사용한다. 다른23개 유물은 기존 표시를 유지한다.

## 검증

- Godot 4.7.2 에셋 가져오기와 10개 SVG XML 검사 통과.
- 전용 실행 검사 1,268개 단언 통과: 실제 기억의 쉼터→도감 탭·33개 유물 페이지 순회·보유/소진 표시·실제 보상 선택/취소·삽화/텍스트 비중첩·원본 효과 및 전투/저장 상태 보존.
- 실제 OpenGL 렌더링90장 통과: 1280×720·1600×720·1280×800에서 도감11페이지, 보유10종, 소진 깃털, 보상7페이지, 저장 오류 안내를 각각 확인한다. 렌더 검사1,359개 단언 통과. 두 보상 페이지의10개 원화, 미보유/보유/사용 완료 도감 배치를 시각 확인했다.
- 기존 전체 실행 검사16개 묶음의 검증을 완료했다. 처음 통과한4개 묶음과, 시간 제한으로 중단된12개 묶음의 재실행 결과를 합쳐 모든 검사를 통과했다. 재실행은 해당 검사 스크립트의 첫 단계부터 이후 모든 호출을 원래 순서대로 실행했으며 로컬 시간 배율3·동시2개를 사용했다. 검사 항목과 실패 판정은 유지했다. 각 묶음에서 Android 리소스 팩 내보내기·내보낸 게임 부팅도 통과했다. 16개 검사 사본의 게임 소스·새 에셋·전용 검사 파일이 최종 소스와 동일함을 확인했다.
- 기존 45초 제한을 넘긴 GP-136 seed를 직전 main(`65e634e`)에서도 비교했다. 직전 main84.39초·이번 소스79.24초로 모두 정상 통과해 기존 제한이 부족함을 확인했다. `GODOT_CHECK_TIMEOUT_MULTIPLIER` 옵션(1–4, 기본1)을 추가하고 로컬 재검증에는3을 사용한다. CI 설정과 기본 시간 제한은 유지한다. Bash 구문 검사와 잘못된 배율0 거부를 확인했다.
