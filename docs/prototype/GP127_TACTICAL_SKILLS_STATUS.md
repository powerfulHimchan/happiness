# GP-127 · 삼연 베기·집중 사격·스킬 후보 전환

검·활 스킬을 각 다섯 종류로 확장한다. 기본 두 슬롯은 유지하며 새 스킬은 정예 휴식의 교체 보상으로 획득한다.

- 삼연 베기: 재사용 9초, 동작 0.8초, 0.14/0.34/0.54초에 기본 피해 24/28/36. 시전 방향을 고정해 정면 2.4m·상하 0.9m의 대상들을 세 번 공격한다. 0.2초부터 회피 취소가 가능하며 피격·무기 전환은 남은 타격을 취소한다.
- 집중 사격: 재사용 10초, 동작 1.05초, 0.7초 준비 후 기본 피해 80의 화살 한 발을 시전 정면으로 발사한다. 이동·방향 변경 불가, 0.2초부터 회피 취소 가능. 조준선·준비 원을 표시하며 피격·무기 전환은 준비와 지연 발사를 취소한다. 화살은 1개체만 타격한다.
- 기존 실제 검 피해·활 충돌 경로를 사용하므로 무기 등급·성장·흡수와 스킬 집계가 적용된다. 각 연타는 고유 사건 ID로 중복을 막는다.
- 보상 화면은 네 후보(검·활 각 둘)를 유지한다. ‘다른 후보’로 세 묶음을 순환해 현재 미보유 여섯 스킬을 모두 비교한다. 현재 보유 스킬은 제외하고 버린 기술은 다음 정예에서 다시 제안한다. 후보 전환은 슬롯 선택을 초기화하며 보상·저장·대기시간을 변경하지 않는다. 화면에 없는 기술의 직접 확정을 거부한다.
- 교체는 정예마다 한 번, 기존 스킬의 더 긴 대기시간은 유지한다. 저장 실패는 구성·모든 대기시간·보상 사용을 되돌리고 같은 선택으로 재시도한다. 기존 중간 저장 형식 그대로 새 ID를 허용하며 잘못된 무기 슬롯·중복·알 수 없는 ID는 기존 검증으로 거부한다. 초기 저장과 새 도전은 기본 스킬을 유지한다.

## 검증

`gp127_runtime_test.gd` seed/resume/finish/legacy/combat 다섯 프로세스와 기존 전체 실행 검사를 실행한다. 두 화면비의 순환 버튼·카드·슬롯 안전 영역 및 비중첩·전체 미보유 후보·터치 선택 초기화·실제 그리기, 미표시 확정 차단·저장 실패 롤백·개별 슬롯 교체·별도 프로세스 복원·보스 완주·이전 저장 호환, 실제 타격 시점·경계·각 피해·고유 ID·피격 취소·이동 잠금·준비 표시·방향·투사체 충돌·1개체 제한·무기 전환을 검사한다.
