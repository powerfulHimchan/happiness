# GP-512–514 · 지역 배경 그래픽 3종

## 적용

| 작업 | 지역 | 배경과 표면 표현 |
| --- | --- | --- |
| GP-512 | 바람꽃 평원·능선 | 그라데이션 하늘, 구름·구릉, 풍차·울타리, 꽃길과 발판 장식 |
| GP-513 | 거꾸로 자란 숲·수관 오솔길 | 청록빛 숲 안개, 하늘로 뻗은 뿌리와 아래로 늘어진 수관, 숲 제단, 뿌리 무늬 |
| GP-514 | 별시계 유적·시계 회랑 | 푸른 황혼, 별자리·석주, 파손된 천문 관측대와 천구 시계, 석재 균열과 마름모 문양 |

원화는 기존 벡터 에셋 체계의 800×640 SVG 3개다. 같은 텍스처를 여러 위치에서 재사용하며 하늘·원경·지면 장식은 월드 CanvasItem에 정적으로 그린다. 배경에는 새 프레임 처리, 파티클, 물리 몸체, 타격 대상 또는 저장 필드를 추가하지 않는다.

지역 전환과 두 번째 구간 진입 때 부모 월드도 다시 그려 이전 배경이 남지 않게 한다. `meadow`는 평원 그림을 공유한다. 자유 전투, 태엽 위험 경로, 축제, 성문, 중심부와 심장 의식의 방은 기존 배경 경로를 유지한다. 움직이는 발판의 장식은 현재 발판 사각형 안에 그린다.

## 검증

- Godot 4.7.2 에셋 가져오기와 스크립트 구문 확인.
- 실제 게임 렌더링: 세 지역 × 두 구간 × 전투/발판 × 1280×720·1600×720·1280×800 = 36장. 같은 장면에서 세 지역의 실제 전투 HUD 3장과 자유 전투 복귀 화면도 확인.
- 기존 신규 적 전투 검사 354항목 통과.
- 전체 Godot 실행 검사 4개 묶음 모두 통과. 각 묶음에서 Android 리소스 내보내기와 묶음 실행도 통과.

배경은 전투 배우보다 낮은 채도와 대비로 표시하며 적 본체·대상 표시·공격 경고를 덮지 않는다. 기존 충돌 발판의 좌표·크기·이동 규칙은 변경하지 않는다. Android 실기기 플레이는 수행하지 않았으며 APK는 생성하지 않는다.
