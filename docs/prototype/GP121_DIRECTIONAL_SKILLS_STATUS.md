# GP-121 · 일섬과 산개 사격

정예 무기 보상 뒤 스킬 교체에서 보유하지 않은 검·활 기술을 각각 두 개씩 제안한다. 네 후보를 한 화면에서 보고 선택한 무기의 두 현재 슬롯과 성능을 비교한다. 기술을 선택하면 교체 슬롯 선택을 다시 요구하며, 정예마다 한 번 확정한다. 기존 기본 구성은 유지한다. 새 도전에서는 기본 구성으로 초기화하고 이전 교체 저장은 그대로 읽는다.

| 기술 | 동작 | 피해 | 재사용 | 취소 가능 |
|---|---|---:|---:|---:|
| 검 · 일섬 | 0.45초 뒤 정면 4m·상하 0.9m 직사각 범위 1타, 총 동작 0.80초 | 개체마다 60 | 12초 | 0.50초부터 |
| 활 · 산개 사격 | 0.18초 뒤 정면 -15/0/+15도 세 발, 각 최대 한 개체, 총 동작 0.50초 | 화살마다 16 | 7초 | 0.22초부터 |

일섬은 시전 방향을 고정하고 이동·방향 전환을 잠근다. 범위 안의 여러 개체를 타격하고 뒤쪽·거리 밖·높이 밖은 제외한다. 타격 때 정면 범위와 선을 벡터로 표시한다. 산개는 이동을 허용하고 방향을 잠근다. 대상 자동 조준 대신 시전 시 정면 방향을 기준으로 펼쳐진 화살을 발사한다. 무기 등급·보조 고유 효과·성장 배율을 기존 스킬 피해 계산으로 적용한다. 세 화살은 별도 피해 ID를 사용하고 각각 스킬 적중·필살기 게이지로 집계한다. 투사체는 한 개체에 맞은 뒤 다시 충돌을 검사해도 추가 개체를 관통하지 않는다.

두 슬롯 어느 쪽에 교체해도 해당 기술의 동작·표시·대기시간을 사용한다. 교체 대기시간은 기존 슬롯 잔여 시간과 새 기술 재사용 시간 중 긴 값이다. 다른 슬롯·보조 무기는 유지한다. 시전 중 피격·무기 비활성화·회피·낙하·사망·부활은 기존 행동 취소 흐름을 따른다. 타격·발사 전 중단하면 뒤늦게 공격을 만들지 않으며 소모한 대기시간을 환급하지 않는다.

기존 스킬 보상 저장 경로로 기술 구성·사용 완료·슬롯 대기시간을 함께 확정한다. 저장 실패는 모든 구성과 슬롯 대기시간을 되돌려 같은 화면에서 재시도한다. 한 스킬의 중복 장착·다른 무기 기술·알려지지 않은 ID는 기존 검증에서 차단한다. 새 필드와 저장 버전 변경은 없다. 교체 이전 저장은 기본 구성·해당 정예 사용 완료로 읽어 새 기술 보상을 소급 지급하지 않는다.
