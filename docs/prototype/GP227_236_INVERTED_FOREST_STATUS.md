숲은 입장 시 보너스를 주지 않는다. 정예를 통과한 뒤에만 보너스를 지급하며 최종 보스 승리는 기존 구출/파괴 선택과 완주 절차를 따른다. 숲의 적 체력 배율·처치 경험치·정예 보상은 기존 단계 규칙을 사용한다. 다른 경로로 이동하면 일반 적의 기존 단일 도약·3발 사격·단일 돌진으로 돌아간다.

각 후속 공격에도 기존 길이의 경고와 다른 공격 ID를 사용한다. 씨앗 경고는 실제 부채의 외곽/안쪽 방향을 표시한다. 적 필살기 감속·전투 정지·사망 중단·단계 전환 투사체 정리를 기존 규칙과 연결했다. 움직이는 발판은 일반 물리 시간으로 움직이며 전투 조회/일시 정지/마을에서는 멈춘다.
