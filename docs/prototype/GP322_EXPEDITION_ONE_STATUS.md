# GP-322 · 클리어 후 원정 1

기획서의 첫 상위 난이도 규칙인 정예 몬스터 증가를 구현한다. 도착·귀환·해방·새벽 중 엔딩 하나를 영구 기록하면 새 전체 여정 준비 화면에서 기본/원정 1을 선택한다. 아직 엔딩 기록이 없는 진행 중 여정이나 엔딩 기록 쓰기 실패는 해금하지 않는다. 3·5스테이지 일반 도전과 지역 순회는 기본 난이도를 유지한다.

원정 1은 10개 스테이지 각각의 두 번째 혼합 웨이브에 갑옷 멧돼지 한 마리를 추가한다. 일반 적만 처치해서는 웨이브가 끝나지 않으며 추가 정예 처치 뒤 기존 마지막 정예/보스로 진행한다. 각 스테이지의 추가 정예와 마지막 정예는 서로 다른 전투 생명으로 초기화된다. 기존 체력 배율·공격 주기·전리품 규칙은 유지하고 추가 처치의 경험치와 기존 확률 회복 구슬은 정상 적용한다. 일회·영구 동행 지원은 기존 마지막 정예 구간에서만 사용한다. 최종 수호기사·세라·행복의 심장과 엔딩 흐름을 유지한다.

준비 화면에 적용 규칙과 잠김 조건을 안내하고 취소 시 이전 난이도를 되돌린다. 일반 도전으로 바꾸면 기본으로 돌아가며 시작 API도 미해금/잘못된 모드의 원정을 거부한다. 해금 조회는 준비 화면 진입과 입력 시에 갱신하고 매 프레임 파일을 읽지 않는다. 전투 HUD·도전 정보·결과·마을 최근 이력에 원정 1을 표시한다. 진행 중 이력과 완주 이력에 모두 난이도를 기록한다. 기존 전체/길이별 통계는 난이도를 합산한 전체 도전 통계다.

## 저장과 호환

버전1 체크포인트의 선택 필드 `stage.expedition`에 1을 저장한다. 필드가 없는 기존 저장은 기본(0)으로 복원하며 진행 중 저장에 원정을 소급하지 않는다. 0/1 정수 외 값과 전체 여정이 아닌 원정 저장을 거부한다. 난이도는 준비 화면 선택과 독립적으로 복원하고 다음 스테이지와 최종 선택 저장까지 유지한다. 저장 실패는 기존 정상 파일과 난이도를 보존한다. 해금은 기존 엔딩 영구 저널을 읽으므로 도전 기록 삭제와 독립적이다. 새 저널/새 영구 수치 보상은 만들지 않는다.

## 검증

`gp322_runtime_test.gd`의 두 주인공×검/활×8단계, 총32개 실행을 기존 Godot PR/main 검사에 추가한다. 잠김/해금 실패/취소/모드 전환, 실제 추가 정예와 완료 게이트, 별도 프로세스 이어하기, 변조 저장과 저장 오류, 이전 저장, 1280×720·1600×720 버튼 배치, 이야기 꺼짐의 재실행/다음 스테이지, 10개 추가 정예와 실제 기본 공격 심장 처치·최종 엔딩·결과/이력을 검사한다. 실제 화면 렌더링으로 한글과 안내·버튼 배치도 확인한다. 기존 전체 검사와 Android 리소스 내보내기·패키지 부팅을 확인한 뒤 병합한다. Android 실기기 조작·성능·난이도 평가는 별도 확인 대상이다. APK는 요청 시에만 만든다.

다음 원정 2~5의 회복 제한·새 패턴·특수 제약은 이번 범위가 아니다.
