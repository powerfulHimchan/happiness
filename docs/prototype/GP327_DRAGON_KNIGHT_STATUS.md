# GP-327 · 첫 상위 직업 용염기사

후속 [GP-328·329](GP328_329_ADVANCED_JOBS_STATUS.md)에서 파쇄자·폭풍사수를 추가했다. 이제 선봉대는 진화 직전 여명의 칼날을 보유하면 파쇄자, 미보유하면 용염기사가 된다. 이미 용염기사인 저장과 진화 후 여명의 칼날 선택은 기존 진화를 유지한다. 아래는 GP-327 당시 구현 기록이다.

새 전체 여정의 7스테이지 이후, 선봉대의 근력8·투지5를 모두 채우면 용염기사로 자동 진화한다. 성향은 기존 능력70%·무기20%·특수10%와 출처별 상한을 유지한다. 시작 직업은 없으며, 일반3/5단계·지역 순회·미발현·추적자는 이 진화를 적용하지 않는다. 7단계 진입에 이미 조건을 채웠으면 즉시, 늦게 채우면 실제 능력 선택·검 적중·정확한 회피 뒤 판정한다. 기존 저장의 기본 직업은 자동으로 상위 직업으로 바뀌지 않는다.

## 진화 보상

선봉대의 기본 패시브와 보유 카드를 계승하며 검 기본 공격·스킬·공격형 필살기 피해 보너스에15%p를 더하고 최대 체력20을 늘린다. 이때 체력20 회복은 기존 원정2 이상의75%·정수 올림 규칙을 사용한다. 최대 체력 자체는 줄이지 않는다. 선봉대의 모든 전용 카드도 계속 등장한다.

| 새 콘텐츠 | 효과 |
| --- | --- |
| 용염의 칼날 | 검 기본 공격·스킬·공격형 필살기 피해 +20%p, 도전당1회 |
| 용의 심장 | 최대 체력 +30·체력30 회복, 도전당1회 |
| 용염 폭발 | 주변3m 검 피해120·3초 적 시간15% |
| 불꽃의 수호 | 체력50 회복·주변3m 검 피해40·5초 적 시간25% |

진화 화면에서 두 필살기 중 하나를 고르면 기존 선봉대 필살기를 한 번 교체한다. 게이지를 새로 지급하거나 소비하지 않으며 사용 중인 필살기의 효과·남은 시간은 기존 스냅샷으로 자연 종료한다. 시간의 여운·유물·원정5 발동 봉인은 기존 경로로 적용한다. 진화 화면은 전투를 멈추고 실제 터치 확정 후 재개한다. 직업 영구 기록 실패는 확인을 보류하며 재시도로 복구한다. 머리 위에는 기본 직업과 구별되는 불꽃 표식을 그린다.

## 저장과 도감

체크포인트 버전1의 기존 `growth.job`에 `dragon_knight`를 추가한다. 추가 필수 필드는 없다. 상위 직업·성향·단계/모드·전용 카드와 상한·최대 체력·피해 보너스·필살기 소속을 검증하고 변조된 저장은 거부한다. 복원은 저장된 수치를 읽어 진화 보상을 다시 지급하지 않는다. 전투 중 종료하면 기존 정책대로 직전 완료 지점으로 돌아가며 이후 진화 조건을 다시 판정한다.

마을 직업 도감에 `상위 직업` 탭을 추가해 조건·계승·능력·필살기와 미발견/영구 발견/현재 진화를 표시한다. 영구 발견은 기존 직업 저널에 남으며 사망·새 도전·도전 기록 삭제와 독립이다. 도감 열람은 저장이나 보상을 변경하지 않는다. 새 도전은 직업·진화 패시브·전용 카드를 초기화한다.

## 검증 범위

`gp327_runtime_test.gd`를 PR/main 전체 검사에 추가한다. 로안·루미별 seed/resume/legacy/late의8개 실행에서 6→7단계 자동 진화, 늦은 실제 적중 진화, 전용 두 필살기의 실제 피해/회복과 사용 중 효과 보존, 기본 능력 계승·상위 카드1회 제한, 기록 실패 재시도·쓰기 실패·변조 거부, 별도 프로세스 반복 복원과 다음 스테이지, 새 도전 초기화·기존 저장·영구 도감·두 화면비 배치를 확인한다. 실제 렌더링으로1280×720·1600×720의 진화 화면·도감·불꽃 표식을 확인한다.

기존 기본 직업·카드 강화·필살기·도감과 전체 Godot 자동 검사를 유지한다. Android 실기기 조작·성능·진화 조건 및 전투 밸런스는 별도 확인 대상이다. APK는 사용자 요청 시에만 만든다. 다른 상위 직업과 새 무기 계열은 후속 범위다.
