## 실행 규칙

- 스킬마다 고유 타격/투사체 ID를 사용하며 큰 프레임에서 예정된 모든 타격을 한 번씩 처리한다. 방향 전환·재시전·회피 가능 시점과 피격·낙하·사망·무기 전환의 취소 규칙은 기존 행동 상태기를 사용한다.
- 전진/후퇴는 기존 충돌 이동으로 처리하며 추가 무적이나 방어 효과를 부여하지 않는다. 방패 신규5종은 공격형 기술이다. 기존 방패 올리기·응수·수호 돌진의 방어 규칙을 유지한다.
- 수정 부채탄은 -18/0/+18도 얼음탄3발, 각2개체. 쌍별 화염은 두 발 각각 맞은 위치 주변1.4m에 폭발한다. 새벽 맥동은 시전자 주변2.6m, 폭풍의 인장은 시전 표적 위치 주변1.2m에 고정된다. 퇴보 빙창은 조준 방향을 유지하며 각3개체까지 관통한다.
- 별빛 소나기는 시전 위치에 고정되고 제비 추적은 시전 표적을 추적한다. 표적 소실/범위 이탈은 기존 직진 전환 규칙을 따른다. 후퇴 부채시는3발을 두 번 발사하며 도감에 총6발을 표시한다.
- 성장·장비·유물·직업 피해 보정과 스킬 적중/피해 통계, 여행자 수련 과제에 기존 공통 경로로 연결했다. 영구 효과나 신규 저장 필드를 추가하지 않는다.
