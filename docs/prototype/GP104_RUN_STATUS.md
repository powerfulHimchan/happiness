# GP-104 · 성장 보존과 3스테이지 연속 진행

GP-103에서 마지막 레벨업에 발현한 직업과 선택 필살기를 다음 전투에서 활용하도록 연결했다. Android `0.0.31-gp104-run`, versionCode 31, ARM64 디버그 빌드다.

## 플레이 경로

1. 스테이지 시작으로 새 도전을 시작한다.
2. 기존 전진·웨이브·정예의 다섯 구간을 진행하고 경험치·능력을 선택한다.
3. 선봉대·추적자 발현 시 해당 직업 필살기를 확정한다.
4. 1~2스테이지 완료 시 최대 체력의 20%를 올림하여 회복한다. 최대 체력을 넘지 않으며 완료당 한 번만 적용한다.
5. 풀숲 길 또는 바람 길 카드를 눌러 다음 스테이지를 시작한다. 이 화면에서는 전투·스테이지 시간·필살기 타이머가 멈춘다.
6. 직업과 능력을 활용해 2~3스테이지를 진행한다. 3스테이지 완료 후 한 번의 도전 결과를 표시한다.

## 경로와 보존 규칙

| 경로 | 다음 첫 웨이브 | 선택 보상 |
|---|---|---|
| 풀숲 길 | 풀잎 슬라임 + 씨앗 포대 | 기본 완료 회복 후 체력 20 추가 회복 |
| 바람 길 | 풀잎 슬라임 + 바람 정령 | 필살기 게이지 +25, 최대 100 |

다음 스테이지는 같은 지형·다섯 구간 구조를 재사용한다. 두 번째 웨이브는 세 일반 적, 마지막은 갑옷 멧돼지다. 적 최대 체력은 1/2/3스테이지에서 원래 값의 100/125/150%이며 공격 피해·경고 시간·패턴은 그대로다. 경로는 다음 첫 웨이브와 즉시 보상에 적용한다. 독립된 세 지역이나 서로 다른 맵은 아니다.

| 상태 | 스테이지 이동 | 새 도전/재도전 |
|---|---|---|
| 레벨·현재/누적 경험치·카드 랭크·피해 강화 | 보존 | 초기화 |
| 직업·성향 점수·패시브·표식·선택 필살기 | 보존 | 초기화 |
| 현재 체력·최대 체력 | 보존, 완료·경로 회복 적용 | 100으로 초기화 |
| 필살기 게이지·무기 선택·무기별 쿨다운 | 보존, 경로 게이지 적용 | 초기화 |
| 재추첨 | 다음 스테이지 1회로 보충 | 1회 |
| 진행 중 공격·필살기 감속·투사체·화면 흔들림 | 종료·정리 | 정리 |
| 플레이어 위치·낙하 복귀점 | 시작 지점으로 이동 | 시작 지점으로 초기화 |

카드·발현 선택을 모두 마친 뒤에 스테이지 완료를 처리하므로 마지막 보상을 잃지 않는다. 무기와 쿨다운은 보존하되 예약 전환과 진행 중 스킬은 취소한다. 중간 선택은 앱 복귀 알림에도 유지하며 재도전·사망·씬 종료 시 일시정지 소유권을 해제한다.

같은 적 인스턴스를 재등장시키므로 공격 이벤트 ID에 인스턴스와 생명 세대를 포함한다. 새 생명의 첫 공격을 이전 생명의 중복으로 차단하지 않으며 같은 생명의 같은 타격은 여전히 중복 차단한다. 씨앗탄·접촉·멧돼지 돌진·충격파에 적용한다. 경험치도 생명 세대별로 한 번만 보상한다.

## 시간과 로컬 기록

각 스테이지의 180초는 측정 목표이며 강제 제한이 아니다. 3스테이지 도전 목표는 540초다. 중간 선택 시간은 전투 시간에서 제외하고 결과에는 총 전투 시간과 세 스테이지별 시간을 표시한다.

JSON Lines는 한 도전 ID 안에 스테이지 시작·완료와 구간 기록을 추가하고 마지막에만 `run_completed`를 기록한다. 중간 완료를 완주 횟수로 집계하지 않는다. 기존 단일 스테이지 기록은 유지하고, 결과 화면의 3스테이지 최고·평균 시간은 3스테이지 기록끼리 비교한다. 기존 스키마 1은 그대로이며 새 필드를 추가했다. 기록은 플레이 상태를 복원하는 저장 파일이 아니다.

## 검증과 실기기 확인

CP-206~406, GP-101~104 총 15개 런타임 검사다. 기존 단일 스테이지 완료·기록 검사는 명시적인 단일 스테이지 fixture로 유지한다. GP-104는 두 직업의 3스테이지 전체 사용자 화면 경로, 총 경험치 240, 전용 카드와 실제 직업 필살기 피해, 경로별 실제 적 구성·보상, 성장·게이지·쿨다운 보존, 재추첨 보충, 중복 선택·회복 차단, 실제 투사체 정리, 재등장 적 피해와 동일 타격 중복 차단, 안전 영역·앱 복귀·재도전·사망·씬 종료, 완료 시간과 기록 분리·재읽기를 검사한다. 적 처치와 이동은 테스트 이벤트로 재현한다.

Android에서는 관련 무기 카드를 반복 선택해 직업을 발현하고, 2스테이지에서 전용 카드와 필살기를 사용한 뒤 3스테이지 결과·재도전 초기화를 확인한다. 두 경로를 각각 선택하고 경로 화면에서 백그라운드 복귀도 확인한다. 기존 20분 안정성 통과는 2026-09-30 사용자 보고이며 GP-104 새 기능의 실기기 통과를 의미하지 않는다.

## 다음 범위

스테이지 사이 중간 저장·앱 재시작 이어하기, 서로 다른 맵과 지역, 전체 10스테이지 진행, 상위 직업·영구 해금은 아직 구현하지 않았다. 다음 단위는 스테이지 경계의 로컬 저장·이어하기다.
