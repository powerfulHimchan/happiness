## 새 무기의 규칙

- 조건형 무기는 별도 영구 해금 없이 정예 보상에서 선택한다. 휴대 중인 두 계열만 후보에 나오고, 같은 계열의 다른 설계와 같이 희귀/영웅 두 등급으로 제공한다. 기존74개 도감 항목 뒤에60개 등급 항목을 추가해 총134개를 표시한다. 기존 항목의 순서·ID를 보존한다. 외형은 기존 여섯 무기 계열 표현을 사용한다.
- 공통 무기 피해는 희귀+10%, 영웅+20%이다. 조건 충족 시 해당 공격 종류의 고유 피해를 각각+25%, +40% 적용한다. 보조 무기의 고유 효과는 같은 조건에서50%만 적용한다. 자기 무기의 공통 피해·고유 효과와 보조 고유 효과는 기존처럼 합산한다.
- 평정은 체력80% 이상, 역전은30% 이하이며 정수 비율로 경계를 판정한다. 결계는 방벽 잔량이 있을 때, 대지/창공은 각각 지상/공중일 때 적용한다. 조건부 효과는 생존 상태에서 판정한다. 필살기는 모든 장비 피해/고유 효과에서 기존처럼 제외한다.
- 기존 피해 생성 시점을 유지한다. 화살·마법탄처럼 발사 시 피해를 계산하는 공격은 그 시점의 조건을 사용하며, 이후 체력이나 자세가 바뀌어도 이미 발사된 탄환을 소급 변경하지 않는다. 치명타 판정과 연계 발동은 기존 적중 규칙을 유지한다.
- 선택된 설계는 기존 `weapons.blueprints`에 보존한다. 새 저장 필드나 영구 해금·재화는 만들지 않는다. 새 도전은 기본 무기로 돌아가고 이전 저장도 그대로 읽는다. 알 수 없는 설계·다른 계열·일반 등급의 조건형 설계는 거부한다.

## 보급소와 도감

보급소의 종류/상태/무기/정렬은 함께 사용할 수 있다. 필터나 페이지 이동은 선택 상품과 교체 슬롯을 해제해 숨겨진 상품을 확정하지 않도록 한다. **상세·기록**에서 상품 상세, 구매 내역, 재입고 미리보기를 열고 닫는다. 뒤로가기는 상세창을 먼저 닫는다. 상점 내역과 잔액 요약은 기존 구매·재입고·과제 영수증에서 계산한다. 조회만으로 구매하거나 저장하지 않는다.

스킬 비교의 **타격합**은 현재 성장·장비·조건에 따른 각 기본 타격의 합이다. 산탄 수·공간적 중복·거리·치명타·연속 적중 가능성을 포함한 실전 총 피해나 DPS를 뜻하지 않는다. 두 슬롯을 각각 비교하며 구매/교체에는 기존 슬롯 확정 규칙을 유지한다.

재입고 미리보기는 기존 시드/구간/다음 재입고 규칙으로 계산한다. 확정 시에만10전을 소비하며 서비스·무기 승급 재고와 구매 이력은 유지한다. 같은 휴식에서 이미 재입고했다면 완료 상태를 보여준다. 구매 후 잔액은 상세에서 보여주고 돈이 모자라면 부족액을 표시한다.

무기 도감 필터와 정렬은 조회 전용이다. 장착 중인 두 설계는 정확히 구분하고, 검색 결과가 없어도 빈 안내 카드와 안전한 페이지를 제공한다. **장비100 기준** 비교는 성장·기억·유물·전술·치명타를 제외하고 장비 배율만 비교한다. 휴대 계열의 후보는 기존 보조 무기를 유지한 채 해당 후보를 주 무기로 사용했을 때와 현재 장비를 비교한다. 미휴대 계열은 일반 기본 장비/보조를 기준으로 후보 성능을 표시한다. 진행 중 도전은 현재 체력·방벽·자세를, 도전이 없으면 체력100%·지상·방벽 없음 기준을 사용하며 화면에도 기준을 표시한다.

보상 첫 페이지는 기존 기본/해금 무기만 유지한다. 조건형 무기는 추가 설계 페이지로 분류해 첫 페이지에 과도하게 늘어놓지 않는다. 보급소와 도감의 모든 필터·상세·비교는 저장 파일·장비·성장·치명타 난수를 변경하지 않는다.
