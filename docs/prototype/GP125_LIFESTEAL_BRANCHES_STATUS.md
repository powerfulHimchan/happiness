# GP-125 · 생명 흡수 강화 가지

기획의 획득 능력 전용 강화 가지를 생명 흡수에 연결한다. 기본 능력을 선택한 이후 레벨업에서 두 공용 강화 후보가 등장한다. 하나를 선택하면 해당 도전에서는 다른 가지를 선택할 수 없다.

| 강화 | 효과 |
| --- | --- |
| 깊은 흡수 | 실제 검·활 피해의 10%를 항상 회복 |
| 위기의 흡수 | 타격 시 체력이 최대 체력의 30% 이하이면 15%, 그 외에는 기본 5% 회복 |

- 선행 능력, 도전당 한 번, 상호 배타 조건을 후보·재추첨·오래된 화면 선택·저장 검증에 동일하게 적용한다. 체력이 부족하지 않거나 전투가 정지됐거나 플레이어가 사망했을 때의 기존 제한은 유지한다.
- 정수 누적량 한 단위는 체력 1/20이다. 기본 타격은 실제 피해를 한 배, 깊은 흡수는 두 배, 위기 타격은 세 배로 누적한다. 강화 선택이나 체력 문턱 이동으로 이전 소수를 버리지 않는다.
- 한 타격의 배율은 공격 직전 체력으로 정한다. 회복으로 30%를 넘더라도 해당 타격 전체에 15%를 적용하며 화살비·관통의 다음 개별 적중은 새 체력으로 다시 판정한다. 최대 체력이 성장해도 비율 문턱을 사용한다.
- HUD는 현재 적용되는 흡수율 5/10/15%를 표시한다. 다른 피해·체력·약·대기시간은 바꾸지 않는다. 강화 성향은 자연 0.75·투지 0.75다.
- 능력 등급에서 강화를 복원해 추가 저장 필드를 만들지 않는다. 이어하기·스테이지 이동은 선택한 가지와 소수를 유지하고 새 도전은 초기화한다. 이전 저장은 기본 5%를 유지한다. 선행 능력 없는 강화·양쪽 강화·2등급 강화는 거부한다.

## 검증

`gp125_runtime_test.gd`의 seed/resume/crisis/restore/legacy/combat 여섯 프로세스는 실제 두 차례 처치 레벨업·카드 터치·두 화면비 그리기, 선행·배타·중복·재추첨·저장 변조, 기본→강화 소수 보존·체력 문턱·성장 체력·회복약, 두 가지의 각각 별도 프로세스 복원·실제 화살 적중, 화살비·세 대상 관통·일섬의 타격별 위기 배율, 이전 저장·새 도전·실제 보스 완주를 검사한다. 기존 실행 검사 전체도 함께 실행한다.
