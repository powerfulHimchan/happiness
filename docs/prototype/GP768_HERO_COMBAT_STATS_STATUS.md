# GP-768 · 주인공 공통 전투 능력치

로안·루미에게 공격력, 방어력, 치명타 확률, 치명타 피해, 체력을 연결했다. 고유 특성은 후속 [GP-769](GP769_HERO_TRAITS_STATUS.md)에서 로안 ‘반격의 순간’과 루미 ‘별빛의 응답’으로 구현했다.

| 능력치 | 새 도전 기본값 | 성장 |
| --- | --- | --- |
| 공격력 | 100 | 기존 ‘새벽의 힘’ 1등급마다 +10 |
| 방어력 | 0 | ‘단단한 결의’ 1등급마다 +10, 최대 5등급 |
| 치명타 확률 | 0% | ‘예리한 감각’ 1등급마다 +5%p, 최대 10등급 |
| 치명타 피해 | 150% | ‘결정적 일격’ 1등급마다 +25%p, 최대 5등급 |
| 체력 | 100/100 | 기존 체력·직업·기억·회복 효과 유지 |

공격력 100은 기존 무기 기본 피해의 기준이다. 공통 공격력과 무기별 피해 보너스를 기존 방식대로 합산한 뒤 장비·유물·직업·조건부 배율을 적용한다. 공격력 +10을 기존 ‘피해 +10%’와 중복 적용하지 않는다. 무기마다 기본 피해·스킬 계수가 달라 주인공 공격력과 한 타격의 피해량은 구분한다.

방어력은 `100 / (100 + 방어력)`을 받는 전투 피해에 곱한다. 기존 방패·유물·위기 보정과 함께 한 번 반올림하고 최소 피해 1을 보장한 뒤 방벽을 소비한다. 예를 들어 방어력 50에서 30 피해는 20, 방벽 10이 있으면 체력 피해는 10이다. 낙하 체력 비용은 기존 방식으로 처리한다.

치명타는 실제 타격에만 적용한다. 여섯 무기의 기본 공격·스킬·공격형 필살기가 공통 경로를 사용하며 치명타 피해 150%는 최종 피해 1.5배를 뜻한다. 타격 이벤트마다 결과를 보존하므로 같은 이벤트를 재전달해도 재추첨·추가 피해·중복 치명타 연출이 없다. 투사체 원본 피해와 태그를 바꾸지 않아 관통·다중 적중에서 배율이 누적되지 않는다. 적 방어 보정 전 실제 출발 피해를 공격 통계·적중 피드백에 연결하고, 생명 흡수는 실제 감소한 적 체력을 사용한다. 성공한 치명타에는 금색 ‘치명타’ 숫자를 띄운다.

## 표시·획득·저장

- `도전 상태 → 도전 정보` 첫 페이지에 다섯 능력치와 방어력에 의한 감소율을 표시한다. 조회·피해 미리보기는 치명타 난수를 소비하지 않는다.
- 신규 3종은 공용 성장 후보·능력 도감·보유 능력·영구 발견에 기존 카드 체계로 연결했다. 새벽의 힘·튼튼한 심장은 기존 카드를 그대로 사용한다.
- 새 능력치는 저장된 성장 카드 등급에서 복원한다. 별도 능력치 사본이나 저장 버전 변경이 없어 기존 저장을 읽을 수 있다. 반복 이어하기로 중복 증가하지 않으며 새 도전에서는 초기화한다.
- 기존 기본 전투 피해를 유지하도록 방어력·치명타 확률은 0에서 성장한다. 두 주인공의 공통 초기값은 같다.

## 검증 범위

`hero_stats_runtime_test.gd`의 seed/resume/combat 단계는 기본값·실제 성장 선택·공격력 합산·체력 증가·잘못된 등급의 저장 거부·별도 프로세스 반복 복원·새 도전 초기화를 검사한다. 고정 난수로 여섯 무기 × 기본/스킬/필살기의 치명타와 비치명타·중복 전달·원본 보존을 검사하며, 실제 네 근접 무기·화살·마법탄·필살기와 흡수 경로도 확인한다. 방어력과 방벽, 무적, 낙하의 상호작용을 포함한다.

render 단계는 실제 OpenGL 렌더러로 1280×720, 1600×720, 1280×800 화면을 출력해 능력치 카드의 배치와 문구를 확인한다. 실기기 플레이 검증과 APK 빌드는 이번 범위에 포함하지 않는다. 신규 실행 단계는 기존 프로젝트 검사 스크립트에 추가했다.

확인 결과: 신규 seed/resume/combat 3단계(265개 assertion), 관련 기존 전투·성장·회복·방벽·직업·저장 검사145개, 실제 렌더링3종을 통과했다. 기존 전체 콘텐츠 조합 행렬의 완료를 뜻하지 않는다. 저장 복구 검사는 원래 스크립트의 seed/resume/corrupt/recover 순서를 보존해 확인했다.
