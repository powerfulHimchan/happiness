# 행복 동화 시작 화면

## 적용 범위

- 사용자 선택: 첫 번째 **왼쪽 메뉴형**, 첫 번째 **새벽으로 가는 길** 배경.
- 한국어 제목과 앱 표시 이름을 **행복 동화**로 변경했다. 영문 표기 Happiness Tale와 부제 Rewind to Dawn은 유지한다.
- 중앙 패널을 걷어내고 제목·메뉴를 왼쪽에, 넓은 배경을 오른쪽에 배치한다.
- 진행 중인 저장이 있으면 이어하기·새 도전·마을을, 없으면 새 도전·마을을 표시한다. 기억 수첩·설정·조작 배치는 작은 하단 메뉴로 유지한다.
- 실제 입력과 그리기가 같은 레이아웃을 사용한다. 상태 안내와 업적·칭호는 하단에 표시한다.
- Godot 시작 이미지를 숨기고 Android 시스템 시작 아이콘을 기존 게임 아이콘으로 지정한다. Android 시스템 자체의 시작 화면은 남을 수 있다.
- 제목 변경 전의 데스크톱 저장 경로를 플랫폼별로 유지한다. Android 패키지 식별자는 유지한다.

## 검증

- Godot 4.7.2: 시작 화면 자동 검사 176개 통과.
- 실제 OpenGL 렌더러: 1280×720·1600×720·1280×800의 저장 있음/없음 6장, 렌더 포함 검사 183개 통과.
- 새 도전·마을·기억 수첩·설정·조작 배치의 실제 터치 연결, 메뉴 겹침·안전 영역·저장 폴더 확인.
- 새 검사를 기존 `scripts/check_godot_project.sh`에 연결했다.
- 기존 프로젝트 정적 검사 통과. Windows에서는 같은 Godot 버전으로 기존 실행 검사를 직접 실행했다.
- 시작 화면·체크포인트 생성/재개/완주/손상 복구/삭제, 시작 무기, 마을, 로안·루미 기억 수첩, 영구 업적, 유물 및 캐릭터·적·보스 그래픽, 지역 적 배치, 성장·연속 진행의 총 52묶음 통과. 최종 레이아웃 정리 뒤 시작 화면 176개 검사도 재통과했다.

APK 생성과 Android 실기기 설치·플레이 검증은 하지 않았다.
