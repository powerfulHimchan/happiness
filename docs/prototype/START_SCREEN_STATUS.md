# 다시 피는 새벽 시작 화면

## 적용 범위

- 사용자가 승인한 두 번째 시안을 기준으로 한국어 제목과 Godot/Android 앱 표시 이름을 **다시 피는 새벽**으로 변경했다. 부제는 Rewind to Dawn이다.
- 제목·부제·홈 메뉴 5개는 투명 이미지 7종으로 표시한다. 기본 폰트로 메뉴 글자를 출력하지 않는다. 이미지 원본은 재생성 가능한 SVG 경로이며 Godot 임포트 후 텍스처로 그린다.
- 사각 버튼·메뉴 테두리·배경 판을 없앴다. 글자 경계와 손가락 여백을 공유하는 입력 영역을 사용한다. 선택 메뉴는 금색과 작은 마름모로 표시한다.
- 기존 새벽으로 가는 길 배경을 유지하고, 구름의 느린 흐름·폭포의 흐름·물안개·전경 꽃 흔들림·빛 입자를 더했다. 배경 셰이더 한 개와 고정 입자 18개를 재사용한다.
- 수동 애니메이션 시계는 홈에서만 진행하며 앱 비활성화/다른 메뉴에서는 멈춘다. 그림·애니메이션은 게임 난수를 소비하지 않는다.
- 홈의 조작 배치 버튼과 입력 연결을 제거했다. **설정 → 조작 배치 / 배치 편집**으로 이동했고, 적용·취소·뒤로가기는 설정으로 복귀한다. 저장 실패는 편집 화면에 남는다. 10초 조작 테스트와 전투 중 편집의 3초 복귀는 유지한다.
- 설정 패널의 음량·진동·화면 흔들기·조작 배치·기록 초기화 행을 겹치지 않게 재배치했다. 개인정보 안내와 메인 복귀를 유지한다.
- 저장 유무에 따른 이어하기/새 도전, 마을·기억 수첩, 실제 저장 안내와 업적/칭호 표시는 유지한다.
- Android 앱 식별자와 기존 플랫폼별 사용자 저장 디렉터리를 유지한다. 이름을 바꿔도 기존 세이브 경로는 바뀌지 않는다.

## 검증

- Godot 4.7.2: 확장한 시작 화면 실행 검사 268개 통과.
- 실제 OpenGL 렌더러: 1280×720·1600×720·1280×800에서 293개 검사 통과. 저장 있음/없음과 시간 차 프레임 12장, 설정 3장, 조작 편집 3장 등 총18장 확인.
- 시간 차 렌더의 픽셀 변화를 확인했다. 홈/다른 화면/앱 비활성화의 시계 정지·재개, 난수 비소비, 음수 시간 방어를 검사했다.
- 실제 터치로 설정→조작 배치, 저장·취소·저장 실패·10초 테스트·키보드 뒤로가기를 확인했다. 모든 홈/설정 입력 영역의 포함·비중첩을 검사했다.
- 기존 CP-401–406 조작 배치·프리셋 저장/복원·복귀 카운트다운·음향 설정·로컬 기록 검사 통과.
- 기존 새 도전 준비 검사 1,333개 통과.
- 기존 GP-105 체크포인트 생성→별도 프로세스 이어하기→완주→저장 없음 4단계 통과. 새 이미지 글자 터치로 저장된 무기·성장·잔량을 복원했다.
- 프로젝트 정적 검사, Android용 게임 리소스 팩 내보내기와 메인 장면 시작 확인 통과.

Android 실기기 설치·플레이 검증은 하지 않았다. 이번 요청에서는 APK를 생성하지 않았다.
