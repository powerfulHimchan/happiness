# GP-142 · 처치 회복

기획의 처치 회복 빌드를 공용 성장 카드 **처치 회복**으로 구현한다. 도전당 한 번 선택하며 이후 전투 중 실제 적 처치마다 현재 최대 체력의 2%를 회복한다. 소수는 올림한다(최대100→2,105→3). 체력 상한을 넘지 않고 최대 체력·방벽·회복약·스킬 대기를 바꾸지 않는다. 선택 직후 회복이나 선택을 일으킨 이전 처치의 소급 회복은 없다.

검 실제 타격, 활 실제 투사체와 공격형 필살기의 유효 처치를 같은 규칙으로 처리한다. 일반·정예·보스·조력 처치를 구분해 배율을 늘리지 않는다. 생명 흡수는 실제 피해에 따른 회복과 기존 소수를 유지하고, 시간 수집은 필살기 +5를 별도로 적용한다. 이 효과는 적 처치의 경험치가 성장 화면을 열기 전에 적용한다.

적이 실제로 쓰러진 순간의 전투 그룹·가시성·트리 정지 상태를 임시로 기록하고, 도전 진행과 실제 전투 화면 자격을 함께 검사한다. 같은 개체의 같은 생명은 한 번만 지급한다. 적 재등장 시 임시 처치 표식을 비운다. 살아 있는 적의 위조 신호, 연습 표적·숨김·플레이어 사망·외부 정지·현재 도전 조회·조작 편집·스테이지 완료·도전 종료는 회복을 지급하지 않는다. 잠금 상태에서 발생한 처치는 복귀 후 신호를 다시 보내도 누적 회복으로 지급하지 않는다.

카드는 자연/투지 성향을 각각0.75 제공하며 기존70% 능력 가중치를 사용한다. 최대1등급 이후 후보에서 제외하고 오래된 중복 카드의 확정도 거부한다. 영구 발견 기록에 실패하면 능력·성향·체력을 변경하지 않고 같은 카드 재선택을 안내한다.

능력 도감은 실제 원본21능력을 일곱 페이지로 표시한다. 현재 도전의 보유 능력 탭에는 선택 등급과 원본 효과를, 도전 정보의 생존 상태에는 실제 최대 체력에 따른 회복량을 표시한다. 두 화면비에서 여섯 생존 설명 줄과 모든 페이지를 검사한다. 조회와 복귀는 회복이나 저장을 발생시키지 않는다.

기존 성장 등급과 현재 체력 필드만 저장하고 저장 버전을 늘리지 않는다. 이어하기는 남은 체력·흡수 소수·필살기·스킬 대기를 그대로 복원하며 추가 회복을 지급하지 않는다. 기존 저장에 능력이 없으면 자동 지급하지 않는다. 새 도전은 등급을 비우고 영구 발견만 유지한다. 실제 처치 때의 임시 표식은 저장하지 않는다.

`gp142_runtime_test.gd`의 seed/resume/finish/legacy-seed/legacy/combat 여섯 프로세스로 실제 카드 선택·기록 실패 재시도·선택 계기 처치 미적용, 실제 검·활·공격형 필살기와 일반/정예/보스 처치, 중복·위조·새 생명·자격 차단·잠금 해제 후 재전송,105체력 올림·상한, 흡수/시간 수집 합산, 변조 등급 거부·정상 저장 보호, 별도 프로세스 반복 복원·5스테이지 완주·새 도전·기존3스테이지 저장을 검증한다. 기존 전체 회귀 검사를 유지한다.
