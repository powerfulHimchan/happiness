# GP-136 · 견고한 방벽

레벨업 공용 능력에 견고한 방벽을 추가한다. 마력 방벽을 선택한 뒤에만 등장하며 도전당 한 번 선택할 수 있다. 최대 방벽은20→30으로 늘고 선택 당시 잔량에10을 더한다. 가득 찬20은30, 잔량13은23, 소진0은10이 된다. 이미 강화한 능력의 반복 선택/호출은 추가 보충하지 않는다. 실제 다음 스테이지 진입에서30으로 충전한다.

현재 체력·회복약·스킬 대기시간은 선택 시 바꾸지 않는다. 회복약·휴식·불사조 부활은 방벽을 충전하지 않는다. 기존 타격의 방벽 흡수·초과분 체력 피해·경직·회피/피격 무적·중복 차단·낙하 우회 규칙을 유지한다. 사망 후 충전을 거부한다.

전투 HUD에 방벽 잔량/최대치를 표시하고 원호도 현재 최대치를 기준으로 그린다. 17종 능력 도감에서 원본 효과·마력 방벽 선행·현재 등급·영구 발견을 읽는다. 발견만으로 새 도전에 능력을 지급하지 않는다.

기존 강화 등급과 barrier_health로 상태를 저장하며 새 저장 필드를 만들지 않는다. 기록 저장이 성공해야 강화와10 보충을 적용한다. 저장 검증은 선행/최대1등급, 기본 방벽20 또는 강화 방벽30의 실제 상한, 잔량 정수 타입을 확인한다. 반복 이어하기는 정확한 잔량을 복원하고 무료 보충하지 않는다. 새 도전에서 초기화하고 기존 마력 방벽 저장은20 상한을 유지한다.

`gp136_runtime_test.gd` seed/resume/finish/legacy/combat 다섯 프로세스를 전체 검사에 추가한다. 실제 적 처치·선행/강화 카드 선택·기록 실패 재시도·단일 선택·부분/가득/소진 시 보충·두 화면비 카드/도감/HUD·변조 및 중간 저장 실패·별도 프로세스 잔량/소진 복원·30 충전·기존20 저장·보스 완주를 확인한다. 실제 피격에서는 유효/무효·중복·피격/회피 무적·경직·완전/초과 흡수·파괴 배율·낙하·회복약·부활·사망 독립성을 검증한다. 이전 전체 검사를 유지한다.
