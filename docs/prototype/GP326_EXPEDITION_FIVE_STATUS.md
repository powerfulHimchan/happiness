# GP-326 · 원정 5 스테이지 특수 제약

원정 4 전체 여정 엔딩과 영구 완주 기록이 성공한 뒤 새 전체 여정에서 원정 5를 선택한다. 기본→원정1→2→3→4→5 순환과 취소를 지원한다. 다른 모드·미해금·원정6 이상은 시작하지 않는다. 원정5 완주 후 상한은5다.

## 스테이지 규칙

| 스테이지 | 두 번째 웨이브의 제약 |
| --- | --- |
| 2·6 | 회복약 사용 봉인 |
| 4·8 | 새 필살기 발동 봉인 |
| 1·3·5·7·9·10 | 제약 없음 |

전체 여정의 번호로 결정해 경로 선택·재시작·이어하기로 바뀌지 않는다. 해당 웨이브를 넘기면 즉시 해제한다. 이동·점프·회피·무기·스킬은 유지한다. 회복약은 잔량·체력·방벽을 바꾸지 않고, 필살기는 게이지를 소비하지 않는다. 게이지 획득은 유지하고 진입 전에 사용 중이던 필살기는 정상 종료까지 지속한다. 다른 체력 회복은 원정2의75%·정수 올림을 유지한다. 방벽과 부활은 기존 규칙이다.

`ExpeditionStageConstraint`가 일정·행동 차단·설명을 공유한다. 스테이지 러너의 현재 모드·난이도·번호·구간·실패/완료 여부로 활성 상태를 계산해 별도 잠금 플래그를 저장하지 않는다. 플레이어와 필살기 컨트롤러가 같은 판정 함수를 읽으므로 직접 호출과 모바일 입력에 모두 적용한다. 상세 조회 일시정지로 해제되지 않으며 실패·스테이지 재시작·모드 변경 뒤 남지 않는다.

기존 추가 정예·회복75%·일반 적 연속 공격·보스 재공격을 그대로 계승한다. 적 체력과 피해를 늘리지 않는다.

## 저장과 표시

버전1 체크포인트의 선택 필드 `stage.expedition`에0~5 정수를 허용한다. 필드 없는 저장과 원정1~4는 이전 규칙으로 복원한다. 제약은 저장한 난이도와 스테이지에서 다시 계산한다. 진행 이력·결과·최근 이력과 영구 원정 완주 기록에5를 허용한다. 엔딩과 원정 완주 기록이 모두 성공해야 완주를 확정하며 부분 실패는 별도 프로세스에서 한 번만 복구한다. 도전 기록 삭제는 영구 해금과 독립이다.

준비 화면에 번호별 봉인 규칙을 표시한다. 전투 HUD는 사전 예고→봉인→제약 해제를 표시하고 해당 행동 버튼에 봉인을 표시한다. 잔량과 게이지는 기존 표시를 유지한다. 도전 정보에는 별도 제약 카드로 일정과 보존/해제 규칙을 안내한다.
