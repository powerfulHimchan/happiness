# GP-155 · 모래시계 유물

두 번째 정예 완료 후 다섯 유물 중 하나로 모래시계를 선택한다. 획득 이후 기본 공격 적중·스킬 적중·정확한 회피·시간 수집의 처치 게이지를1.25배로 계산하고 최종 정수 반올림한다. 검과 활의 기본 적중은4→5, 스킬 적중은8→10, 정확한 회피는12→15, 시간 수집 처치는5→6을 얻는다. 시간 수집이 없으면 처치 보너스를 지급하지 않는다. 경로 보상의 게이지는 원래 수치를 유지한다.

기존100 상한과 필살기100 소비, 발동 중 충전·재사용 차단을 유지한다. 유물 선택 자체는 기존 게이지를 늘리거나 체력·회복약·성장·양 무기 대기를 변경하지 않는다. 공용/네 직업 필살기의 피해·회복·지속시간·감속과 시간의 여운은 별도로 적용한다. 모래시계는 부활하거나 소비되지 않는다.

실제 보상 확정과 체크포인트 기록에 성공한 뒤에만 효과를 적용한다. 기록 실패는 빈 유물로 롤백하고 원래 게이지 획득량과 정상 저장을 보존한 채 재선택할 수 있다. 기존 `relic`의ID와`used: false`만 저장하며 중복 배율 필드를 추가하지 않는다. 별도 프로세스 반복 이어하기에서 배율을 한 번 적용하고 기존 게이지·체력·약·대기를 복원한다. 이전 저장은 새 효과를 지급하지 않으며 새 도전에서 유물을 초기화한다.

기존 네 유물의 순서를 유지하고 다섯째 모래시계와 도형 아이콘을 추가한다. 작은 화면의 다섯 카드에 맞게 효과와 조건 설명을 간결하게 정리한다. 유물 HUD와 도감, 현재 도전의 실제 기본/스킬/회피 획득량을 연결한다. 시간 수집 HUD와 현재 도전의 처치 게이지도 실제5/6을 표시한다. 조회는 게임 상태와 파일을 변경하지 않는다.

## 검증

`seed`, `resume`, `finish`, `legacy-seed`, `legacy`, `combat` 여섯 실행을 전체 검사에 추가한다. 실제 두 정예 진행·다섯 후보 비교/취소/선택·저장 실패 재시도·변조 저장 보호·별도 프로세스 반복 복원·5단계 보스 완주·기존 저장3단계 완주·새 도전 초기화를 확인한다.

실제 검 타격과 활 투사체의 기본5/스킬10·동일 타격 중복 차단·피해/흡수/대기 독립, 실제 지상 회피 입력과 적 투사체의 정확 회피15·중복 판정 차단, 시간 수집 미획득/획득 처치와 생명 중복·반올림6, 경로20 유지·100상한·발동 중 처치6·재사용 차단을 확인한다. 네 직업 필살기의 원본 효과와 공격 필살기 처치6, 시간의 여운4초 조합, 정상 사망·저장 정리도 검사한다. 1280×720·2400×1080에서 다섯 후보와 전체 도감 설명, 현재 도전 안전 영역·조회 파일 보존을 검사한다.

기존264개와 새6개로 총270개의 runtime test 성공을 기준으로 검증한다. 실기기 플레이는 별도 확인이 필요하며 APK는 명시적 요청이 있을 때만 만든다.
