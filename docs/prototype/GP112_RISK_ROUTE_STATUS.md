# GP-112 · 태엽 폐허 위험 경로

보스를 파괴한 뒤 **일회 태엽핵 보상을 적용한 다음 도전**에서 위험 경로를 선택한다. 1스테이지의 무기 보상 이후 기존 풀숲·바람 길에 태엽 폐허 카드를 추가한다. 영구 핵의 잔향만 장착하거나 일회 보상을 건너뛰면 기존 두 경로만 제공한다. 현재 범위는 2스테이지의 한 경로이며 3스테이지에는 기존 두 경로로 복귀한다.

| 항목 | 태엽 폐허 |
|---|---|
| 전진 | 세 개의 좁은 주황색 발판, 낙하 주의 표시, 기본 점프로 횡단 |
| 첫 웨이브 | 슬라임·씨앗 포대·바람 정령 동시 배치 |
| 체력 | 해당 스테이지 일반·정예 적의 기존 체력 ×1.20 |
| 통과 보상 | 기본 최대 체력 20% 회복 외 체력 +20, 필살기 게이지 +50 |
| 상한 | 회복은 최대 체력, 게이지는 100에서 제한 |

일회 핵의 주는 피해·받는 전투 피해 +10%는 기존대로 유지한다. 위험 길 진입 시 풀숲·바람의 즉시 보상은 받지 않고, 정예 처치 후 통과 보상을 받는다. 기존 희귀·영웅 무기 보상과 성장 선택을 유지한다. 낙하 피해·마지막 안전 발판 복귀는 기존 규칙을 사용한다. 별도 함정, 새 무기 등급·지역·마을은 이번 범위에 포함하지 않는다.

## 저장과 검증

기존 완료 지점 저장에 경로 ID `clockwork`를 사용한다. 파괴 보상이 적용된 도전의 2스테이지 현재 경로·이력만 허용하며, 권한이 없거나 잘못된 단계·미등록 경로의 저장은 거부한다. 전투 도중 앱 종료는 이전 완료 지점부터 재개한다. 위험 길 완료 후 저장은 지급된 체력·게이지를 복원하고 추가 보상을 다시 지급하지 않는다. 새 도전에서는 위험 지형·적 체력 배율·이전 권한을 초기화한다. 기존 저장 형식과 두 일반 경로를 유지한다.

GP-112의 세 별도 프로세스 검사는 기본 도전·기억만 장착·보상 건너뛰기의 잠금, 실제 위험 카드 터치와 두 화면 비율 입력 영역, 좁은 발판의 물리 점프·낙하 복귀, 일반·정예 체력 및 첫 웨이브, 추가 보상·반복 통지, 저장 권한 검증, 별도 실행 이어하기, 일반 경로 복귀·보스 완주·새 도전 초기화를 확인한다. 기존 CP-206~406·GP-101~111도 회귀 검사한다.

자동 검사는 Android 실기기 플레이와 구분한다. 실기기에서는 파괴→보상 적용→위험 길 선택, 좁은 발판의 조작성, 통과 보상과 앱 재실행 이어하기를 확인해야 한다. 현재 개발 APK는 빌드마다 서명이 달라 기존 앱 삭제 후 설치가 필요할 수 있으며, 앱 삭제 시 진행·영구 해금도 삭제된다.
