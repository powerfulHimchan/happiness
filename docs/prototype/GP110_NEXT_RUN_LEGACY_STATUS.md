# GP-110 · 다음 도전의 태엽 기사 보상

웃는 태엽 기사 보스를 구출하거나 파괴한 뒤 다음 새 도전 **1회**에 보상을 적용한다. 시작 무기 화면에서 적용을 켜거나 건너뛸 수 있다. 화면 취소는 소비하지 않으며, 적용을 끄고 도전을 시작하면 이번 보상 기회를 소비한다. 이어하기는 기존 효과를 복원하고 새 보상을 소비하지 않는다. 효과·카드·장비는 다음 새 도전에 누적되지 않는다.

| 선택 | 이번 다음 도전 효과 | 제한 |
|---|---|---|
| 구출 | 기본 최대 체력 +10, 정예 등장 시 자동 지원 피해 20 | 정예 지원은 스테이지당 한 번 |
| 구출 | 전투 비치명타 뒤 체력 25% 이하에서 최대 체력 30% 회복 | 도전당 한 번, 치명타·낙하에는 발동하지 않음 |
| 파괴 | 기본 공격·스킬·필살기 피해 ×1.10 | 카드·장비 배율 이후 적용 |
| 파괴 | 받는 전투 피해 ×1.10 | 기존 중복·무적 판정 유지, 낙하 피해는 유지 |

시작·메인 화면에 효과를 설명하고 전투 HUD에 기사 회복 대기/사용 상태 또는 핵의 공격·위험을 표시한다. 추가 조작 버튼은 없다. 영구 능력 해금·장착은 [GP-111](GP111_PERMANENT_MEMORIES_STATUS.md)에서 연결한다. 무기 설계도, 새 지역, 전용 위험 경로, 여러 조력자 선택은 후속 범위다.

## 저장

`boss_legacy.jsonl`에 버전과 SHA-256을 가진 보상·소비·회복·정예 지원 이벤트를 기록하고 즉시 flush한다. 중간 저장과 테스트 기록에서 독립적이다. 같은 완주 ID는 보상을 다시 지급하지 않는다. 새 도전은 소비 저장에 성공한 뒤 시작하며 실패 시 기존 상태와 미사용 보상을 유지한다. 구조·지원은 사용 기록 저장에 성공한 뒤 적용한다. 손상된 줄·미완성 마지막 줄은 무시하며 다음 정상 이벤트를 읽을 수 있다.

중간 저장에는 효과의 원본 완주 ID, 현재 도전 ID, 회복·지원 사용 상태를 보존한다. 복원할 때 독립 사용 기록을 합쳐 이전 스테이지 백업으로 돌아가도 구조·지원 사용이 되살아나지 않는다. 보너스 체력을 성장 카드 공식과 함께 검증하고 변조된 효과/ID/중복 지원/스테이지 범위를 거부한다. 이전 GP-105~109 저장은 효과가 없는 상태로 호환한다.

보스 선택 확정 저장 직후 앱이 종료되면 이어하기 또는 새 도전 전에 해당 선택의 보상을 회수한다. 보상 저장이 실패한 확정 체크포인트는 보존하며 새 도전은 회수를 재시도한 뒤 진행한다. 소비 저장 직후 첫 스테이지 완료 전에 강제 종료하면 기존 정책대로 전투 중 상태는 이어할 수 없으며 해당 1회 기회는 이미 사용된 상태다.

## 자동 검사와 기기 확인

별도 프로세스 검사로 실제 보스 구출→보상 저장, 기록 초기화 독립성, 시작 화면 적용/취소·두 화면 비율, 1회 소비, 체력/정예 지원/구조 회복, 이전 체크포인트의 구조 사용 복원, 사망·재도전 초기화, 핵의 공격·위험 배율·장비 합성·원본 이벤트 보존, 건너뛰기, 손상 마지막 줄 복구, 소비/구조 저장 실패 후 재시도를 확인한다. 기존 CP-206~406·GP-101~109 회귀 검사도 실행한다.

실기기에서는 보스 구출 후 다음 도전의 동행·자동 회복, 파괴 후 공격과 피격 증가, 보상 적용 토글, 앱 재시작 이어하기를 확인해야 한다. 자동 검사와 실제 Android 플레이 확인 여부는 구분한다. APK는 ARM64 디버그 빌드이며 현재 빌드마다 서명이 달라 이전 APK에서 업데이트 설치하려면 기존 앱 삭제가 필요하고 저장도 삭제된다.
