# GP-135 · 샘의 이슬·세 유물 선택

두 번째 정예 완료 후 유물 선택에 샘의 이슬을 추가한다. 불사조 깃털·시계추 조각·샘의 이슬 세 후보 중 하나만 획득한다. 조회·취소는 보상을 소비하지 않으며 실제 저장이 성공해야 효과를 적용한다.

샘의 이슬은 최대 체력에 대한 회복약 회복 비율을 10%p 더한다. 기본 조제는 25→35%, 농축 조제는 40→50%다. 원래 조제와 소지 개수를 유지하고 획득 시 치료하거나 보충하지 않는다. 회복약을 사용해도 유물은 소비되지 않는다. 회복약 주머니와 조합할 수 있으며 최대 체력 상한과 정수 올림 규칙을 유지한다. 예를 들어 최대 체력101의 기본약은36, 농축약은51을 회복한다.

전투 HUD에 적용된 회복 비율과 유물 보유를 표시한다. 약방은 다음 새 도전의 조제 원본을 계속 표시한다. 휴식·회복 구슬·생명 흡수·스킬·회피·필살기에는 이슬 효과를 적용하지 않는다. 치명타에는 기존 사망 처리를 하고 깃털 부활이나 소비 저널을 실행하지 않는다.

세 후보는 원본 후보 수에서 카드 너비를 계산한다. 유물 도감도 원본 세 유물을 읽고 현재 도전 보유/미보유를 표시한다. 작은 카드의 설명은 기존 글자 축소 규칙을 사용하며 두 화면비의 안전 영역·입력 비중첩·글자 너비를 확인한다.

저장 구조는 기존 id/used 두 필드를 유지한다. 지속 유물인 시계추와 이슬은 used=true 저장을 거부한다. 반복 이어하기는 회복 비율을 다시 계산하고 실제 남은 개수를 복원한다. 같은 도전의 깃털 소비 저널이 이슬을 소비하지 않는다. 보스 완료 저장의 소진0개도 복원하고 새 도전에서는 유물을 초기화한다. 유물 없는 이전 저장을 호환한다.

`gp135_runtime_test.gd` seed/resume/finish/legacy/combat 다섯 프로세스를 전체 검사에 추가한다. 실제 정예 보상·저장 실패 재시도·중복/변조 차단·세 후보/도감·재시작·모바일 회복약 사용·소진 저장·완주·이전 저장을 검증한다. 농축 실효50%·101 체력 올림·최대 체력 상한·주머니 조합·만피/피격잠금/메인/사망 사용 차단·구슬/고정 회복/대기시간 독립성도 확인한다. 기존 전체 회귀 검사를 유지한다.
