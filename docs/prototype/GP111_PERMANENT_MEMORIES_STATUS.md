# GP-111 · 영구 기억 해금과 장착

웃는 태엽 기사의 구출·파괴 선택으로 새로운 능력을 영구 해금한다. 해금은 장착할 수 있는 선택지를 열며, 새 도전에서 **하나만** 장착한다. 추가 전투 버튼은 없다. 반복 클리어로 능력 수치는 늘어나지 않는다.

| 선택 | 영구 기억 | 이번 도전 효과 |
|---|---|---|
| 구출 | 태엽 수호 | 기본 최대 체력 +5, 시작 시 체력도 +5 |
| 파괴 | 핵의 잔향 | 검·활 스킬 피해 ×1.10, 기본 공격·필살기는 유지 |
| 선택 없음 | 기억 없음 | 보너스 없이 시작 |

시작 무기 화면에 세 기억 카드와 잠금 조건을 표시한다. 잠긴 카드는 선택할 수 없으며, 무기·기억·다음 도전 일회 보상을 함께 확정한다. 취소는 선택 저장·진행 중 도전·체크포인트를 변경하지 않는다. 마지막으로 확정한 기억을 다음 준비 화면에서 기본 선택한다. 새 도전과 스테이지 전환에서 중복 체력을 더하지 않으며, 이어하기는 해당 도전에서 장착했던 기억을 복원한다. 결과·메인·HUD에서 해금과 장착을 표시한다.

기존 GP-110 일회 보상은 별도로 적용하거나 건너뛴다. 수호와 기사 동행의 기본 체력 보너스는 합계 +15이고, 공격 기억과 일회 핵은 스킬 피해에 각각 ×1.10으로 작용한다. 카드·장비·보조 무기 효과는 기존대로 먼저 계산한다. 영구 능력치 제한을 넘겨 반복적으로 쌓을 수 없다. 이후 범위는 무기 설계도, 전용 위험 경로, 마을·추가 능력이다.

## 저장·호환

기존 `boss_legacy.jsonl`의 정상 보상 이벤트에서 두 해금을 복원한다. 이미 소비한 GP-110 구출·파괴도 영구 해금에 포함하고, 소비된 일회 보상은 다시 지급하지 않는다. 같은 완주 ID는 중복 해금·반복 수치 강화가 없다. 테스트 기록 초기화와 독립적이다.

보상이 있는 새 도전은 보상 소비와 기억 선택을 하나의 체크섬 이벤트로 기록한다. 보상이 없을 때는 달라진 기억 선택만 기록한다. 저장 실패 시 도전을 시작하거나 보상을 소비하지 않는다. 장착 시에도 해금 여부를 다시 검증하며, 손상된 기억 이벤트는 이전 정상 선호와 해금을 유지한다.

중간 저장에 `memory_id`를 추가하고, 체력은 기존 성장 카드 공식·일회 동행·영구 수호를 합쳐 검증한다. 미등록 ID, 복수 장착, 손상 타입, 중복 보너스를 거부한다. GP-105~110처럼 필드가 없으면 기억 없는 도전으로 복원한다. 당시 도전의 장착과 새 도전 선호는 독립적이다. 전투 중 주기적 상태 갱신마다 해금 저널을 다시 읽지 않고 실제 보상·지원·피격·시작·복원 시 갱신한다.

## 검증

별도 프로세스 GP-111 검사: 잠금·해금, 이미 소비한 GP-110 저널 호환, 두 화면 비율 입력 영역, 취소·백그라운드 복귀, 기억 저장 실패, 체력·카드 합산과 중복 거부, 저장·이어하기·스테이지 유지, 실제 반대 보스 선택 완주로 양쪽 해금, 보상·기억의 묶음 저장 실패 후 재시도, 스킬만 강화·장비 합성, 기억 없음과 이전 체크포인트 실제 복원, 반복 도전의 고정 수치, 기록 초기화·잘못된 이벤트의 영향 차단을 확인한다. 기존 CP-206~406·GP-101~110 회귀 검사도 실행한다.

실기기에서는 구출·파괴 후 해금 안내, 다음 도전 준비에서 잠금·장착·보상 토글, 앱 종료 후 이어하기와 고정 수치를 확인해야 한다. 자동 검사와 실제 Android 플레이 확인 여부를 구분한다. 현재 개발 APK는 빌드마다 서명이 달라 업데이트 설치에는 기존 앱 삭제가 필요하며, 앱 삭제 시 영구 해금도 함께 삭제된다. 같은 설치에서 앱 재실행·도전 실패·기록 초기화에는 유지한다.
