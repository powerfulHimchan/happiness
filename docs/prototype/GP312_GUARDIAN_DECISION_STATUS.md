# GP-312 · 성문 수호기사 구출·파괴

전체 여정9스테이지 수호기사 처치 뒤 이야기(켜짐일 때)→전용 구출/파괴 선택→기존 장비/스킬 보상→중심부로 진행한다. 카드 비교로는 런 상태나 파일을 바꾸지 않고 확정 버튼으로만 적용한다. 선택 전에는 경로 후보·보상 확정·직접 다음 구간 진입을 차단한다. 기존 마지막 태엽 기사의 선택과 영구 보상은 별개로 유지한다.

## 현재 여정 보상

| 선택 | 효과 |
|---|---|
| 구출 | 기존 구간 완료 회복에 더해 현재 최대 체력20% 올림 회복, 해금한 방벽20 보충, 필살기25 보충. 모두 현재 상한 적용 |
| 파괴 | 이후 검·활 기본 공격/스킬·공격형 필살기 피해1.10배, 받는 전투 피해1.10배. 기존 성장·장비·유물·태엽핵 보정과 곱한 뒤 최종 반올림 |

구출은 한 번만 적용하며 확인/이어하기로 다시 지급하지 않는다. 방벽 미해금이면 방벽을 새로 해금하지 않는다. 파괴의 피격 보정은 방벽보다 먼저 적용하고 원본 이벤트·무적·동일 타격 차단·낙하 환경 피해를 보존한다. 사망/완주/새 도전에서 플레이어 효과를 정리하며 선택 기록은 결과에 남긴다. 다음 도전의 태엽 기사 보상과 영구 기억·설계도를 수호기사 선택으로 지급하지 않는다. 수호기사 전용 영구 해금/다음 도전 조력자는 후속 범위다.

## 저장과 표시

체크포인트 버전1을 유지하고9완료 이후 현재 단계와9번째 이력에 동일한 `guardian_choice`를 저장한다. 타입·값·이력 일치·모드/구간·미선택 보상 완료와 미선택 중심부 저장을 검증한다. 선택 저장 실패 시 선택/이력/체력/방벽/게이지를 모두 되돌리고 정상 파일을 보존한다. 성공 후 반복 복원은 저장된 잔량과 보상 대기 상태로 돌아온다.

필드가 없는 이전 성문/중심부 완료 저장은 추가 효과 없이 이미 통과한 상태로 복원한다. 이미 지급한 장비·이야기를 다시 요구하지 않으며 다음 정상 저장부터 통과 상태를 명시한다.8완료 이전 저장에서 새로 성문을 통과하면 새 선택이 열린다.

현재 도전 정보에 성문 수호기사 선택/효과 카드를 표시하며 조회는 전투·파일을 바꾸지 않는다. 완료 결과와 광장 최근 이력에는 성문 선택과 마지막 태엽 기사 선택을 구분한다. 같은 선택 화면을 사용하되 이름·설명·효과·확정 버튼을 보스에 맞게 바꾸고 기존 마지막 보스 화면은 도전 완료로 돌아온다.

## 검증

신규42개 실행 단계: 로안/루미×검/활×구출/파괴의9완료 미선택 저장→별도 프로세스 복원/실제 선택 입력→확정 잔량 반복 복원/중심부 이동→10완료 재실행/반대 최종 선택·결과/이력/새 도전, 각 선택의 쓰기 실패/되돌림/재시도·이전 성문/중심부 저장·변조 거부·실제 검/활 충돌/공격 필살기 배율·피격/방벽/무적/중복·화면 전환/두 화면비/조회 불변을 검사한다.

기존 여정 회귀 검사는 새 성문 선택을 실제 카드/확정 입력으로 구출한 뒤 원래 보상·저장·이동 검사를 이어간다. 신규 검사는 자동 확정을 끄고 미선택부터 두 분기를 직접 검증한다. 전체829개 실행 검사와 Android 리소스 내보내기·변환된 패키지 부팅을 실행한다. 창 렌더링과 실기기 검증은 구분한다. APK는 요청 시에만 만든다.

## 후속 범위

수호기사 영구 조력자/설계도, 미소의 여왕 세라·행복의 심장·정식 엔딩은 후속 작업이다. 실기기 조작감·성능·밸런스·전체 여정 소요 시간은 별도 확인이 필요하다.
