# GP-307 · 10스테이지 전체 여정 구조

새 도전 준비에서 `전체 여정 · 10단계`를 선택한다. 기존 일반 3/5스테이지와 지역 순회 5단계를 유지한다.

| 구간 | 진행 규칙 |
| --- | --- |
| 1–2 | 시작 시 저장한 무작위 지역 우선순위의 첫 지역을 두 구간 진행 |
| 3–4 | 아직 완료하지 않은 최대 두 지역 중 선택한 지역을 두 구간 진행 |
| 5–6 | 남은 최대 두 지역 중 선택해 두 구간 진행 |
| 7–8 | 마지막 남은 지역의 두 구간 진행 |
| 9 | 행복의 나라 성문으로 고정 이동 |
| 10 | 중심부의 태엽 기사 전투 후 구출/파괴 확정 |

첫 구간부터 선택한 지역의 실제 충돌 발판·적 패턴·시간 함정을 사용한다. 홀수 구간 완료 후에는 같은 지역의 두 번째 구간만 제시하며, 두 구간을 모두 완료한 뒤 지역 완료로 표시한다. 다음 지역 선택은 기존 무작위 우선순위를 사용하므로 보상 비교·취소·이어하기에서 후보를 다시 추첨하지 않는다. 네 지역 완료 후 성문/중심부만 허용한다.

각 완료 지점에서 성장·장비·스킬·회복약·유물·주인공·이야기 확인 상태와 지역 순서를 저장한다. 보상 쓰기 실패는 선택을 되돌리며 정상 저장을 보존한다. 체크포인트 버전1을 유지하고 이전 일반/순회 저장과 호환한다. 10단계 저장에 모드/순서가 빠지거나 두 지역 구간의 연결·후보·최종 구간 순서가 잘못되면 원자적으로 거부한다. 전투 중 종료는 기존대로 마지막 완료 지점으로 복귀한다.

기존 정예 보상과 스킬 교체, 두 번째 완료 뒤 유물 선택, 지역 통과 회복과 게이지 보너스를 유지한다. 무기 등급은 영웅이 상한이며 유물을 중복 지급하지 않는다. 기사 동행의 자동 지원 기록은 10구간까지 보존한다. 마지막 태엽 기사 체력은 시제품 수치960이다.

HUD·구간 이동·현재 도전 정보·결과·광장 이력/길이별 통계에 10단계를 표시한다. 기존 이야기 모드를 켜면 각 완료 장면과 조각8종·여행 기록4종을 연결하며, 성문 완료에는 짧은 진입 장면을 제공한다.

## 검증

신규54개 실행 단계: 로안/루미×검/활의 실제 준비 입력과 시작, 완료1~9의 별도 프로세스 반복 이어하기, 같은 지역 두 구간·미방문 후보·성문/중심부 이동, 마지막 선택과 완주 기록 재실행을 검사한다. 96시드 진행 규칙, 잘못된 모드/길이/순열/이력 거부, 보상 저장 실패 재시도, 기존3단계 이어하기, 이야기 꺼짐과 후반 기사 지원/조회 정지를 검사한다. 16:9/20:9 준비·구간 선택·장면/보상 복귀를 포함한다. 기존641개와 함께 총695개 실행 단계 및 Android 리소스 내보내기·변환된 패키지 부팅을 전체 검사 스크립트에서 실행한다.

## 범위와 후속 작업

이번 작업은 10스테이지 진행 구조다. 지역 두 구간은 기존 지형/전투 자원을 재사용하며 구간 번호와 적 체력은 다르지만 전용 두 번째 맵은 후속 작업이다. 성문/중심부는 고정 경로와 다리/기존 적을 사용한 전투 시제품이다. 행복의 나라 전용 아트·주민 연출·관문 보스·세라·행복의 심장·정식 엔딩은 아직 구현하지 않았다. 30분은 열 구간의 설계 목표이며 실기기 소요 시간과 밸런스는 미확인이다. 새 첫 구간의 움직이는 발판/시간 함정 횡단도 실기기 확인이 필요하다. APK는 요청 시에만 만든다.
