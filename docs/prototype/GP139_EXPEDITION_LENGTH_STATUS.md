# GP-139 · 도전 길이·5스테이지

새 도전 준비에서 3스테이지(목표 약9분) 또는 5스테이지(목표 약15분)를 선택한다. 목표 시간은 측정 기준이며 강제 제한이 아니다. 기본 선택은3이고 현재 앱 실행 중 마지막 준비 선택을 기억한다. 선택만으로 기존 도전·저장·장비·일회 보상을 변경하지 않는다. 돌아가기는 이전 선택을 복원하며 확정할 때 새 길이를 적용한다. 검·활, 영구 기억, 조제, 조력 적용과 함께 선택한다.

5스테이지는 기존 전투 구역·경로를 재사용한다. 1–4번째에 갑옷 멧돼지 정예를 배치하고 각 완료 뒤 무기 및 스킬 교체와 경로 선택을 제공한다. 무기 등급은 영웅이 상한이다. 같은 설계·등급의 보유 무기를 선택하면 ‘유지 · 보상 확정’으로 처리하고 대기시간을 유지한다. 다른 장비의 실제 교체·저장 실패는 기존 장비로 롤백한다. 유물은 두 번째 정예에서 한 번 선택하며 이후 정예 선택 대기·이어하기에도 유지한다. 파괴 일회 보상으로 열린 위험 경로는 기존대로 두 번째 스테이지에만 선택한다.

일반 적·정예 체력은 기존 단계별25% 증가를 계속 적용한다. 긴 도전의 마지막5번째에 웃는 태엽 기사720 체력을 배치한다. 기존3스테이지 도전은 마지막3번째 보스480을 유지한다. 기존 패턴은 같으며 실제 최대 체력의50%에서2페이즈에 들어간다. 구출 조력은1–5단계의 각 정예/보스에서20 피해를 한 번만 주고 별도 사용 기록으로 이어하기의 중복 지급을 막는다.

기존 checkpoint의 stage.limit를 그대로 사용하며 새 필드는 추가하지 않는다. 길이3과5만 허용하고 단계·이력·최종 보스 선택을 해당 길이에 맞게 검증한다. 기존 보스 대기 저장을 긴 도전의 중간 상태로 바꾸는 변조, 잘못된 길이·타입·소수·범위 밖 조력을 거부한다. 이미 얻은 유물은3·4단계의 새 무기 보상 선택 전에도 저장한다. 이어하기는 준비 길이 선택을 참고하지 않고 저장된 길이·등급·스킬·대기시간·성장·유물·게이지·조력 사용을 복원한다. 완료 기록은 기존 집계의 길이별 항목으로3/5를 구분하며 새 도전은 기존대로 도전 능력·장비·유물을 초기화한다.
