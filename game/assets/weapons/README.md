# 추가 무기 계열 벡터 그래픽

기존 SVG 전투 소품과 같은 코드 기반 벡터 리소스다. 외부 원화나 폰트를 사용하지 않는다.

- `fist.svg`: 금빛 판금과 청록색 손목 띠의 권갑. 기본/타격 위치를 바꾸고 파동권도 금빛으로 표시한다.
- `staff.svg`: 보랏빛 수정과 황동 갈래 장식의 지팡이. 시전 때 기울고 수정 고리가 켜진다.
- `polearm.svg`: 녹색 금속 마개와 감은 손잡이를 가진 장봉. 대기는 대각선, 타격 때 수평/회전으로 표시한다.
- `shield.svg`: 하늘빛 보석과 금색 테두리의 방패. 방어 중 푸른 호, 응수 성공 시 금빛 호를 표시한다.

`WeaponFamilyPresentation`은 실제 타격/발사 때만 잔광을 시작한다. 로안과 루미의 보석 강조색은 각각 청록/코랄이다. 좌향 반전·비활성 무기 숨김·일시정지·사망·낙하·단계 이동의 기존 행동 수명을 따른다. 무기 그래픽과 이펙트이며 인체 공격 스프라이트를 새로 만든 것은 아니다. 캐릭터의 은발/금발과 기존 의상·이동 원화는 유지한다.

화염탄은 불꽃 꼬리, 얼음창은 마름모 창끝, 낙뢰는 꺾인 번개와 고정 범위 원을 사용한다. 새 기술의 권격·서리 파문·봉 회전·방패 원형격은 실제 타격 시점을 따라 원호를 표시한다. 그림은 피해·충돌·범위·게이지·저장 상태를 변경하지 않는다.
