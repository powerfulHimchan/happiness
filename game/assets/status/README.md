# 주인공 상태 · 전용 벡터 원화10종

기존 동화풍 SVG 원화·아이콘 체계에 맞춰 직접 제작한 자체 완결형 SVG다. 문자는 원화에 넣지 않고 실제 UI에서 표시한다. 외부 이미지·폰트·네트워크 리소스를 참조하지 않는다.

| 작업 | 파일 | 표시 위치 |
| --- | --- | --- |
| GP-821 | dawn_archive.svg | 주인공 상태 화면의 새벽 기록실 배경 |
| GP-822 | attack.svg | 공격력 문양·공격 상세 |
| GP-823 | defense.svg | 방어력 문양·방어 상세 |
| GP-824 | critical_chance.svg | 치명타 확률 문양 |
| GP-825 | critical_damage.svg | 치명타 피해 문양 |
| GP-826 | health.svg | 체력 문양 |
| GP-827 | roan_counter.svg | 로안 ‘반격의 순간’·주인공 선택·특성 상세 |
| GP-828 | lumi_starlight.svg | 루미 ‘별빛의 응답’·주인공 선택·특성 상세 |
| GP-829 | main_weapon_frame.svg | 주 무기 전용 금빛 장식 프레임 |
| GP-830 | backup_weapon_frame.svg | 보조 무기 전용 청록 장식 프레임 |

문양은128×128, 무기 프레임은384×320, 배경은1920×1080이다. 문양의 투명 여백과 종횡비를 유지해 작은 화면에서도 표현한다. 프레임은 기존 장비 영역 안에만 그려져 버튼 위치나 터치 범위를 바꾸지 않는다.

소비 코드는 `game/scripts/ui/hero_status_art.gd`이며 주인공 상태와 준비 화면에서 공유한다. 전투·성장·특성 타이머·장비 효과·저장 형식은 변경하지 않는다.
