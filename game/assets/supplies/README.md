# 여행 보급소 벡터 그래픽

GP-445–447에서 추가한 프로젝트 전용 SVG다. 외부 이미지나 폰트를 포함하지 않는다.

- `travel_stall.svg`: 1600×900 천막·등불·나무 기둥·진열대·산 능선 배경. 화면 전체에 맞춘다. 글자와 실제 버튼은 Godot에서 별도로 표시한다.
- `meal.svg`, `potion.svg`, `charge.svg`, `refresh.svg`: 회복 식사·회복약·필살기 충전·기술 정비, 각128×128 투명 아이콘.
- `sword.svg`, `bow.svg`: 상점용 검·활 아이콘. 나머지 네 계열은 기존 `assets/weapons/` SVG를 재사용한다. 전투 장비 외형은 변경하지 않는다.
- `skill.svg`: 기술 책자. 미리보기에서 해당 무기 계열 아이콘을 겹쳐 구분한다.
- `coin.svg`: 새벽 해 문양 보급전. 상점·전투 HUD·경로 선택 버튼에 표시한다.
- `restock.svg`: 순환 화살표와 별. 유료 기술 재입고 버튼에 표시한다.

`SupplyShopArt`가 비율을 유지해 아이콘을 배치한다. 선택은 금색 테두리/마름모, 품절은 옅은 아이콘/체크 도장, 구매 불가는 자물쇠와 기존 사유 문구로 표시한다. 표시 여부를 결정하는 구매 규칙과 저장 데이터는 기존 상점 모델을 그대로 사용한다.
