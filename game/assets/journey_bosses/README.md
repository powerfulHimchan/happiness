# 전체 여정 보스 원화

직접 작성한 자체 SVG. 외부 이미지·폰트·네트워크를 참조하지 않는다.

- `belo.svg`, `aurel.svg`, `ian.svg`: 가면극장 단장, 시계룡, 잊힌 시계공. 동일 이미지를 색만 바꾸지 않고 각기 다른 실루엣과 소품을 사용한다.
- `*_arena.svg`: 전용 극장·새벽 경계·공방의 배경.
- `sigil.svg`: 2·4·6스테이지에서 활성화하는 문양과 시간 구슬.
- `pocketwatch.svg`: 이안 처치로 해금되는 회중시계.

`scripts/build_journey_boss_art.py`로 생성한다. 그림과 실제 공격 경고·판정은 분리되어 있으며, 문양 수집과 보상은 저장 모델이 관리한다.
