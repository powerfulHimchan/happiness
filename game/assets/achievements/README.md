# Achievement hall vectors

Original, repository-native SVG artwork for the permanent achievement screen.
The 1600×900 hall frames the existing safe area; the nine 96×96 emblems use the
game's slate, sage and brass palette. No external fonts or images are required.

| Asset | Category |
| --- | --- |
| honors_hall.svg | Stone record hall, clock banners and laurel framing |
| exploration.svg | Exploration: folded map and compass |
| vocation.svg | Basic/advanced jobs: star shield; advanced jobs add a rim star |
| weapon.svg | Weapon research: crossed blades |
| growth.svg | Ability collection: budding seedling |
| ending.svg | Endings: open doorway and dawn light |
| expedition.svg | Expeditions: mountain route and summit flag |
| memory.svg | Memories: connected fragments |
| bond.svg | Bonds: heart and joined hands |
| secret.svg | Secrets: archive book and key |

`AchievementArt` renders state using a lock, check or crown plus the existing
status text and progress values. Text, card bounds and navigation retain the
existing input routes. Rendering does not read or write save files.
