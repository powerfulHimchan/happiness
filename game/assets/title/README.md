# 다시 피는 새벽 시작 화면

`dawn-road.png`는 사용자가 선택한 첫 번째 배경인 **새벽으로 가는 길**이다. 1672×941 원본을 그대로 사용하며 화면 비율에 맞게 가운데를 기준으로 채운다.

Codex 내장 이미지 생성 도구로 제작했다. 장면에는 글자·메뉴가 포함되지 않는다. [생성 프롬프트](prompt.json).

`lettering/`의 제목·부제·메뉴 7종은 글리프를 경로로 변환한 투명 SVG 이미지다. Godot에서 텍스처로 임포트해 그리므로 메뉴는 기본 폰트나 런타임 텍스트 렌더링에 의존하지 않는다. 꽃·덩굴·메뉴 밑줄 장식을 쓰지 않고 따뜻한 흰색/선택 금색으로 표시한다. 터치 영역은 글자 이미지의 경계에 손가락 여백을 더한다.

글자 원본: NAVER NanumMyeongjo / NanumMyeongjoBold (SIL OFL 1.1). 폰트 파일은 배포하지 않는다. 재생성은 `python3 scripts/build_title_lettering.py --font-dir <두 TTF 파일이 있는 디렉터리>`로 한다. 이미지 자체는 폰트를 이용해 만든 문서/그래픽이며 폰트 프로그램을 포함하지 않는다.

`dawn-motion.gdshader`는 기존 배경 한 장의 하늘·폭포·전경 영역에 작은 움직임을 적용하고 물안개와 새벽빛을 더한다. 건축물과 메뉴 글자는 움직이지 않는다. `StartScreenBackdrop`의 수동 시계로 120초 주기를 유지하고, 다른 화면이나 앱 비활성화 동안에는 멈춘다. 고정된 빛 입자 18개는 게임 난수를 사용하지 않는다.

`menu-shade.tres`는 왼쪽 메뉴의 가독성을 위한 반투명 가로 그라데이션이다.
