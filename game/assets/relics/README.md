# Relic illustrations

Ten original, transparent 128×128 SVG illustrations for GP-608–617. The brass,
slate, teal and sage palette follows the existing game assets. Each filename is
an existing relic ID; no gameplay or save identifiers are introduced.

| Asset | Motif |
| --- | --- |
| phoenix_feather.svg | Warm feather, luminous spine and spark |
| clock_fragment.svg | Broken pendulum clock with chain fragments |
| spring_dew.svg | Spring droplet with leaves and healing cross |
| dawn_ember.svg | Layered flame in a brass holder |
| hourglass.svg | Glass, falling sand and metal frame |
| guardian_seal.svg | Star shield and ribbon |
| wind_knot.svg | Interwoven cord, wind trails and flowing ribbons |
| vital_seed.svg | Seed shell and two living leaves |
| duelist_emblem.svg | Crossed blades on a heraldic shield |
| arcane_emblem.svg | Six-point seal and floating crystal |

`RelicArt` shares the same textures between the reward screen and the codex.
Other relics retain the existing drawing path. Owned/spent codex states add a
check or spent seal alongside the original status text.
